# Loop Note Alpha

**Cycle guard test (1 of 2).** Alpha says its parent is Beta; Beta says its parent is Alpha. That is a cycle, which a table of contents can never contain. The acyclicity guard must **reject the closing edge** — the app should keep the first relationship and refuse the one that would close the loop, without crashing or hanging.
