## What's in the latest tree (what the next session inherits)

### Permanent fixes (keep, verified working)

1. `LIBRARIES_CACHE` — in-memory cache for `load_all_libraries` (Rust side). Invalidated by `save_libraries` and `set_active_universe`. (`src-tauri/src/libraries.rs`)
2. **Paint-first architecture** — `appReady = true` happens before any IPC await. (`src/routes/+layout.svelte:initializeApp`)
3. **Zero filesystem walks on boot** — `cache_reconcile` and `enrichNodesBackground` removed from the boot path. Only triggered by watcher events or explicit "Rebuild Index".
4. **cache_boot_snapshot** + dedicated read-only SQLite connection. (`src-tauri/src/cache.rs`)
5. **mtime-first gate in `index_note`** — skip disk reads for unchanged files. (`src-tauri/src/search.rs`)
6. **`get_recent_notes` metadata-only** + per-library `std::thread` parallelism. (`src-tauri/src/libraries.rs`)
7. **Search Hub lazy-open** — `constellation_search` / `constellation_search_universal` fallback uses `ensure_search_db_ready` (cheap), not full reconcile.
8. **Empty-state gated on `$libraries` not `$libraryStats`** — Welcome screen no longer flashes while star counts are loading.
9. **`librariesLoaded` flag** — distinguishes hydration window from truly empty universe.
10. **`constellation_boot_bundle`** — single IPC returns libraries + settings + bookmarks + workspaces + property types + workspace bases + child universes + child-universe lib paths. Eliminates 9 round-trips of IPC overhead. (`src-tauri/src/boot_bundle.rs`)
