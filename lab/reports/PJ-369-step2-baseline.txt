NUMBER FORMATTING (verified 2026-08-24, tutorial-auditor round 3)
The sentence interpolates the count with plain String(count) — interpCount, in
src/lib/i18n/index.ts:162-170, does form.replace(/{count}/g, String(count)) with no
Intl.NumberFormat. So 1200 renders as "1200 entries", NOT "1,200 entries". An earlier
version of this file wrote it with a comma; corrected, because a tutorial that quotes a
thousands separator the app never prints teaches the Boss to report a non-bug.

FEDERATION — checked, because a partial federation makes the classifier REFUSE (count 0)

ClassifierCtx::build refuses to classify ANY row when a universe declares child universes and
none of them resolve (the Attack-1 guard). A refusal and a genuinely-clean universe look
IDENTICAL to the user (no sentence), so the two must not be conflated in the record.

Read from each universe's .constellation/universe.json:

  Eisa Universe            declares 2 children, BOTH resolve  -> no refusal; the 603 stands.
                           Its children are:
                              E:\Constellation Universes\كون عيسى
                              E:\Constellation Universes\Eisa Cognitive Knowledge   <-- his DAILY
                           So inside Eisa Universe, his daily universe is federated in as a
                           Linked Universe, and its notes are Keep-linked, never phantoms.
                           (The Step-1 Rust audit's "Keep-linked 9" is exactly this.)

  كون عيسى                 declares 1 child that DOES NOT EXIST
                              E:\Constellation Universes\Two universe UNIVERSE\Two Universe UNIVERSE
                           -> declared_children = 1, linked_roots empty -> REFUSAL FIRES.
                           Its zero is "the app refuses to guess", NOT "this universe is clean".

  All others               declare 0 children -> no refusal.

Why the refusal fires rather than silently passing: for a genuinely-missing child
(ErrorKind::NotFound) `resolve_child_universe_roots_strict` KEEPS the declared path in its
output (universe.rs:750) rather than dropping it, so declared_children stays 1 while
foreign_library_roots resolves nothing. Had it dropped the missing child, declared_children
would have been 0 and the Attack-1 guard would never have fired. Verified by reading both
functions, not assumed.

CONSEQUENCE WORTH KEEPING: the partial-federation refusal is LIVE and reachable on the Boss's
own machine. That is the fail-closed path I declined to test by asking him to eject a drive.
It is not directly observable to him (silence looks the same either way), so it is recorded as
verified-by-inspection rather than dressed up as a user-visible test.
