- **The real root cause is an altitude error, not timing:** `validate_path_in_any_library` (libraries.rs:230) authorized a write against ONLY the **active** universe's libraries. That coupling is what fails every deferred-write-during-switch (this, and any future variant).

A path outside EVERY registered/federated universe is still rejected (the real security bound intact). New helpers `own_libraries_for_root` + `registered_universe_roots` in universe.rs; Rust test `own_libraries_for_root_reads_non_recursive`. Full lib suite **1048 passed**.
