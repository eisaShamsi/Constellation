## 4. Method that earned its keep, and the traps it caught
- **A check that cannot disagree is worthless** — demonstrated five times today: a computed-style
  harness with no Svelte scope class measured nothing and "confirmed" my hypothesis; a font stack
  whose quotes terminated the HTML attribute made before and after identical; a registry search using
  the wrong key shape (ids are stored WITHOUT the `--` prefix) produced a false CONFIRM; and **a
  stylesheet filename proves nothing** because CSS comments are stripped, so a comment-only edit
  yields the same content hash — verify the chunk carrying the actual change.
- **Bundle verification has THREE emit locations**: `build/_app/immutable/assets/*.css`,
  `build/_app/immutable/chunks/*.js`, and `build/assets/screen-*`. `LESSONS-LEARNED` §611's documented
  command scans only the first and would have verified **38 of 78** occurrences here. Anchor the
  patterns — four retired names are substrings of their replacements.
- **The wrap panel caught four things three inspector rounds missed**, all the same shape: a verified
  string inside a false instruction. A label-matcher cannot see that a screen is never mounted.
- **Prove the binary embeds the build** by finding this build's chunk/stylesheet filename inside the
  exe, never by mtime alone. A cargo step was killed mid-run once today and the stale binary would
  have cost a sitting.
