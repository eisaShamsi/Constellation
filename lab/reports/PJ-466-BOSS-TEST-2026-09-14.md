## What this screen is, and what was wrong with it

Some of your template files — the empty molds you make new notes from — ended up wrongly carrying a
**birth date**, the way a real note does. A template should not have one; only the note you create
*from* it should. Constellation has a review screen that finds these files, shows you exactly what it
will change, and changes them only after you click Fix. Nothing else in the file is touched.

**PJ-466 rebuilt the report you see *after* clicking Fix**, because it said things that were not true.
You saw this yourself in the rehearsal on 13 September:

- It said **"Templates fixed"** over a run that fixed **zero** files.
- A file Constellation genuinely failed to write was called **"skipped"** — the same word it used for
  a file that needed nothing at all.
- It said **"a backup of every file was saved first"** when a whole second batch was never attempted.
- Nothing told you which files were never reached.

It also fixes a real behavioural bug, not just words. Files with an unusual shape are repaired first,
on their own, so a systematic problem cannot reach the rest. But if one of those files turned out to
need **nothing**, the old code counted that as a **failure** and **stopped the whole run** before
touching any ordinary file. Stage 1 proves that is gone.
