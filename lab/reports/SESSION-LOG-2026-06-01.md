## MIG-067 §H.3 — Typed-Link pill redesigned from scratch as one self-contained source (`83485b91`)
§H.2 **FAILED the Boss re-test**: the Backlinks vs Outgoing pills STILL looked different even though both already used the shared `<LinkTypePill>`. The build was verified to contain the component (the new class is in the bundle), confirming the cause was CONTEXT bleed — the pill INHERITED font / text-direction / flex-alignment from each host row. Boss directive: "start from scratch designing the Typed-Link pills. One source serves all." An Explore agent inventoried every pill site: the complete Svelte set is **Backlinks, Outgoing, KnowledgeHealthDashboard** (the last drew a hardcoded `typeColors` map that had drifted — `supports` green there vs registry blue); `LinkDashboard`/`PropertyEditor` set `--pill-*` only for confidence/tier chips (NOT type pills); the editor label (livePreview.ts CM6) already uses registry colour + note-language. Rebuilt `LinkTypePill` to be IMMUNE to its host — it sets its own font (`--font-interface-theme`), `dir="auto"`, size/shape (from `appSettings` directly, not host vars), colour (§G registry, the one source), and centring (`align-self`/`justify-content`/`vertical-align`, fixed line-height). Rolled out: KHD insight badge → `<LinkTypePill>`, KHD bars → `linkTypeColor()`, hardcoded map deleted; Backlinks/Outgoing API-compatible (no change). No new svelte-check errors. Rebuilt for the Boss re-test. **Open observation (separate from the pill):** Backlinks inherits the UI text-direction while Outgoing uses `dir="auto"` (content direction) — so for an English note under an Arabic UI the two panels' ROWS align to opposite sides. The pill now renders identically regardless; making the row alignment consistent is a distinct panel change, pending Boss's call.

**§H.3 Boss-VALIDATED** (`33ac6c4c`): "It is clear that they all come from a single source." The self-contained pill renders identically across Backlinks, Outgoing, and the Knowledge-Health dashboard (badges + distribution bars). One polish requested + applied: the glyphs sat ~1px low (optical effect of a tight line-height — most fonts render a hair below true centre), fixed by wrapping the label and `translateY(-1px)` (a visual transform that leaves the flex centring + row layout untouched). One source → the nudge lands on every pill everywhere from a single line. Rebuilt for the final confirm. **Lesson:** a *shared* Svelte component can STILL render differently per host when it INHERITS font / text-direction / flex-alignment — for anything that must look identical everywhere, make it fully self-contained (own font, dir, size, centring), not merely shared.
