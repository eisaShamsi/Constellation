## RESUME HERE — §D (read swap + Mode-2 staleness + harness + Boss test)
Per `MIG-083-Plan.md` §D. All gated on `crate::review::is_stamped(conn)`; the read keeps the legacy `scan_due_recursive` fallback when unstamped. **This is the Boss-test phase — run an adversarial review before the Boss test (the §D/§E pattern).** Build it in landable pieces:
1. **`content_changed_at`** (the Mode-2 content signal, deferred here from §B): add an `INTEGER` column to `note_meta` (idempotent ensure, MIG-002 pattern); in `index_note` (gated), compute a **stable FNV-1a hash** of `plain_body`, compare to a stored `content_hash` column (also new), and bump `content_changed_at = modified` ONLY when the hash differs (so autosave/sync/cid_cn touches don't false-fire). **No separate back-fill needed** — the staleness JOIN uses `COALESCE(dep.content_changed_at, dep.modified)` so un-initialized notes fall back to `modified`.
2. **`get_due_notes` swap** (gated): when stamped → the **union of two lenses**: (a) Mode 1/3 from the table — `SELECT … FROM review_schedule WHERE due_days <= today AND reason != 'dismissed'`; (b) **Mode-2 staleness JOIN** — `review_schedule rs` ⋈ `note_links jl` (`jl.source_path = rs.path` AND `jl.link_type IN ('supports','contradicts','derives-from','part-of','supersedes')` — reuse `crate::review::STALENESS_TRIGGER_TYPES`) ⋈ `note_meta dep ON dep.path = <resolve jl.target_name → path>` WHERE `COALESCE(dep.content_changed_at, dep.modified) > <rs.last_reviewed as days/secs>`. Each stale `DueNote` carries `reason="stale"` + the triggering neighbour + link type + date. Else (unstamped) → legacy `scan_due_recursive`. **NOTE:** `note_links` keys targets by `target_name` (name, not path) — resolve via `note_meta.name`/aliases (see the stratum SQL's alias join for the pattern). Order: stratum DESC, days_overdue DESC.
3. **`get_note_review_status(notePath)`** — new IPC, a PK lookup on `review_schedule` (for the §F note-context Review tab).
4. **`rehearse_against_live_copy`** — a dev/test harness: on a COPY of `E:/Cognitive Knowledge`'s DB (7,611 notes), assert the indexed read == the corrected reference computation; measure `get_due_notes` <100 ms with zero `.md` syscalls. **If the Mode-2 JOIN is slow, escalate to a trigger-maintained `neighbourhood_max_changed` column** (Architect's reserve).
5. **Boss test** (per the Testing Instructions Rule).
Then §E (remove `scan_due_recursive`, `/simplify`, 3-agent audit, orientation v-bump, help/manual) → **MIG-080 §F** (note-context Review tab + the two-lens full-page reviewer) → §G.
