## §4 — §H.1 Hotfix landed in this audit cycle

Two findings warranted inline fix before §I (so the Boss-test gate doesn't hit cold):

### §H.1.A — `invalidate_search_state` in universe switch

**Files:**
- `src-tauri/src/search.rs` — new `pub fn invalidate_search_state(app)` that resets `SearchState.db` to `None`.
- `src-tauri/src/universe.rs::set_active_universe` — new call to `crate::search::invalidate_search_state(&app)` alongside the existing `invalidate_libraries_cache` call.

**Why:** Pre-existing latent bug; MIG-055 first feature to expose. Closing it also fixes stale-data reads on the search/FTS path across universe switches.

### §H.1.B — open-note listener prefers `libraryName`

**Files:**
- `src/routes/+layout.svelte:2196-2215` — listener now reads `detail.libraryName` first, falls back to path-prefix matching for legacy dispatchers (UniversalEmbedWidget).

**Why:** Federated cUniverse rows whose path prefix coincidentally matches a different library's path would silently mis-route. LensBlock already dispatched `libraryName` in the payload (the listener just wasn't reading it).

- `cargo test --lib lens::` — 84/84 still pass.
- `npx svelte-check --threshold error` — 0 new errors (3 pre-existing baseline unchanged).
