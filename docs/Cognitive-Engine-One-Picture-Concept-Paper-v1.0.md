## 0. Why this paper exists

The Cognitive Engine measures many things about a note — **stratum, maturity, stage, provenance, confidence, source, content-type, network position**. Listed flat, this is overwhelming. A user cannot hold ten dimensions in mind, and *"so complex for users to understand"* is a real failure, not a knowledge gap.

This paper adds nothing. It **reveals the structure already there** — the one picture that makes every cognitive element cohere, so the complexity collapses into understanding. It is the simple lens through which every downstream decision (the Base columns, the rank-sorts, where a new measurement or a legacy value goes) is read.

It is the founding principle — *"Strong yet Simple, by default"* — applied to the Cognitive Engine itself.

## 1. The picture: one process, four questions, one destination

```
                          ┌─────────────────────────────────────────┐
   WHAT YOU DO  ─────────►│  THE FIVE ACTS  (the only verb)         │
                          │  Observe → Connect → Tension →          │
                          │  Synthesize → Conviction                │
                          └─────────────────────────────────────────┘
                                          │ produces
                                          ▼
   WHAT THE SYSTEM     ┌───────────────────────────────────────────────┐
   MIRRORS BACK ──────►│  FOUR QUESTIONS about each note (the mirror)  │
   (for every note)    │  1. Development — how grown?                  │
                       │  2. Altitude    — how high?                  │
                       │  3. Origin      — where from / how known?    │
                       │  4. Connection  — how related?               │
                       └───────────────────────────────────────────────┘
                                          │ all move toward
                                          ▼
   WHERE IT LEADS ────► CONVICTION — understanding that survives contradiction
```

The whole system is three things, not ten:

1. **One process** — what the user actually *does*: the **Five Acts** (Observe → Connect → notice Tension → Synthesize → reach Conviction). This is the only verb. The user writes and links; that *is* walking the Acts.
2. **Four questions** — what the system *reflects back* about every note. The user never sets these; they are a **mirror**.
3. **One destination** — **Conviction**: knowledge that survives contradiction. Everything moves toward it.

The user has to learn **one verb, not ten nouns.** Everything else is feedback.

## 2. The four questions

Each is a question a person *already* asks about any idea — no taxonomy required. For each: what it asks, which cognitive elements answer it, the failure it prevents, and how the user *feels* it (without studying anything).

### Q1 — Development — *"How grown is this — a raw spark, or settled understanding?"*
- **Answered by**: `stage` (spark → birth → growth → maturity → dormancy → archival) · `maturity` (seed → sapling → evergreen → canonical; *wilting* = the condition of any level left untouched 90+ days).
- **Prevents**: ideas dying as orphan captures. It tells you **what each note needs next** — a seed needs links; an evergreen needs review.
- **Felt as**: the file-tree border deepening green from seed to evergreen; the wilting fade; the stage breadcrumb.

### Q2 — Altitude — *"How high does it reach — a stray fact, or a worldview?"*
- **Answered by**: `stratum` (Datum → Information → Proposition → Concept → Principle → Theory → Paradigm → Worldview, 1→8).
- **Prevents**: 7,000 facts masquerading as understanding. It asks *"are you rising, or just accumulating?"*
- **Felt as**: node size in Sky View; the 360.3D vertical position.

### Q3 — Origin — *"Where did this come from — mine, or borrowed, and how do I know it?"*
- **Answered by**: `provenance` (Received / Discovered / Mixed + trust-depth) · `source` (the 11 means of knowing: perception, inference, testimony, mass-transmission, comparison, postulation, non-apprehension, memory, innate-disposition, inspiration, revelation) · `content-type` (what *kind* of knowledge).
- **Prevents**: a universe of borrowed thoughts. It asks the question almost no tool asks — *"is this understanding YOURS?"* This is the **isnad**: knowledge you can trace and trust.
- **Felt as**: the provenance glow; the Cataloger's Source × Content-type classification.

### Q4 — Connection — *"How does it relate — what does it support, contradict, depend on?"*
- **Answered by**: the **8 typed links** (supports, contradicts, causes, exemplifies, generalizes, derives-from, part-of, supersedes; + `associative` default) · CNS network measures (community, centrality, **bridges**, **blind-spots**, load-bearing).
- **Prevents**: isolated thinking. It finds where your thinking is **alive** (tension = a `contradicts` link = real thinking) and where it is **missing** (a blind spot = the next idea you haven't had).
- **Felt as**: the typed-link colors; the CNS wiring view; the tension count.

## 3. The destination — Conviction — and why certainty is not a fifth question

The Five Acts **end in Conviction**: *"evidence accumulates, confidence upgrades, the idea becomes bedrock."*

Certainty — `confidence` (hypothesis → evidence → established → contested), and the epistemic-states scale (ignorance → doubt → opinion → belief → knowledge → certainty) — is **not a fifth coordinate of position.** It is the **destination** the four questions move toward, and confidence is its progress-meter.

**Why four, not five (the ruling):**
- The four questions describe a note's **observable standing** — structural, auto-measured, a snapshot of *where it is*.
- Certainty is **earned** through the whole process — it is the explicit *endpoint*, a different kind of thing.
- The two are **orthogonal**: a note can be highly *developed* (evergreen, high stratum) yet *contested*. Certainty is independent of position **because it is the goal, not a location.** Making it the fifth coordinate would flatten the destination into the map.

So: **four coordinates locate the note; Conviction is the North Star; confidence is the distance-to-go.**

## 4. Why this is the whole of it (the grounding)

The four questions are not arbitrary — they are the **classical anatomy of a knowledge claim**:

| Question | Classical name | Tradition it sharpens |
|---|---|---|
| **Altitude** | the claim's **content / level** | DIKW (Data → … → Wisdom), sharpened to Datum → Worldview |
| **Origin** | its **justification / source** | the *isnad* (chain of narration); the *pramāṇa* valid means of knowing |
| **Connection** | its **coherence / relations** | the typed link as the unit of cognition |
| **Development** | its **life over time** | the note as a living thing that grows (and wilts) |

A belief has content, a justification, relations to other beliefs, and it develops over time. **Constellation measures what epistemology has always named.** Nothing in the Cognitive Engine falls outside the four — §6 proves it.

## 5. The simple essence (for the user)

> **You never set any of this. You write, and you link. Constellation reflects back where each idea stands — and quietly tells you what it needs next to become understanding.**

One action (write + link). One mirror (the four questions). One destination (Conviction). The dimensions are *"a mirror, not a judgment."* The user **lives** the Five Acts; the four questions are **felt, not studied.**

## 6. Where every element fits (the complete mapping — and the decision rule)

Every cognitive element answers exactly one of the four questions (or measures the destination). This table IS the decision rule: **when a new measurement or a legacy value appears, ask which of the four questions it answers — that is where it lives.**

| Cognitive element | Question it answers |
|---|---|
| `stratum` (Datum → Worldview) | **Altitude** |
| `maturity` (seed → … → canonical; *wilting* = condition) | **Development** |
| `stage` (spark → … → archival) | **Development** |
| `provenance` (Received / Discovered / Mixed), trust-depth | **Origin** |
| `source` (11 means of knowing) | **Origin** |
| `content-type` (5 branches) | **Origin** (what *kind* of knowledge) |
| typed links (the 8) | **Connection** |
| CNS: community / bridges / blind-spots / load-bearing | **Connection** |
| `confidence` (hypothesis → … → contested) | *the destination* (Conviction's progress-meter) |

**Legacy / edge values resolve themselves under this rule:**
- `literature` → **Origin** (it means "from a source" = Received). It is *not* a Development stage — so on the `stage` column it sorts off-spine; its true home is the provenance facet.
- `fleeting` → **Development** (a transient capture ≈ stage `spark` + maturity `seed`).
- `synthesis` → **Altitude** (it organizes other notes ≈ stratum Concept/Theory) + Five-Acts Act IV.
- `spark-idea` → **Development** (it *is* `spark`, personally labelled — ranks with spark).

The legacy Zettelkasten note-types were a **low-dimensional shadow** of what this model measures in full: one label trying to say "Origin" or "Altitude" before there was an axis for it. Constellation does not need the conflated labels because it measures each question natively — *that is the strength.*

## 7. How this makes the product Simple (Strong yet Simple)

- **Surface the four questions, not the ten dimensions.** A user should feel *"this note is still raw and a bit one-sided,"* not read a four-axis numeric readout.
- **Depth is opt-in.** The four questions are the surface; the precise stratum number, the exact source-leaf, is one click deeper for whoever wants it. (The Base's add-column picker is the canonical expression: familiar fields first, cognitive depth below the fold.)
- **Felt, not studied.** The green border, the node size, the wilting fade — absorbed the way you read a room, without a glossary.
- Every cognitive surface (the Base columns, 360.3D, the Cataloger, Sky View) organizes around the **same four questions**, so learning one teaches all.

## 8. What this lens decides (downstream consequences)

- **The Base's cognitive columns** (MIG-066/067/068) group under the four questions — Development, Altitude, Origin, Connection — not as a flat list of dimensions.
- **Rank-aware sorting** applies to each question's ranked axes: Development sorts by the `stage` spine (spark → … → archival) and the `maturity` spine (seed → … → canonical); Altitude by `stratum` (Datum → … → Worldview). *Wilting is a condition over Development, never a rank.* (See memory `project_ranked_dimensions_sort_by_rank`.)
- **`literature` and friends** are placed by §6's rule, not guessed.
- **Conviction is the telos** every surface should make visible — how close is this note (this universe) to understanding that survives contradiction?
