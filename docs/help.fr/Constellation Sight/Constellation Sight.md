# Constellation Sight

## Qu'est-ce que c'est ?

**Constellation Sight** est l'**instrument diagnostique** de votre univers de connaissances. Un **dôme d'ancrage** central montre chaque note positionnée par **strate** (profondeur de la pensée) et **temps** (quand écrite), avec quatre **mini-dômes** à côté qui ré-encodent le même univers à travers différents canaux : **Confiance**, **Stade**, **Actes**, **Provenance**.

Il répond à une question avec cinq lentilles complémentaires : **« Comment mon Contenu Épistémique est-il façonné et organisé ? »**

Survolez n'importe quelle étoile dans n'importe quel dôme et la même note s'allume dans les cinq surfaces — anneau doré sur l'étoile, teinte dorée sur les puces correspondantes de la barre latérale. Cliquez sur une puce de la barre latérale et les cinq vues se réduisent. Shift+cliquez sur une étoile dans le mini Stade et l'univers filtre instantanément à ce stade du cycle de vie. Cliquez sur l'espace vide dans n'importe quel mini-dôme et il « promeut » à l'emplacement principal en taille réelle, tandis que le précédent principal descend dans l'emplacement mini vacant.

## Pourquoi est-ce important ?

La plupart des applications de prise de notes vous montrent ce que vous avez écrit. Constellation Sight vous montre la **forme** de ce que vous savez.

- Où votre pensée est-elle **concentrée** ? (le gradient de densité dans l'ancrage)
- Qu'est-ce qui est encore **en début de stade** vs **fondation stable** ? (le gradient de couleur du mini Stade)
- Quelles notes sont **porteuses** vs **isolées** ? (l'encodage de taille du mini Actes)
- D'où vient chaque idée — votre propre pensée, lecture, écoute, tradition ? (la disposition en secteurs du mini Provenance)
- Quelle est votre **confiance** dans vos conclusions ? (le gradient d'opacité du mini Confiance)

Une note au centre de l'ancrage (haute connectivité → porteuse) mais en cyan dans le mini Stade (`spark` — à peine commencée) vous dit quelque chose de diagnostique : une idée porteuse pas encore mûrie.

## Comment l'ouvrir

1. Cliquez sur l'**icône œil** dans le dock à gauche de Constellation.
2. Le dôme d'ancrage s'affiche en 2–5 secondes pour la plupart des univers.
3. Pour fermer : cliquez sur **(×)** en haut à droite, ou appuyez sur **Esc**.

## Ce que vous voyez

### La Bande d'En-tête

Haut de la vue Sight, de gauche à droite :
- **« Constellation Sight »** — le titre.
- **« v6.1 — Coordinated Views (Phase 2) »** — sous-titre de version.
- **Badge « X / Y notes »** doré — visible uniquement quand un filtre est actif.
- **Badge « EXTENDED »** en petites majuscules dorées — visible uniquement quand la vue Étendue est activée.
- **Bouton « Reset View »** — visible uniquement quand la disposition a été modifiée.
- **(×)** bouton de fermeture — toujours présent.

### Le Dôme d'Ancrage (Emplacement Principal)

Grand dôme crème-sur-sombre au centre :
- **Anneaux de strate** — 5 cercles concentriques. Le plus intérieur = vos notes les plus fondamentales ; le bord extérieur = vos étincelles les plus récentes.
- **Bordure du calendrier** — 12 étiquettes de mois autour de l'extérieur.
- **Étiquettes de strate** — texte italique en haut, nommant chaque bande.
- **Étoiles** — chaque note dessinée comme petit point crème, positionnée par strate × temps.
- **Lignes de connexion** — arêtes de liens typés entre notes, opacité faible sous les étoiles.
- **Anneau de survol** — cercle doré autour de l'étoile survolée.

### Les Quatre Mini-Dômes

Côté droit, grille 2×2. Cachés par défaut ; révélés par **Ctrl+D** (session) ou **Ctrl+Shift+D** (persistant — voir vue Étendue).

Chaque mini rend le même univers via un encodage :

1. **CONFIDENCE — opacité.** Notes plus confiantes plus brillantes ; tentatives s'estompent.
2. **STAGE — teinte (disque plein).** Couleur catégorielle par stade du cycle de vie :
   - **Cyan** = `spark` (idée venant d'être étincelée)
   - **Orange** = `birth` (prenant forme)
   - **Violet** = `growth` (en mouvement actif)
   - **Vert** = `maturity` (entièrement formée)
   - **Jaune** = `renewal` (récemment revisitée)
   - **Gris** = `dormancy` / `archival` (inactive / fermée)
3. **ACTS — taille (décile supérieur).** Top 10% par nombre de liens = points plus grands ; le reste reste petit.
4. **PROVENANCE — 5 secteurs.** Étoiles repositionnées en 5 secteurs angulaires : **Self / Read / Heard / Reasoned / Tradition**.

### L'Ancrage Rétrogradé (Quand un Mini est Promu)

Si vous promouvez un mini à l'emplacement principal, l'ancrage descend dans l'emplacement mini vacant. Il s'affiche alors comme **points crème neutres** avec le titre **« UNIVERSE — primary view »**.

### La Barre Latérale de Facettes (Bord Gauche)

Panneau pliable avec **6 groupes de filtre de facettes**, chacun affichant des catégories avec comptages en direct :

- **Folder** — hiérarchie de dossiers
- **Library** — noms de bibliothèques
- **Stratum** — Foundation / Roots / Trunk / Branches / Twigs / Edge of Knowing
- **Confidence** — Hypothesis / Evidence / Established / Contested
- **Stage** — Spark / Birth / Growth / Maturity / Dormancy / Renewal / Archival
- **Provenance** — Self / Read / Heard / Reasoned / Tradition

Cliquez sur l'onglet **▶** au bord pour développer. Cliquez sur n'importe quelle puce pour activer ou désactiver le filtre.

## Interaction

| Geste | Effet |
|---|---|
| **Survoler une étoile** | Anneau doré sur la même étoile dans les 5 surfaces + puces correspondantes en doré. |
| **Clic simple sur étoile** | Ouvre la note dans l'éditeur. Bouton **« Return to Sight »** apparaît. |
| **Shift+clic sur étoile** dans mini Stage / Confidence / Provenance | Bascule un filtre sur la catégorie de cette étoile. |
| **Shift+clic sur étoile** dans Acts ou ancrage | Aucun effet. |
| **Clic sur zone vide d'un mini** | Ce mini promeut à l'emplacement principal. |
| **Molette de zoom (principal)** | Zoom vers le curseur. Plage : 0,5× à 24×. |
| **Clic+glisser zone vide** | Pan de la vue. |
| **Ctrl+0 / Cmd+0** | Réinitialise zoom + pan. |
| **Ctrl+D / Cmd+D** | Bascule visibilité des mini-dômes — **session uniquement**. |
| **Ctrl+Shift+D / Cmd+Shift+D** | Bascule la **vue Étendue** — persistant. |
| **Clic sur puce de barre latérale** | Bascule la catégorie de facette dans l'ensemble du filtre. |
| **Bouton Reset View** | Retourne à l'ancrage principal au zoom 1.0. |
| **Esc** | Ferme Sight. |

## Mode Fantôme — Sélection Multiple Depuis le Dôme

Quand un filtre est actif, les étoiles non-correspondantes restent visibles mais à **opacité faible (15%)** au lieu de disparaître. Cela signifie :

- Vous voyez toujours OÙ sont les étoiles non-correspondantes.
- Vous pouvez les survoler (anneau doré apparaît).
- Vous pouvez **Shift+cliquer pour AJOUTER leur catégorie au filtre**.

## Mode Densité

Quand le nombre d'étoiles visibles (correspondantes) dépasse le seuil de densité (par défaut **5 000**), les mini-dômes passent à un **rendu de densité perceptuel**.

## Vue Étendue

Appuyer sur **Ctrl+Shift+D** (ou **Cmd+Shift+D** sur Mac) bascule la « vue Étendue » — lorsqu'activée, les mini-dômes sont visibles par défaut à chaque ouverture de Sight. L'état persiste à travers les fermetures de Sight, redémarrages d'app et reboots.

## Quand Sight Est le Plus Utile

- **Auditer la forme de votre savoir** — ouvrir Sight après une session d'écriture.
- **Trouver les angles morts** — secteurs du dôme avec peu de notes peuvent être des domaines à explorer.
- **Repérer la faiblesse porteuse** — note positionnée centralement en couleur de stade précoce vous dit que vous dépendez de quelque chose pas encore mûri.
- **Filtrer et inspecter** — Shift+clic réduit l'univers ; promouvoir un mini pour étudier un canal en taille réelle.
- **Suivre la provenance épistémique** — promouvoir Provenance pour voir comment votre savoir provient de Self / Read / Heard / Reasoned / Tradition.

## Surfaces Associées

- **Constellation Nervous System (CNS)** — visualisation complémentaire (icône neurone à côté de l'œil Sight).
- **Constellation Map** — visualisation en rayons solaires.
- **Sky View** — visualisation de liens basée sur graphe.
- **Panneau Index** — navigateur de termes.
