# מדריך למשתמש Constellation

**גרסה 0.3.4 | מרץ 2026**

Constellation הוא יישום שולחני לניהול ידע אישי (PKM) לניהול ספריות הערות ב-Markdown. הוא בנוי באמצעות Tauri v2, SvelteKit ו-Rust, ופועל באופן מקומי על Windows, macOS ו-Linux עם תמיכה מלאה בעברית, ערבית ושפות RTL.

## 1. תחילת עבודה

### התקנה

הורידו את תוכנית ההתקנה העדכנית מ[עמוד ההפצות של Constellation](https://github.com/eisaShamsi/Constellation/releases):

- **Windows**: קובץ `.exe` (NSIS) או מתקין `.msi`
- **macOS**: קובץ `.dmg`
- **Linux**: קובץ `.AppImage` או חבילת `.deb`

### הפעלה ראשונה

בפתיחה הראשונה של Constellation, **אשף הגדרת היקום** ידריך אתכם דרך:

1. **בחרו שפה** — תמיכה ב-15 שפות
2. **צרו או ייבאו ספרייה** — הפנו לתיקייה קיימת של קובצי Markdown, או התחילו מאפס
3. **תנו שם ליקום שלכם** — היקום הוא המכולה לכל הספריות שלכם

### סקירת הממשק

| רכיב | תיאור |
|-------|--------|
| **סרגל צד (Ribbon)** | כפתורי ניווט: עץ קבצים, חיפוש, תצוגת כוכבים, יומן, תבניות, הגדרות |
| **עץ קבצים** | עיון בהערות ובתיקיות בתוך הספריות |
| **עורך** | קריאה ועריכה של הערות Markdown |
| **שורת לשוניות** | פתיחת מספר הערות בלשוניות |
| **שורת מצב** | ספירת מילים, ספירת תווים, זמן קריאה משוער |

## 2. יקום וספריות

### מהו יקום?

**יקום** הוא המכולה העליונה שמחזיקה את כל הספריות שלכם. חשבו עליו כסביבת העבודה שלכם או כאוסף הספריות.

### מהי ספרייה?

**ספרייה** היא תיקייה במחשב שלכם המכילה קובצי Markdown (`.md`). ניתן להחזיק מספר ספריות ביקום אחד — למשל, אחת להערות עבודה ואחת להערות אישיות.

### ניהול ספריות

- **הוספת ספרייה**: הגדרות > ספריות > הוסף ספרייה, או גררו תיקייה אל היישום
- **הסרת ספרייה**: הגדרות > ספריות > לחצו על כפתור ההסרה ליד שם הספרייה
- **הגדרות ספרייה**: לכל ספרייה יכולות להיות הגדרות מראה משלה (גופנים, צבעים)

### יקומים מקוננים

ניתן לקנן יקומים בתוך יקומים. **יקום מקונן** הוא תיקיית יקום נוספת שהיקום ההורה מפנה אליה. הערות מיקומים מקוננים מופיעות בתצוגת הכוכבים לצד ההערות שלכם, כאשר קישורים בין ספריות מוצגים כקווים מקווקווים.

### פתיחה מחדש אוטומטית

Constellation זוכר את היקום הפעיל האחרון ופותח אותו מחדש אוטומטית בעת ההפעלה. אם היקום הועבר או שהנתיב שלו השתנה, Constellation מזהה זאת ומתקן את הנתיב אוטומטית.

### יקומים ניידים

יקומי Constellation ניידים לחלוטין. ניתן להעביר את תיקיית היקום לכל מיקום — כונן אחר, מפתח USB, או מחשב אחר — ו-Constellation יזהה ויתקן אוטומטית את כל הנתיבים הפנימיים בעת פתיחה מחדש.

להעברת יקום:
1. סגרו את Constellation
2. העבירו או העתיקו את תיקיית היקום למיקום החדש
3. פתחו את Constellation → מסך הפתיחה מופיע (הנתיב הישן כבר לא תקף)
4. בחרו **פתח יקום קיים** והפנו למיקום החדש
5. כל ההערות והספריות מופיעות מיידית — הנתיבים מתוקנים אוטומטית

מבנה תיקיית היקום עוקב אחר מודל Obsidian: הערות נמצאות ישירות בתיקיית השורש, ההגדרות נמצאות ב-`.constellation/`.

## 3. יצירה ועריכה של הערות

### יצירת הערה

| שיטה | פעולה |
|-------|--------|
| **מקלדת** | `Ctrl+N` |
| **עץ קבצים** | לחיצה ימנית על תיקייה > הערה חדשה |
| **מרכז הפיקוד** | `Ctrl+P` > "הערה חדשה" |

### מצבי עורך

Constellation מציע שני מצבי עריכה, הניתנים לבחירה ב**הגדרות > עורך > סוג עורך**:

#### עורך Markdown (CodeMirror)

העורך המוגדר כברירת מחדל למשתמשים מתקדמים. כתבו Markdown ישירות עם:

- **תצוגה מקדימה חיה** — מעבד עיצוב תוך כדי כתיבה
- **מצב מקור** — מציג תחביר Markdown גולמי
- **סרגל עיצוב** — מופיע בעת בחירת טקסט
- **פקודות מהירות** — הקלידו `/` להוספות מהירות
- **השלמה אוטומטית של Wikilink** — הקלידו `[[` לקישור הערות
- **סמנים מרובים** — `Alt+Click` או `Ctrl+D`

#### עורך מסמכים (TipTap)

חוויית עיבוד תמלילים ויזואלית עם סרגל כלים:

- מודגש, נטוי, קו תחתון, קו חוצה, הדגשה
- כותרות (H1–H3), יישור טקסט
- רשימות תבליטים, רשימות ממוספרות, רשימות משימות
- ציטוטים, בלוקי קוד, קווים אופקיים
- טבלאות (הוספה, הוספה/הסרה של שורות ועמודות)
- קישורים ותמונות

שני העורכים שומרים כקובצי Markdown סטנדרטיים. ניתן לעבור ביניהם בכל עת ללא אובדן נתונים.

### תיבות הדגשה (Callouts)

צרו בלוקים מעוצבים להערות, אזהרות, טיפים והנחיות נוספות:

```markdown
> [!note] מידע חשוב
> תוכן תיבת ההדגשה נכתב כאן.

> [!warning] היזהרו
> לא ניתן לבטל פעולה זו.

> [!tip]- לחצו להרחבה
> תוכן תיבה מתקפלת.
```

סוגים נתמכים: `note`, `tip`, `warning`, `danger`, `success`, `question`, `failure`, `bug`, `example`, `quote`, `abstract`. לכל סוג צבע וסמל ייחודיים. הוסיפו `-` אחרי הסוג כדי להפוך אותו למתקפל (מתחיל מקופל), או `+` (מתחיל מורחב).

### תחביר הדגשה (Highlight)

עטפו טקסט בסימני שוויון כפולים כדי להדגיש אותו:

```markdown
זהו ==טקסט מודגש== בהערה שלכם.
```

בתצוגה מקדימה חיה, סימני `==` מוסתרים והטקסט מופיע עם רקע צהוב.

### בלוקי קוד

בלוקי קוד מגודרים מוצגים עם צבע רקע ותווית שפה:

````markdown
```javascript
const greeting = "Hello, world!";
```
````

שם השפה מופיע כתג מעל בלוק הקוד.

### הטמעת תמונות

הטמיעו תמונות ישירות בהערות שלכם:

```markdown
![טקסט חלופי](https://example.com/image.png)   — כתובת URL חיצונית
![[photo.jpg]]                                    — קובץ מקומי מהספרייה
```

בתצוגה מקדימה חיה, תמונות מוצגות בשורה. תמונות מקומיות חייבות להיות בתיקיית הספרייה שלכם. תמונות חיצוניות דורשות חיבור לאינטרנט.

### סרגל כלים לטבלאות

כאשר הסמן נמצא בתוך טבלת markdown, מופיע סרגל כלים צף עם:

- **+ שורה / + עמודה** — הוספת שורות או עמודות
- **- שורה / - עמודה** — הסרת שורות או עמודות
- **יישור** — יישור שמאל, מרכז או ימין לכל עמודה
- **מיון** — מיון שורות בסדר עולה או יורד לפי העמודה הנוכחית
- **Tab / Shift+Tab** — ניווט בין תאי הטבלה

### קיצורי עיצוב טקסט

| קיצור | פעולה |
|--------|--------|
| `Ctrl+B` | מודגש |
| `Ctrl+I` | נטוי |
| `Ctrl+Shift+S` | קו חוצה |
| `Ctrl+Shift+H` | הדגשה |
| `Ctrl+K` | הוספת Wikilink |
| `Ctrl+Z` | ביטול |
| `Ctrl+Shift+Z` | ביצוע מחדש |

### קישור הערות

הקלידו `[[` כדי לפתוח השלמה אוטומטית של הערות. התחילו להקליד שם הערה ובחרו מההצעות. קישורים מופיעים כ-Wikilinks לחיצים: `[[שם ההערה]]`.

ניתן גם לקשר לכותרות ספציפיות: `[[שם ההערה#כותרת]]`.

## 4. חיפוש

Constellation כולל מנוע חיפוש היברידי רב-לשוני המבוסס על SQLite FTS5 עם דירוג BM25, מסנני שאילתות מובנים ונרמול מותאם לערבית. החיפוש נגיש מסרגל הכלים בסרגל הצד.

### כיצד לחפש

לחצו על סמל החיפוש בסרגל הצד או השתמשו ב-`Ctrl+Shift+F` כדי להפעיל מצב חיפוש. הקלידו את השאילתה והתוצאות יופיעו לאחר עיכוב קצר (300 מ"ש). לחצו `Escape` או לחצו על כפתור `×` כדי לנקות את החיפוש ולחזור לעץ הקבצים.

### תחביר חיפוש

| תחביר | דוגמה | מה נמצא |
|-------|-------|---------|
| טקסט חופשי | `ניהול פרויקטים` | הערות המכילות מילים אלו בכותרת או בגוף |
| סינון תגית | `#מחקר` | הערות המתויגות ב-`#מחקר` |
| סינון מאפיין | `status=active` | הערות עם מאפיין frontmatter `status` השווה ל-`active` |
| סינון ויקיקישור | `links to [[אקלים]]` | הערות המקשרות ל-`[[אקלים]]` |
| טווח ספרייה | `in:הספרייה-שלי` | מגביל תוצאות לספרייה מסוימת |
| משולב | `#מחקר status=active כלכלה` | כל המסננים מופעלים יחד |

### תגי סוג התאמה

כל תוצאת חיפוש מציגה תג צבעוני המציין כיצד נמצאה ההתאמה. התג מציג אות מתורגמת בשפתכם לנגישות (בטוח לעיוורי צבעים):

| תג | צבע | משמעות |
|----|------|--------|
| **כ** | כחול | התאמת כותרת — מונח החיפוש מופיע בשם ההערה |
| **ת** | ירוק | התאמת תוכן — מונח החיפוש מופיע בגוף ההערה |
| **ס** | סגול | התאמה סמנטית — קשור מושגית (דורש מודל embedding) |
| **מ** | ענבר | התאמת מאפיין — נמצא דרך מסנן מאפיין frontmatter |
| **#** | ורוד | התאמת תגית — נמצא דרך מסנן תגית |
| **ק** | כחול בהיר | התאמת ויקיקישור — נמצא דרך מסנן ויקיקישור |

אותיות התגים מתורגמות ל-15 השפות הנתמכות.

### תוצאות מוצמדות (ניווט בין תוצאות)

תוצאות החיפוש נשארות גלויות לאחר לחיצה על אחת מהן. ההערה הפתוחה מודגשת ברשימת התוצאות כדי שתדעו איזו תוצאה אתם צופים בה. לחצו על תוצאה אחרת כדי לנווט אליה ללא חיפוש מחדש.

כדי לנקות את החיפוש, לחצו `Escape` או לחצו על כפתור `×`.

### ניווט במקלדת

| מקש | פעולה |
|-----|-------|
| `חץ למטה` | בחירת התוצאה הבאה |
| `חץ למעלה` | בחירת התוצאה הקודמת |
| `Enter` | פתיחת התוצאה שנבחרה |
| `Escape` | ניקוי החיפוש וחזרה לעץ הקבצים |

### הדגשת מונח החיפוש

כאשר פותחים הערה מתוצאות החיפוש, כל המופעים של מונח החיפוש מודגשים בעורך. תכונה זו עובדת עם זיהוי ניקוד ערבי — חיפוש "ادارة" ידגיש "إدارة" ואת כל הווריאציות הדיאקריטיות.

### היסטוריית חיפוש

לחצו על שדה החיפוש כשהוא ריק כדי לראות את החיפושים האחרונים (20 שאילתות אחרונות). כל רשומה מציגה את טקסט השאילתה ומתי בוצעה. לחצו על רשומה כלשהי כדי להריץ מחדש את החיפוש מיידית. השתמשו בקישור "נקה היסטוריה" בתחתית כדי למחוק את כל ההיסטוריה.

היסטוריית החיפוש נשמרת מקומית במכשירכם ונשמרת בין הפעלות מחדש.

### Search Hub

ה-Search Hub הוא חוויית חיפוש במסך מלא. לחצו על סמל הזכוכית המגדלת בסרגל העגינה כדי לפתוח אותו. שני סרגלי הצד מתקפלים כדי לתת מרחב מרבי. הקלידו כל מונח ו-Constellation מחפש בכל מקום בו-זמנית, ומקבץ תוצאות ל-5 קטגוריות: כותרות, תכנים, תגיות, מאפיינים וויקילינקים. לכל קטגוריה יש מקטע מתקפל עם תג ספירה. לחצו על כל תוצאה כדי לפתוח אותה בעורך עם כל המופעים מודגשים. כפתור "חזרה ל-Search Hub" מופיע כדי שתוכלו לחזור מבלי לחפש מחדש.

### אופרטורי קישורים

Constellation תומך ב-6 אופרטורי חיפוש טופולוגיית קישורים:

| תחביר | מה הוא מוצא |
|--------|-------------|
| `links to [[X]]` | הערות שמקשרות ל-X (קישורים נכנסים) |
| `links from [[X]]` | הערות ש-X מקשר אליהן (קישורים יוצאים) |
| `mutual [[X]]` | הערות מקושרות ל-X ו-X מקשר בחזרה (דו-כיווני) |
| `mentions [[X]]` | הערות המכילות את שם X ללא [[ויקילינק]] |
| `orphans` | הערות ללא קישורים נכנסים או יוצאים |
| `links between [[X]] and [[Y]]` | הערות שמקשרות גם ל-X וגם ל-Y |

בעת הקלדת כל אופרטור קישור, ההשלמה האוטומטית `[[` מציגה את כל ההערות ביקום. לאחר בחירת הערה, הקלידו `#` להשלמת כותרות או `|type:` להשלמת סוג קישור.

## 5. תצוגת כוכבים (GraphMind)

תצוגת הכוכבים מציגה את ההערות שלכם כגרף תלת-ממדי אינטראקטיבי המופעל על ידי מנוע **GraphMind** (Pixi.js WebGL).

### פתיחת תצוגת הכוכבים

- לחצו על סמל הגרף בסרגל הצד
- הקישו `Ctrl+G`
- מרכז הפיקוד (`Ctrl+P`) > "תצוגת כוכבים"

### ניווט

| קלט | פעולה |
|------|--------|
| **לחיצה + גרירה** | הזזת הגרף |
| **גלגלת** | זום פנימה/החוצה |
| **לחיצה על צומת** | פתיחת ההערה |
| **לחיצה ימנית על צומת** | תפריט הקשר (פתיחה, מיקוד, נעיצה, הסתרה) |
| **גרירה עם לחצן אמצעי** | סיבוב בתלת-ממד |
| **W/A/S/D** | טיסה במרחב התלת-ממדי |
| **0** | איפוס סיבוב לדו-ממד |
| **Ctrl+F** | חיפוש והדגשה |
| **Space** | מצב מיקוד |

### מצבי פריסה

הקישו `Ctrl+L` כדי לעבור בין:

- **אורגני** — פריסה מבוססת כוחות שבה אשכולות מתגבשים באופן טבעי
- **היררכי** — פריסת עץ מלמעלה למטה
- **זמני** — הערות מסודרות לפי תאריך יצירה על ציר זמן

### מצב מיקוד

לחיצה ימנית על צומת > **מיקוד** כדי לראות רק את השכנות שלו. ניתן להתאים:

- **עומק** (1–5 דילוגים) — כמה רמות של חיבורים להציג
- **כיוון** (↔/←/→) — כל הקישורים, נכנסים בלבד, או יוצאים בלבד

### ניווט תלת-ממדי

לחצו על הלחצן האמצעי וגררו כדי לסובב. השתמשו ב-W/A/S/D/Q/E כדי לטוס דרך שדה הכוכבים. מצביע צירים XYZ בפינה מציג את הכיוון שלכם. הקישו `0` לאיפוס.

### הגדרות

לחצו על סמל גלגל השיניים עבור:

- **מראה**: גודל צומת, נראות תוויות, גודל גופן, עובי קישורים, הצגת הערות יתומות
- **פיזיקה**: כוח דחייה, כוח קישור, מרחק קישור
- **AI**: סף קישור סמנטי (שלב 2)

### מקרא

מקרא בפינה הימנית התחתונה מציג צבעי ספריות/תיקיות עם תיבות סימון להחלפת נראות.

### שכבות ידע

תצוגת הכוכבים מסווגת אוטומטית את ההערות שלכם לשמונה שכבות ידע לפי רמת ההפשטה:

| שכבה | תיאור |
|-------|--------|
| **תמונת מצב** | הערות מהירות וחולפות |
| **יומן** | אירועים מתוארכים ורשומות יומן |
| **נושא** | מושגים אטומיים סביב רעיון יחיד |
| **מפה** | הערות מארגנות המחברות נושאים אחרים |
| **מסגרת** | מודלים ומסגרות חשיבה |
| **עיקרון** | כללים ואקסיומות מאומתים |
| **אמונה** | ערכים ואמונות יסודיות |
| **יצירה** | עבודות מוגמרות וסופיות |

השכבה נקבעת אוטומטית מה-frontmatter, המבנה והקישורים של ההערה. ניתן לעקוף את הסיווג ידנית על ידי הוספת מאפיין `stratum` ב-frontmatter.

### מחזור חיי בשלות

כל הערה עוברת מחזור חיי בשלות המשקף את מידת ההתפתחות שלה:

- **זרע** — רעיון ראשוני או טיוטה גולמית
- **שתיל** — ההערה מתחילה לקבל צורה ויש לה כמה קישורים
- **ירוק-עד** — הערה בשלה, מבוקרת ומקושרת היטב
- **קנונית** — מקור סמכותי וסופי בתחומו

רמת הבשלות מתעדכנת אוטומטית בהתבסס על מספר הקישורים, תאריך הסקירה ותדירות העריכה. ניתן גם להגדיר אותה ידנית באמצעות מאפיין `maturity` ב-frontmatter.

## 6. תצוגה מפוצלת

תצוגה מפוצלת מאפשרת לכם לערוך מספר הערות זו לצד זו בחלון הראשי.

### פתיחת תצוגה מפוצלת

- **לוח הפקודות**: `Ctrl+P` ואז הקלידו "Split View"
- **קיצור מקלדת**: השתמשו בקיצור המוקצה כדי לעבור בין מצבים
- **מחזור**: כבוי ← אנכי (זה לצד זה) ← אופקי (למעלה ולמטה) ← כבוי

### עריכה בתצוגה מפוצלת

כל חלונית היא עורך עצמאי לחלוטין עם:
- סרגל כלים מלא (מודגש, נטוי, כותרות, יישור וכו')
- ניווט נתיב (ספרייה / שם ההערה)
- לוח מאפיינים ותפריט שלב נפתח
- תמיכה בשמירה (`Ctrl+S` שומר את החלונית הפעילה)
- עריכת כותרת ושינוי שם קובץ

### שינוי גודל חלוניות

גררו את המפריד בין חלוניות כדי לשנות את גודלן. כל מפריד הוא עצמאי — עם 3 הערות פתוחות או יותר, תוכלו לשנות גודל של כל זוג סמוך מבלי להשפיע על האחרים. עובד במצב אנכי ואופקי כאחד.

### מיקוד

לחצו על חלונית כלשהי כדי למקד אותה. החלונית הממוקדת מקבלת קיצורי מקלדת ומעוקבת על ידי לוחות סרגל הצד הימני (מאפיינים, קישורים חוזרים וכו').

## 7. אינדקס

האינדקס הוא מילון מונחים מקיף בכל הספריות שלכם — כל מילה משמעותית, ממוינת לפי סדר אלפביתי עם מספרי הופעות.

### פתיחת האינדקס

- **כפתור הדוק**: לחצו על סמל האינדקס (ספר) בדוק השמאלי
- **לוח הפקודות**: `Ctrl+P` ואז הקלידו "Index"

### צינור NLP רב-לשוני

האינדקס מעבד טקסט דרך צינור מודע-שפה לפני האינדוקס:

- **ערבית**: אלגוריתם Lucene Light10 — מסיר תשכיל, מאחד המזה, מסיר תחילית יידוע (الـ), מסיר סיומות דקדוקיות
- **עברית**: הסרת קידומות (ב/ל/מ/ה/ו/כ/ש)
- **אנגלית**: גזירה דמוית Porter (רבים, צורות פועל, סיומות)
- **צרפתית/ספרדית/פורטוגזית/גרמנית**: הסרת סיומות ספציפיות לשפה
- **רוסית/טורקית/הינדי/פרסית**: הסרת סיומות מורפולוגיות
- **כל 15 השפות**: סינון מילות עצירה (תחיליות יידוע, מילות יחס, מילות חיבור)

### עיון

- **לשוניות שפה**: עברו בין הכל, ערבית, עברית, אנגלית או # (תווים מיוחדים)
- **סרגל אלפבית**: לחצו על אות כדי לסנן מונחים שמתחילים באותה אות — מונה המונחים מתעדכן להציג כמה מונחים תואמים
- **לחצו שוב על אותה אות** כדי לנקות את הסינון ולהציג את כל המונחים
- **מצבי מיון**: אלפביתי (ברירת מחדל) או לפי תדירות (הנפוצים ביותר קודם)

### עריכה מהאינדקס

לחצו על הערה כלשהי בהפניות של מונח כדי לפתוח אותה בחלונית תצוגה מקדימה מפוצלת לצד האינדקס. חלונית התצוגה המקדימה היא עורך מלא — תוכלו לערוך, לשמור, לשנות מאפיינים ולקדם שלב. מונח החיפוש מסומן בהערה והגלילה אליו אוטומטית.

לחצו `Ctrl+Click` כדי לפתוח את ההערה כלשונית רגילה. כפתור "חזרה לאינדקס" מופיע בסרגל הלשוניות — לחצו עליו כדי לחזור בדיוק למקום שבו הפסקתם באינדקס.

### שילוב עם המסך השני

כאשר המסך השני פתוח:
- **לחצו על מונח** → המסך השני מציג את כל ההערות שמכילות את המונח בתצוגה מפוצלת (רשימת הערות + עורך)
- **Ctrl+Click על מספר מונחים** → המסך השני מציג מצב השוואה עם כל מונח בעמודה משלו

## 8. Constellation Sight

Constellation Sight מציג את מערכת הידע שלך כולה כגרף בור כבידה. הוא עונה על השאלה: **"איך נראה הידע שלי, ומה מצב בריאותו?"**

### פתיחת Sight

לחץ על **כפתור Sight** (סמל עין) ברצועה השמאלית. גרף בור הכבידה מופיע. לחץ על x לסגירה.

### גרף בור הכבידה

הערות מסודרות בטבעות קונצנטריות לפי חשיבות (מרכזיות). ההערות המחוברות ביותר יושבות במרכז; הערות היקפיות בשוליים. בתוך כל טבעת, ההערות מקובצות לפי ספרייה (הארגון שלך). צבע הצומת = ספרייה.

| אלמנט | משמעות |
|--------|--------|
| **צומת גדול** | מרכזיות גבוהה — מגשר בין תחומי ידע שונים |
| **צומת קטן** | היקפי — בתוך תחום אחד |
| **צבע הצומת** | שיוך לספרייה |
| **קו רציף** | קישור בין שתי הערות |
| **חיצי כיוון** | חיצים קטנים המראים את כיוון הקישור |
| **עובי הקו** | רמת ביטחון (עבה = מבוסס, דק = השערה) |

### אינטראקציה

- **לחיצה בודדת** על צומת: מדגישה את השכנות שלו (כל ההערות המחוברות). כל השאר מעומעם.
- **לחיצה כפולה**: פותחת את ההערה בעורך.
- **לחיצה על שטח ריק**: מנקה את ההדגשה.
- **גלילה**: זום. **גרירה**: הזזה. **התאמה למסך**: כפתור בסרגל הכלים.

### חיפוש ב-Sight

לחץ על זכוכית המגדלת. תומך בכל האופרטורים: `links to [[X]]`, `links from [[X]]`, `mutual [[X]]`, `orphans`, `supports [[X]]`, `contradicts [[X]]`, `#tag`, טקסט חופשי וחיפוש סמנטי. התוצאות מציגות צבעי כיוון: ירוק (נכנס), אדום (יוצא).

### פאנל ניתוח (SightPanel)

לחץ על סמל הרשת כדי לפתוח את סרגל הצד. מציג: ציון בריאות היקום (0-100), מוני הערות/קישורים/יתומים, סרגלי סוג קישור וביטחון, 10 הגשרים המובילים ותובנות ידע (עדות חזקה ביותר, יסודות חלשים, מתחים, קיפאון, המחוברים ביותר, פערי ידע).

### הגדרות

סמל גלגל שיניים: התאם עובי קו קישור, שקיפות וגודל חץ. ההגדרות נשמרות בין הפעלות.

## 9. מסך שני

המסך השני הוא חלון מלווה מבוסס מצבים שמתאים את עצמו למצב סרגל הצד הנוכחי.

- **פתיחה**: לחצו על סמל המסך השני בסרגל הצד, או `Ctrl+Shift+2`
- **סגירה אוטומטית**: כשאתם סוגרים את החלון הראשי, המסך השני נסגר אוטומטית

### מלווה מבוסס מצבים

המסך השני משנה את תוכנו בהתאם למצב סרגל הצד הפעיל בחלון הראשי:

| מצב סרגל צד ראשי | המסך השני מציג |
|---|---|
| **סייר קבצים** | לוח מחוונים של היקום — סטטיסטיקות, פירוט ספריות, יקומי בת, תגיות, הערות שנערכו/נפתחו לאחרונה |
| **נווט** | תצוגת נווט מלאה לעיון בהערות |
| **תצוגת שמים** | עץ תצוגת שמים עם מבנה תיקיות |
| **תצוגת כוכבים** | מלווה תצוגת כוכבים עם קישורים חוזרים, קישורים קדימה, תגיות וגרף מקומי |

### לוח מחוונים של היקום (מצב סייר קבצים)

כשהחלון הראשי במצב סייר קבצים, המסך השני מציג לוח מחוונים עם:

- **כרטיסי סטטיסטיקה** — שם היקום, מספר יקומי בת, סך כל הספריות, התיקיות וההערות
- **יקומי בת** — כל יקום בת עם הספריות המקושרות שלו ומספרי תיקיות/הערות
- **ספריות** — כל ספרייה עם מספרי תיקיות/הערות בתיבות סטטיסטיקה צבעוניות
- **נערכו לאחרונה** — הערות ששיניתם בהפעלה הנוכחית (מעוקבות בעת שמירה)
- **נפתחו לאחרונה** — הערות שפתחתם אך לא עריכתם בהפעלה הנוכחית
- **תגיות** — כל התגיות בכל הספריות ממוינות לפי מספר; לחצו על תגית כדי לראות את כל ההערות שמשתמשות בה

### אינטראקציה עם לוח הבקרה

כאשר לוח הבקרה פעיל בחלון הראשי, לחיצה על פריטים שולחת אותם למסך השני:

- **נערכו/נפתחו לאחרונה**: לחצו על הערה כדי לפתוח אותה כעורך מלא במסך השני
- **תגיות**: לחצו על תגית כדי להציג את כל ההערות המשתמשות בה בתצוגה מפוצלת — רשימת הערות בצד שמאל, עורך מלא בצד ימין

כל העריכות במסך השני מסתנכרנות אוטומטית עם החלון הראשי.

### עריכת הערות במסך השני

המסך השני תומך בעריכת הערות מלאה — הקלידו, שמרו, שנו שם ושנו מאפיינים בדיוק כמו בחלון הראשי. שינויים מסתנכרנים אוטומטית עם החלון הראשי.

### סנכרון הגדרות

כל ההגדרות החזותיות מתפשטות מיד למסך השני — אין צורך בהפעלה מחדש:

- **שפה**: שינויי שפת הממשק חלים מיד
- **ערכת נושא**: מצב בהיר/כהה/מערכת עובר מיד
- **גופנים**: גופן ממשק, גופן טקסט, גופן מונו וגופנים ייעודיים לכתב
- **גודל גופן**: גודלי גופן ממשק ועורך
- **עורך**: רוחב שורה קריא, מספרי שורות, סרגל כלים צף
- **צבע הדגשה**: שינויי צבע הדגשת ערכת הנושא

## 10. מאפיינים ו-Frontmatter

להערות יכול להיות Frontmatter בפורמט YAML בראש הקובץ:

```yaml
---
tags: [project, active]
date: 2026-03-19
status: in-progress
---
```

Constellation מזהה סוגי מאפיינים באופן אוטומטי:

| סוג | דוגמה |
|------|--------|
| **טקסט** | `author: John` |
| **מספר** | `priority: 5` |
| **תאריך** | `date: 2026-03-19` |
| **רשימה** | `tags: [a, b, c]` |
| **תיבת סימון** | `done: true` |
| **קישור** | `related: [[הערה אחרת]]` |

ניתן להחליף את תצוגת המאפיינים ב**הגדרות > עורך > מאפיינים במסמך** (גלוי / מוסתר / מקור).

## 12. טבלאות

### טבלאות Markdown

הקלידו טבלת Markdown ידנית או השתמשו בפקודה המהירה `/table`:

```markdown
| כותרת 1 | כותרת 2 |
|----------|----------|
| תא 1    | תא 2    |
```

### סרגל כלים לטבלאות

כאשר הסמן נמצא בתוך טבלה, מופיע סרגל כלים צף עם:

- הוספה/הסרה של שורות ועמודות
- יישור עמודות (שמאל, מרכז, ימין)
- ניווט בין תאים עם `Tab` / `Shift+Tab`

### טבלאות בעורך המסמכים

## 17. הגדרות

גשו להגדרות מסמל גלגל השיניים בסרגל הצד או באמצעות `Ctrl+,`.

### כללי

- שפה (15 שפות)
- ערכת נושא (בהיר / כהה)
- גופן ממשק, גופן טקסט, גופן קוד, גודל גופן
- ערכת גופנים — שילובי גופנים מוכנים מראש (מכונת כתיבה, קלאסי, מודרני ועוד) להחלפה מהירה
- **ערכות נושא** — בחרו משש ערכות מובנות, צרו ערכות מותאמות (עורך חמישה צבעים), ייבאו ערכות ממאגר הקהילה של Obsidian (200+ ערכות), או ייבאו קובץ ערכה `.json`. מחקו כל ערכה מותאמת עם כפתור ✕ בריחוף.

### Style Settings

לשונית ייעודית להתאמה אישית עדינה של כל אלמנט גלוי בממשק, מוחלת בזמן אמת על הערכה הפעילה.

- **צבעים** — רקע, משטחים, טקסט (רגיל/מעומעם/חלש), הטיה, גבולות, צבעי מצב
- **טיפוגרפיה** — גדלי גופן ממשק/פתק/קוד, גדלי H1–H6, משקל כותרות, גובה שורות, רווח פסקאות
- **פריסה וצורה** — רדיוסי פינה קטן/בינוני/גדול, רוחבי גבולות, צללים, אורך שורה קריא בעורך, שולי צד
- **רכיבים** — עגינת סרט, סרגל פעולות צדדי, סרגל פריסה (מתגי לוחיות), סרגל עליון/רצועת לשוניות, סרגל מצב, סרגל צד ימני (בוחן), סייר קבצים (פתקי היקום, יקום-בן, ספריות, תיקיות, פתקים), כפתורים, תגיות, callouts — כל אחד עם גודל, רדיוס, צבע עצמאיים, וסגנון מצב פעיל כאשר רלוונטי
- **עורך** — צבע/ריחוף/קישוט קישור, צבע/רקע/רדיוס קוד מוטבע, רוחב/צבע פס ציטוט, צבע סמן, רקע בחירה

**ייבוא/ייצוא** — סרגל כלים בראש הלשונית:
- הדבקה מהלוח (לחיצה אחת)
- ייבוא/הדבקה (תיבת טקסט עם מיזוג או החלפה)
- מקובץ (.json)
- העתקה (ערכים נוכחיים ללוח)
- ייצוא (.json)

הפורמט תואם בדיוק לתוסף Style Settings של Obsidian, כך שאפשר לשתף הגדרות בין Obsidian ל-Constellation.

השינויים נשמרים אוטומטית בערכה הפעילה; אם עורכים ערכה מובנית, היא משוכפלת אוטומטית לערכות המותאמות שלכם כדי שהשינויים ישמרו בלי לשנות את המקור.

### עורך

- סוג עורך (Markdown / מסמך)
- תצוגת ברירת מחדל (קריאה / עריכה)
- מצב תצוגה מקדימה חיה
- מספרי שורות, מדריכי הזחה, בדיקת איות
- סגירה אוטומטית של סוגריים, רשימות חכמות

### ספריות

- הוספה/הסרה של ספריות
- הגדרות מראה לכל ספרייה
- מיקום תיקיית קבצים מצורפים

### עדכונים

- בדיקת עדכונים
- טוקן GitHub לעדכונים ממאגר פרטי

## 19. תמיכה ב-RTL ובעברית

Constellation מספק תמיכה מלאה בעברית, ערבית, פרסית, אורדו ושפות RTL נוספות:

- **זיהוי אוטומטי**: כיוון ההערה מזוהה אוטומטית מהתוכן
- **ממשק**: ממשק RTL מלא כאשר נבחרת שפת עברית/ערבית
- **עורך**: עריכת טקסט RTL עם תנועת סמן ובחירה נכונות

- **מקרא**: פריטים מתהפכים בסדר נקודה/טקסט בהתאם לשפת התוכן
- **גופני כתב**: הגדרת גופנים לעברית, ערבית ו-CJK בנפרד בהגדרות

### הגדרה לעברית

1. עברו אל **הגדרות > כללי > שפה** ובחרו עברית
2. ניתן להגדיר גופן עברית ייעודי ב**הגדרות > כללי > גופני כתב**
3. הערות עם תוכן בעברית יוצגו אוטומטית ב-RTL

## 21. מפת ידע

מפת הידע היא תצוגה רדיאלית (Sunburst) שמציגה את המבנה, הצפיפות והבשלות של יקום הידע שלך כולו.

### פתיחת המפה

- **כפתור הדוק**: לחצו על סמל מפת הידע בסרגל הצדדי השמאלי
- **פלטת פקודות**: `Ctrl+P` ואז הקלידו "Constellation Map"

### מה שאתם רואים

- **מרכז**: שם היקום שלכם עם סך הערות ומילים
- **טבעת ראשונה**: ספריות (כל אחת בצבע שלה). אם ליקום שלכם יש יקומי ילד, הם מופיעים כאן גם.
- **טבעות עמוקות**: תיקיות ותת-תיקיות בתוך כל ספרייה
- **קטעים חיצוניים**: הערות בודדות

### מצבי צבע

עברו בין שלושה מצבים דרך התפריט:
- **בשלות**: זרע (אפור) ← שתיל (ירוק בהיר) ← ירוק-עד (ירוק) ← קנוני (זהב) ← נובל
- **שכבה**: L1 (כחול) ← L8 (אדום) — מציג מורכבות ידע
- **ספרייה**: כל הקטעים יורשים את צבע הספרייה

### ניווט בהתעמקות

לחצו על קטע תיקייה כדי להתקרב. שביל ניווט מראה את המסלול שלכם. לחצו על פריט בשביל כדי לחזור, או הקישו Escape. לחצו על קטע הערה כדי לפתוח אותה בעורך.

### חזרה למפה

לאחר פתיחת הערה מהמפה, כפתור "חזרה למפה" מופיע בסרגל הלשוניות. לחצו עליו כדי לחזור בדיוק למקום שהייתם — אותה רמת התעמקות נשמרת.

## 22. המנוע הקוגניטיבי

המנוע הקוגניטיבי הוא מערכת האינטליגנציה המובנית של Constellation, המנתחת את ההערות שלכם וחושפת דפוסים נסתרים וקשרים בין הרעיונות שלכם. הפילוסופיה המרכזית:

> "כמות הנתונים שלכם לא משנה. לא מדובר בכמה מקורות אתם שומרים, אלא באיך אתם מעצבים את הידע שלכם מהם ומקשרים אותו למודעות אחת בעלת משמעות."

המנוע הקוגניטיבי מורכב מתשעה כלים משולבים: קישורים מסווגים, שכבות ידע, מחזור בשלות, גלאי מתחים, שרשרת מקור, מנוע החצנה, פולס סקירה, שבילים ותצוגות רב-עדשתיות.

---

### 17.1 קישורים מסווגים

#### מה זה?

קישורים מסווגים הם קישורי ויקי הנושאים סוג יחס המתאר את טיבו של הקשר בין שתי הערות. במקום לכתוב סתם `[[הערה]]`, כותבים `[[הערה|סוג-יחס]]` כדי לבטא את מהות החיבור — האם היא נגזרת ממנה? סותרת אותה? מרחיבה אותה?

#### למה זה חשוב?

קישור רגיל אומר "יש כאן חיבור" אבל לא אומר איזה. קישורים מסווגים הופכים את רשת ההערות שלכם מערימת הפניות למפת ידע אמיתית שמציגה מבני חשיבה, תלויות והסקות בין רעיונות.

#### איך להשתמש

1. פתחו הערה בעורך
2. כתבו קישור ויקי עם סוג יחס: `[[הערת יעד|derives-from]]`
3. סוגים נתמכים: `derives-from` (נגזר מ-), `supports` (תומך ב-), `contradicts` (סותר), `extends` (מרחיב), `exemplifies` (ממחיש), `questions` (מעלה שאלה)
4. ניתן גם להוסיף סוגים דרך מאפייני ההערה בסרגל הצד הימני

#### היכן רואים?

- **תצוגת הכוכבים (GraphMind)**: כקווים צבעוניים ומתויגים בין הצמתים
- **סרגל צד ימני**: בלשונית "קישורים חוזרים" עם ציון סוג כל קישור
- **לשונית מקור**: משמשת לבניית עץ ייחוס הידע

---

### 17.2 שכבות ידע

#### מה זה?

המנוע הקוגניטיבי מסווג אוטומטית כל הערה לאחת משמונה שכבות: תמונת מצב, יומן, נושא, מפה, מסגרת, עיקרון, אמונה, יצירה. הסיווג מבוסס על מבנה ההערה, תוכנה ומספר הקישורים שלה.

#### למה זה חשוב?

הכרת סוג כל הערה חושפת את האיזון הידעי בספרייתכם. האם רוב ההערות שלכם הן רק תמונות מצב חולפות, או שהן התפתחו לעקרונות ומסגרות? מודעות זו לטיב התוכן היא הצעד הראשון לבניית ידע אמיתי ולא רק איסוף מידע.

#### איך להשתמש

1. הסיווג מתבצע אוטומטית — אין צורך לעשות דבר
2. כדי לעקוף את הסיווג האוטומטי, הוסיפו מאפיין `stratum` ב-frontmatter:
   ```yaml
   ---
   stratum: framework
   ---
   ```
3. ערכים זמינים: `snapshot`, `log`, `topic`, `map`, `framework`, `principle`, `conviction`, `artifact`

#### היכן רואים?

- **סרגל צד ימני**: באזור מאפייני ההערה תחת "שכבה"
- **תצוגת הכוכבים**: כצבעים שונים של צמתים לפי השכבה
- **הגדרות > מנוע קוגניטיבי**: להפעלה או השבתה של סיווג אוטומטי

---

### 17.3 מחזור בשלות

#### מה זה?

המנוע עוקב אחר רמת הבשלות של כל הערה בארבעה שלבים: **זרע** → **שתיל** → **ירוק-עד** → **קנונית**. כל הערה מתחילה כזרע וגדלה בהדרגה עם תוספת תוכן, קישורים וסקירות.

#### למה זה חשוב?

הבשלות מבחינה בין רעיון גולמי לידע מעובד. הזרע של היום יכול להפוך למקור סמכות מחר אם תקדישו לו מספיק תשומת לב. מעקב בשלות מסייע לכם לזהות הערות הראויות לפיתוח ותשומת לב נוספים.

#### איך להשתמש

1. הבשלות משתנה אוטומטית על פי: מספר מילים, מספר קישורים נכנסים ויוצאים ותאריך עריכה אחרון
2. להגדרת בשלות ידנית, הוסיפו מאפיין `maturity` ב-frontmatter:
   ```yaml
   ---
   maturity: evergreen
   ---
   ```
3. ערכים זמינים: `seed` (זרע), `sapling` (שתיל), `evergreen` (ירוק-עד), `canonical` (קנונית)

#### היכן רואים?

- **סרגל צד ימני**: סמל ליד כותרת ההערה המציג את שלב הבשלות הנוכחי
- **תצוגת הכוכבים**: כגודל הצומת — ככל שההערה בשלה יותר, הצומת גדול יותר
- **הגדרות > מנוע קוגניטיבי**: להפעלה או השבתה של מעקב בשלות

---

### 17.4 גלאי מתחים

#### מה זה?

גלאי המתחים בוחן הערות מקושרות ומתריע כאשר טענות או מסקנות סותרות זו את זו בין שתי הערות או יותר. הוא מסתמך על ניתוח קישורים מסווגים מסוג `contradicts` ועל דמיון נושאי בין הערות.

#### למה זה חשוב?

מתחים אינם בהכרח שגיאות — הם הזמנות לחשיבה עמוקה יותר. כאשר שני רעיונות בספרייתכם סותרים זה את זה, פירוש הדבר שהבנתכם התפתחה או שיש כאן מורכבות הראויה לחקירה. גילוי מתחים מונע מכם לבנות ידע על יסודות סותרים מבלי לדעת.

#### איך להשתמש

1. הוסיפו קישור מסווג `contradicts` בין הערות סותרות: `[[הערה אחרת|contradicts]]`
2. המנוע מזהה גם מתחים מרומזים באמצעות ניתוח תוכן
3. בדקו את רשימת המתחים שהתגלו מסרגל הצד

#### היכן רואים?

- **סרגל צד ימני**: בלשונית "מתחים" כאשר מתגלות סתירות
- **תצוגת הכוכבים**: כקווים אדומים מקווקווים בין צמתים סותרים
- **לוח התראות**: התראות בעת גילוי מתח חדש

### 17.5 שרשרת מקור

#### מה זה?

שרשרת מקור עוקבת אחר מוצא כל רעיון — מהיכן הוא הגיע וממה הוא נגזר. היא משתמשת בקישורי `[[הערה|derives-from]]` כדי לבנות עץ ייחוס המציג את מסלול התפתחות הידע מהמקור המקורי ועד הניסוח הנוכחי.

#### למה זה חשוב?

לדעת מהיכן באים הרעיונות שלכם מבחינה בין ידע מתקבל (מספרים, מאמרים, הרצאות) לידע מתגלה (המסקנות וההרהורים שלכם). מודעות זו למקור הידע מסייעת לכם להעריך את מהימנות הרעיונות ולהבין איך החשיבה שלכם התעצבה לאורך הזמן.

#### איך להשתמש

1. בעת יצירת הערה הנגזרת ממקור, הוסיפו קישור: `[[מקור מקורי|derives-from]]`
2. ניתן לבנות שרשראות רב-שלביות: הערה ← נגזרת מ- ← נגזרת מ- ← מקור מקורי
3. סווגו מקורות חיצוניים באמצעות `source-type: received` ב-frontmatter

#### היכן רואים?

- **סרגל צד ימני**: לשונית "מקור" מציגה את עץ הייחוס המלא
- **תצוגת הכוכבים**: ככיוון החיצים על הקישורים (מהמקור לנגזר)
- **מאפייני ההערה**: סיווג כ"מתקבל" או "מתגלה" בהתבסס על שרשרת המקור

### 17.6 מנוע החצנה

#### מה זה?

צינור פורמליזציה מתקדם שעוקב אחר התבגרות ההערות שלכם מלכידות גולמיות לתובנות מגובשות. כל הערה יכולה להיות משויכת לאחד מארבעה שלבים:

| שלב | סמל | משמעות |
|-----|------|--------|
| חולף | 🌱 | לכידה מהירה, מחשבה חולפת |
| ספרות | 📖 | נכתבה מחדש ממקור במילים שלכם |
| קבוע | 🔗 | רעיון אטומי, מושג אחד, מחובר לגרף שלכם |
| סינתזה | ✨ | תובנה מקורית המשלבת מספר הערות קבועות |

#### למה זה חשוב?

רוב האפליקציות מתייחסות לכל ההערות באופן שווה. מנוע ההחצנה הופך את ההבחנה לגלויה — אתם יכולים לראות במבט אחד כמה מהספרייה שלכם היא לכידה גולמית לעומת הבנה אמיתית.

#### איך להשתמש

1. בסרגל הניווט (מעל העורך), השתמשו בתפריט הנפתח של השלבים כדי לבחור שלב.
2. או הרחיבו את המאפיינים והשתמשו בתפריט הנפתח של השלבים שם. שניהם מסתנכרנים מיד עם עץ הקבצים.
3. לקידום הערה, שנו את התפריט הנפתח משלב אחד לבא. במצב מיקוד, לחצו על "קידום לקבוע" בתחתית.
4. להסרת שלב, בחרו "— שלב —" מהתפריט הנפתח.

#### היכן רואים?

- **סרגל ניווט**: תפריט נפתח עם אימוג'י + שם שלב
- **פאנל מאפיינים**: תפריט נפתח כאשר מאפיין `stage` קיים
- **עץ קבצים**: סמל אימוג'י ליד שם ההערה
- **כותרת תחתונה של מצב מיקוד**: כפתור "קידום לקבוע"

### 17.7 פולס סקירה

#### מה זה?

פולס סקירה הוא מערכת להעלאה מחדש במרווחים הולכים וגדלים שמחזירה הערות לתשומת לבך: יום אחד, אחר כך 3, אחר כך 7, אחר כך 14, אחר כך 30 יום לאחר הסקירה האחרונה. המערכת גם עוקבת אחר הערות עם תגיות `#assumption` או `#model` כנקודות ביקורת למודלים מנטליים, ומנהלת תור "מעולם לא נסקרו" עבור הערות שנלכדו אך מעולם לא נבדקו מחדש.

#### למה זה חשוב?

ידע דועך ללא ביקור מחדש. אתה כותב הערה היום ובעוד שלושה שבועות שכחת שהיא קיימת. חזרה מרווחת היא הטכניקה המבוססת ביותר במדעי הקוגניציה למאבק בדעיכה זו. פולס סקירה מיישם עיקרון זה על ההערות האמיתיות שלך.

#### כיצד להשתמש

1. לחץ על לשונית **פולס סקירה** בסרגל הצדדי השמאלי. תראה שלושה חלקים: ממתינות לסקירה, נקודות ביקורת למודלים מנטליים (`#assumption` / `#model`), ומעולם לא נסקרו.
2. לחץ על הערה כלשהי כדי לפתוח אותה ולקרוא.
3. בחר אחת משלוש פעולות:
   - **נסקרה** (סימן וי) — מתזמנת את הסקירה הבאה במרווח הבא (1 ← 3 ← 7 ← 14 ← 30 ימים).
   - **דחייה ל-7 ימים** (סמל עין) — דוחה את ההערה ב-7 ימים מבלי לקדם את המרווח.
   - **ביטול** (סמל ארכיון) — מסיר את ההערה מתור הסקירה לצמיתות.
4. פתח את לוח הפקודות והקלד "Review due notes" למעבר ישיר להערות ממתינות.

#### היכן רואים?

- **סרגל צדדי שמאלי**: לשונית פולס סקירה עם תג מספרי להערות ממתינות
- **לוח פקודות**: פקודת "Review due notes" לגישה מהירה

### 17.8 שבילים

#### מה זה?

שבילים הם רצפים מסודרים ובעלי שם של הערות — כמו פרקים בספר או תחנות בסיור מודרך בידע שלך. הם מוגדרים על ידי הוספת `trail: true` ב-frontmatter של הערה, ואז רשימת ויקי-קישורים לפי סדר בגוף ההערה.

#### למה זה חשוב?

ידע הוא לא תמיד רשת. לפעמים הוא שביל — רצף למידה, התקדמות טיעון, סיפור. שבילים לוכדים את הסדר הזה באופן מפורש, ומוסיפים ממד ליניארי לספרייה הלא-ליניארית שלך.

#### כיצד להשתמש

1. צור הערה חדשה עם `trail: true` ב-frontmatter.
2. בגוף ההערה, רשום ויקי-קישורים בסדר הרצוי.
3. כשפותחים הערה השייכת לשביל, סרגל הניווט מציג מחוון עם שם השביל והמיקום (למשל "השביל שלי 2/5"). חצי ניווט מאפשרים מעבר להערה הקודמת והבאה.
4. פתח את לוח הפקודות והקלד "Open Trail" כדי לראות את כל השבילים.

#### היכן רואים?

- **סרגל ניווט**: מחוון שביל עם שם, מיקום וחצי ניווט
- **לוח פקודות**: פקודת "Open Trail" מציגה את כל השבילים

### 17.9 תצוגות רב-עדשתיות

#### מה זה?

תצוגות רב-עדשתיות מאפשרות לצפות בספרייה שלך דרך סכמות סיווג שונות — מבלי לשנות את מבנה התיקיות או לשכפל הערות. "עדשה" היא קיבוץ וירטואלי שמארגן מחדש הערות לפי מאפיין או תגית. עדשות מובנות: "לפי שלב" (חולף/ספרותי/קבוע/סינתזה) ו"לפי נושא" (קיבוץ לפי תגיות). ניתן ליצור עדשות מותאמות אישית בהגדרות.

#### למה זה חשוב?

מבני תיקיות כופים היררכיה יחידה, אבל ידע לא נכנס לעץ אחד. תצוגות רב-עדשתיות מאפשרות מעבר בין נקודות מבט שונות ללא הזזת קבצים. אותן הערות, דרך עדשות ארגוניות שונות.

#### כיצד להשתמש

1. בסרגל הצד, מצא את **בוחר העדשות** בראש עץ הקבצים (ברירת מחדל "תיקיות").
2. בחר עדשה: "לפי שלב", "לפי נושא" או עדשה מותאמת אישית. סרגל הצד מתארגן מחדש מיד.
3. בחר "תיקיות" כדי לחזור לעץ הקבצים הרגיל.
4. ליצירת עדשה מותאמת אישית: פתח **הגדרות > ניהול ידע**, לחץ על **יצירת עדשה**, תן שם ובחר את מאפיין ה-frontmatter לקיבוץ.
5. או השתמש בלוח הפקודות: הקלד "Create Lens".

#### היכן רואים?

- **בוחר בסרגל הצד**: בוחר עדשות בראש עץ הקבצים
- **הגדרות > ניהול ידע**: יצירה, עריכה ומחיקה של עדשות מותאמות אישית
- **לוח פקודות**: פקודת "Create Lens"

### הגדרות המנוע הקוגניטיבי

כל כלי המנוע הקוגניטיבי ניתנים להגדרה ב-**הגדרות > מנוע קוגניטיבי**:

- **סיווג שכבות** — הפעלה או השבתה של סיווג אוטומטי
- **מעקב בשלות** — הפעלה או השבתה של מעקב מחזור חיי בשלות
- **קישורים מסווגים** — כוונון סף הרגישות לזיהוי קישורים (0.0 – 1.0)
- **גלאי מתחים** — הפעלה או השבתה של גילוי מתחים אוטומטי
- **עקיפה ידנית** — הוסיפו מאפייני `stratum` ו-`maturity` ב-frontmatter כדי לעקוף את הסיווג האוטומטי
