# Constellation Sight

## מה זה?

**Constellation Sight** הוא **כלי האבחון** של יקום הידע שלך. **כיפת עוגן** מרכזית מציגה כל הערה ממוקמת לפי **שכבה** (עומק המחשבה) ו**זמן** (מתי נכתבה), לצד ארבע **מיני-כיפות** שמקודדות מחדש את אותו יקום דרך ערוצים שונים: **Confidence**, **Stage**, **Acts**, **Provenance**.

עונה על שאלה אחת עם חמש עדשות משלימות: **"כיצד התוכן האפיסטמי שלי מעוצב ומאורגן?"**

רחף מעל כל כוכב בכל כיפה ואותה הערה זוהרת בכל חמשת המשטחים — טבעת זהב סביב הכוכב, גוון זהב בשבבים תואמים בסרגל הצד. לחץ על שבב בסרגל הצד, וכל חמש התצוגות מצטמצמות. Shift+לחיצה על כוכב במיני Stage והיקום מסונן באופן מיידי לשלב מחזור החיים ההוא. לחץ על אזור ריק בכל מיני-כיפה והיא "מקודמת" לחריץ הראשי בגודל מלא, בעוד הראשי הקודם יורד לחריץ המיני שהתפנה.

## למה זה חשוב?

רוב אפליקציות ההערות מראות לך מה כתבת. Constellation Sight מראה לך את **הצורה** של מה שאתה יודע.

- היכן **מרוכז** המחשבה שלך? (שיפוע הצפיפות של העוגן)
- מה עדיין **בשלב מוקדם** ומה **בסיס יציב**? (שיפוע צבע מיני Stage)
- אילו הערות **נושאות עומס** ואילו **מבודדות**? (קידוד גודל מיני Acts)
- מאיפה הגיע כל רעיון — מחשבה משלך, קריאה, שמיעה, מסורת? (פריסת הסקטורים של מיני Provenance)
- כמה אתה **בטוח** במסקנות שלך? (שיפוע אטימות של מיני Confidence)

הערה במרכז העוגן (קישוריות גבוהה → נושאת עומס) אבל בצבע ציאן (`spark` — חדשה שנדלקה) במיני Stage אומרת לך משהו אבחוני: רעיון נושא עומס שעדיין לא הבשיל.

## איך לפתוח

1. לחץ על **סמל העין** ב-dock השמאלי של Constellation.
2. כיפת העוגן מתבצעת תוך 2–5 שניות לרוב היקומים.
3. כדי לסגור: לחץ על **(×)** בפינה הימנית העליונה או הקש **Esc**.

## מה תראה

### רצועת הכותרת

חלק עליון של תצוגת Sight, משמאל לימין:
- **"Constellation Sight"** — כותרת.
- **"v6.1 — Coordinated Views (Phase 2)"** — תת-כותרת גרסה.
- **תג "X / Y notes" זהב** — מופיע רק כאשר מסנן פעיל.
- **תג "EXTENDED" באותיות קטנות גדולות בזהב** — מופיע רק כאשר תצוגה מורחבת מופעלת.
- **כפתור "Reset View"** — מופיע רק כאשר הפריסה השתנתה.
- **כפתור סגירה (×)** — תמיד נוכח.

### כיפת העוגן (חריץ ראשי)

כיפה גדולה בצבע קרם על רקע כהה במרכז:
- **טבעות שכבה** — 5 מעגלים קונצנטריים. הפנימי ביותר = ההערות הבסיסיות ביותר; הקצה החיצוני = הניצוצות האחרונים שלך.
- **קצה לוח שנה** — 12 תוויות חודשים סביב החוץ.
- **תוויות שכבה** — טקסט נטוי בחלק העליון.
- **כוכבים** — כל הערה כנקודת קרם קטנה, ממוקמת לפי שכבה × זמן.
- **קווי קישור** — קצוות קישור מסוגים בין הערות, אטימות נמוכה מתחת לכוכבים.
- **טבעת ריחוף** — מעגל זהב סביב כל כוכב שהסמן מרחף מעליו.

### ארבע מיני-כיפות

הצד הימני, רשת 2×2. מוסתר כברירת מחדל; מוצג עם **Ctrl+D** (סשן בלבד) או **Ctrl+Shift+D** (קבוע — ראה תצוגה מורחבת).

כל מיני מבצעת את אותו יקום דרך קידוד אחד:

1. **CONFIDENCE — אטימות.** הערות בטוחות יותר בהירות יותר; טנטטיביות דוהות.
2. **STAGE — צבע (דיסק מלא).** צבע קטגורי לפי שלב מחזור חיים:
   - **ציאן** = `spark` (רעיון שזה עתה נדלק)
   - **כתום** = `birth` (לוקח צורה)
   - **סגול** = `growth` (בתנועה פעילה)
   - **ירוק** = `maturity` (מעוצב במלואו)
   - **צהוב** = `renewal` (ביקור מחודש לאחרונה)
   - **אפור** = `dormancy` / `archival` (לא פעיל / סגור)
3. **ACTS — גודל (עשירון עליון).** 10% עליונים של ספירת קישורים = נקודות גדולות יותר; השאר קטן.
4. **PROVENANCE — 5 סקטורים.** הכוכבים ממוקמים מחדש ב-5 סקטורי זווית: **Self / Read / Heard / Reasoned / Tradition**.

### עוגן מוּרד דרגה (כאשר מיני מקודמת)

אם תקדם מיני כלשהי לחריץ הראשי, העוגן יורד לחריץ המיני שהתפנה. שם הוא מבוצע כ**נקודות קרם ניטרליות** תחת הכותרת **"UNIVERSE — primary view"**.

### סרגל צד פאסטים (קצה שמאלי)

לוח מתכווץ עם **6 קבוצות פאסט מסנן**, כל אחת מציגה קטגוריות עם ספירה חיה:

- **Folder** — היררכיית תיקיות
- **Library** — שמות ספריות
- **Stratum** — Foundation / Roots / Trunk / Branches / Twigs / Edge of Knowing
- **Confidence** — Hypothesis / Evidence / Established / Contested
- **Stage** — Spark / Birth / Growth / Maturity / Dormancy / Renewal / Archival
- **Provenance** — Self / Read / Heard / Reasoned / Tradition

לחץ על **▶** בקצה כדי להרחיב. לחץ על כל שבב כדי לעבור כמסנן.

## אינטראקציה

| תנועה | אפקט |
|---|---|
| **ריחוף מעל כוכב** | טבעת זהב על אותו כוכב בכל 5 המשטחים + גוון זהב בשבבים תואמים בסרגל הצד. |
| **לחיצה פשוטה על כוכב** | פותח את ההערה בעורך. כפתור **"Return to Sight"** מופיע. |
| **Shift+לחיצה על כוכב** במיני Stage / Confidence / Provenance | מחליף את המסנן עבור קטגוריית הכוכב הזה. |
| **Shift+לחיצה על כוכב** ב-Acts או בעוגן | ללא אפקט. |
| **לחיצה על אזור ריק של מיני** | המיני הזה מקודם לחריץ הראשי. |
| **זום בגלגלת (ראשי)** | זום לעבר הסמן. טווח: 0.5× עד 24×. |
| **לחיצה+גרירה על אזור ריק** | החלקת תצוגה. |
| **Ctrl+0 / Cmd+0** | אפס זום + החלקה. |
| **Ctrl+D / Cmd+D** | החלף נראות מיני-כיפות — **סשן בלבד**. |
| **Ctrl+Shift+D / Cmd+Shift+D** | החלף **תצוגה מורחבת** — קבוע. |
| **לחיצה על שבב בסרגל הצד** | החלף קטגוריית פאסט בערכת המסנן. |
| **כפתור Reset View** | חזור לראשי-עוגן בזום 1.0. |
| **Esc** | סגור את Sight. |

## מצב רפאים — בחירה מרובה מהכיפה

כאשר מסנן כלשהו פעיל, כוכבים שאינם תואמים נשארים גלויים ב**אטימות נמוכה (15%)** במקום להיעלם. זה אומר:

- אתה עדיין יכול **לראות** היכן הכוכבים שאינם תואמים.
- אתה יכול לרחף מעליהם (טבעת זהב מופיעה).
- אתה יכול **לעשות Shift+לחיצה כדי להוסיף את הקטגוריות שלהם למסנן**.

## מצב צפיפות

כאשר מספר הכוכבים הגלויים (התואמים) חורג מסף הצפיפות (ברירת מחדל **5,000**), מיני-כיפות עוברות ל**ביצוע צפיפות תפיסתית**.

## תצוגה מורחבת

הקשת **Ctrl+Shift+D** (או **Cmd+Shift+D** ב-Mac) מחליפה "תצוגה מורחבת" — כאשר מופעלת, מיני-כיפות גלויות כברירת מחדל בכל פעם שאתה פותח את Sight. המצב נמשך לאורך סגירות Sight, הפעלות מחדש של האפליקציה ואתחולי מערכת.

## מתי Sight הכי שימושי

- **ביקורת צורת ידע** — פתח את Sight לאחר סשן כתיבה.
- **מצא נקודות עיוורות** — סקטורים של הכיפה עם מעט הערות עשויים להיות אזורים לחקירה.
- **זהה חולשות נושאות עומס** — הערה בצבע שלב מוקדם במיקום מרכזי.
- **סנן ובחן** — Shift+לחיצה מצמצמת את היקום; קדם מיני לגודל מלא ללימוד ערוץ.
- **עקוב אחר מקור אפיסטמי** — קדם Provenance כדי לראות איך הידע שלך מגיע.

## משטחים קשורים

- **Constellation Nervous System (CNS)** — הדמיה משלימה (סמל הנוירון ליד סמל העין של Sight ב-dock).
- **Constellation Map** — הדמיית סאנברסט.
- **Sky View** — הדמיית קישור מבוססת גרף.
- **לוח Index** — דפדפן מונחים.
