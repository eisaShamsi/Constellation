# PaRDeS (פרד״ס)

**ファミリー**: ユダヤ(アブラハム) · **形状**: リング(4同心深さゾーン)

## ヒーロー・メタファー

ドームは古典ユダヤ釈義スキームの解釈レベルごとに**4つの同心円リング**
に分割されます。頭字語PaRDeSはヘブライ語で「果樹園」を意味し — 4つの
レベルは順々に入る門です:

- **Pəshaṭ**(פשט) — 最外側リング。テキストの平易または字義通りの意味。
- **Remez**(רמז) — 第2リング。暗示または寓意的意味。
- **Drash**(דרש) — 第3リング。解釈的またはミドラシュ的意味、説教的・
  倫理的。
- **Sod**(סוד) — 最内側リング。隠された、または神秘的意味。

幾何学は*解釈の深さ*をエンコードします: 縁に表面、核に神秘。これは
最も忠実なレンダリングです — PaRDeSは明示的に深さ階層的であり、カテゴリ
的ではありません。

## スコープ

**この伝統を使うべき時。** 同じパッセージが複数の層化された読みを許す
テキスト解釈的コンテンツを扱うとき。聖書 / トーラー注釈、ラビ的モデル
に着想を得た文学的解釈学、表面 / 暗示 / 解釈 / 神秘が有用な分類である
任意のプロジェクトに有用。

**この伝統を使うべきでない時。** コンテンツにテキスト解釈的次元がない
とき — 経験的、手続き的、または記述的なノートは関連する意味での
*pəshaṭ*を持ちません。非自明に適用するには重い伝統でもあります:
pəshaṭは「簡単な読み」ではなく、sodは「神秘的に感じるもの」ではあり
ません。

## 適用範囲

- ユダヤ釈義伝統におけるトーラー / 聖書注釈。
- PaRDeSをモデルにした文学的解釈学。
- 層化された読みのプロジェクト(法的テキスト、詩、任意の伝統における
  聖典)。

## 系譜

中世ユダヤ釈義。4つのレベル自体はタルムードとミドラシュに現れます;
それらの正典的4つ組系統化は、基礎的カバラ・テキストである『ゾーハル』
の周辺で Moses de León(13世紀)に帰属させられます。フレームワークは
ラビ的およびカバラ的釈義の両方で支配的になり、現代のユダヤ解釈学
において標準的なヒューリスティックであり続けています。

## 批評

PaRDeSは*sod*が*pəshaṭ*を支配する「深いほど真」読みを危険にさらすと
批判されてきました — 現代のユダヤ学者(Gershom Scholem、Moshe Idel
など)は、4つのレベルがラダーとしてではなく補完的モードとして最もよく
読まれることを強調してきました。同心円リングレンダリングは深さメタ
ファーを視覚的に特権化します; 平坦・カテゴリ的読みを好むユーザーは、
これを党派的と感じるかもしれません。
