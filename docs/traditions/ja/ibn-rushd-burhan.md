# Ibn Rushd burhān (مراتب البرهان)

**ファミリー**: アラビア / イスラム uṣūl を超えて · **形状**: リング(4同心ゾーン)

## ヒーロー・メタファー

ドームは**4つの同心円リング**の言説に分割され、中心から縁へと論証力
の降順で:

- **burhān** — 必当然的論証。哲学者たちの厳密さ。
- **jadal** — 弁証論。蓋然的前提からの神学者の論争。
- **khaṭāba** — 修辞。説教者と法律家の説得。
- **shiʿr** — 詩的イメージ。一般大衆のための想像的連想の言説。

これはアリストテレスの『オルガノン』のイブン・ルシュドによる適応 —
『分析論後書』、『トピカ』、『修辞学』、『詩学』が4つの聴衆にマッピング
されたもの。それぞれが聴衆にとっての*正しい*言説です; 視覚化は良い対
悪いの階層ではなく、*聴衆への適合性*の階層です。

Constellationは、ほとんどの知識が論証へと弁証論を通じて高められる前に
想像的連想として始まるという弁護可能な読みに基づき、ノートをデフォルト
で*shiʿr*(最外側のリング)にします。

## スコープ

**この伝統を使うべき時。** 哲学的、神学的、修辞的、または教育的コン
テンツを扱うとき、同じアイデアが異なる聴衆のために異なる言説形式を取る
場合。宗教哲学テキストの修辞分析、議論の古典的階層を教えること、
自己監査(私は*burhān*モードで書いているか、それとも*khaṭāba*モードで
書いているか?)に有用。

**この伝統を使うべきでない時。** コンテンツに聴衆-言説次元がないとき —
純粋な技術的コンテンツ、記述的経験的作業、哲学的・修辞的レジスターの
外側の創作は適しません。

## 適用範囲

- ファルサファとカラーム分析。
- 宗教テキストにおける修辞と聴衆分析。
- 著述自己監査として4言説階層を教える。

## 系譜

12世紀アンダルシアのファルサファ。Ibn Rushd(アヴェロエス、1126–1198)
コルドバ生まれは、『*Faṣl al-Maqāl*』(決定的論文)とアリストテレスの
『オルガノン』への注釈で、ギリシャ言説階層をイスラム文脈に適応させま
した — *burhān*は哲学者の特権的モードであるが、*jadal*、*khaṭāba*、
*shiʿr*をそれぞれの適切な聴衆のために非合法化するものではないと論じ
ました。論文はイスラムにおける哲学の許容可能性についてのガザーリー後の
論争への直接的介入でした。

## 批評

イブン・ルシュドの階層はエリート主義として批判されてきました — 哲学者
の論証を大衆の詩的・想像的理解の上に置くことは見下しのように読めます。
現代のムスリム哲学者たちは、フレームワークを様々に弁護(聴衆の多様性
について正直)し、批判(ギリシャ貴族的知性主義の残余)してきました。
Constellationレンダリングは同心円リング形状を使用し、階層的読みを視覚
的に顕著にします — 階層を拒絶するユーザーは、リングを質ラダーとしてで
はなく言説*種類*として読むことを好むかもしれません。
