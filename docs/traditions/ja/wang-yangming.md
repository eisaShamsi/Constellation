# 王陽明 (Wang Yangming)

**ファミリー**: 東アジア儒教 · **形状**: 二項フロー(垂直、中央良知付き)

## ヒーロー・メタファー

ドームは左右の**2つの半球**に分割され、双方向フロー矢印が結び、中央
ラベル軸があります:

- **知 zhī**(知る) — 一方の半球
- **行 xíng**(行う) — もう一方の半球
- **良知 liángzhī**(生得的道徳知) — 両者に給される貯水池としてラベル
  された中央軸

王陽明の特徴的明代教義 — *zhī-xíng héyī*(知行合一、知と行の一致)
— は、2つの別個のセルではなく*フロー付き二項*としてレンダリングされ
ます: 両者は分析的に区別されますが、実践においては一つです。双方向矢印
は言います: すべての知ることは既に行うことであり、すべての行うことは
既に知ることである。

垂直レイアウト二項フローレンダラは、Phase η.2でこの伝統に特化して、
イブン・ハルドゥーンが使う水平レイアウト二項フローおよびDusselが使う
同心円レイアウトとは別個に追加されました。

## スコープ

**この伝統を使うべき時。** コンテンツが洞察を実践に明示的に結びつける
とき — 問いが「この知ることは何を*した*か?」または「この行為に暗黙の
うちにある知ることは何か?」であるとき。応用倫理、瞑想実践、および
理論と実践の離婚を拒絶したい任意の著述に有用。

**この伝統を使うべきでない時。** 行為次元が生じない純粋な理論的コン
テンツ、および知る次元が当然視される純粋な実践的コンテンツは適しません。
フレームワークはまた強く反二元論的 — 「私はXを知っているが、時にXに
従って行動しないことがある」という通常の区別を受け入れません。

## 適用範囲

- 王陽明研究と明代新儒教哲学。
- 知ることに暗黙の行為が要点である応用倫理。
- 知識/実践分割に抵抗する瞑想実践ジャーナリング。

## 系譜

明代新儒教。Wáng Yángmíng(王陽明、1472–1529)、明の政治家、将軍、
哲学者は、官僚的儒教を支配していた朱熹正統(程朱理学、理學)への批判
的代替として*心學*(Xīnxué、心の学)を創設しました。知識と行為が一つで
あるという王の主張は、まず物事の原理を究め(格物)、その後知ったこと
に従って行動するという朱熹の立場に挑戦しました。教義は哲学的に急進的
であり政治的に重要でもありました — 王の追随者たちは明末中国および
近世日本と朝鮮で主要な知的勢力となりました。

## 批評

統一テーゼは哲学的に不明瞭として批判されてきました — 伝統内外の批評家
は、真の*akrasia*(正しいと知っていることに反して行動すること)をどう
説明するかを問います。王の弁護者たちは、教義はakrasiaを否定するのでは
なく*再記述する*と論じます: 知ることなしに行為するように見えるものは、
実際には不完全な知ることです。Constellationのフロー二項としてのレンダ
リングは、王が完全に崩壊させることを拒絶した分析的区別を尊重します。
