# Husserl

**ファミリー**: 近代西洋 · **形状**: リング(同心円ゾーン)

## ヒーロー・メタファー

ドームは**領域存在論の同心円リング**に分割されます — それぞれの*存在の
領域*が、形式的存在論(対象性一般の本質を研究する)とは別個の固有の
*アプリオリ*な本質的構造を持つというHusserlの主張です。

Constellationレンダリングは4つのリングを使用します(Husserlのテキスト
は様々です):

- **形式的** — 最内側。対象性そのものの本質。
- **質料的自然** — 物理的・因果的規則性。
- **動物的自然** — 心的・生命的構造。
- **精神** — 文化的、間主観的、歴史的形成。

各リングは固有の本質的法則を持つ領域 — 精神を動物的自然に、動物的自然
を質料的自然に、またはそれらのいずれかを形式的存在論に還元することは
できません。リングはこの*層的還元不可能性*を可視化します。

## スコープ

**この伝統を使うべき時。** コンテンツが複数の存在論的領域にまたがり、
あるノートがどの領域に住んでいるかを見たいとき。心の哲学、生物学の哲学、
および自然 / 生命 / 文化領域にまたがって明示的に作業する任意のプロ
ジェクトに有用。

**この伝統を使うべきでない時。** すべてのコンテンツが一つの領域にある
とき — 例えば、物理学に関するプロジェクト全体、または文化史に関する
プロジェクト全体 — 領域構造はコントラストを提供しません。要求も厳しい:
領域存在論フレームワークは急峻な参入コストを持ちます。

## 適用範囲

- 心の哲学 / 生物学の哲学 / 社会科学の哲学。
- 存在論的領域を横断する学際的研究。
- 現象学的方法論とその応用。

## 系譜

ドイツ現象学、創設世代。Edmund Husserl(1859–1938)は『イデーンI』
(1913)で、諸科学の基礎学としての現象学を提供するプロジェクトの一部
として形式的対領域的の区別を明確にしました。領域存在論はHusserlの
テキスト全体で様々です; Constellationレンダリングは、『イデーンII』の
提示に近似する一般的な4つ版(形式的 + 質料的自然 + 動物的自然 + 精神)
を使用します。

## 批評

Husserlの領域存在論は、より広い超越論的現象学を前提としており、それ
自体が争われています — Heideggerの『存在と時間』(1927)での批判は、
Dasein の基礎存在論を支持して形式的対領域的分割を拒絶しました。
4領域レンダリングはまた、間主観性、生活世界、歴史性に関する後期
Husserl作業から抽象化し、それがクリーンなリング構造を複雑化します。

## 引用
