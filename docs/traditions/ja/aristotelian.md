# Aristotelian

**ファミリー**: 西洋古典 · **形状**: 扇形(アイデンティティ・リマップ)

## ヒーロー・メタファー

ドームは、あなたのUniverseを**時間を通じた成熟度のグラデーション**として
表示します。5つの同心円状のStratumバンド(基礎 → 根 → 幹 → 枝 → 小枝 →
未知の縁)は内側から外側へと読まれ、角度のスイープは作成時刻をエンコード
します。理解が深まるにつれ、ノートはStratumを通って「上昇」します。
これはデフォルトのSight文法を一つの選択として明示的に示したもの —
本来であれば無印のベースラインとして暗黙的に扱われるものを、ここでは多く
の枠組みの一つとして名付けています。

## スコープ

**この伝統を使うべき時。** 常にデフォルトとして利用可能です。Universe全体
の成熟度プロファイルを見たいとき — 仕事の大半がどこにあるか、密なクラス
ターがどこにあるか、未知の縁に何があるかを把握したいときに有用です。
「自分の思考のどこにいるのか?」という質問が「これはどのような知識か?」
よりも優先されるときに最適です。

**この伝統を使うべきでない時。** カテゴリ的なレンズが必要なとき
(主張を支える証拠の*種類* — 証言、論証、類推など)。Aristotelianは
すべての知識を単一の成熟度軸に平坦化します。カテゴリ的な伝統(pramāṇa、
masādir、Peirce)は、Aristotelianには不可能な証明種別の識別を提供します。

## 適用範囲

- 任意のUniverseの初回オープン時のデフォルト・ビュー。
- Universe形状の診断: Stratumごとの密度、成長方向。
- 知識プロジェクトの全体的ライフサイクルの追跡。

## 系譜

アリストテレスの『分析論後書』(紀元前4世紀)と、それに続く分類学的な
西洋哲学の長い伝統。成熟度Stratumマッピング自体はConstellationの選択 —
アリストテレスは幾何学的配置を割り当てませんでしたが、論証による知の
階層的モデルが、知識には深さのレベルがあるという仮定の基礎となっています。

## 批評

これはすべての伝統の中で最も西洋的デフォルトです。これを(無名のベース
ラインとして紛れ込ませるのではなく)明示的な選択として示すことが*要点*
です — しかし成熟度グラデーションの仮定は依然として、知識が進歩し、
深化し、成熟するという特定の認識論をエンコードしています。このセットの
他の伝統(複数宇宙的、補完的、関係論的)は明示的にその仮定に抵抗します。
