# Talmudic 13 middot (שלוש עשרה מידות)

**ファミリー**: ユダヤ(アブラハム) · **形状**: ラダー(13ステップ螺旋)

## ヒーロー・メタファー

ドームは**13の解釈学的規則**を示します — ラビ・イシュマエルの
*sheloshah ʿaśar middot*、トーラー・テキストから法を導出するための
正典タンナーイティック・ツールキット。13ステップ螺旋ラダーとして
レンダリング。middotは*内容階層*ではなく*ツールキット*: 各規則は
推論パターン(*qal vaḥomer*アフォルティオリ、*gezerah shavah*言語的
類推、*binyan av*一つの源泉からのパラダイム、など)。

13ステップ・レンダリングは、ラビ・イシュマエルの列挙が正典的典礼・教育
版となり、朝礼サービスの*Korbanot*セクションで毎日朗唱されるため選択
されました。ヒレルの以前の7規則版がよりクリーンとしてしばしば引用され
る代替 — Constellationは13規則版を出荷します、それが歴史的に最も
顕著であるため。

## スコープ

**この伝統を使うべき時。** 法的・解釈学的コンテンツを扱うとき、問いが
*この判決を生み出した推論パターンはどれか*であるとき。タルムードと
ハラハー研究、法的解釈の哲学、解釈学的チェックリスト(私はこれを
*qal vaḥomer*で結論を導いているか — そしてここでそれは正当化されるか?)
として有用。

**この伝統を使うべきでない時。** 非法的・非解釈学的コンテンツは13の規則
に意味のある分類をしません。13は高い濃度でもあります — ほとんどの
ユーザー・コンテンツは1つか2つの規則に集まります。

## 適用範囲

- タルムード研究とハラハー的分析。
- 法的解釈の哲学(形式的推論規則を持つ任意の法的伝統において)。
- ユダヤとイスラムの法的解釈学の比較分析(*qiyās*対*qal vaḥomer*、
  など)。

## 系譜

タンナーイティック / 初期ラビ的ユダヤ教、2世紀CE。ラビ・イシュマエル・
ベン・エリシャは、ヒレルの以前の7規則リスト(ヒレルの*baraita*)の
拡張として13規則を成文化しました。13規則リストはレビ記の『*Sifra*』
に保存され、伝統的典礼で毎日朗唱されます。タルムード論理に関する現代
の学術(特にLouis Jacobs)は、形式論理と法理論フレームワークに照らして
規則を分析してきました。

## 批評

13はクリーンな視覚分類のための厄介な濃度です — Constellationラダーは
13ステップすべてをレンダリングしますが、ほとんどのユーザー・コンテンツ
は3つか4つ以上を行使しません。一部の学者は規則を生成的手続きではなく
法的決定の*事後的*合理化と論じますが、その場合ツールキットフレーミング
は誤解を招きます。イシュマエルの13対ヒレルの7の選択は、伝統自身の中で
も論争の的の編集決定です。
