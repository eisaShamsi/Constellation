# Dewey

**ファミリー**: 近代西洋 · **形状**: 循環フロー(5セグメント + 矢印)

## ヒーロー・メタファー

ドームは**5つのセグメントを持つ循環リング**としてレンダリングされます
— Deweyの**探究のパターン** — シェブロン矢印が時計回りの時間的フローを
示します。順序通りの5つの段階:

1. **不確定な状況** — 落ち着かない、問題のある、疑わしい状態で、探究を
   開始する。
2. **問題の定式化** — 何が間違っているかを命名し、何が懸かっているかを
   フレームする。
3. **仮説(アイデア)** — 可能な解決策を提案する。
4. **推論** — 仮説の含意を働き出す。
5. **テスト / 判断** — 仮説を状況に対してチェックする; (暫定的な)
   確定的状況に到達する。

サイクルは新しい不確定な状況から再発火します。シェブロン矢印は*時間性*
を可視化します: これは静的なタイポロジーではなくプロセスです。

## スコープ

**この伝統を使うべき時。** Universe自体が*探究*の記録であるとき —
研究ノート、実験ノートブック、デバッグログ、調査ジャーナリズム、ケース
ワーク。探究サイクルの段階でノートを視覚化することで、どこで詰まって
いるか(問題の定式化? 仮説不足?)、どこで作業が積み重なっているか
(常にテストし、決して再フレーミングしない?)が表面化します。

**この伝統を使うべきでない時。** 静的、百科事典的、または記述的なコン
テンツは探究パターンの枠組みに合いません — 段階にあるべき探究がない
ためです。参照ノート、定義済み用語ノート、瞑想的著述は適しません。

## 適用範囲

- 各ノートが探究段階タグを持つ研究ノートブック。
- デバッグ、トラブルシューティング、根本原因分析ログ。
- 調査が実際にどのように展開するかの教育的分析。

## 系譜

アメリカン・プラグマティズム、成熟期。John Dewey(1859–1952)は『論理
学 — 探究の理論』(1938)の体系的核として探究のパターンを明確にしました。
パターンは、落ち着いた信念が落ち着かない疑いからどのように回復される
かの普遍的記述として意図されています — 日常の問題解決、科学的調査、
倫理的熟議、美的判断に等しく適用可能。

## 批評

パターンはあまりにきちんとしているとして批判されてきました — 実際の
探究は5つの離散的段階をクリーンな順序で進むことはまれです。Dewey自身は
パターンを記述的順序ではなく分析的再構成として限定しました。科学哲学
側からは、パターンは仮説演繹的およびアブダクティブモデルと重複します;
現象学的側からは、探究の驚きと行き詰まりの生きられた経験を平坦化でき
ます。
