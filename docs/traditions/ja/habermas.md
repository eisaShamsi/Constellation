# Habermas

**ファミリー**: 近代西洋 · **形状**: 扇形(3楔形)

## ヒーロー・メタファー

ドームは**3つの認識構成的関心**に分割されます — 知識生産は常に既に
3つの還元不可能な人間的関心のうちの1つによって形成されるという
Habermasの主張:

- **技術的(Technical)** — 客観化されたプロセスの道具的制御。経験的・
  分析的諸科学。
- **実践的(Practical)** — 解釈を通じた間主観的理解。歴史的・解釈学的
  諸科学。
- **解放的(Emancipatory)** — 自律(*Mündigkeit*)に向けた自己反省。
  批判的諸科学。

3つのセクターはそれぞれ120°に位置し、+π/6回転されて(§δ.1-fix-1)
ドーム上部のStratumラベルから区切り線を遠ざけます。

## スコープ

**この伝統を使うべき時。** 問いが*この知識は何のためか?* — その生産の
背後にある関心であるとき。研究Universeの学術的ミックスを診断するのに
有用: 技術的作業、解釈学的作業、批判的作業のどれをしているか?
特に解放的スライスは、プロジェクトに自身の条件への自己反省が含まれて
いるかを問うための良い視覚的プロンプトです。

**この伝統を使うべきでない時。** Habermasの関心は知ることの*目的*を
分類するもので、*内容*ではありません。ノートが、行う仕事ではなくトピック
で分類されている場合、この伝統はほとんど何も表面化しません。素朴に適用
するには重い伝統でもあります; 3つ分割はHabermas自身の後の*コミュニケー
ション的行為*フレームワークによって相当複雑化されています。

## 適用範囲

- 社会科学の方法論と哲学。
- 批判理論の作業とその自己反省。
- 単一のプロジェクト内で応用 / 解釈 / 批判の研究ストランドを区別する。

## 系譜

ドイツ批判理論、第二世代フランクフルト学派。Jürgen Habermas
(生年1929)は『認識と関心』(1968)で初期認識論の明示的フレームワーク
として3つの認識構成的関心を明確にしました。関心は後に『コミュニケー
ション的行為の理論』(1981)に包含されました — しかし問い立場のタイポ
ロジーとして、1968年の定式は教育的に依然として有用であり、Constellation
がレンダリングするものです。

## 批評

Habermas自身は成熟した作業で厳密な3つ関心のタイポロジーから離れました;
批評家(Rorty、別の角度からのFoucaultを含む)は、タイポロジーが実際
にはより流動的な関心を本質化したと論じました。解放的関心は最も争われ
てきました — 批評家は、それが実践的関心の解釈学的批判と本当に区別され
るかを問います。Constellationは1968年のタイポロジーを出荷します、それ
は幾何学的にクリーンであるため; 成熟した*コミュニケーション的行為*の
枠組みを望むユーザーは、別の伝統が必要です。
