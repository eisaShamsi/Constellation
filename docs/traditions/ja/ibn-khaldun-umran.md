# Ibn Khaldūn ʿumrān (علم العمران)

**ファミリー**: アラビア / イスラム uṣūl を超えて · **形状**: 二項フロー(水平、循環)

## ヒーロー・メタファー

ドームは**2つの水平バンド**に分割され、それらを結ぶ循環フロー矢印が
あります — イブン・ハルドゥーンの『*ʿilm al-ʿumrān*』(文明の学)に
おける基礎的区別:

- **ʿumrān ḥaḍarī** (上) — 都市的、定住的生活。洗練され、分業に依存
  し、奢侈と*ʿaṣabiyya*(集団結束)の衰退に陥りやすい。
- **ʿumrān badawī** (下) — 田園的、遊牧的、部族的生活。頑強で、結束し、
  *ʿaṣabiyya*の源泉。次の支配王朝を生み出す王朝エネルギーの貯水池。

循環フロー矢印(回転 — 左上 + 右下)は*文明的時間性*を可視化します:
badawīが ḥaḍarī を征服し、定住し、ḥaḍarī となり、衰退し、新しいbadawī
の波に征服される。これは静的なカテゴリではなく動的な移行です。

## スコープ

**この伝統を使うべき時。** コンテンツが文明的、マクロ社会学的、または
ロングデュレ歴史的次元を持つとき。政治理論、歴史哲学、人類学、比較社会学
の作業で、都市/田園の二項と興亡のダイナミクスが組織化軸である場合に
有用。

**この伝統を使うべきでない時。** 法的、儀礼的、または神秘的コンテンツ
には不適合 — badawī/ḥaḍarī二項は知るモードではなく*社会的存在*のモード
を分類します。時間的・文明的次元のないコンテンツにも不適。

## 適用範囲

- イブン・ハルドゥーンのフレームワークを使ったマクロ社会学的分析。
- 比較歴史哲学。
- 社会的結束と衰退に関する政治理論作業。

## 系譜

14世紀マグリブ歴史学および原始社会学。Ibn Khaldūn(1332–1406)、チュニジア
生まれのマーリク派法律家、博学者、歴史家は、計画された普遍史の方法論的
序論として『*Muqaddima*』(1377)を書きました。*ʿumrān*フレームワークは
方法論的中心 — イブン・ハルドゥーンは物語としての歴史および規範として
の政治哲学とは別個の新しい学を創始していると論じました。現代の読者
(トインビーからゲルナー、現代のハルドゥーン学者まで)は、これを文明の
初期社会学として読んできました。

## 批評

badawī/ḥaḍarīの二項は本質化として批判されてきました — 「遊牧民」と
「都市生活者」に、実際の歴史が複雑化する安定した文化的・心理的特性を
帰属させること。*ʿaṣabiyya*概念は、啓発的である一方、互いに非互換な
政治プログラムの広範な範囲を正当化するために使われてきました(反植民
ナショナリズムから権威主義的レアルポリティクまで)。Constellationの
二項レンダリングは最も忠実な幾何学ですが、一部の学者が引き出す4側面
拡張(地理的、人類学的、社会学的、王朝的)を平坦化します。
