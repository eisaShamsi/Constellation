# PaRDeS (פרד״ס)

**خاندان**: یہودی (ابراہیمی) · **شکل**: rings (4 مرتکز گہرائی زون)

## مرکزی استعارہ

گنبد **چار مرتکز rings** میں تقسیم ہوتا ہے، کلاسیکی یہودی exegetical اسکیم میں تشریح کے ہر سطح کے لیے ایک۔ مخفف PaRDeS عبرانی لفظ "باغ" کے لیے ہے — اور چار سطحیں وہ دروازے ہیں جو شخص ترتیب وار داخل ہوتا ہے:

- **Pəshaṭ** (פשט) — سب سے بیرونی ring۔ متن کا سادہ یا لفظی معنی۔
- **Remez** (רמז) — دوسرا ring۔ اشارہ یا تمثیلی معنی۔
- **Drash** (דרש) — تیسرا ring۔ تشریحی یا midrashic معنی، homiletical اور اخلاقی۔
- **Sod** (סוד) — سب سے اندرونی ring۔ پوشیدہ یا تصوفی معنی۔

ہندسہ *تشریح کی گہرائی* encode کرتی ہے: کنارے پر سطح، core پر راز۔ یہ سب سے زیادہ وفادار رینڈرنگ ہے — PaRDeS واضح طور پر hierarchical-in-depth ہے، زمرہ جاتی نہیں۔

## دائرہ کار

**اس روایت کو کب استعمال کریں۔** جب متن-تشریحی مواد کے ساتھ کام کر رہے ہوں جہاں ایک ہی فقرہ متعدد تہہ دار پڑھائیوں کی اجازت دیتا ہے۔ بائبل / Torah تفسیر، ادبی hermeneutics جو rabbinic ماڈل سے متاثر ہے، اور کسی بھی منصوبے کے لیے کارآمد جہاں سطح / اشارہ / تشریح / راز ایک کارآمد چھانٹ ہے۔

**اس روایت کو کب استعمال نہ کریں۔** جب مواد میں کوئی متن-تشریحی جہت نہیں — تجرباتی، طریقہ کاری، یا وصفی نوٹس متعلقہ معنی میں *pəshaṭ* نہیں رکھتے۔ غیر معمولی طور پر لاگو کرنے کے لیے ایک بھاری روایت بھی: pəshaṭ "آسان پڑھائی" نہیں ہے اور sod "جو مجھے تصوفی لگتا ہے" نہیں ہے۔
