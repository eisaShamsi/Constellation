# Peirce

## המטאפורה המרכזית

הכיפה מתחלקת ל**שלוש קטגוריות פנומנולוגיות** ש-Peirce טען שעומדות בבסיס כל חוויה וכל הסקה:

- **Firstness** — איכות, רגש, אפשרות. ה"להיות אדום" *לפני* שכל דבר אדום קיים.
- **Secondness** — פעולה, תגובה, עובדה גסה. ההתנגשות האמיתית, התנגדות העולם.
- **Thirdness** — תיווך, חוק, הרגל, סימן. הדפוס שמחבר את Firstness ו-Secondness; הסדירות שמסבירה מדוע זה קורה אחרי ההוא.
