# Maldonado-Torres

**家族**:拉丁美洲解殖民 · **形状**:环(3 同心层)

## 核心隐喻

穹顶分为**三个同心环**,每个环是 Nelson Maldonado-Torres 从 Quijano
和 Mignolo 扩展的*殖民性*概念的一层:

- **权力殖民性** — 最外环。全球种族-资本主义组织的结构矩阵
  (Quijano 的基础贡献)。
- **知识殖民性** — 中环。范畴、方法论和学科形式的欧洲中心霸权
  (Mignolo 的扩展)。
- **存在殖民性** — 最内环。本体论维度 — 殖民性如何进入自我和人格
  经验(Maldonado-Torres 自己的贡献,与海德格尔基础本体论对话)。

俄罗斯套娃几何编码嵌套论证:权力是外部条件;知识是权力自我再生产的
媒介;存在是创伤所在的本体论深度。

## 范围

**何时使用此传统。** 当处理特别涉及*殖民性*文献的内容时,或当问题
是殖民性*在什么深度*运作 — 结构、认识论或本体论 — 的批判性工作时。
对批判种族理论、后殖民哲学和解殖民女性主义工作很有用。

**何时不使用此传统。** 没有批判权力分析维度的内容不适合。三层渲染
也预设了解殖民框架的承诺 — 不熟悉 Quijano 和 Mignolo 的读者会发现
环标签晦涩。

## 适用性

- 解殖民哲学和批判种族理论。
- 知识系统的后殖民和解殖民阅读。
- 在三个层级上对自己写作中未被识别的殖民性进行自我审计。

## 谱系

加勒比-美国解殖民哲学。Nelson Maldonado-Torres(罗格斯大学),明确建
立在 Aníbal Quijano 和 Walter Mignolo 之上,在他 2007 年同名文章中将
*存在殖民性*阐述为补充前两个表述的第三层。三层框架已成为解殖民哲学
文献中的标准参考。

## 批评

三层环渲染,像 Mignolo 的轴辐式一样,本身可以被批评为执行了解殖民
理论抵抗的总体化姿态 — 将*殖民性*概念固定到整齐的三重图式中。从解
殖民学术内部,"X 殖民性"表述的激增(性别殖民性、自然殖民性、感性
殖民性)表明三层框架可能已经不够。
