# PaRDeS (פרד״ס)

**家族**:犹太(亚伯拉罕系) · **形状**:环(4 同心深度区域)

## 核心隐喻

穹顶分为**四个同心环**,每个对应经典犹太注释体系中的一个解释层级。
首字母缩写 PaRDeS 拼出希伯来语"果园"一词 — 而四个层级是依次进入
的门:

- **Pəshaṭ**(פשט) — 最外环。文本的字面或浅显意义。
- **Remez**(רמז) — 第二环。暗示或寓言意义。
- **Drash**(דרש) — 第三环。解释或米德拉什意义,布道和伦理。
- **Sod**(סוד) — 最内环。隐藏或神秘意义。

几何编码*解释的深度*:边缘是表面,核心是奥秘。这是最忠实的渲染 —
PaRDeS 明确是深度等级化的,而非范畴的。

## 范围

**何时使用此传统。** 当处理文本解释内容时,同一段落允许多个层化阅读。
对犹太注释传统中的圣经 / 妥拉评注、受拉比模型启发的文学诠释学,以及
任何表面 / 暗示 / 解释 / 奥秘是有用排序的项目很有用。

**何时不使用此传统。** 当内容没有文本解释维度时 — 经验、程序或描述性
笔记在相关意义上没有 *pəshaṭ*。也是一个非平凡应用的沉重传统:pəshaṭ
不是"容易的阅读",sod 也不是"感觉对我神秘的"。

## 适用性

- 犹太注释传统中的妥拉 / 圣经评注。
- 以 PaRDeS 为模型的文学诠释学。
- 层化阅读项目(法律文本、诗歌、任何传统中的圣典)。

## 谱系

中世纪犹太注释。四个层级本身存在于塔木德和米德拉什中;它们正典的
四重系统化归属于摩西·德·莱昂(13 世纪),在基础卡巴拉文本《佐哈尔》
的轨道上。该框架在拉比和卡巴拉注释中都成为主导,并在当代犹太诠释学
中仍然是标准启发式方法。

## 批评

PaRDeS 因冒着"越深越真"阅读的风险而被批评,在这种阅读中 *sod* 支配
*pəshaṭ* — 现代犹太学者(格肖姆·朔勒姆、摩西·伊德尔等)强调四个层级
最好被读作互补模式而非阶梯。同心环渲染在视觉上特权化深度隐喻;偏好
平面范畴阅读的用户可能会觉得它有倾向性。
