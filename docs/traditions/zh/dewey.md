# Dewey

**家族**:现代西方 · **形状**:循环流(5 段 + 箭头)

## 核心隐喻

穹顶呈现为**带有五段的循环环** — Dewey 的**探究模式** — 雪佛龙箭头
指示顺时针时间流。按顺序的五个阶段:

1. **不确定情境** — 启动探究的不稳定、有问题、可疑的状态。
2. **问题表述** — 命名出了什么问题,框定什么处于危险中。
3. **假设(想法)** — 提出可能的解决方案。
4. **推理** — 推演假设的含义。
5. **测试 / 判断** — 对照情境检验假设;到达(暂定的)确定情境。

循环然后从新的不确定情境重新触发。雪佛龙箭头使*时间性*可见:这不
是静态类型学而是过程。

## 范围

**何时使用此传统。** 当你的 Universe 本身是*探究*的记录时 — 研究笔记、
实验笔记本、调试日志、调查新闻、案例工作。按笔记在探究循环中的阶段
可视化笔记,可以浮现你卡在哪里(问题表述?假设不足?),工作在哪里
堆积(总是测试,从不重新框定?)。

**何时不使用此传统。** 静态、百科全书或描述性内容不适合探究模式
框架 — 没有处于阶段的探究。参考笔记、定义术语笔记和沉思写作不适合。

## 适用性

- 每条笔记带有探究阶段标签的研究笔记本。
- 调试、故障排除和根本原因分析日志。
- 探究实际如何展开的教学分析。

## 谱系

美国实用主义,成熟阶段。John Dewey(1859–1952)在他的《*Logic: The
Theory of Inquiry*》(1938)的系统核心中阐述了探究模式。该模式旨在
作为关于如何从不安定的怀疑中恢复安定信念的普遍描述 — 同样适用于
日常问题解决、科学调查、伦理审议和审美判断。

## 批评

该模式因过于整齐而受到批评 — 实际探究很少以干净的顺序经过五个离散
阶段。Dewey 自己将该模式限定为分析重构,而非描述性序列。从科学哲学
侧来看,该模式与假设演绎和溯因模型重叠;从现象学侧来看,它可以平坦
化探究的惊喜和死胡同的生活经验。
