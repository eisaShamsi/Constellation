# 王阳明 (Wang Yangming)

**家族**:东亚儒家 · **形状**:二元流(垂直,带中央良知)

## 核心隐喻

穹顶分为左右**两个半球**,由双向流箭头连接,并带有中央标记轴:

- **知 zhī**(知) — 一个半球
- **行 xíng**(行) — 另一个半球
- **良知 liángzhī**(天生道德认知) — 标记为滋养两者的储备的中央轴

王阳明独特的明代教义 — *zhī-xíng héyī*(知行合一) — 渲染为*带流的
二元*,而非两个分离的格子:两者在分析上不同但实践中是一。双向箭头说:
每个知已经是行,每个行已经是知。

垂直布局二元流渲染器在 Phase η.2 专门为这个传统添加,与伊本·赫勒敦
使用的水平布局二元流和 Dussel 使用的同心布局不同。

## 范围

**何时使用此传统。** 当你的内容明确将洞察与实践联系起来时 — 当问题是
"这个知*做了*什么?"或"这个行动中暗含的知是什么?"。对应用伦理、
沉思实践,以及任何你想要拒绝理论与实践分离的写作很有用。

**何时不使用此传统。** 纯粹理论内容(其中行动维度不出现)和纯粹实践
内容(其中知维度被认为理所当然)不适合。该框架也是强烈反二元论的 —
它不容纳"我知道 X"与"我有时不能按 X 行动"之间的普通区分。

## 适用性

- 王阳明研究和明代新儒学哲学。
- 应用伦理,其中行动暗含于知是要点。
- 抵抗知识/实践分裂的沉思实践日志记录。

## 谱系

明代新儒学。王阳明(王陽明,1472–1529),明朝政治家、将军和哲学家,
创立了 *心学*(*Xīnxué*)作为对主导官方儒学的朱熹正统(程朱理学)的
批判性替代。王的知识与行动为一的主张挑战了朱熹的立场,即首先研究
事物的原理(格物),然后按所知行动。该教义在哲学上是激进的,在政治
上也有重大影响 — 王的追随者成为明末中国及近代早期日本和韩国的主要
知识力量。

## 批评

统一论被批评为在哲学上晦涩 — 传统内外的批评者询问如何解释真正的
*akrasia*(违背所知正确之事的行动)。王的辩护者认为该教义*重新描述*
而非否认 akrasia:看似不行动的知实际上是不完整的知。Constellation 渲染
为流二元尊重了王拒绝完全坍缩的分析区分。
