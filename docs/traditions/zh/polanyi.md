# Polanyi

**家族**:现代西方 · **形状**:梯度(不透明度叠加)

## 核心隐喻

穹顶保持其 Aristotelian 布局 — 但其上绘制了**雾**。靠近中心的星星暗淡
("默会的",被承认但无法明言);靠近边缘的星星清晰("明示的",你
可以完全说出的)。隐喻颠倒了通常的 Aristotelian 解读:中心不是
"基础",而是**默会维度** — 技能中的知识、判断中的知识、识别中的
知识 — 我们拥有但无法还原为命题的东西。

Polanyi 是*调制*,而非重新分配。笔记不移动;其可见性改变。这是策划
基线中唯一进行叠加而非重新定位的传统。

## 范围

**何时使用此传统。** 当你想问"我所知的有多少在我的技能而非我的笔记
中?"时 — 当审计问题是关于可表达性时。对手艺、表演、医学临床、科学
实验和教育内容很有用,在这些领域,一个人能做的和能说的之间的差距是
有趣的变量。

**何时不使用此传统。** 当你所有的内容都是明确写出的命题时,梯度不会
浮现太多。当你想要范畴(此对彼)透镜时也是如此 — Polanyi 的连续梯度
是有意非范畴的。

## 适用性

- 手艺和技能传统(医学、科学、音乐、木工)。
- 组织背景下的默会/明示知识审计。
- knowing-how 与 knowing-that 的现象学。

## 谱系

现代西方多元认识论。Michael Polanyi(1891–1976),一位成为哲学家的
匈牙利-英国物理化学家,将默会/明示极性引入为连续光谱。《*Personal
Knowledge*》(1958)是系统性陈述;《*The Tacit Dimension*》(1966)是
正典的简短提炼。关键论点:*我们知道的比能说的多* — 而我们无法说的
仍然做认识论工作。

## 批评

默会/明示极性因过于整齐而受到批评 — 来自经验侧的批评者(Harry Collins
对默会知识的类型学)认为 Polanyi 混淆了几种不同的现象。从现象学侧
来看,梯度假设了一个稳定的轴,而那里可能有不可通约的默会种类。
Polanyi 更广泛的"涌现"形而上学在 Sight 渲染中未被调用 — 仅有默会/
明示极性。
