# Habermas

**家族**:现代西方 · **形状**:扇形(3 楔形)

## 核心隐喻

穹顶分为**三种知识构成性兴趣** — Habermas 的主张,即知识生产总是已经
被三种不可还原的人类兴趣之一所塑造:

- **技术性(Technical)** — 对客观化过程的工具性控制。经验分析科学。
- **实践性(Practical)** — 通过解释达成的主体间理解。历史解释学科学。
- **解放性(Emancipatory)** — 朝向自主(*Mündigkeit*)的自我反思。
  批判科学。

三个扇区各位于 120°,旋转 +π/6(§δ.1-fix-1),以保持分隔线远离穹顶
顶部的 Stratum 标签。

## 范围

**何时使用此传统。** 当问题是*这种知识是为了什么?* — 其生产背后是
什么兴趣时。对诊断研究 Universe 中的学术混合很有用:你在做技术工作、
解释学工作还是批判工作?特别是解放切片是一个很好的视觉提示,询问你
的项目是否包括对自己条件的自我反思。

**何时不使用此传统。** Habermas 的兴趣分类的是知识的*目的*,而非
*内容*。如果你的笔记按主题而非按它们所做的工作排序,这个传统几乎不
显示什么。素朴应用也很沉重;三重划分已被 Habermas 自己后期的
*交往行动*框架大大复杂化。

## 适用性

- 社会科学方法论和哲学。
- 批判理论工作及其自我反思。
- 在单一项目中区分应用 / 解释 / 批判研究分支。

## 谱系

德国批判理论,第二代法兰克福学派。Jürgen Habermas(生于 1929 年)在
《*Erkenntnis und Interesse*》(1968)中阐述了三种知识构成性兴趣,
作为他早期认识论的明确框架。这些兴趣后来被纳入《*交往行动理论*》
(1981) — 但作为探究立场的类型学,1968 年的表述在教学上仍然有用,
是 Constellation 渲染的内容。

## 批评

Habermas 自己在其成熟工作中远离了严格的三兴趣类型学;批评者(包括
Rorty、从不同角度的 Foucault)认为该类型学本质化了实践中更流动的
兴趣。解放兴趣是最有争议的 — 批评者询问它是否真正不同于实践兴趣的
解释学批判。Constellation 提供 1968 年类型学,因为它在几何上很干净;
想要成熟的*交往行动*框架的用户需要单独的传统。
