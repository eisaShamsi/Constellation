# Peirce

**家族**:现代西方 · **形状**:扇形(3 楔形)

## 核心隐喻

穹顶分为 Peirce 认为构成所有经验和所有推理基础的**三个现象学范畴**:

- **第一性(Firstness)** — 性质、感觉、可能性。任何红色事物存在
  *之前*"作为红色是什么"。
- **第二性(Secondness)** — 行动、反应、原始事实。实际碰撞、世界的
  抵抗。
- **第三性(Thirdness)** — 中介、法则、习惯、符号。连接第一性和第
  二性的模式;解释为什么这个之后发生那个的规律。

三个扇区各位于 120°,从基本轴旋转 +π/6(§δ.1-fix-1),使穹顶顶部的
Stratum 标签上没有分隔线穿过。

## 范围

**何时使用此传统。** 当问题是这内容描述*什么经验范畴*时。对符号学
工作,区分感觉性质、行动事实和解释法则,以及分析论证类型(在一种
Peirce 解读中,溯因式第一性、演绎式第二性、归纳式第三性)非常出色。

**何时不使用此传统。** 当内容没有现象学切分时 — 当它全是数据,或
全是行动,或全是法则时,范畴词汇无法提供有用的排序。也是一个要求
很高的传统:范畴需要努力才能正确应用,而朴素的解读倾向于将第三性
坍缩为第二性。

## 适用性

- 符号学、符号理论、传播研究。
- 经验的现象学。
- 论证类型分析(溯因 / 演绎 / 归纳)。

## 谱系

美国实用主义。Charles Sanders Peirce(1839–1914),实用主义(pragmaticism)
和现代形式逻辑的创立者,在其整个职业生涯中阐述了这三个范畴;它们早期
出现("On a New List of Categories", 1867)并在他的符号学和现象学工
作中变得更加精炼。范畴是*普遍的*:Peirce 认为它们构成所有现象的不可
还原词汇,而不仅仅是一个领域。

## 批评

范畴以没有训练难以应用而著称,Peirce 自己也多次修订他的论述。来自
分析侧的批评者质疑三向分割是否详尽;来自现象学侧的批评者认为 Peirce
的范畴过于形式化,无法捕捉生活经验。当前 Constellation 渲染默认所有
笔记为第一性,因为每条笔记的 frontmatter 提取尚未发布 — 一旦发布,
用户可以将笔记 opt-in 到他们意图的范畴。
