# Ibn Khaldūn ʿumrān (علم العمران)

**家族**:阿拉伯 / 伊斯兰超越 uṣūl · **形状**:二元流(水平、循环)

## 核心隐喻

穹顶分为**两个水平带**,带有连接它们的循环流箭头 — 伊本·赫勒敦在
《*ʿilm al-ʿumrān*》(文明的学问)中的基础区分:

- **ʿumrān ḥaḍarī**(顶部) — 城市定居生活。精炼,依赖分工,易陷入
  奢侈和 *ʿaṣabiyya*(群体团结)的衰败。
- **ʿumrān badawī**(底部) — 乡村、游牧、部落生活。坚韧、有凝聚力,
  是 *ʿaṣabiyya* 的源泉。产生下一个统治家族的王朝能量储备。

循环流箭头(旋转 — 左上 + 右下)使*文明时间性*可见:badawī 征服
ḥaḍarī,定居下来,变成 ḥaḍarī,衰败,被新的 badawī 浪潮征服。这不是
静态范畴而是动态过渡。

## 范围

**何时使用此传统。** 当你的内容具有文明、宏观社会学或长时段历史维度
时。对政治理论工作、历史哲学、人类学和比较社会学很有用,其中城市/
乡村二元和兴衰动态是组织轴。

**何时不使用此传统。** 对法律、仪式或神秘内容不适合 — badawī/ḥaḍarī
二元分类的是*社会存在*模式,而非认知模式。对没有时间-文明维度的内容
也不适合。

## 适用性

- 使用伊本·赫勒敦框架的宏观社会学分析。
- 比较历史哲学。
- 关于社会凝聚和衰败的政治理论工作。

## 谱系

14 世纪马格里布史学和原社会学。伊本·赫勒敦(1332–1406),突尼斯出生的
马立克派法学家、博学者和历史学家,撰写了《*Muqaddima*》(1377)作为
计划中的普世历史的方法论引言。*ʿumrān* 框架是方法论核心 — 伊本·赫勒敦
认为他正在创立一门不同于作为叙事的历史和作为规定的政治哲学的新科学。
现代读者(从汤因比到盖尔纳到当代赫勒敦学者)将其读作早期文明社会学。

## 批评

badawī/ḥaḍarī 二元被批评为本质化 — 将"游牧民"和"城市居民"归因于
实际历史所复杂化的稳定文化心理特质。*ʿaṣabiyya* 概念虽然富有启发,
但已被用于辩护各种不兼容的政治计划(从反殖民民族主义到威权现实政治)。
Constellation 的二元渲染是最忠实的几何,但确实平坦化了一些学者引出的
四方面扩展(地理、人类学、社会学、王朝)。
