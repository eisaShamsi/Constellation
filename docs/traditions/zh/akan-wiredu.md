# Akan Wiredu

**家族**:非洲哲学 · **形状**:扇形(3 楔形)

## 核心隐喻

穹顶分为**三个扇区**,取自 Kwasi Wiredu 关于阿坎概念图式的分析哲学
工作:

- **nokware** — 真实性。在 Wiredu 的解读中,通常翻译为"真理"的阿坎
  术语根本上是*话语和人格*的属性(being-truthful),而非命题的属性
  (being-true)。这是 Wiredu 最被引用的主张:西方的真/假二元不能干净
  地翻译为阿坎语。
- **ahonyam** — 意见 / 推测。低于有保证断言的主张的地位。
- **adwene** — 思想 / 认知能力。心灵本身,产生真实断言和单纯意见的
  能力。

三个扇区各位于 120°,旋转 +π/6(Peirce / Habermas 3 扇区模式),清除
垂直轴上的 Stratum 标签。

该框架是*紧缩的*:它不是真理的替代形而上学,而是对西方真理形而上学
普遍性假设的批判。

## 范围

**何时使用此传统。** 当你的内容涉及非洲哲学、比较认识论或概念解殖民
工作时。作为询问西方命题真理透镜是否对你的材料做了扭曲工作的提示很
有用 — 芯片的*工作*部分是使该问题可见。

**何时不使用此传统。** Wiredu 自己会警告不要将该框架作为与其激发问题
无关的内容的排序机制应用。将非阿坎内容强制纳入 nokware / ahonyam /
adwene 冒着该框架批评的同样的普遍化动作的风险。

## 适用性

- 阿坎和加纳哲学,更广泛的非洲分析哲学。
- 西方和非洲传统之间的比较认识论。
- 概念解殖民分析:你的概念是可移植的,还是它们正在偷渡其起源语言的
  承诺?

## 谱系

当代学术非洲哲学。Kwasi Wiredu(1931–2022,加纳)在《*Philosophy and
an African Culture*》(1980)和基础文章"The Concept of Truth in the
Akan Language"(1985)中主张*概念解殖民* — 通过阿坎概念图式工作以识
别什么是阿坎的、什么是殖民残余的项目。Wiredu 的同时代人 Kwame Gyekye
(1939–2019)在《*An Essay on African Philosophical Thought: The Akan
Conceptual Scheme*》(1987)中提供了对同样材料的平行但不同的阅读。

## 批评

Wiredu 的紧缩解读从两侧受到批评:一些非洲哲学家(特别是 Paulin
Hountondji)担心它冒着*民族哲学*的风险 — 将特定非洲文化的语言特征
打包为简单的"非洲哲学"。从分析侧,Wiredu 的真理-真实性主张即使在
阿坎哲学内部也有争议(Gyekye 在文本阅读上不同意)。

Constellation 渲染为三扇区芯片本身就是*扇形*动作 — 而 Wiredu 的框架,
作为紧缩性的,比更范畴的传统不那么干净地适合扇形习语。芯片最好读作
对命题真理假设进行自我怀疑的提示。
