# Maimonidean prophecy (Mishnah ha-Nevuʾah)

**家族**:犹太(亚伯拉罕系) · **形状**:阶梯(11 级螺旋)

## 核心隐喻

穹顶显示先知知识的**十一个分级阶段**,渲染为从边缘向内上升的螺旋
阶梯。较低阶段对完善了理性和想象但尚未接受神圣流溢的哲学家是可达
的;较高阶段涉及与能动智性的越来越多的直接接触。每个阶段的具体身份
有意未在芯片中显示 — 《*困惑者指南*》II.45 作为文本权威列举它们。
在第十一阶段之上有一个(视觉上未表示的)第十二阶段:摩西的预言,
迈蒙尼德将其视为超越等级的特殊种类。

螺旋渲染器在 Phase ζ.2 专门添加,用于尊重不适合干净扇形几何的等级
N 步传统。

## 范围

**何时使用此传统。** 当你的内容具有真正分级的结构时(无论是字面关于
预言还是通过方法论类比 — 洞察的程度、掌握的阶段、沉思成就的层次)。
对中世纪犹太哲学内容和明确使用分级成就词汇的项目很有用。

**何时不使用此传统。** 当内容没有正确形状的等级结构时,11 步阶梯将在
视觉上占主导地位而不浮现有意义的模式。11 是高基数 — 大多数用户内容
会集中在一两个步骤。

## 适用性

- 中世纪犹太哲学和受法尔萨法影响的理性主义传统。
- 亚伯拉罕系宗教间预言的比较分析。
- 更普遍的分级成就框架(佛教 *bhūmis*、苏菲 *maqāmāt*) — 尽管这些
  不是策划基线的一部分。

## 谱系

12 世纪安达卢西亚-埃及犹太哲学。摩西·迈蒙尼德(拉姆巴姆,1138–1204)
在《*Moreh Nevukhim*》(困惑者指南)第二部分第 32–48 章中,将十一个
层次阐述为圣经先知材料与阿维森纳和亚里士多德哲学的综合。该等级在
其自己的时代是有争议的解读(迈蒙尼德受到来自理性主义和传统主义两侧
的攻击),并在中世纪犹太哲学学术中仍然是试金石。

## 批评

十一步等级预设了支撑它的中世纪亚里士多德心灵哲学(能动智性、想象的
完善作为预言的先决条件)。没有该框架的现代读者会发现这些步骤难以
激发动机。具体顺序在迈蒙尼德注释传统内也有争议。该等级也是哲学精英
导向的:"这位先知说的是真话吗?"这个实际问题没有被预言*如何*被接受
的等级处理。
