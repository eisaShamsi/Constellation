# 孟子 四端 (Mencian sprouts)

**家族**:东亚儒家 · **形状**:扇形(4 象限 + 可选中央 信 环)

## 核心隐喻

穹顶分为**四个象限**,每个象限对应孟子认定为每个人天生具有的道德
心之一端(*duān*):

- **恻隐 cèyǐn**(同情) → 绽放为 **仁 rén**(仁爱)
- **羞恶 xiūwù**(羞耻) → 绽放为 **义 yì**(义)
- **辞让 círàng**(谦让) → 绽放为 **礼 lǐ**(礼仪)
- **是非 shìfēi**(是非感) → 绽放为 **智 zhì**(智慧)

一个小的中央环承载汉代的添加:**信 xìn**(信实),第五种常德
(*wǔcháng* 五常)。扇区各位于 90°,从基本轴旋转 +π/4,清除垂直轴上
的 Stratum 标签 — 同样的 Longino 偏移。

"端"(萌芽)隐喻是该框架的核心:这些不是完成的美德,而是必须培养
的种子。可视化编码每条笔记倾向于哪个萌芽。

## 范围

**何时使用此传统。** 当处理道德心理内容、伦理人格发展或应用儒家伦理
时。对按笔记探索或例示哪种美德排序笔记、用于自我修养日志记录,以及
比较伦理很有用。

**何时不使用此传统。** 纯粹描述性的经验内容没有道德萌芽维度。该框架
也是强烈伦理规范的 — 对天生美德主张持怀疑态度的用户可能会觉得几何
有倾向性。

## 适用性

- 儒家伦理、美德伦理、人格形成写作。
- 跨传统的比较美德伦理。
- 使用四端检查清单的自我修养日志记录。

## 谱系

经典儒家。孟子(Mèngzǐ,约公元前 372–289 年),仅次于《论语》的第
二重要儒家经典,在《孟子》2A.6 — 著名的"小孩落井"段落 — 中阐述
了四端,其中作为同情天生而非后天习得的证据,提供了普遍的人类恐惧
反应。汉代将 *xìn* 添加为第五种美德产生了在后续儒家教育中成为标准
的 *wǔcháng*(五常)正典。

## 批评

天生萌芽论自荀子(公元前 3 世纪)以来一直是儒家内部争议,他主张相反
的观点 — 人性最初是恶的,美德是文化成就。现代批评者质疑四端是否在
*经验上*普遍或文化特定。汉代添加 *xìn* 也是并非所有解释者都接受的
教义动作;Constellation 将其作为可选中央环而非第五个扇区包括,以保
留孟子的四重和汉代的五重两种解读可用。
