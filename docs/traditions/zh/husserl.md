# Husserl

**家族**:现代西方 · **形状**:环(同心区域)

## 核心隐喻

穹顶分为**区域本体论的同心环** — Husserl 的主张,即每个*存在区域*都有
其独特的*先验*本质结构,区别于形式本体论(研究一般对象性的本质)。

Constellation 渲染使用四个环(Husserl 文本各异):

- **形式的** — 最内。对象性本身的本质。
- **物质自然** — 物理因果规律。
- **动物自然** — 心理生命结构。
- **精神** — 文化、主体间和历史形成。

每个环是一个具有自己本质法则的领域 — 你不能将精神还原为动物自然,
将动物自然还原为物质自然,或将它们中的任何一个还原为形式本体论。
环使这种*层化的不可还原性*可见。

## 范围

**何时使用此传统。** 当你的内容跨越几个本体论区域,并且你想看到给定
笔记居住在哪个区域时。对心灵哲学工作、生物学哲学,以及任何明确跨越
自然 / 生命 / 文化领域工作的项目很有用。

**何时不使用此传统。** 当你所有的内容都位于一个区域时 — 例如,完全
关于物理学的项目,或完全关于文化历史的项目 — 区域结构不提供对比。
也很苛求:区域本体论框架有陡峭的进入成本。

## 适用性

- 心灵哲学 / 生物学哲学 / 社会科学哲学。
- 跨本体论领域的跨学科研究。
- 现象学方法论及其应用。

## 谱系

德国现象学,创立一代。Edmund Husserl(1859–1938)在《观念 I》(1913)
中阐述了形式与区域的区分,作为他将现象学提供为科学基础学科项目的一
部分。区域本体论在 Husserl 文本中各异;Constellation 渲染使用常见的
四重版本(形式 + 物质自然 + 动物自然 + 精神),近似于《观念 II》的
呈现。

## 批评

Husserl 的区域本体论预设了他更广泛的超越论现象学,而这本身是有争议
的 — Heidegger 在《存在与时间》(1927)中的批评拒绝形式与区域的分割,
转而支持此在的基础本体论。四区域渲染也抽象掉了后期 Husserl 关于主体
间性、生活世界和历史性的工作,这些工作使任何干净的环结构复杂化。
