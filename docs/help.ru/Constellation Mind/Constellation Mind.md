# Constellation Mind (عقل Constellation)

## Что это?

Constellation Mind — это слой локальной большой языковой модели (LLM) в Constellation — ИИ-помощник, который знает вашу Вселенную и может говорить с вами о ваших заметках, **не отправляя ни одну из них в облако**.

Три вещи отличают его от любого другого инструмента «ИИ для заметок»:

1. **Локальный-первым.** Модель работает на вашем устройстве. Ваши заметки никогда его не покидают. Нет облачного обмена туда-обратно — чат локальный и работает в офлайн-режиме.
2. **Арабский-первым.** Поставляемая модель по умолчанию — **Fanar-1-9B**, арабо-центрическая, осведомлённая о суннитском контексте модель Катарского института вычислительных исследований (QCRI). Нативная компетенция в MSA и диалектах Залива; английский — второй язык, а не единственный.
3. **Привязанный к цитатам.** Каждое фактическое утверждение, которое ИИ делает о ваших заметках, должно цитировать заметку-источник. Галлюцинированные цитаты улавливаются валидатором после генерации (Фаза 1).

## Что выпускается сегодня (Фаза 0b — 2026-05-24)

- **Панель Настройки → Mind** — перечисляет устанавливаемые модели (в настоящее время только Fanar 1.9B Q4_K_M, ~5 ГиБ), с кнопкой Установить, которая скачивает и проверяет модель.
- **Установка модели** — фрагментированная загрузка из GitHub Release (без сторонних облаков), проверка SHA-256 на фрагмент и на собранное целое.
- **Реальная среда выполнения инференса** — `llama-cpp-2` (только CPU в v1) загружает GGUF Q4_K_M и передаёт токены.
- **Пока нет поверхности чата** — это Фаза 1 (следующая веха). Сегодня вы можете установить модель и проверить её; диалоговый UI приземляется в MIG-048.

## Как установить Fanar

1. Откройте **Настройки → Mind**.
2. Найдите **Fanar 1.9B (Q4_K_M)** в каталоге. Карточка показывает размер (5,01 ГиБ), лицензию (Apache-2.0 с защитными уведомлениями Gemma) и кнопку «Установить активной» или «Установить».
3. Нажмите **Установить**. Индикатор прогресса показывает загрузку + проверку SHA + сборку в три фазы.
4. Когда значок переключается на **Установлено** + **Активно**, модель готова. Fanar живёт в `<app-data>/Constellation/models/fanar-1-9b-q4km-v1.gguf` и поддерживается mmap (без копирования в RAM).

Вот и всё. Пока Фаза 1 не выпустит поверхность чата, установленная модель находится в режиме ожидания.

## Что придёт в Фазе 1 (следующая веха)

- **Поверхность чата** — панель Constellation, где вы разговариваете с Fanar о своей Вселенной на арабском или английском (с поддержкой RTL для каждого сообщения).
- **Инструменты чтения** — Mind может вызывать `search_notes`, `read_note`, `find_similar`, `list_recent`, чтобы основать свои ответы на ваших реальных заметках.
- **Валидатор цитат** — каждое утверждение цитирует реальную заметку; сфабрикованные ссылки `note:UUID` отклоняются до того, как достигнут вас.
- **Предварительный прогрев при запуске приложения** — Mind загружается в фоновом режиме, чтобы ваш первый чат не платил 10 секунд холодной загрузки.
- **История разговоров** — сохраняется по Вселенной; может быть повышена до Заметки.

См. `docs/Constellation-Mind-Concept-Paper-v1.1.md` для полной архитектуры и `docs/Constellation-Mind-Implementation-Plan-v1.0.md` для пофазной дорожной карты.

## Что придёт позже

- **Фаза 2 — Инструменты записи** (Mind предлагает правки / новые заметки / ссылки под вашим явным одобрением).
- **Фаза 2.5 — RoutedProvider + Jais** (вторая модель, Jais-2-8B от G42/MBZUAI, присоединяется к Fanar как со-умолчание; Mind маршрутизирует между ними на основе запроса).
- **Фаза 3 — Автоклассификация + умная связка** (Mind предлагает аспекты и ссылки при сохранении заметки).
- **Фаза 4 — Инструменты возможностей** (голос → заметка, OCR → заметка, перевод).
- **Фаза 5 — Подключение облака** (ваш собственный ключ Anthropic / OpenAI, с лимитом стоимости на Вселенную и журналом исходящего трафика на ход).

## Конфиденциальность и поток данных

- **Исходящий HTTP только при установке модели** — Constellation загружает файлы модели из [`models/*` GitHub Releases](https://github.com/eisaShamsi/Constellation/releases) этого репозитория. Без телеметрии. Без облачного инференса (пока — это Фаза 5, и только с вашим явным согласием).
- **На диске:** GGUF модели + реестр `installed_models.json`, отслеживающий, какие модели у вас есть и какая активна.
- **Во время выполнения:** загруженный файл модели отображается в память; ваши промпты и ответы существуют только в RAM.

## Лицензии

Каждая модель несёт свой LICENSE.txt рядом с собой в GitHub Release. Для Fanar:

- **Лицензия Apache 2.0** (лицензия, заявленная QCRI в репозитории Fanar-1-9B-Instruct).
- **Условия использования Gemma** — Fanar — это продолжающееся предварительное обучение `google/gemma-2-9b`; Constellation отправляет уведомления Gemma защитно, даже если QCRI переклассифицирует результат только как Apache-2.0.
- **Цитирование Fanar** (Fanar Team 2025, arXiv:2501.13944).
- **Уведомление о повторном распространении Constellation** — GGUF в GitHub Release Constellation является квантизацией upstream safetensors от QCRI, произведённой `.github/workflows/model-pipeline.yml` и распространяемой под Apache-2.0 с сопровождающим оригинальным LICENSE.

Полный LICENSE.txt живёт рядом с каждой моделью в её релизе: <https://github.com/eisaShamsi/Constellation/releases/tag/models/fanar-1-9b-q4km-v1>.

## Устранение неисправностей

**Значок «Ещё не готов» вместо кнопки Установить.** В поставляемом каталоге есть SHA-256 заполнитель для этой модели. Это не должно происходить при обычной установке Constellation; если вы это видите, каталог не обновлён для этой версии модели. Откройте issue.

**Установка зависает на «Загрузка части X/Y».** Проблема сети. Отмените из Настройки → Mind, повторите установку — частичные фрагменты автоматически очищаются.

**Установка успешна, SHA-256 файла не совпадает.** Бит-флип при загрузке. Переустановка получит свежий файл.

**Поверхность чата отсутствует.** Фаза 1 (MIG-048) ещё не выпущена. Модель сегодня можно установить и проверить; диалоговый UI приземлится в следующем релизе.
