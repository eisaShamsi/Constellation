# Constellation Sight

## Что это?

**Constellation Sight** — это **диагностический инструмент** для вашей вселенной знаний. Центральный **якорный купол** показывает каждую заметку, позиционированную по **страту** (глубине мышления) и **времени** (когда написано), с четырьмя **мини-куполами** рядом, перекодирующими ту же вселенную через разные каналы: **Уверенность**, **Стадия**, **Действия**, **Происхождение**.

Отвечает на один вопрос пятью дополняющими линзами: **«Как сформирован и организован мой эпистемический контент?»**

Наведите курсор на любую звезду в любом куполе, и та же заметка засветится во всех пяти поверхностях — золотое кольцо вокруг звезды, золотой оттенок на соответствующих чипах боковой панели. Кликните чип в боковой панели — все пять видов сузятся. Shift+клик по звезде в мини-куполе Stage мгновенно фильтрует вселенную к этой стадии жизненного цикла.

## Почему это важно?

Большинство приложений для заметок показывают что вы написали. Constellation Sight показывает **форму** того что вы знаете.

- Где **сконцентрировано** ваше мышление? (градиент плотности в якоре)
- Что ещё в **раннем стадии** vs **стабильный фундамент**? (градиент цвета мини Stage)
- Какие заметки **несущие** vs **изолированные**? (кодирование размера мини Acts)
- Откуда пришла каждая идея — собственное мышление, чтение, услышанное, традиция? (секторная компоновка мини Provenance)
- Насколько **уверены** в своих выводах? (градиент непрозрачности мини Confidence)

Заметка в центре якоря (высокая связность ← несущая) но в циане в мини Stage (`spark` — только что искрилась) говорит вам нечто диагностическое: несущая идея, ещё не созревшая.

## Как открыть

1. Кликните **иконку глаза** в доке слева от Constellation.
2. Якорный купол рендерится за 2–5 секунд для большинства вселенных.
3. Закрыть: кликните **(×)** справа вверху, или нажмите **Esc**.

## Что вы видите

### Полоса заголовка

Верх вида Sight, слева направо:
- **«Constellation Sight»** — заголовок.
- **«v6.1 — Coordinated Views (Phase 2)»** — подзаголовок версии.
- **Значок «X / Y notes»** золотой — виден только при активном фильтре.
- **Значок «EXTENDED»** золотыми малыми прописными — виден только при включённом Расширенном виде.
- **Кнопка «Reset View»** — видна только когда раскладка изменена.
- **(×)** кнопка закрытия — всегда присутствует.

### Якорный купол (Основной слот)

Большой кремово-на-тёмном купол в центре:
- **Кольца страт** — 5 концентрических кругов. Внутреннее = ваши самые фундаментальные заметки; внешний край = ваши новейшие искры.
- **Календарная кромка** — 12 меток месяцев снаружи.
- **Метки страт** — курсивный текст вверху.
- **Звёзды** — каждая заметка как маленькая кремовая точка, позиционированная по страту × времени.
- **Линии связи** — рёбра типизированных ссылок между заметками, низкая непрозрачность под звёздами.
- **Кольцо наведения** — золотой круг вокруг звезды, на которую наведён курсор.

### Четыре мини-купола

Правая сторона, сетка 2×2. Скрыты по умолчанию; раскрываются **Ctrl+D** (только сессия) или **Ctrl+Shift+D** (постоянно — см. Расширенный вид).

Каждый мини рендерит ту же вселенную через одно кодирование:

1. **CONFIDENCE — непрозрачность.** Более уверенные заметки ярче; пробные затухают.
2. **STAGE — цвет (полный диск).** Категорический цвет по стадии жизненного цикла:
   - **Голубой** = `spark` (только-что-искрившаяся идея)
   - **Оранжевый** = `birth` (принимающая форму)
   - **Фиолетовый** = `growth` (в активном движении)
   - **Зелёный** = `maturity` (полностью сформированная)
   - **Жёлтый** = `renewal` (недавно пересмотренная)
   - **Серый** = `dormancy` / `archival` (неактивная / закрытая)
3. **ACTS — размер (верхний дециль).** Топ 10% по числу ссылок = большие точки; остальное маленькое.
4. **PROVENANCE — 5 секторов.** Звёзды перепозиционированы в 5 угловых секторов: **Self / Read / Heard / Reasoned / Tradition**.

### Сниженный якорь (когда мини повышен)

Если вы повышаете любой мини в основной слот, якорь опускается в освободившийся мини-слот. Там он рендерится как **нейтральные кремовые точки** с заголовком **«UNIVERSE — primary view»**.

### Боковая панель фасетов (левый край)

Сворачиваемая панель с **6 группами фильтров фасетов**, каждая показывает категории с живыми счётчиками:

- **Folder** — иерархия папок
- **Library** — имена библиотек
- **Stratum** — Foundation / Roots / Trunk / Branches / Twigs / Edge of Knowing
- **Confidence** — Hypothesis / Evidence / Established / Contested
- **Stage** — Spark / Birth / Growth / Maturity / Dormancy / Renewal / Archival
- **Provenance** — Self / Read / Heard / Reasoned / Tradition

Кликните **▶** на краю для расширения. Кликните любой чип для переключения фильтра.

## Взаимодействие

| Жест | Эффект |
|---|---|
| **Наведение на звезду** | Золотое кольцо на той же звезде во всех 5 поверхностях + соответствующие чипы золотистый оттенок. |
| **Обычный клик по звезде** | Открывает заметку в редакторе. Появляется кнопка **«Return to Sight»**. |
| **Shift+клик по звезде** в Stage / Confidence / Provenance мини | Переключает фильтр на категорию этой звезды. |
| **Shift+клик по звезде** в Acts или якоре | Нет эффекта. |
| **Клик на пустую область мини** | Этот мини повышается в основной слот. |
| **Зум колесом (основной)** | Зум к курсору. Диапазон: 0.5× до 24×. |
| **Клик+перетаскивание** | Pan вида. |
| **Ctrl+0 / Cmd+0** | Сброс зума + pan. |
| **Ctrl+D / Cmd+D** | Переключение видимости мини-куполов — **только сессия**. |
| **Ctrl+Shift+D / Cmd+Shift+D** | Переключение **Расширенного вида** — постоянно. |
| **Клик на чип боковой панели** | Переключение категории фасета в наборе фильтров. |
| **Кнопка Reset View** | Возврат к основному якорю на зум 1.0. |
| **Esc** | Закрывает Sight. |

## Режим Призрака — Множественный выбор из купола

Когда любой фильтр активен, несоответствующие звёзды остаются видимыми, но рендерятся с **низкой непрозрачностью (15%)** вместо исчезновения. Это значит:

- Вы всё ещё можете ВИДЕТЬ где несоответствующие звёзды.
- Можете наводить на них (золотое кольцо появляется).
- Можете **Shift+клик чтобы ДОБАВИТЬ их категорию в фильтр**.

## Режим плотности

Когда количество видимых (соответствующих) звёзд превышает порог плотности (по умолчанию **5,000**), мини-купола переключаются на **перцептуальный рендеринг плотности**.

## Расширенный вид

Нажатие **Ctrl+Shift+D** (или **Cmd+Shift+D** на Mac) переключает «Расширенный вид» — когда включён, мини-купола видны по умолчанию каждый раз при открытии Sight. Состояние сохраняется через закрытия Sight, перезапуски приложения и системы.

## Когда Sight наиболее полезен

- **Аудит формы знания** — открыть Sight после сессии написания.
- **Найти слепые пятна** — секторы купола с малым количеством заметок могут быть областями для исследования.
- **Выявить несущую слабость** — центрально позиционированная заметка в раннем-стадии цвете.
- **Фильтровать и инспектировать** — Shift+клик сужает вселенную; повысьте мини для изучения канала в полном размере.
- **Отслеживать эпистемическое происхождение** — повысьте Provenance чтобы увидеть как ваше знание происходит.

## Связанные поверхности

- **Constellation Nervous System (CNS)** — дополняющая визуализация (иконка нейрона рядом с глазом Sight).
- **Constellation Map** — солнечно-лучевая визуализация.
- **Sky View** — графовая визуализация ссылок.
- **Панель Index** — браузер терминов.
