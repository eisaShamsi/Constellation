# Внешний вид и темы

Внешний вид Constellation управляется из **Настроек**:

1. **Внешний вид** — выберите или создайте тему, импортируйте темы из реестра сообщества Obsidian, задайте выравнивание заголовка и жизненный цикл живых ссылок.
2. **Настройщик стиля (Style Setter)** — собственная вкладка в боковой панели Настроек, и теперь это **единственный дом для всей стилизации**: каждый цвет, размер, шрифт и элемент оболочки интерфейса и редактора, цвета типов ссылок и сохранённые стили. (Прежняя вкладка **Style Settings** упразднена и полностью влита в него.)

Вместе они позволяют преобразовать приложение под ваш рабочий процесс, размер экрана и личный вкус — без единой строки CSS.

## Темы

**Тема** — это именованный набор цветов, настроек и CSS, определяющий внешний вид Constellation. Constellation поставляется с шестью встроенными темами (Constellation Light/Dark, Nord Light/Dark, Solarized Light/Dark), все в парах светлая/тёмная.

### Выбор темы

1. Откройте **Настройки → Внешний вид**.
2. Щёлкните любую карточку в сетке **Темы**. Тема применяется немедленно.
3. Активная карточка выделена акцентной рамкой.

### Создание пользовательской темы

1. В сетке тем щёлкните карточку с пунктиром **+ Новая тема**.
2. Задайте имя, выберите светлую или тёмную и выберите пять цветов (фон, поверхность, текст, акцент, граница).
3. Щёлкните **Сохранить**. Ваша тема появится в сетке.

Все остальные переменные (hover-состояния, тени, приглушённый текст) выводятся автоматически из ваших пяти цветов с помощью HSL-математики, так что вы контролируете только главное.

### Редактирование или удаление пользовательской темы

Наведите курсор на любую карточку пользовательской темы:
- **✏️ (карандаш)** — открывает редактор для изменения имени, типа или пяти основных цветов.
- **✕ (красный X)** — удаляет тему после подтверждения. Встроенные темы нельзя удалить. Если удалить активную тему, Constellation вернётся к теме по умолчанию.

### Импорт темы сообщества Obsidian

Щёлкните **🟣 Темы Obsidian**, чтобы просмотреть более 200 тем сообщества:
1. Ищите по имени или автору.
2. Щёлкните **Предпросмотр**, чтобы увидеть макет и палитру из пяти цветов.
3. Щёлкните **Импорт** — CSS темы загружается, адаптируется для Constellation (shim селекторов + извлечение переменных + цвета синтаксиса CodeMirror) и добавляется в ваши пользовательские темы.
4. Если тема поддерживает **Style Settings**, количество отображается на её карточке; эти опции появляются в **Настройщике стиля** после импорта.

## Style Settings → теперь внутри Настройщика стиля

> **Примечание:** отдельная вкладка **Style Settings** упразднена. Каждый её элемент управления теперь живёт внутри **Настройщика стиля** (его собственная вкладка в боковой панели Настроек) — который охватывает их все и сверх того (путь навигации, сводку заметки, панель Вселенной, шрифты для каждой системы письма). Описание ниже — это та самая поверхность стилизации, которая теперь открывается через Настройщик стиля.

Поверхность стилизации — это родная, независимая от темы панель управления Constellation. Она охватывает каждый видимый элемент оболочки плюс редактор и работает с любой темой (встроенной, пользовательской или импортированной).

### Как организовано

Разделы свёрнуты по умолчанию. Щёлкните шеврон, чтобы развернуть:

- **Constellation — Цвета** — фон и поверхности, текст, акцент
- **Constellation — Типографика** — размеры шрифтов интерфейса/заметки/кода, размеры H1–H6, вес заголовков, межстрочные интервалы, расстояние между абзацами
- **Constellation — Макет и форма** — углы (малый/средний/большой радиусы), ширина границ, тени, длина строки редактора, боковые поля
- **Constellation — Компоненты** — лента-док, боковая панель действий, панель макета (переключатели панелей), верхняя панель/полоса вкладок, строка состояния, проводник файлов, правая боковая панель, кнопки, теги, callout
- **Constellation — Редактор** — ссылки, код и блоки, цитата, курсор и выделение

### Изменение значения

- **Палитры цветов** — щёлкните образец, выберите цвет. Hex показывается рядом.
- **Ползунки** — перетаскивайте для настройки. Числовое значение отображается в единице (px, %, и т. д.).
- **Переключатели** — щёлкните для включения/выключения классов (в основном для импортированных тем).
- **Выпадающие списки** — выберите опцию (стиль оформления ссылки и т. д.).
- **Стрелка сброса (↺)** — появляется при наведении в конце каждой строки. Щелчок очищает ваше переопределение и восстанавливает значение по умолчанию темы.

### Как работает сохранение

- Изменения автоматически сохраняются в **styleSettingsValues** активной темы.
- Если вы меняете Style Setting при активной встроенной теме, Constellation **автоматически клонирует** встроенную в ваши пользовательские темы (как `{Имя} (custom)`), затем сохраняет изменения туда. Встроенная остаётся нетронутой.
- Метка **Сохранено в:** внизу показывает, какая тема сейчас содержит ваши переопределения.
- Щёлкните **Сбросить всё к значениям по умолчанию**, чтобы стереть все переопределения в активной теме.

### Импорт / Экспорт Style Settings

Панель инструментов в верхней части этой поверхности:

- **📋 Вставить из буфера обмена** — один клик: читает буфер обмена и объединяет валидный JSON в активную тему.
- **⬆️ Импорт / Вставить** — открывает текстовое поле; вставьте JSON вручную. Выберите **Объединить** (добавить/переопределить) или **Заменить всё** (стереть, использовать только вставленное).
- **📄 Из файла** — откройте файл `.json`, экспортированный из плагина Style Settings Obsidian или другой установки Constellation.
- **📋 Копировать** — копирует текущие значения в буфер обмена в виде форматированного JSON.
- **⬇️ Экспорт** — сохраняет значения как `{theme-name}-style-settings.json`.

Формат JSON точно соответствует плагину Style Settings Obsidian — плоский объект, сопоставляющий ID настроек со строковыми значениями:

```json
{
  "h1-size": "36",
  "interactive-accent": "#7c3aed",
  "my-themed-color@@light": "#ffffff",
  "my-themed-color@@dark": "#1e1e2e"
}
```

Это значит, вы можете скопировать Style Settings из Obsidian и вставить их прямо в Constellation или наоборот.

## Что вы можете контролировать

Каждая настройка принадлежит одному из пяти блоков выше. Основные:

### Типографика

- **Размер шрифта интерфейса** — боковая панель, панели инструментов, меню
- **Размер шрифта заметки** — основной текст в редакторе
- **Размер шрифта кода** — строчный код и блоки кода
- **Размеры H1 – H6** — каждый уровень заголовка индивидуально
- **Вес заголовков** — лёгкость или жирность всех заголовков
- **Межстрочные интервалы** — обычный (основной) и плотный (заголовки и плотный UI)
- **Расстояние между абзацами** — промежуток между абзацами

### Компоненты оболочки

- **Лента-док (иконки слева)** — ширина, размер кнопки, размер иконки, радиус, цвета
- **Боковая панель действий** — иконки новая заметка/таблица/папка — размер, цвет, высота, фон
- **Панель макета (переключатели панелей)** — переключатели левой/разделённой/правой боковой панели — размер кнопки, размер иконки, цвета, цвет активного состояния
- **Верхняя панель / полоса вкладок** — видна, только когда заметки открыты во вкладках; управляет высотой полосы, фоном, высотой/шрифтом/радиусом вкладки, цветами активной и неактивной вкладок
- **Строка состояния** — высота, размер шрифта, фон, цвет текста
- **Правая боковая панель (инспектор)** — фон, высота строки вкладок, размер иконки вкладки, цвета
- **Проводник файлов (левая боковая панель)** — строка заметок Вселенной, строки дочерних вселенных (cUniverse), имена библиотек, папки, заметки — каждое с независимым размером, весом и цветом; плюс вертикальное расстояние строк

### Редактор

- **Размеры заголовков** (H1–H6) и вес
- **Межстрочный интервал** в тексте заметки
- **Строчный код** фон, цвет текста, радиус, размер шрифта
- **Цвет ссылки** (по умолчанию + hover) и стиль оформления (нет/подчёркивание/пунктир)
- **Ширина полосы callout** и **радиус callout**
- **Цвет курсора** и **фон выделения**

### Цвета (каждый цвет в приложении)

- Фон (основной/альт), поверхности, фон hover, границы, фон ввода
- Текст (обычный/приглушённый/слабый/на акценте), состояния ошибка/предупреждение/успех
- Акцент (интерактивный акцент + hover), текст на акценте

## Настройщик стиля (Style Setter)

**Настройщик стиля** — это **единственный дом для всей стилизации** — дизайн-студия на всю страницу для всего вашего интерфейса. Вместо того чтобы менять настройки по одной и представлять себе результат, вы видите своё настоящее приложение, которое обновляется мгновенно, пока вы оформляете.

**Как открыть:** нажмите вкладку **Настройщик стиля** (✦) в боковой панели Настроек; либо нажмите значок **прицела (✛)** над шестерёнкой Настроек в ленте-доке, чтобы сразу войти в режим осмотра (наведите курсор на любую часть приложения и нажмите её, чтобы стилизовать). Панель можно менять в размере.

Элементы управления организованы в **категории** слева: **Интерфейс** (дерево файлов, строка состояния, панель Вселенной), **Компоненты** (лента-док, панели инструментов, вкладки, кнопки, теги), **Редактор** (заметка — путь навигации, заголовки, ссылки, код, цитата, а также сводка заметки с её цветом, шрифтом и размером), **Общее** (оттенки, акцент, углы, шрифты для каждой системы письма) и **Ссылки** (цвета типов ссылок и их ширина). Внизу появляются **ваши сохранённые стили** для применения одним нажатием.

**Два способа увидеть ваши правки.** Категория **Редактор** показывает **предпросмотр заметки по центру** — нажмите заголовок, ссылку или страницу, и его элементы управления появятся справа и обновятся мгновенно. А **остальные категории** прижимают панель к одной стороне и делают её полупрозрачной, так что ваши правки видны **на настоящем приложении вживую** (на это указывает зелёная метка **● live**): измените цвет строки состояния или ширину ленты-дока — и вы увидите, как реальная оболочка стилизуется, пока вы тянете ползунок.

**Ссылки.** Категория «Ссылки» показывает каждый тип как **«таблетку» (pill)** в его настоящем цвете — нажмите таблетку, чтобы перекрасить её (сразу везде) — вместе с переключателями **раскраски ссылок** и **показа подписей**, **формой таблетки** и многоразовой палитрой **сохранённых цветов**.

**Сохраните ваш облик.** Нажмите **Keep**, чтобы сохранить облик **для этой Вселенной** (он сохраняется после перезапуска); либо **Discard** (или **✕** / **Esc**), чтобы отбросить несохранённые правки — тогда приложение вернётся к прежнему виду; либо **Reset**, чтобы вернуться к простой теме. Ничего не сохраняется на диск, пока вы не нажмёте Keep.

**Переиспользуйте облик — сохраните как стиль.** Впишите имя в поле «draft:» вверху списка и нажмите **+ Save current as a style** — он появится в списке **Сохранённых стилей** (внизу слева), действует на уровне всех Вселенных и захватывает именно тот облик, который вы создали в Настройщике, а не просто тему. Нажмите сохранённый стиль, чтобы применить его; наведите курсор на его строку для **↻ обновить**, **⤓ экспорт**, **✎ переименовать** и **✕ удалить**. (Встроенные темы остаются в **Настройках → Внешний вид**; Настройщик хранит ваши сохранённые стили и живой облик.)

## Частые вопросы

### Могу ли я стилизовать заголовок окна Windows («Constellation v0.3.4 — …»)?

Нет — эта полоса отрисовывается операционной системой (Windows/macOS/Linux). У Constellation нет CSS-доступа к ней. Всё ниже полностью стилизуемо.

### Как изменить ширину боковой панели?

Ширина боковой панели управляется **маркером перетаскивания** на её крае (перетащите для изменения) — а не ползунком. Ползунок ширины убрали из Настройщика стиля намеренно, потому что он дублировал маркер перетаскивания (во избежание конкурирующих источников истины).

### Где живёт моя стилизация?

То, что вы сохраняете кнопкой **Keep** в Настройщике стиля, хранится **для каждой Вселенной** (переопределение облика на уровне Вселенной) в её настройках, поэтому оно путешествует вместе с директорией Вселенной — если вы синхронизируете её между устройствами, ваша стилизация приходит с ней. А **сохранённые стили** действуют на уровне всех Вселенных.

### Могу ли я поделиться темой с кем-то?

Да:
- **Полная тема** — в редакторе тем щёлкните **Экспорт**. Поделитесь файлом `.json`. Получатель нажимает **↓ Импорт** в сетке тем и выбирает его.
- **Сохранённый стиль** — в **Настройщике стиля** наведите курсор на строку сохранённого стиля и нажмите **⤓ Экспорт**, чтобы поделиться им как файлом `.constellation-style.json` (только облик — без секретов и путей). Получатель нажимает **Import…** в списке стилей, чтобы добавить его.

### Импортированная тема Obsidian выглядит сломанной. Что теперь?

Темы Obsidian могут быть сложными. Известные случаи:
- Темы, использующие **HSL-разделённые цвета** (например, Minimal) — поддерживаются в Constellation с этого релиза.
- Темы, зависящие от специфической DOM-структуры Obsidian, могут отображаться частично. Constellation включает класс-shim, который сопоставляет самые распространённые селекторы, но очень структурные темы могут потребовать коррекции пяти основных цветов или ручной настройки значений Style Settings.
