# Руководство пользователя Constellation

**Версия 0.3.4 | Март 2026**

Constellation — это настольное приложение для управления личными знаниями (PKM), предназначенное для работы с библиотеками заметок в формате Markdown. Создано на основе Tauri v2, SvelteKit и Rust, работает нативно на Windows, macOS и Linux с полной поддержкой арабского языка и RTL.

## 1. Начало работы

### Установка

Скачайте последнюю версию установщика со [страницы релизов Constellation](https://github.com/eisaShamsi/Constellation/releases):

- **Windows**: установщик `.exe` (NSIS) или `.msi`
- **macOS**: образ диска `.dmg`
- **Linux**: `.AppImage` или пакет `.deb`

### Первый запуск

При первом открытии Constellation **Мастер настройки Вселенной** проведёт вас через следующие шаги:

1. **Выберите язык** — поддерживается 15 языков
2. **Создайте или импортируйте библиотеку** — укажите существующую папку с Markdown-файлами или начните с нуля
3. **Назовите вашу вселенную** — вселенная является контейнером для всех ваших библиотек

### Обзор интерфейса

| Элемент | Описание |
|---------|----------|
| **Боковая панель (лента)** | Кнопки навигации: дерево файлов, поиск, Star View, календарь, шаблоны, настройки |
| **Дерево файлов** | Просмотр заметок и папок в библиотеках |
| **Редактор** | Чтение и редактирование Markdown-заметок |
| **Панель вкладок** | Открытие нескольких заметок во вкладках |
| **Строка состояния** | Количество слов, символов, время чтения |

## 2. Вселенная и библиотеки

### Что такое Вселенная?

**Вселенная** — это контейнер верхнего уровня, содержащий все ваши библиотеки. Представьте её как рабочее пространство или коллекцию библиотек.

### Что такое Библиотека?

**Библиотека** — это папка на вашем компьютере, содержащая файлы Markdown (`.md`). В одной вселенной может быть несколько библиотек — например, одна для рабочих заметок, другая для личных.

### Управление библиотеками

- **Добавить библиотеку**: Настройки > Библиотеки > Добавить библиотеку, или перетащите папку в приложение
- **Удалить библиотеку**: Настройки > Библиотеки > нажмите кнопку удаления рядом с названием библиотеки
- **Настройки библиотеки**: Каждая библиотека может иметь собственные настройки внешнего вида (шрифты, цвета)

### Дочерние вселенные

Вселенные можно вкладывать друг в друга. **Дочерняя вселенная** — это папка другой вселенной, на которую ссылается родительская. Заметки из дочерних вселенных отображаются в Star View вместе с вашими собственными заметками, а межбиблиотечные ссылки показываются пунктирными линиями.

## 3. Создание и редактирование заметок

### Создание заметки

| Способ | Действие |
|--------|----------|
| **Клавиатура** | `Ctrl+N` |
| **Дерево файлов** | Правый клик по папке > Новая заметка |
| **Mission Control** | `Ctrl+P` > "New note" |

### Режимы редактора

Constellation предлагает два режима редактора, выбираемых в разделе **Настройки > Редактор > Тип редактора**:

#### Markdown-редактор (CodeMirror)

Редактор по умолчанию для опытных пользователей. Пишите Markdown напрямую:

- **Живой предпросмотр** — отображает форматирование прямо при наборе текста
- **Режим исходного кода** — показывает необработанный синтаксис Markdown
- **Панель форматирования** — появляется при выделении текста
- **Слэш-команды** — введите `/` для быстрых вставок
- **Автодополнение Wikilink** — введите `[[` для связывания заметок
- **Множественные курсоры** — `Alt+Click` или `Ctrl+D`

#### Документный редактор (TipTap)

WYSIWYG-редактор с визуальной панелью инструментов:

- Полужирный, курсив, подчёркивание, зачёркивание, выделение
- Заголовки (H1–H3), выравнивание текста
- Маркированные списки, нумерованные списки, списки задач
- Цитаты, блоки кода, горизонтальные линии
- Таблицы (вставка, добавление/удаление строк и столбцов)
- Ссылки и изображения

Оба редактора сохраняют файлы в стандартном формате Markdown. Переключаться между ними можно в любой момент без потери данных.

### Выноски (Callouts)

Создавайте стилизованные блоки выносок для заметок, предупреждений, советов и других указаний:

```markdown
> [!note] Важная информация
> Содержимое выноски размещается здесь.

> [!warning] Будьте осторожны
> Это действие нельзя отменить.

> [!tip]- Нажмите для раскрытия
> Сворачиваемое содержимое выноски.
```

Поддерживаемые типы: `note`, `tip`, `warning`, `danger`, `success`, `question`, `failure`, `bug`, `example`, `quote`, `abstract`. Каждый тип имеет свой цвет и значок. Добавьте `-` после типа, чтобы сделать его сворачиваемым (начинает свёрнутым), или `+` (начинает развёрнутым).

### Синтаксис выделения

Оберните текст двойными знаками равенства для выделения:

```markdown
Это ==выделенный текст== в вашей заметке.
```

В режиме живого просмотра метки `==` скрываются, и текст отображается с жёлтым фоном.

### Блоки кода

Ограждённые блоки кода отображаются с цветом фона и меткой языка:

````markdown
```javascript
const greeting = "Hello, world!";
```
````

Название языка отображается в виде бейджа над блоком кода.

### Встраивание изображений

Встраивайте изображения непосредственно в свои заметки:

```markdown
![Альтернативный текст](https://example.com/image.png)   — внешний URL
![[photo.jpg]]                                              — локальный файл из библиотеки
```

В режиме живого просмотра изображения отображаются в строке. Локальные изображения должны находиться в папке вашей библиотеки. Внешние изображения требуют подключения к интернету.

### Панель инструментов таблицы

Когда курсор находится внутри markdown-таблицы, появляется плавающая панель инструментов с:

- **+ Строка / + Столбец** — добавить строки или столбцы
- **- Строка / - Столбец** — удалить строки или столбцы
- **Выравнивание** — выравнивание по левому краю, по центру или по правому краю для каждого столбца
- **Сортировка** — сортировка строк по возрастанию или убыванию по текущему столбцу
- **Tab / Shift+Tab** — навигация между ячейками таблицы

### Сочетания клавиш для форматирования текста

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+B` | Полужирный |
| `Ctrl+I` | Курсив |
| `Ctrl+Shift+S` | Зачёркивание |
| `Ctrl+Shift+H` | Выделение |
| `Ctrl+K` | Вставить wikilink |
| `Ctrl+Z` | Отменить |
| `Ctrl+Shift+Z` | Повторить |

### Связывание заметок

Введите `[[`, чтобы открыть автодополнение заметок. Начните вводить название заметки и выберите из предложений. Ссылки отображаются как кликабельные wikilink-ссылки: `[[Note Name]]`.

Также можно ссылаться на конкретные заголовки: `[[Note Name#Heading]]`.

## 4. Star View (GraphMind)

Star View визуализирует ваши заметки в виде интерактивного 3D-графа на основе движка **GraphMind** (Pixi.js WebGL).

### Открытие Star View

- Нажмите на значок графа в боковой панели
- Нажмите `Ctrl+G`
- Mission Control (`Ctrl+P`) > "Star View"

### Навигация

| Ввод | Действие |
|------|----------|
| **Клик + перетаскивание** | Перемещение графа |
| **Прокрутка** | Увеличение/уменьшение |
| **Клик по узлу** | Открыть заметку |
| **Правый клик по узлу** | Контекстное меню (Открыть, Фокус, Закрепить, Скрыть) |
| **Средняя кнопка + перетаскивание** | Вращение в 3D |
| **W/A/S/D** | Полёт в 3D-пространстве |
| **0** | Сброс вращения к 2D |
| **Ctrl+F** | Поиск и выделение |
| **Space** | Переключение режима фокуса |

### Режимы компоновки

Нажмите `Ctrl+L` для переключения между:

- **Органический** — силовая компоновка, при которой кластеры формируются естественно
- **Иерархический** — древовидная компоновка сверху вниз
- **Хронологический** — заметки располагаются по дате создания на временной шкале

### Режим фокуса

Правый клик по узлу > **Фокус**, чтобы видеть только его окружение. Настройте:

- **Глубина** (1–5 переходов) — сколько уровней связей показывать
- **Направление** (↔/←/→) — все ссылки, только входящие или только исходящие

### 3D-навигация

Зажмите среднюю кнопку мыши и перетаскивайте для вращения. Используйте W/A/S/D/Q/E для полёта по звёздному полю. Индикатор осей XYZ в углу показывает вашу ориентацию. Нажмите `0` для сброса.

### Настройки

Нажмите на значок шестерёнки:

- **Внешний вид**: Размер узлов, видимость меток, размер шрифта, толщина связей, показать изолированные
- **Физика**: Сила отталкивания, сила связей, расстояние связей
- **AI**: Порог семантических связей (Фаза 2)

### Легенда

Легенда в правом нижнем углу показывает цвета библиотек/папок с флажками для переключения видимости.

### Страты знаний

Star View автоматически классифицирует ваши заметки по восьми стратам знаний в зависимости от уровня абстракции:

| Страта | Описание |
|--------|----------|
| **Снимок** | Быстрые, мимолётные заметки |
| **Журнал** | Датированные события и дневниковые записи |
| **Тема** | Атомарные концепции об одной идее |
| **Карта** | Организационные заметки, связывающие другие темы |
| **Фреймворк** | Модели и мыслительные рамки |
| **Принцип** | Проверенные правила и аксиомы |
| **Убеждение** | Базовые ценности и убеждения |
| **Артефакт** | Завершённые, окончательные работы |

Страта определяется автоматически на основе frontmatter, структуры и ссылок заметки. Вы можете переопределить классификацию вручную, добавив свойство `stratum` в frontmatter.

### Жизненный цикл зрелости

Каждая заметка проходит жизненный цикл зрелости, отражающий степень её развития:

- **Семя** — Начальная идея или черновой набросок
- **Саженец** — Заметка начинает обретать форму и имеет несколько ссылок
- **Вечнозелёная** — Зрелая, проверенная и хорошо связанная заметка
- **Каноническая** — Окончательный, авторитетный справочник в своей области

Уровень зрелости обновляется автоматически на основе количества ссылок, даты ревизии и частоты редактирования. Вы также можете установить его вручную через свойство `maturity` в frontmatter.

## 5. Второй экран

Откройте отдельное окно для параллельного просмотра заметок.

- **Открыть**: Нажмите на значок второго экрана в боковой панели или `Ctrl+Shift+N`
- **Синхронизация**: Заметки на втором экране открываются независимо. Настройки шрифтов и темы применяются к обоим окнам.
- **Ширина заметки**: Регулируется ползунком ширины на панели инструментов

## 6. Свойства и Frontmatter

Заметки могут содержать YAML frontmatter в начале:

```yaml
---
tags: [project, active]
date: 2026-03-19
status: in-progress
---
```

Constellation автоматически определяет типы свойств:

| Тип | Пример |
|-----|--------|
| **Текст** | `author: John` |
| **Число** | `priority: 5` |
| **Дата** | `date: 2026-03-19` |
| **Список** | `tags: [a, b, c]` |
| **Флажок** | `done: true` |
| **Ссылка** | `related: [[Other Note]]` |

Переключите отображение свойств в разделе **Настройки > Редактор > Свойства в документе** (Видимые / Скрытые / Исходный код).

## 7. Шаблоны

Создавайте многоразовые шаблоны заметок:

1. Создайте папку для шаблонов в вашей библиотеке
2. Укажите путь к папке шаблонов в разделе **Настройки > Шаблоны**
3. При создании новой заметки выберите шаблон из средства выбора шаблонов

Шаблоны поддерживают переменные:

| Переменная | Заменяется на |
|------------|---------------|
| `{{date}}` | Текущая дата |
| `{{time}}` | Текущее время |
| `{{title}}` | Название заметки |
| `{{clipboard}}` | Содержимое буфера обмена |

## 8. Таблицы

### Markdown-таблицы

Введите Markdown-таблицу вручную или используйте слэш-команду `/table`:

```markdown
| Header 1 | Header 2 |
|----------|----------|
| Cell 1   | Cell 2   |
```

### Панель инструментов таблицы

Когда курсор находится внутри таблицы, появляется плавающая панель инструментов с:

- Добавление/удаление строк и столбцов
- Выравнивание столбцов (по левому краю, по центру, по правому краю)
- Навигация по ячейкам с помощью `Tab` / `Shift+Tab`

### Таблицы в документном редакторе

Документный редактор (TipTap) предоставляет визуальный опыт работы с таблицами:

- Нажмите кнопку таблицы для вставки
- Используйте выпадающее меню для управления строками/столбцами
- Измените ширину столбцов перетаскиванием границ

## 9. Задачи

Constellation поддерживает флажки задач в заметках:

```markdown
- [ ] Невыполненная задача
- [x] Выполненная задача
```

В режиме живого предпросмотра флажки кликабельны. Задачи можно искать и фильтровать по всем библиотекам.

## 10. Импортёр

Импортируйте заметки из других PKM-инструментов:

- **Obsidian** — импорт хранилищ с полной совместимостью wikilink
- **Папки Markdown** — импорт любой папки с файлами `.md`

## 11. Календарь

Представление «Календарь» показывает заметки, упорядоченные по датам:

- Заметки со свойством `date` отображаются в соответствующие дни
- Для любой даты можно создать ежедневную заметку
- Переключение между месяцами с помощью кнопок-стрелок

Откройте календарь из боковой панели.

## 12. Линза

Линза предоставляет отфильтрованные представления ваших заметок:

- Фильтрация по тегам, папкам, свойствам
- Сортировка по имени, дате или пользовательским свойствам
- Сохранение конфигураций линзы для быстрого доступа

## 13. Настройки

Откройте настройки через значок шестерёнки в боковой панели или `Ctrl+,`.

### Общие

- Язык (15 языков)
- Тема (Светлая / Тёмная)
- Шрифт интерфейса, шрифт текста, моноширинный шрифт, размер шрифта

### Редактор

- Тип редактора (Markdown / Документный)
- Представление по умолчанию (Чтение / Редактирование)
- Режим живого предпросмотра
- Номера строк, направляющие отступов, проверка орфографии
- Автоматическое закрытие скобок, умные списки

### Библиотеки

- Добавление/удаление библиотек
- Индивидуальные настройки внешнего вида библиотек
- Расположение папки вложений

### Обновления

- Проверка обновлений
- Токен GitHub для обновлений из приватного репозитория

## 15. Поддержка RTL и арабского языка

Constellation обеспечивает первоклассную поддержку арабского, иврита, персидского, урду и других RTL-скриптов:

- **Автоопределение**: Направление заметки определяется автоматически по содержимому
- **Интерфейс**: Полный RTL-интерфейс при выборе арабского/иврита
- **Редактор**: Редактирование RTL-текста с правильным перемещением курсора и выделением
- **Star View**: Арабские метки отображаются справа налево с корректным запасным шрифтом
- **Легенда**: Элементы меняют порядок точки/текста в зависимости от языка содержимого
- **Шрифты скриптов**: Настройте арабские, ивритские и CJK-шрифты независимо в настройках

### Настройка для арабского языка

1. Перейдите в **Настройки > Общие > Язык** и выберите арабский
2. По желанию задайте отдельный арабский шрифт в **Настройки > Общие > Шрифты скриптов**
3. Заметки с арабским содержимым будут автоматически отображаться в режиме RTL

## 16. Безопасность и конфиденциальность

- **Все данные остаются на вашем устройстве** — без облачной синхронизации, телеметрии и отслеживания

## 17. Когнитивный движок

Когнитивный движок — это встроенная интеллектуальная система Constellation, которая анализирует ваши заметки и выявляет скрытые закономерности и связи между идеями.

### Страты знаний

Когнитивный движок автоматически классифицирует каждую заметку в одну из восьми страт знаний (Снимок, Журнал, Тема, Карта, Фреймворк, Принцип, Убеждение, Артефакт) на основе структуры, содержания и ссылок заметки. Эта классификация помогает понять распределение знаний в библиотеке и выявить пробелы.

### Жизненный цикл зрелости

Движок отслеживает уровень зрелости каждой заметки в четыре этапа: **Семя** → **Саженец** → **Вечнозелёная** → **Каноническая**. Уровень изменяется автоматически по мере добавления ссылок и ревизий.

### Типизированные ссылки

Когнитивный движок обнаруживает семантические связи между заметками на основе сходства содержания, даже если они не связаны явно через wikilink. Эти связи отображаются пунктирными линиями в Star View; их чувствительность можно настроить в параметрах Star View.

### Настройки когнитивного движка

- **Классификация страт** — Включить или отключить автоматическую классификацию
- **Отслеживание зрелости** — Включить или отключить отслеживание жизненного цикла зрелости
- **Типизированные ссылки** — Настроить порог чувствительности обнаружения ссылок (0.0 – 1.0)
- **Ручное переопределение** — Добавьте свойства `stratum` и `maturity` в frontmatter для переопределения автоматической классификации
