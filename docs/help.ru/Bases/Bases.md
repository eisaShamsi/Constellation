# Базы

**База** превращает набор ваших заметок в живую таблицу: **одна строка на заметку, один столбец на свойство**. Ничего не копируется и не перемещается — таблица читает ваши заметки на месте и отражает их такими, какие они прямо сейчас.

> [!tip] Сильно, но просто — по умолчанию
> База открывается знакомой и без лишнего — только имена ваших заметок и важные для вас поля. Более глубокие, когнитивные столбцы Созвездия всегда **в одном клике**, но они никогда не загромождают первый экран. Вы сами решаете, сколько структуры подтянуть.

> [!info] Без разрушения данных
> База никогда не меняет ваши заметки сама по себе. Это небольшой файл `.base`, хранящий запрос — «показать эти заметки, с этими столбцами, в этом порядке». Ваши файлы Markdown остаются ровно там, где они есть.

---

## Два способа использовать Базу

**1. Как полноценную вкладку.** Откройте файл `.base`, и он заполнит вкладку интерактивной таблицей.

**2. Внутри заметки.** Вставьте огороженный блок кода в любую заметку, и он отрисуется встроенным образом:

````markdown
```base
view: table
```
````

Оба варианта работают на одном и том же движке, поэтому ведут себя одинаково.

## Создание Базы

Используйте **Новая база** на боковой панели (действие «+» / Новая база). Созвездие записывает для вас небольшой файл `.base` в формате **YAML**:

```yaml
schema: 1
lens: My Notes
scope:
  libraries: all
  federation: auto
columns:
  - dimension: note.name
view: table
```

| Поле | Значение |
|-------|---------|
| `schema` | Версия формата (сейчас `1`). |
| `lens` | Имя, отображаемое вверху таблицы. |
| `scope.libraries` | `all` или список конкретных библиотек для включения. |
| `scope.federation` | `auto` — также включать заметки из любых связанных Вселенных (cUniverse). |
| `columns` | Столбцы для отображения. Новая База начинается только с **Имени** заметки. |
| `view` | `table` (таблица — это представление Базы). |

Вам редко нужно править это вручную — собственные элементы управления таблицы (ниже) записывают каждое изменение обратно в файл за вас.

## Таблица

- **Столбец Имя** — всегда первый. Нажмите имя заметки, чтобы открыть её.
- **Каждая подходящая заметка становится строкой.** Ограничения на число строк **нет**. Таблица *виртуализирована* — она отрисовывает только те строки, что сейчас на экране, — поэтому База над тысячами заметок открывается мгновенно и прокручивается плавно.
- **Направление для каждой ячейки** — каждое значение само определяет, написано ли оно слева направо или справа налево, поэтому таблицы со смешанными языками читаются правильно.
- В нижнем колонтитуле показано, сколько времени занял запрос.

## Поиск заметки в таблице

### Поиск по этой Базе

**Поле поиска** в заголовке фильтрует таблицу по мере ввода. Оно ищет совпадения и в **имени** заметки, *и* в тексте **каждого видимого столбца**, поэтому строку можно найти по любому значению, которое вы видите. Значок счётчика рядом с названием во время фильтрации показывает **«совпало / всего»** (например, `4/7684`) и возвращается к обычному общему числу, когда вы очищаете поиск.

Поиск работает в **любой письменности** — введите арабский, чтобы найти арабские заголовки, и так далее. Поскольку каждая строка уже в памяти, фильтрация мгновенна даже в Базе из тысяч заметок.

### Буквенная полоса

Когда в Базе **50 и более строк**, вдоль края таблицы появляется тонкая полоса букв. Её буквы построены из **первых букв ваших реальных заголовков заметок** — поэтому она показывает **A–Z** для английских заголовков, **أ ب ت …** для арабских и правильные буквы для любой другой письменности, которая у вас есть. (В интерфейсах справа налево полоса автоматически располагается с нужной стороны.)

**Нажмите букву, чтобы перейти** к первой заметке, начинающейся с неё. Если таблица ещё не отсортирована по Имени, нажатие буквы **сначала сортирует её по Имени**, а затем переходит — так что буквы всегда означают именно то, что вы ожидаете.

### Правый клик по строке

**Щёлкните правой кнопкой мыши по любой строке**, чтобы получить стандартное меню заметки: **Открыть**, **Открыть в новой вкладке**, **Закладка**, **Копировать путь** / **Копировать имя**, **Показать в дереве файлов**, **Открыть в приложении по умолчанию**, **Показать в проводнике** и **Стиль…**. Переименование, перемещение и удаление здесь намеренно *не* предлагаются — делайте это в дереве файлов, где список обновляется безопасно.

## Столбцы — добавление, удаление, изменение порядка

### Добавить столбец

Нажмите **Добавить столбец**. Выборщик сгруппирован надвое:

- **Ваши поля** — свойства frontmatter, которые Созвездие нашло в ваших заметках (например, `status`, `maturity`, `author`). Это *ваши* данные.
- **Созвездие** — встроенные поля, которые приложение знает всегда: **Имя**, **Путь**, **Создано** и **Сводка**.

Начните печатать, чтобы отфильтровать список. Поля, уже присутствующие в таблице, помечены, чтобы вы не добавили их дважды.

### Удалить столбец

Наведите курсор на заголовок столбца и нажмите **×**.

### Изменить порядок столбцов

**Зажмите заголовок столбца и перетащите его в сторону.** Весь столбец приподнимается (он тускнеет, а заголовок показывает контур захвата), и вертикальная линия отмечает, куда он встанет. Отпустите, чтобы переместить. Столбец Имя остаётся закреплённым первым.

Каждое добавление, удаление и изменение порядка автоматически сохраняется обратно в файл `.base`.

## Сортировка

**Нажмите заголовок столбца, чтобы отсортировать по нему.** Каждый клик переключает **по возрастанию → по убыванию → выключено** (стрелка показывает текущее направление).

Для сортировки по нескольким столбцам откройте панель **Сортировка**:

- Добавьте несколько столбцов — первый задаёт основную сортировку, следующие разрешают совпадения.
- Переключите любой уровень между возрастанием и убыванием.
- Перемещайте уровни вверх или вниз, чтобы изменить приоритет, или удаляйте их.

## Редактирование заметки из таблицы

Дважды щёлкните по ячейке в одном из **ваших** столбцов frontmatter, чтобы отредактировать её:

- **Поля со свободным текстом** — введите новое значение; **Enter** сохраняет, **Escape** отменяет.
- **Поля-списки** (как `maturity`) — появляется **выпадающий список** с допустимыми значениями **в их естественном порядке** (для `maturity`: *seed → sapling → evergreen → canonical*). Выберите одно или введите своё.

Изменение записывается прямо в YAML-frontmatter этой заметки на диске, и таблица обновляется на месте.

> [!note] Столбцы только для чтения
> **Имя** и **Создано** (и остальные встроенные столбцы Созвездия) вычисляются за вас, поэтому они не редактируются. Здесь можно менять только ваши собственные поля frontmatter.

## Открытие более старой Базы

Если вы переходите с Obsidian или с более ранней версии Созвездия, ваши существующие файлы `.base` используют более старый формат.

**Ваш файл никогда не затрагивается.** Когда Созвездие открывает такой файл, оно показывает спокойное уведомление о том, что формат старый, и предлагает кнопку **Преобразовать в Базу Созвездия**. Преобразование происходит **только когда вы нажимаете её** — оно обновляет файл на месте до нового формата YAML (перенося то, что может: имя, столбцы и простые текстовые фильтры). Пока вы не решите преобразовать, исходный файл остаётся ровно таким, каким был.

---

## Федерация

База учитывает Вселенную. С `federation: auto` она включает заметки из любых связанных Вселенных (cUniverse) наряду с вашими собственными. Заметки, живущие в связанной Вселенной, доступны только для чтения — вы можете просматривать и сортировать их в Базе, но редактирование зарезервировано для заметок, которыми владеете вы.

---

## Локально-первый и файл-важнее-приложения

Базы не хранят собственных данных. Каждое значение, которое вы видите, берётся из реального файла `.md` на вашем диске, прочитанного вживую. Удалите файл `.base` — и ваши заметки совершенно не пострадают: База — это всего лишь линза, которую вы наводите на уже имеющиеся у вас заметки.

## Клавиатура и мышь

| Действие | Что делает |
|--------|--------------|
| **Ввод** в поле поиска | Фильтрует строки по имени и любому видимому столбцу (любая письменность) |
| **Клик** по букве на полосе | Переход к первой заметке, начинающейся с неё (при необходимости сначала сортирует по Имени) |
| **Правый клик** по строке | Меню заметки: открыть · закладка · копировать · показать · стиль |
| **Клик** по заголовку столбца | Сортировка по нему (по возрастанию → по убыванию → выключено) |
| **Перетаскивание** заголовка столбца | Изменение порядка этого столбца |
| **Клик** по × на заголовке | Удаление этого столбца |
| **Двойной щелчок** по ячейке frontmatter | Редактирование (выпадающий список для полей-списков) |
| **Enter** | Сохранить правку |
| **Escape** | Отменить правку |
| **Клик** по имени заметки | Открыть заметку |
