# Sky View

Sky View отображает ваши заметки как интерактивную сеть из узлов и связей на движке **GraphMind** (Pixi.js WebGL). Каждый узел — это заметка, а каждая линия — это `[[вики-ссылка]]` между заметками. Чем больше связей у заметки, тем крупнее её узел.

## Открытие Sky View

| Способ | Действие |
|--------|--------|
| **Mission Control** | Нажмите `Ctrl+P` и введите «star view» |
| **Клавиатура** | `Ctrl+G` |

Нажмите `Escape`, чтобы закрыть Sky View.

> [!note]
> Значок Sky View убран из левого дока. Теперь Sky View доступен через горячую клавишу или Mission Control. Режим Sky View (оргсхема) доступен как вкладка в боковой панели управления заметками.

## Работа с графом

### Основные действия

| Ввод | Поведение |
|-------|----------|
| **Панорамирование** | Щёлкните и перетащите по пустому месту |
| **Масштабирование** | Колесо прокрутки (2D) или `Ctrl+прокрутка` (3D) |
| **Перетаскивание узлов** | Щёлкните и перетащите любой узел, чтобы переместить его |
| **Наведение** | Показывает имя заметки в строке состояния и подсвечивает связанные узлы и рёбра |
| **Щелчок по узлу** | Открывает эту заметку в редакторе |
| **Двойной щелчок по узлу** | Приближает и центрирует на этом узле |
| **Щелчок правой кнопкой по узлу** | Открывает контекстное меню |

### Контекстное меню

Щёлкните правой кнопкой по любому узлу, чтобы получить доступ к командам:

| Команда | Описание |
|--------|-------------|
| **Открыть** | Открывает заметку в редакторе |
| **Фокус** | Включает режим фокуса с центром на этом узле |
| **Закрепить** | Фиксирует узел в его текущем положении. Щёлкните ещё раз, чтобы открепить. |
| **Скрыть** | Скрывает узел из графа. Используйте «Показать все» на панели инструментов, чтобы вернуть скрытые узлы. |

## 3D-навигация

Sky View поддерживает полноценную 3D-навигацию — летите сквозь свои заметки, как сквозь звёзды.

### Вход в 3D-режим

**Щёлкните средней кнопкой и перетащите** (или **Alt+щелчок и перетаскивание**), чтобы повернуть граф в 3D-пространстве. После поворота становятся активными элементы управления 3D-навигацией.

### Управление в 3D

| Ввод | Действие |
|-------|--------|
| **Перетаскивание средней кнопкой** | Поворот вокруг осей X и Y |
| **Shift+перетаскивание средней кнопкой** | Поворот вокруг оси Z |
| **W / Стрелка вверх** | Лететь вперёд (вглубь экрана) |
| **S / Стрелка вниз** | Лететь назад |
| **A / Стрелка влево** | Смещение влево |
| **D / Стрелка вправо** | Смещение вправо |
| **Q** | Опуститься вниз |
| **E** | Подняться вверх |
| **Ctrl+прокрутка** | Масштаб (изменение поля зрения) |
| **Обычная прокрутка** | Лететь вперёд/назад вдоль направления камеры |
| **0** | Сбросить поворот обратно к плоскому 2D-виду |
| **Кнопка сброса** (значок ↺) | То же, что нажатие `0` |

### Указатель осей XYZ

В 3D-режиме в левом нижнем углу появляется цветовая подсказка осей:

| Ось | Цвет | Направление |
|------|-------|-----------|
| **X** | Красный | Влево–вправо |
| **Y** | Зелёный | Вверх–вниз |
| **Z** | Синий | Вперёд–назад (глубина) |

Указатель поворачивается вместе с камерой, поэтому вы всегда знаете свою ориентацию.

### Наведение и щелчок в 3D

Во время навигации в 3D можно наводить курсор на узлы и щёлкать по ним. Имя заметки появляется в строке состояния, а щелчок открывает заметку — так же, как в 2D-режиме.

## Режимы раскладки

Sky View предлагает три алгоритма раскладки. Переключайтесь между ними нажатием `Ctrl+L` или кнопкой раскладки на панели инструментов.

| Режим | Описание | Лучше всего для |
|------|-------------|----------|
| **Органическая** | Силовая раскладка. Кластеры возникают естественным образом из плотности связей. | Общего исследования — режим по умолчанию. |
| **Иерархическая** | Направленный ациклический граф (DAG) сверху вниз. | Структурированных библиотек с отношениями «родитель–потомок». |
| **Хронологическая** | Узлы расставлены вдоль горизонтальной оси времени по дате создания. | Того, чтобы увидеть, когда были созданы заметки и как росла библиотека. |

Переключение режимов запускает плавный анимированный переход, сохраняющий вашу пространственную ориентацию.

> [!tip]
> Иерархический режим особенно полезен для заметок с древовидной структурой (например, карты содержания, ведущие к подтемам). Хронологический режим раскрывает вашу интеллектуальную хронологию — когда создавались кластеры связанных заметок.

## Режим фокуса

Режим фокуса показывает только конкретную заметку и её окружение. Это динамический интерактивный локальный граф.

### Вход в режим фокуса

- **Щёлкните правой кнопкой по узлу** → **Фокус**
- **Нажмите Пробел**, чтобы включить режим фокуса для текущей активной заметки

### Управление фокусом

В режиме фокуса вверху появляется панель управления:

| Элемент | Описание |
|---------|-------------|
| **Ползунок глубины** (1–5) | Сколько шагов связей показывать. 1 = только прямые ссылки, 5 = пять уровней вглубь. |
| **Фильтр направления** (↔ / ← / →) | Показать все ссылки, только входящие или только исходящие. |
| **Кнопка выхода** (×) | Вернуться к полному Sky View |

### Цепочка навигации

По мере того как вы переходите по узлам в режиме фокуса, вверху появляется цепочка навигации («хлебные крошки»), показывающая ваш путь. Щёлкните по любому звену, чтобы вернуться к локальному графу этой заметки.

> [!tip]
> Сочетайте режим фокуса с ползунком глубины, чтобы постепенно исследовать окружение заметки. Начните с глубины 1, чтобы увидеть прямые связи, затем увеличивайте её, чтобы обнаружить отношения второй и третьей степени.

## Поиск с подсветкой

Нажмите `Ctrl+F`, чтобы открыть строку поиска. Введите запрос, чтобы подсветить совпадающие заметки.

В отличие от фильтра, поиск с подсветкой **приглушает** несовпадающие узлы, не удаляя их. Вы сохраняете полную структуру графа и пространственный контекст, пока совпадающие узлы подсвечены.

> [!tip]
> Поиск работает как в полном графе, так и в режиме фокуса. Искать можно и в 3D-режиме.

## Панель настроек

Щёлкните значок шестерёнки (⚙) на панели инструментов, чтобы открыть панель настроек. В ней три вкладки:

### Внешний вид графа

| Параметр | Описание | По умолчанию |
|---------|-------------|---------|
| **Размер узла** | Увеличить или уменьшить все узлы | 1.5 |
| **Видимость подписей** | Когда появляются подписи: при наведении, всегда или никогда | При наведении |
| **Размер шрифта подписи** | Размер подписей с именами заметок | 12 |
| **Толщина связи** | Ширина линий рёбер | 1 |
| **Показывать изолированные заметки** | Включать заметки без связей | Вкл |

> **Цвет фона холста.** Цвет позади пузырей задаётся в **Настройки → Настройщик стиля → Sky View → Холст → Фон** (не на этой панели). Он независим от ваших боковых панелей, поэтому вы можете дать графу собственный фон — например, насыщенный цвет, чтобы пузыри выделялись, — не меняя остальной интерфейс. Если значение не задано, холст совпадает с поверхностью панели. См. *Внешний вид и темы → Холст Sky View*.

### Физика

| Параметр | Описание | По умолчанию |
|---------|-------------|---------|
| **Отталкивание** | Насколько сильно узлы отталкиваются друг от друга | 50 |
| **Сила связи** | Насколько сильно связанные узлы притягиваются | 0.05 |
| **Расстояние связи** | Целевое расстояние между связанными узлами | 30 |
| **Перезапустить симуляцию** | Запустить силовую раскладку заново из текущего состояния | — |

### ИИ

Настройки для семантических ИИ-связей (Фаза 2 — требуется локальная модель эмбеддингов).

| Параметр | Описание |
|---------|-------------|
| **Показывать семантические связи** | Включить/выключить штриховые рёбра, найденные ИИ |
| **Порог уверенности** | Ползунок для фильтрации семантических связей по показателю сходства |

## Легенда

Легенда появляется в правом нижнем углу и показывает назначение цветов вашим библиотекам.

### Переключатель режима окраски

Щёлкните кнопки **Библиотека** или **Папка** вверху легенды, чтобы изменить способ окраски узлов:

| Режим | Окраска |
|------|----------|
| **Библиотека** | Каждая библиотека получает уникальный цвет |
| **Папка** | Каждая папка верхнего уровня получает уникальный цвет |

### Флажки видимости

У каждой записи легенды есть флажок. Снимите флажок с библиотеки или папки, чтобы скрыть её узлы из графа. Это позволяет сосредоточиться на конкретных частях вашей базы знаний.

> [!tip]
> В режиме «Папка» количество папок показано в скобках. Длинные списки папок можно прокручивать.

## Строка состояния

Строка состояния в левом нижнем углу показывает:

- **Число узлов** — всего видимых узлов
- **Число рёбер** — всего видимых рёбер
- **Число карт содержания** — количество карт содержания (узлов-хабов с высокой связностью)
- **Имя заметки под курсором** — появляется при наведении на узел

## Поддержка RTL

Sky View обеспечивает первоклассную поддержку арабского, иврита и других письменностей с написанием справа налево (RTL):

- **Подписи узлов** автоматически определяют направление письма — арабские заголовки отображаются справа налево
- **Элементы легенды** меняют порядок «точка/текст» в зависимости от языка содержимого
- **Всплывающие подсказки и панели** учитывают раскладку RTL
- **Резервный арабский шрифт** — подписи используют системные арабские шрифты (Noto Naskh Arabic, Segoe UI), когда в основном шрифте нет арабских глифов

## Наложение «картинка в картинке» (PiP)

Когда Sky View открыт и вы щёлкаете по дочерней вселенной, библиотеке или папке в боковой панели управления заметками, появляется окно **«картинка в картинке» (PiP)** — наложение с изменяемым размером поверх основного графа.

### Что показывает PiP

PiP отображает отфильтрованный подграф, содержащий только узлы, относящиеся к выбранной области. Например, щелчок по библиотеке показывает только заметки этой библиотеки и их взаимосвязи.

### Возможности PiP

| Возможность | Описание |
|---------|-------------|
| **Отфильтрованный граф** | Появляются только узлы из выбранной области |
| **Отфильтрованная легенда** | У PiP своя легенда, показывающая только релевантные записи |
| **Изменяемый размер** | Тяните за края или углы, чтобы изменить размер окна PiP |
| **Перемещаемое** | Тяните за заголовок, чтобы переместить PiP в любое место экрана |

### Синхронизация выбора между режимами

Щелчок по дочерней вселенной, библиотеке, папке или заметке в любом режиме боковой панели (Дерево, Список или Оргсхема) подсвечивает соответствующие узлы в графе Sky View. Эта двусторонняя синхронизация помогает сохранять пространственную ориентацию при просмотре в боковой панели.

## Страты знаний

Sky View автоматически задаёт размер узлов в зависимости от их уровня знаний (1–8):

- Маленькие точки: простые заметки (Данное, Информация)
- Средние узлы: связанные заметки (Утверждение, Концепция)
- Крупные светящиеся хабы: синтезирующие заметки (Теория, Парадигма, Мировоззрение)

Узлы более высокого уровня имеют светящийся ореол дополнительного цвета для визуального контраста. Он активируется, когда в библиотеке 20+ заметок.

---

## Зрелость заметки

Узлы отображают цветное кольцо, обозначающее зрелость:

- Без кольца: Семя (новая заметка)
- Светло-зелёное кольцо: Саженец (растущая)
- Насыщенно-зелёное кольцо: Вечнозелёная (хорошо устоявшаяся)
- Золотое кольцо: Каноническая (авторитетный источник)

Зрелость также показана в дереве файлов (левая граница) и на панели вкладок (цветная точка).

---

## Свечение происхождения

Узлы в Sky View показывают тонкое цветное свечение, обозначающее происхождение знания:

- **Синее свечение**: Полученное знание — цепочка источников заметки восходит к внешней ссылке (заметке с url, author или doi в её frontmatter)
- **Янтарное свечение**: Открытое знание — цепочка источников заметки берёт начало из собственных заметок пользователя

## Технические заметки

Sky View работает на движке **GraphMind** — рендерере Pixi.js WebGL с силовой симуляцией d3-force, выполняемой в отдельном Web Worker. Такая архитектура обеспечивает:

- **Рендеринг 60 кадров/с** даже при тысячах узлов
- **Неблокирующую раскладку** — силовая симуляция никогда не замораживает интерфейс
- **Наведение только визуально** — наведение никогда не запускает пересчёт физики
- **Симуляция останавливается после стабилизации** — как только узлы находят свои позиции, физический движок полностью останавливается. Перезапускают его только перетаскивание узла или изменение настроек.
