# ベース

**ベース** は、あなたのノートの集合をライブテーブルに変えます。**1 ノートにつき 1 行、1 プロパティにつき 1 列** です。何もコピーされず、移動もされません — テーブルはノートをその場で読み取り、今この瞬間のありのままを反映します。

> [!tip] 既定で、力強くもシンプルに
> ベースは、見慣れたすっきりした姿で開きます — ただノートの名前と、あなたが気にかけるフィールドだけです。星座のより深い認知的な列は常に **ワンクリック** で呼び出せますが、最初の画面を決して混雑させません。どれだけの構造を引き込むかは、あなたが決めます。

> [!info] 非破壊的
> ベースがひとりでにノートを変更することは決してありません。それは「これらのノートを、これらの列で、この順序で表示する」というクエリを保持する小さな `.base` ファイルです。あなたの Markdown ファイルは、まさにあるべき場所にとどまります。

## ベースの 2 つの使い方

**1. タブ全体として。** `.base` ファイルを開くと、インタラクティブなテーブルとしてタブいっぱいに表示されます。

**2. ノートの中で。** 任意のノートにフェンス付きコードブロックを挿入すると、インラインで描画されます。

````markdown
```base
view: table
```
````

どちらも同じエンジンで動いているため、まったく同じように振る舞います。

---

## ベースを作成する

サイドバーから **新規ベース**（「+」/ 新規ベースのアクション）を使います。星座が、あなたのために小さな **YAML** の `.base` ファイルを書き出します。

```yaml
schema: 1
lens: My Notes
scope:
  libraries: all
  federation: auto
columns:
  - dimension: note.name
view: table
```

| フィールド | 意味 |
|-------|---------|
| `schema` | フォーマットのバージョン（現在は `1`）。 |
| `lens` | テーブルの上部に表示される名前。 |
| `scope.libraries` | `all`、または含める特定のライブラリのリスト。 |
| `scope.federation` | `auto` — 連携されたユニバース（cUniverse）のノートも含めます。 |
| `columns` | 表示する列。新しいベースはノートの **名前** だけで始まります。 |
| `view` | `table`（テーブルがベースのビューです）。 |

これを手作業で編集する必要はめったにありません — テーブル自体のコントロール（以下）が、すべての変更をファイルへ書き戻してくれます。

---

## テーブル

- **名前の列** — 常に先頭です。ノートの名前をクリックすると開きます。
- **一致するすべてのノートが 1 行になります。** **行数の上限はありません。** テーブルは *仮想化* されており — 現在画面に表示されている行だけを描画します — そのため数千のノートにまたがるベースでも瞬時に開き、なめらかにスクロールします。
- **セルごとの方向** — 各値は自身の左横書き（左から右）または右横書き（右から左）のスクリプトを検出するため、複数言語が混在するテーブルも正しく読めます。
- フッターには、クエリにかかった時間が表示されます。

---

## 列 — 追加・削除・並べ替え

### 列を追加

**+ 列を追加** をクリックします。ピッカーは 2 つに分かれています。

- **あなたのフィールド** — 星座があなたのノートの中で見つけたフロントマターのプロパティ（例: `status`、`maturity`、`author`）。これらは *あなたの* データです。
- **星座** — アプリが常に把握している組み込みフィールド: **名前**、**パス**、**作成日時**、そして **概要**。

入力を始めるとリストが絞り込まれます。すでにテーブルにあるフィールドには印が付いており、二重に追加してしまわないようになっています。

### 列を削除

列の見出しにカーソルを合わせて **×** をクリックします。

### 列を並べ替え

**列の見出しを押したまま横にドラッグします。** 列全体が持ち上がり（薄くなり、見出しにつかみ取りの輪郭が表示されます）、縦の線がドロップ先を示します。離すと移動します。名前の列は先頭に固定されたままです。

すべての追加・削除・並べ替えは、自動的に `.base` ファイルへ書き戻されます。

---

## 並べ替え

**列の見出しをクリックすると、その列で並べ替えます。** クリックするたびに **昇順 → 降順 → オフ** と循環します（矢印が現在の方向を示します）。

複数の列で並べ替えるには、**並べ替え** パネルを開きます。

- 複数の列を追加します — 最初の列が主たる並べ替えで、続く列が同順位を解きほぐします。
- 任意のレベルを昇順と降順の間で切り替えます。
- レベルを上下に動かして優先順位を変える、または削除します。

---

## テーブルからノートを編集する

**あなたの** フロントマター列のセルをダブルクリックすると編集できます。

- **自由テキストのフィールド** — 新しい値を入力します。**Enter** で保存、**Escape** でキャンセルします。
- **リスト型のフィールド**（`maturity` など）— 有効な値が **自然な順序で** 並んだ **ドロップダウン** が表示されます（`maturity` の場合: *seed → sapling → evergreen → canonical*）。1 つを選ぶか、独自の値を入力します。

変更はディスク上のそのノートの YAML フロントマターへ直接書き込まれ、テーブルはその場で更新されます。

> [!note] 読み取り専用の列
> **名前** と **作成日時**（およびその他の組み込みの星座の列）は自動で計算されるため、編集できません。ここで変更できるのは、あなた自身のフロントマターのフィールドだけです。

## 古いベースを開く

Obsidian から、あるいは星座の以前のバージョンから移行した場合、既存の `.base` ファイルは古い形式になっています。

**あなたのファイルが触られることは決してありません。** 星座がそれを開くと、形式が古いことを説明する穏やかな通知を表示し、**星座ベースに変換** ボタンを提示します。変換は **クリックしたときにだけ** 行われます — ファイルをその場で新しい YAML 形式へアップグレードします（移し替えられるもの: 名前、列、そして単純なテキストフィルターを引き継ぎます）。変換を選ばない限り、元のファイルはあったままに残されます。

---

## フェデレーション

ベースはユニバースを認識します。`federation: auto` の場合、連携されたユニバース（cUniverse）のノートも、あなた自身のノートと並べて含めます。連携されたユニバースにあるノートは読み取り専用です — ベース内で表示・並べ替えはできますが、編集はあなたが所有するノートに限られます。

---

## ローカルファースト & ファイル・オーバー・アプリ

ベースは自身のデータを一切保持しません。表示されるすべての値は、ディスク上の実際の `.md` ファイルから、ライブで読み取られたものです。`.base` ファイルを削除しても、あなたのノートはまったく影響を受けません — ベースは、すでに持っているノートに向けるレンズにすぎません。

---

## キーボード & マウス

| 操作 | はたらき |
|--------|--------------|
| 列の見出しを **クリック** | その列で並べ替え（昇順 → 降順 → オフ） |
| 列の見出しを **ドラッグ** | その列を並べ替え |
| 見出しの × を **クリック** | その列を削除 |
| フロントマターのセルを **ダブルクリック** | 編集する（リスト型フィールドはドロップダウン） |
| **Enter** | 編集を保存 |
| **Escape** | 編集をキャンセル |
| ノートの名前を **クリック** | ノートを開く |
