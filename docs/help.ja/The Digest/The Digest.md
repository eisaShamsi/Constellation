# 宇宙ダイジェスト

> *ダイジェストはあなたの心の目次のように考えてください — ファイルのリストではなく、アイデアのリストです。*

**宇宙ダイジェスト** は、知識ベース全体を *意味* のレベルで概観する場所です。ファイルツリー(名前のみ)やスタービュー(形のみ)の代わりに、ダイジェストはあなたに各ノートの下に **そのノートが何についてかを示す一文** を見せます。行をタップすると、複数文のフル要約がインラインで展開されます。一つも開かずに、五十のノート分の中身を一分で読めます。

これは **左ドック** に存在し、ファイルツリー、ノートナビゲータ、スタービューと並びます — Constellation が提供する 4 つのナビゲーション方法の一つです。

---

## なぜダイジェストが存在するのか

ファイルツリーはあなたが *持っている* ものを伝えます。検索はあなたが *尋ねた* ものを伝えます。ダイジェストはあなたが *知っている* ものを伝えます。

宇宙が数百のノートを超えて成長すると、「それぞれを開いて何が書いてあるかを思い出す」ことは不可能になります。スクロールの速度で各ノートの **要旨** を読む方法と、より注意深く考えたい瞬間に任意の要旨をフル要約に展開する方法が必要です。それがダイジェストです。

これは **Note Summary Creator (NSC)** コアプラグインの第三の柱です:
- **柱 1**: 要約エンジン(フェーズ 1 / MIG-043)。
- **柱 2**: ノートが現れる場所ならどこでも要約を配置するサービス(フェーズ 2 / MIG-044 — 分類器、検索結果、エディタ帯、バックリンク、アウトゴーイングリンク、インデックス、スタービューのホバー)。
- **柱 3**: このビュー — 宇宙ダイジェスト(フェーズ 3 / MIG-045)。

---

## ダイジェストを開く

**左サイドバー** で、**宇宙ダイジェストのアイコン** (角に円のついた小さなリスト)をクリックします — 列の 4 番目のアイコンで、ファイルツリー / ノートナビゲータ / スタービューの隣にあります。サイドバーがダイジェストペインに切り替わります。

戻すには、他の 3 つのアイコンのいずれかをクリック(または **Escape** を押す)します。

## あなたが見るもの

上から下へ:

1. **ツールバー。** 検索入力 + 小さな時計アイコン(ソート切替、デフォルトは「新しさ順」)。
2. **Library ヘッダ。** 大文字の紫色のバー — 宇宙内の library ごとに 1 つ。各々が library 名と含まれるノート数を表示します。
3. **フォルダヘッダ。** 小さなくすんだラベル — *ノートを含む* フォルダごとに 1 つ。library のルートに住むノートはフォルダヘッダを受け取りません。
4. **ノート行。** 各行には:
   - 左側にシェブロン(▶) — クリックすると行が展開します。
   - インタラクティブアクセント色の **ノート名** — クリックするとエディタで **ノートが開きます**。
   - 名前の下にうっすらしたイタリック行 — **要約見出し**(他のすべてのフェーズ 1/2 サーフェスに表示されるのと同じもの)。

## 行を展開してフル要約を読む

行の左にある **シェブロン**(▶)をクリック、または **見出しのイタリック行** 自体をクリックします。シェブロンが ▼ に回転し、**複数文のフル要約** が見出しの下にインラインで現れ、必要な行数にわたって自然に折り返します。

折りたたむには、シェブロン(または見出し)を再度クリックします。

「シェブロンをクリックして展開、名前をクリックして開く」という分割は、二つのジェスチャーを区別したままにします: ノートに *ついて読む* ために展開し、その後それを通り過ぎてスクロールを続けることができます; 名前をクリックしたときだけ、ノートが実際に開いてフォーカスを取ります。

---

## フィルタリング

上部の **検索入力** にタイプします。タイプするにつれてリストが絞り込まれます — **名前、見出し、またはフル要約** にクエリを含むノートのみが表示されます。一致するノートがゼロの Library ヘッダとフォルダヘッダは完全に消えます(空のヘッダはありません)。

入力をクリアして(× ボタンまたはバックスペース)、フルリストを復元します。

フィルタは **瞬時** です — Constellation はディスクやデータベースにヒットしません。メモリにすでにある要約を読むため、10,000 ノートの宇宙でもタイピング速度でフィルタされます。

---

## ソート: 新しさ順またはアルファベット順

ツールバーの **時計アイコン** をクリックして、二つのソートモード間を切り替えます:

- **新しさ順**(デフォルト) — 各フォルダ内で、ノートは **作成時刻、最新が最初** の順序で現れます。library 内のフォルダは含まれる最新のノートでソートされます(最もアクティブなフォルダが最初に現れます)。これがデフォルトなのは *最近作業していたもの* を浮かび上がらせるからです。
- **アルファベット順** — フォルダは名前でソート、各フォルダ内のノートは名前でソート。再度クリックすると新しさ順に戻ります。

切替はセッションごとです; ダイジェストを閉じて開き直すと新しさ順に戻ります。

---

## フェデレーション: 子宇宙はインラインで現れる

宇宙に **リンクされた子宇宙**(cUniverses)がある場合、子宇宙からの各 library は、親宇宙の libraries と並んで、ダイジェストに **独自のピア Library ヘッダ** として現れます。ダイジェストは、この宇宙から到達可能なすべてを統一表示するもので、ここに物理的に住んでいる libraries だけではありません。

(将来の Constellation 更新で、子宇宙の libraries を一時的にダイジェストから隠すためのオン/オフ切替が追加されます; 現在は常に表示されます。)

---

## ダイジェストが巨大な宇宙でも高速に保たれる方法

ダイジェストは **仮想化** されています: スクロールポートで現在表示されている行のみをレンダリングし、ツリー全体ではありません。10,000 ノートの宇宙は 50 ノートのものと同じくらいスムーズにスクロールします。行がビューにスクロールされると、その要約は Constellation のインメモリキャッシュからバッチで取得されます(他のすべてのフェーズ 1/2 サーフェスを動かすのと同じキャッシュ — 別の作業はなく、別のストレージもありません)。

ダイジェストはノートをディスクから読み直すことはありません。要約を再計算することはありません。それはエンジンがフェーズ 1 から populating している同じ `note_summaries` テーブルに対する **読み取り** ビューです。

## 一般的なワークフロー

**「今週何に取り組んでいたかを見たい。」**
ソート = 新しさ順(デフォルト)でダイジェストを開きます。最も最近作成されたノートが各 library/フォルダの上部に現れます。見出しをスキャンします。

**「X について半ば覚えているノートを探しています。」**
ダイジェストを開きます。X(ノートのタイトル、見出し、またはフル要約に現れるであろう単語)をタイプします。リストは候補に絞り込まれます。シェブロンをクリックしてフル要約を読み、名前をクリックして勝者を開きます。

**「自分の Library のトップダウンレビューを書きたい。」**
ダイジェストを開き、ソート = アルファベット順。見出しを順番に歩きます。何かが心を捉えたら、シェブロンをクリックしてより充実した要約を読みます。これを新しい MOC ノート(Map of Content)の背骨として使います。

**「初めてフェデレーションされた cUniverse を探索している。」**
ダイジェストを開きます。自分の libraries を通り過ぎて cUniverse の libraries までスクロールします — それらはピア行です。見出しを読んで、リンクされた宇宙が何を含んでいるかを学びます、そこから何も開かずに。

## ダイジェストに含まれていないもの

- 行の **右クリックコンテキストメニュー** — 新しいタブで開く、アーカイブする等。(v1 では、主要なアクションはクリック-名前で開くとクリック-シェブロンで展開です。将来の更新でコンテキストメニューが追加されます。)
- **カスタムグループ化** — v1 では Library → フォルダが唯一の階層化です。(まだ「タグでグループ化」や「ステージでグループ化」はありません。)
- **ドラッグして並び替え** — ダイジェストは読み取り専用です; ソートはルールから来るもので、手動の順序付けではありません。
- **分類器のような分類コントロール** — ダイジェストは *ブラウズ* ビューです; 分類は **分類器**(別のペイン)に存在します。

## 関連トピック

- **ノートの要約** — 要約がどこから来るのか、優先順位ルール(あなたのが勝つ)、そしてそれらを表示するサーフェスの完全なリスト。
- **分類器** — *すべての要約を作成* のホーム(Library 内のすべての要約を一度に事前計算してダイジェストを瞬時に埋める)。
- **スタービュー** — あなたの知識の *形* のビュー(バブル + リンク); ダイジェストはその補完的な *意味* のビューです。
- **知識の定式化** — Constellation が知識をファイルストレージだけでなく、*接続* と *要約* で整理する理由。
