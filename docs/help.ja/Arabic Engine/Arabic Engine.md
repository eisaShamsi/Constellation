# アラビア語エンジン

Constellation は、本アプリのためにゼロから構築された五層形態解析エンジンでアラビア語テキストを解析します。これは既存ステマーの移植ではなく、アラビア語の語根・語型・固有名詞・外来語、そしてあなた自身の用語を理解するネイティブな道具です。エンジン自体を設定することはありません。あらゆる検索・リンク・索引エントリの下で、それは静かに動作しています。あなたが *設定できる*もの——そして本ヘルプトピックが扱うもの——は、エンジンがあなたの判断を招き入れる唯一の場所、すなわち設定内の **アラビア語エンジン・オーバーライド** パネルです。

---

## なぜエンジンが存在するのか

アラビア語はテンプレート型言語です。ك‑ت‑ب(「書く」)のような単一の語根から、كاتب(書き手)、مكتوب(書かれたもの)、كتاب(本)、يكتب(彼は書く)、كتبنا(私たちは書いた)といった数十の表層形が生成され、検索時にはこれらすべてが同じ意味の核へと収束するべきです。素朴なステマーはこれらの形を壊してしまうか(たとえば وائل を ائل に過剰剥離するなど)、そもそも形同士のつながりを取り逃がしてしまいます。Constellation のエンジンは、あらゆるアラビア語の語を厳格な優先順位で以下の五層に通すことで、どちらの失敗も避けます:

1. **第 0 層 — ユーザー・オーバーライド**(あなたが制御するのはこの層です)
2. **第 2 層 — 保護リスト**(絶対に触れてはならない、約 1,200 個の手作業で厳選された固有名詞・地名・外来語・機能語)
3. **第 3 層 — 生成 FST**(約 7,000 語根 × 158 語型をその完全な表層語彙に写像する、コンパイル済み有限状態トランスデューサ)
4. **第 3b 層 — カスケード**(音韻的修復:同化、弱語根、ハムザ配置)
5. **第 5 層 — ヒューリスティック**(優雅なフォールバック——他のすべての層が答えを拒んだときにのみ発火する、控えめな接辞剥離器)

複数の層が読みを生成した場合、ランキング段(第 4 層)が最良の解析を一つ選びます。そのランキングは、あなたのオーバーライドをすべての上に置きます。

## 機能:アラビア語エンジン・オーバーライド

### それは何か

オーバーライドパネルは設定内の小さな表で、特定のアラビア語表層形をどう解析すべきかを、あなた自身の言葉でエンジンに伝える場所です。各オーバーライドには次のものがあります:

- **表層形** — あなたが入力するそのままのアラビア語の語(例 وائل)。
- **レンマ** — エンジンが返すべき基本形(例 وائل)。
- **語根** — 任意。その語に古典的な語根がある場合の三つまたは四つの子音。
- **語型** — 任意。形態テンプレートを記録したい場合の自由文ラベル(例 `فاعل`)。
- **品詞** — 固有名詞 / 名詞 / 形容詞 / 副詞 / 動詞 / 助詞 / 外来 / 不明。
- **メモ** — 任意。未来の自分のための文脈一行。

### なぜ重要か

いかなる知識ネットワークにも、エンジンが辞書から知り得ない語があります。あなた自身の造語、地元の人名、分野で使う頭字語、同僚が特定の綴りを好む外来語などです。オーバーライドがなければ、エンジンはこれらの表層形に総当たりな解析を当て、検索結果はちょっとした綴りの違いで分断されてしまいます。オーバーライドは主権的な答えです——生成 FST・カスケード・ヒューリスティック・フォールバックに優先します。第 4 層のランキングはオーバーライドに最上位の出所と信頼度 1.0 を与えるため、他の解析に取って代わられることはありません。

オーバーライドは `<あなたの Universe>/.constellation/arabic-overrides.json` という単一 JSON ファイルに保存されます。このファイルはプレーンテキストで、アルファベット順にソートされ、`.tmp` + リネームの組み合わせで原子的に書き込まれます。そのため編集中の電源断でも破損しません。あなたのものです——バージョン管理に入れても、差分を取っても、複数デバイス間で共有してもかまいません。

### 使い方

**ステップ 1: パネルを開く**

右上ツールバーの歯車アイコンをクリックする(または `Ctrl + ,` / `Cmd + ,` を押す)と、設定が開きます。左サイドバーで **アラビア語オーバーライド** を選択してください——**言語** の隣にあります。見当たらない場合はサイドバーをスクロールしてください。

**ステップ 2: 最初のオーバーライドを追加する**

**オーバーライドを追加** をクリックします。表層形・レンマ・語根・語型・品詞・メモの六つのフィールドからなるフォームが現れます。ノートに書くそのままに表層形を入力してください——エンジンは内部でダイアクリティックや alef のバリエーションを正規化するため、正確に一致させる必要はありません。返してほしいレンマを入力してください。語根や語型がわからない場合は空欄のままでかまいません;エンジンはそれでもオーバーライドを使います。ドロップダウンから品詞を選ぶか、**不明** のままにしてください。**保存** をクリックします。

**ステップ 3: 再インデックスのバナーを見る**

保存した瞬間に、パネルは **再インデックス中…** を表示し、エンジンはアクティブな Universe でその表層形を含むすべてのノートを走査します。一致した各ノートは新しいオーバーライドの判定の下で再トークン化されます。走査が終わると——典型的な Universe では通常 1 秒以内です——バナーは **N 件のノートを再インデックスしました** に変わり、3 秒後に自動的に消えます。アプリを再起動する必要も、索引を再構築する必要もありません。

**ステップ 4: 検索で確認する**

検索ハブ(`Ctrl + K` / `Cmd + K`)を開き、その表層形を入力します。一致はあなたが指定したレンマを反映するはずです:レンマへのクエリで表層形が見つかり、表層形へのクエリでそのレンマの他の屈折形が見つかります。

**ステップ 5: オーバーライドを削除する**

そのオーバーライド行の **×** ボタンをクリックします。エントリは即座にディスクから削除され、同じ再インデックス走査が逆方向に実行されます——その表層形を含んでいたノートは、エンジンの汎用解析の下で再トークン化されます。バナーは何件のノートに影響したかを報告します。

### 保護リストとの相互作用

保護リスト(第 2 層)には、剥離されてはならない約 1,200 個の一般的な表層形がすでに含まれています——وائل のような名前、فلسطين のような地名、إنترنت のような外来語です。これらを自分で追加する必要はありません;エンジンに同梱されています。オーバーライドパネルは、あなたの Universe にとって *個人的* な表層形のために使ってください:自分の用語、地元の人名、分野固有の外来語、あるいはエンジンの自動的な読みに同意しない場合などです。

### Universe を跨いだ相互作用

各 Universe は独自のオーバーライドファイルを持ちます。Universe を切り替えるとメモリ内のアクティブなオーバーライドセットが入れ替わります——エンジンは新しい Universe の `.constellation/` フォルダから JSON を再読み込みします。ファイルが存在しない場合(新規 Universe)、エンジンはオーバーライドセットを空として扱います。ファイルの形式が崩れている場合、エンジンは警告をログに残し、読み込みを拒否せず空集合にフォールバックします。

### 手でファイルを編集した場合

可能です。ファイル形式は次のとおりです:

```json
[
  {
    "surface": "وائل",
    "lemma": "وائل",
    "root": null,
    "pattern": null,
    "pos": "ProperNoun",
    "note": "Personal name — never strip"
  }
]
```

git に優しい差分のために、エントリは表層形でアルファベット順にソートして保ってください。エンジンは保存のたびに並べ替えるため、手動での並び替えは UI 経由の編集後には残りません。

## 用語集

- **表層形** — 書かれたままのアラビア語の語。付着するクリティック(例 الكتاب、بالكتاب、كتبنا)を含みます。
- **レンマ** — 屈折を剥ぎ取った語の引用形(例 كتاب)。
- **語根** — ある語族が共有する 3 または 4 子音からなる意味の核(例 ك‑ت‑ب)。
- **語型** — 語根と組み合わさって表層形を生み出す母音と接辞のテンプレート(例 فاعل → كاتب)。
- **FST** — 有限状態トランスデューサ。エンジンはこれを用いて語根 × 語型から完全な表層語彙への写像を効率的に行います。
- **カスケード** — 同化・弱子音・ハムザ配置を扱う音韻的修復の層。
- **オーバーライド** — 特定の表層形をどう解析すべきかについてのあなた自身の判定;他のあらゆる層に優先します。
