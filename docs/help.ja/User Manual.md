# Constellation ユーザーマニュアル

**バージョン 0.3.4 | 2026年3月**

Constellation は、Markdown ノートライブラリを管理するためのパーソナルナレッジマネジメント（PKM）デスクトップアプリケーションです。Tauri v2、SvelteKit、Rust で構築されており、Windows、macOS、Linux 上でネイティブに動作し、アラビア語および RTL を完全サポートしています。

## 1. はじめに

### インストール

[Constellation リリースページ](https://github.com/eisaShamsi/Constellation/releases) から最新のインストーラーをダウンロードしてください：

- **Windows**: `.exe`（NSIS）または `.msi` インストーラー
- **macOS**: `.dmg` ディスクイメージ
- **Linux**: `.AppImage` または `.deb` パッケージ

### 初回起動

Constellation を初めて開くと、**ユニバースセットアップウィザード**が以下の手順を案内します：

1. **言語を選択** — 15言語対応
2. **ライブラリを作成またはインポート** — 既存の Markdown ファイルフォルダを指定するか、新しく作成
3. **ユニバースに名前を付ける** — ユニバースはすべてのライブラリのコンテナです

### インターフェース概要

| 要素 | 説明 |
|------|------|
| **サイドバー（リボン）** | ナビゲーションボタン：ファイルツリー、検索、スタービュー、カレンダー、テンプレート、設定 |
| **ファイルツリー** | ライブラリ内のノートとフォルダを閲覧 |
| **エディター** | Markdown ノートの閲覧と編集 |
| **タブバー** | 複数のノートをタブで開く |
| **ステータスバー** | 文字数、単語数、読了時間 |

## 2. ユニバースとライブラリ

### ユニバースとは？

**ユニバース**は、すべてのライブラリを格納するトップレベルのコンテナです。ワークスペースやライブラリコレクションと考えてください。

### ライブラリとは？

**ライブラリ**は、Markdown（`.md`）ファイルを含むコンピュータ上のフォルダです。1つのユニバースに複数のライブラリを持つことができます。例えば、仕事用ノートと個人用ノートを別々のライブラリにできます。

### ライブラリの管理

- **ライブラリを追加**: 設定 > ライブラリ > ライブラリを追加、またはフォルダをアプリにドラッグ
- **ライブラリを削除**: 設定 > ライブラリ > ライブラリ名の横にある削除ボタンをクリック
- **ライブラリ設定**: 各ライブラリに独自の外観設定（フォント、色）を適用できます

### 子ユニバース

ユニバースの中にユニバースをネストできます。**子ユニバース**は、親ユニバースから参照される別のユニバースフォルダです。子ユニバースのノートは、スタービューで自分のノートと一緒に表示され、ライブラリ間のリンクは破線で示されます。

## 3. ノートの作成と編集

### ノートの作成

| 方法 | 操作 |
|------|------|
| **キーボード** | `Ctrl+N` |
| **ファイルツリー** | フォルダを右クリック > 新規ノート |
| **ミッションコントロール** | `Ctrl+P` > 「新規ノート」 |

### エディターモード

Constellation には、**設定 > エディター > エディタータイプ**で選択できる2つのエディターモードがあります：

#### Markdown エディター（CodeMirror）

パワーユーザー向けのデフォルトエディターです。Markdown を直接記述できます：

- **ライブプレビュー** — 入力中にフォーマットをインラインでレンダリング
- **ソースモード** — 生の Markdown 構文を表示
- **フォーマットツールバー** — テキスト選択時に表示
- **スラッシュコマンド** — `/` を入力してクイック挿入
- **Wikilink 自動補完** — `[[` を入力してノートをリンク
- **マルチカーソル** — `Alt+Click` または `Ctrl+D`

#### ドキュメントエディター（TipTap）

ビジュアルツールバーを備えた WYSIWYG ワープロ体験：

- 太字、斜体、下線、取り消し線、ハイライト
- 見出し（H1～H3）、テキスト揃え
- 箇条書き、番号付きリスト、タスクリスト
- 引用、コードブロック、水平線
- テーブル（挿入、行と列の追加/削除）
- リンクと画像

両方のエディターは標準 Markdown ファイルとして保存されます。データを失うことなくいつでも切り替えできます。

### テキストフォーマットショートカット

| ショートカット | 操作 |
|----------------|------|
| `Ctrl+B` | 太字 |
| `Ctrl+I` | 斜体 |
| `Ctrl+Shift+S` | 取り消し線 |
| `Ctrl+Shift+H` | ハイライト |
| `Ctrl+K` | Wikilink を挿入 |
| `Ctrl+Z` | 元に戻す |
| `Ctrl+Shift+Z` | やり直し |

### ノートのリンク

`[[` を入力するとノート自動補完が開きます。ノート名を入力し、候補から選択してください。リンクはクリック可能な Wikilink として表示されます：`[[ノート名]]`。

特定の見出しにリンクすることもできます：`[[ノート名#見出し]]`。

## 4. スタービュー (GraphMind)

スタービューは、**GraphMind** エンジン（Pixi.js WebGL）を使用して、ノートをインタラクティブな3Dグラフとして可視化します。

### スタービューを開く

- サイドバーのグラフアイコンをクリック
- `Ctrl+G` を押す
- ミッションコントロール（`Ctrl+P`）> 「スタービュー」

### ナビゲーション

| 入力 | 操作 |
|------|------|
| **クリック＋ドラッグ** | グラフをパン |
| **スクロール** | ズームイン/アウト |
| **ノードをクリック** | ノートを開く |
| **ノードを右クリック** | コンテキストメニュー（開く、フォーカス、ピン留め、非表示） |
| **中クリック＋ドラッグ** | 3D回転 |
| **W/A/S/D** | 3D空間を飛行 |
| **0** | 回転を2Dにリセット |
| **Ctrl+F** | 検索＆ハイライト |
| **Space** | フォーカスモード切替 |

### レイアウトモード

`Ctrl+L` を押して切り替え：

- **オーガニック** — クラスターが自然に形成される力学モデルレイアウト
- **階層型** — トップダウンのツリーレイアウト
- **時系列** — 作成日順にタイムライン上に配置

### フォーカスモード

ノードを右クリック > **フォーカス**で、その近傍のみを表示します。調整項目：

- **深さ**（1～5ホップ）— 表示する接続レベル数
- **方向**（↔/←/→）— 全リンク、受信のみ、送信のみ

### 3D ナビゲーション

中クリック＋ドラッグで回転。W/A/S/D/Q/E でスターフィールドを飛行。コーナーの XYZ 軸ギズモで方向を確認できます。`0` を押してリセット。

### 設定

歯車アイコンをクリックして設定：

- **外観**: ノードサイズ、ラベル表示、フォントサイズ、リンクの太さ、孤立ノードの表示
- **物理**: 反発力、リンク力、リンク距離
- **AI**: セマンティックリンクしきい値（フェーズ2）

### 凡例

右下の凡例に、ライブラリ/フォルダの色がチェックボックス付きで表示され、表示/非表示を切り替えられます。

## 5. セカンドスクリーン

横に並べてノートを表示するための別ウィンドウを開きます。

- **開く**: サイドバーのセカンドスクリーンアイコンをクリック、または `Ctrl+Shift+N`
- **同期**: セカンドスクリーンでノートは独立して開きます。フォントとテーマの設定は両方のウィンドウに適用されます。
- **ノート幅**: ツールバーの幅スライダーで調整可能

## 6. プロパティとフロントマター

ノートの先頭に YAML フロントマターを記述できます：

```yaml
---
tags: [project, active]
date: 2026-03-19
status: in-progress
---
```

Constellation はプロパティタイプを自動検出します：

| タイプ | 例 |
|--------|-----|
| **テキスト** | `author: John` |
| **数値** | `priority: 5` |
| **日付** | `date: 2026-03-19` |
| **リスト** | `tags: [a, b, c]` |
| **チェックボックス** | `done: true` |
| **リンク** | `related: [[Other Note]]` |

プロパティ表示の切り替え：**設定 > エディター > ドキュメント内プロパティ**（表示 / 非表示 / ソース）。

## 7. テンプレート

再利用可能なノートテンプレートを作成：

1. ライブラリ内にテンプレート用フォルダを作成
2. **設定 > テンプレート**でテンプレートフォルダのパスを設定
3. 新規ノート作成時にテンプレートピッカーからテンプレートを選択

テンプレートは変数をサポートしています：

| 変数 | 置換内容 |
|------|----------|
| `{{date}}` | 現在の日付 |
| `{{time}}` | 現在の時刻 |
| `{{title}}` | ノートのタイトル |
| `{{clipboard}}` | クリップボードの内容 |

## 8. テーブル

### Markdown テーブル

Markdown テーブルを手動で入力するか、`/table` スラッシュコマンドを使用します：

```markdown
| ヘッダー1 | ヘッダー2 |
|-----------|-----------|
| セル1     | セル2     |
```

### テーブルツールバー

テーブル内にカーソルがあると、フローティングツールバーが表示されます：

- 行と列の追加/削除
- 列の揃え（左、中央、右）
- `Tab` / `Shift+Tab` でセル間を移動

### ドキュメントエディターでのテーブル

ドキュメントエディター（TipTap）はビジュアルなテーブル操作を提供します：

- テーブルボタンをクリックして挿入
- ドロップダウンで行/列の管理
- 境界線をドラッグして列幅を変更

---

## 9. タスク

Constellation はノート内のタスクチェックボックスをサポートしています：

```markdown
- [ ] 未完了タスク
- [x] 完了タスク
```

ライブプレビューモードでは、チェックボックスをクリックできます。タスクはライブラリ全体で検索・フィルタリングできます。

## 10. インポーター

他の PKM ツールからノートをインポート：

- **Obsidian** — Wikilink 完全互換でボールトをインポート
- **Markdown フォルダ** — `.md` ファイルの任意のフォルダをインポート
- **その他の形式** — HTML、テキストファイル

**設定 > インポーター**でインポートを開始します。

## 11. カレンダー

カレンダービューは、日付ごとにノートを整理して表示します：

- `date` プロパティを持つノートが該当する日に表示されます
- 任意の日付でデイリーノートを作成できます
- 矢印ボタンで月を移動

サイドバーからカレンダーを開きます。

---

## 12. レンズ

レンズは、ノートのフィルタリングビューを提供します：

- タグ、フォルダ、プロパティでフィルタリング
- 名前、日付、またはカスタムプロパティでソート
- レンズ設定を保存してクイックアクセス

## 13. 設定

サイドバーの歯車アイコンまたは `Ctrl+,` で設定にアクセスします。

### 一般

- 言語（15言語）
- テーマ（ライト / ダーク）
- インターフェースフォント、テキストフォント、等幅フォント、フォントサイズ

### エディター

- エディタータイプ（Markdown / ドキュメント）
- デフォルトビュー（閲覧 / 編集）
- ライブプレビューモード
- 行番号、インデントガイド、スペルチェック
- 括弧の自動ペアリング、スマートリスト

### ライブラリ

- ライブラリの追加/削除
- ライブラリごとの外観設定
- 添付ファイルフォルダの場所

### アップデート

- アップデートの確認
- プライベートリポジトリ更新用の GitHub トークン

## 15. RTL とアラビア語サポート

Constellation は、アラビア語、ヘブライ語、ペルシア語、ウルドゥー語、その他の RTL スクリプトをファーストクラスでサポートしています：

- **自動検出**: ノートの方向はコンテンツから自動的に検出されます
- **インターフェース**: アラビア語/ヘブライ語を選択すると完全な RTL インターフェース
- **エディター**: 正しいカーソル移動と選択による RTL テキスト編集
- **スタービュー**: アラビア語ラベルは適切なフォントフォールバックで右から左にレンダリング
- **凡例**: コンテンツ言語に基づいてドット/テキストの順序が反転
- **スクリプトフォント**: 設定でアラビア語、ヘブライ語、CJK フォントを個別に設定可能

### アラビア語の設定

1. **設定 > 一般 > 言語**でアラビア語を選択
2. 必要に応じて**設定 > 一般 > スクリプトフォント**で専用のアラビア語フォントを設定
3. アラビア語コンテンツを含むノートは自動的に RTL でレンダリングされます

## 16. セキュリティとプライバシー

- **すべてのデータはローカルに保存** — クラウド同期なし、テレメトリなし、トラッキングなし
- **Markdown ファイル** — ノートは完全に所有できるプレーンテキストファイルです
- **アカウント不要** — Constellation は完全にオフラインで動作します
- **オプションのアップデート** — 設定から手動でアップデートを確認
- **オープンソース** — [github.com/eisaShamsi/Constellation](https://github.com/eisaShamsi/Constellation) でコードを確認
