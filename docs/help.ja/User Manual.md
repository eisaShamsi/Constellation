# Constellation ユーザーマニュアル

**バージョン 0.3.4 | 2026年3月**

Constellation は、Markdown ノートライブラリを管理するためのパーソナルナレッジマネジメント（PKM）デスクトップアプリケーションです。Tauri v2、SvelteKit、Rust で構築されており、Windows、macOS、Linux 上でネイティブに動作し、アラビア語および RTL を完全サポートしています。

## 1. はじめに

### インストール

[Constellation リリースページ](https://github.com/eisaShamsi/Constellation/releases) から最新のインストーラーをダウンロードしてください：

- **Windows**: `.exe`（NSIS）または `.msi` インストーラー
- **macOS**: `.dmg` ディスクイメージ
- **Linux**: `.AppImage` または `.deb` パッケージ

### 初回起動

Constellation を初めて開くと、**ユニバースセットアップウィザード**が以下の手順を案内します：

1. **言語を選択** — 15言語対応
2. **ライブラリを作成またはインポート** — 既存の Markdown ファイルフォルダを指定するか、新しく作成
3. **ユニバースに名前を付ける** — ユニバースはすべてのライブラリのコンテナです

### インターフェース概要

| 要素 | 説明 |
|------|------|
| **サイドバー（リボン）** | ナビゲーションボタン：ファイルツリー、検索、スタービュー、カレンダー、テンプレート、設定 |
| **ファイルツリー** | ライブラリ内のノートとフォルダを閲覧 |
| **エディター** | Markdown ノートの閲覧と編集 |
| **タブバー** | 複数のノートをタブで開く |
| **ステータスバー** | 文字数、単語数、読了時間 |

## 2. ユニバースとライブラリ

### ユニバースとは？

**ユニバース**は、すべてのライブラリを格納するトップレベルのコンテナです。ワークスペースやライブラリコレクションと考えてください。

### ライブラリとは？

**ライブラリ**は、Markdown（`.md`）ファイルを含むコンピュータ上のフォルダです。1つのユニバースに複数のライブラリを持つことができます。例えば、仕事用ノートと個人用ノートを別々のライブラリにできます。

### ライブラリの管理

- **ライブラリを追加**: 設定 > ライブラリ > ライブラリを追加、またはフォルダをアプリにドラッグ
- **ライブラリを削除**: 設定 > ライブラリ > ライブラリ名の横にある削除ボタンをクリック
- **ライブラリ設定**: 各ライブラリに独自の外観設定（フォント、色）を適用できます

### 子ユニバース

ユニバースの中にユニバースをネストできます。**子ユニバース**は、親ユニバースから参照される別のユニバースフォルダです。子ユニバースのノートは、スタービューで自分のノートと一緒に表示され、ライブラリ間のリンクは破線で示されます。

### 自動再オープン

Constellation は最後にアクティブだったユニバースを記憶し、起動時に自動的に再オープンします。ユニバースが移動されたりパスが変更された場合、Constellation はそれを検出してパスを自動的に修正します。

### ポータブルユニバース

Constellation のユニバースは完全にポータブルです。ユニバースフォルダを別のドライブ、USBメモリ、または別のコンピュータなど、任意の場所に移動でき、Constellation は再度開いた際にすべての内部パスを自動的に検出して修正します。

ユニバースを移動するには：
1. Constellation を閉じる
2. ユニバースフォルダを新しい場所に移動またはコピーする
3. Constellation を開く → ウェルカム画面が表示される（古いパスは無効）
4. **既存のユニバースを開く**を選択し、新しい場所を指定する
5. すべてのノートとライブラリが即座に表示される — パスは自動修正されます

ユニバースのフォルダ構造は Obsidian モデルに従います：ノートはルートフォルダに直接配置され、設定は `.constellation/` に格納されます。

## 3. ノートの作成と編集

### ノートの作成

| 方法 | 操作 |
|------|------|
| **キーボード** | `Ctrl+N` |
| **ファイルツリー** | フォルダを右クリック > 新規ノート |
| **ミッションコントロール** | `Ctrl+P` > 「新規ノート」 |

### エディターモード

Constellation には、**設定 > エディター > エディタータイプ**で選択できる2つのエディターモードがあります：

#### Markdown エディター（CodeMirror）

パワーユーザー向けのデフォルトエディターです。Markdown を直接記述できます：

- **ライブプレビュー** — 入力中にフォーマットをインラインでレンダリング
- **ソースモード** — 生の Markdown 構文を表示
- **フォーマットツールバー** — テキスト選択時に表示
- **スラッシュコマンド** — `/` を入力してクイック挿入
- **Wikilink 自動補完** — `[[` を入力してノートをリンク
- **マルチカーソル** — `Alt+Click` または `Ctrl+D`

#### ドキュメントエディター（TipTap）

ビジュアルツールバーを備えた WYSIWYG ワープロ体験：

- 太字、斜体、下線、取り消し線、ハイライト
- 見出し（H1～H3）、テキスト揃え
- 箇条書き、番号付きリスト、タスクリスト
- 引用、コードブロック、水平線
- テーブル（挿入、行と列の追加/削除）
- リンクと画像

両方のエディターは標準 Markdown ファイルとして保存されます。データを失うことなくいつでも切り替えできます。

### コールアウト (Callouts)

メモ、警告、ヒントなどのスタイル付きコールアウトブロックを作成できます：

```markdown
> [!note] 重要な情報
> コールアウトの内容をここに記述します。

> [!warning] 注意
> この操作は元に戻せません。

> [!tip]- クリックして展開
> 折りたたみ可能なコールアウトの内容。
```

対応タイプ: `note`、`tip`、`warning`、`danger`、`success`、`question`、`failure`、`bug`、`example`、`quote`、`abstract`。各タイプには独自の色とアイコンがあります。タイプの後に `-` を追加すると折りたたみ可能になります（折りたたまれた状態で開始）。`+` で展開された状態で開始します。

### ハイライト構文

テキストを二重イコールで囲むとハイライトできます：

```markdown
これはノート内の==ハイライトされたテキスト==です。
```

ライブプレビューでは、`==` マークは非表示になり、テキストが黄色い背景で表示されます。

### コードブロック

フェンス付きコードブロックは背景色と言語ラベル付きで表示されます：

````markdown
```javascript
const greeting = "Hello, world!";
```
````

言語名がコードブロックの上にバッジとして表示されます。

### 画像の埋め込み

ノートに画像を直接埋め込むことができます：

```markdown
![代替テキスト](https://example.com/image.png)   — 外部 URL
![[photo.jpg]]                                     — ライブラリ内のローカルファイル
```

ライブプレビューでは、画像がインラインで表示されます。ローカル画像はライブラリフォルダー内にある必要があります。外部画像にはインターネット接続が必要です。

### テーブルツールバー

カーソルが markdown テーブル内にあるとき、フローティングツールバーが表示されます：

- **+ 行 / + 列** — 行または列を追加
- **- 行 / - 列** — 行または列を削除
- **配置** — 列ごとに左揃え、中央揃え、右揃え
- **ソート** — 現在の列で昇順または降順にソート
- **Tab / Shift+Tab** — テーブルセル間を移動

### テキストフォーマットショートカット

| ショートカット | 操作 |
|----------------|------|
| `Ctrl+B` | 太字 |
| `Ctrl+I` | 斜体 |
| `Ctrl+Shift+S` | 取り消し線 |
| `Ctrl+Shift+H` | ハイライト |
| `Ctrl+K` | Wikilink を挿入 |
| `Ctrl+Z` | 元に戻す |
| `Ctrl+Shift+Z` | やり直し |

### ノートのリンク

`[[` を入力するとノート自動補完が開きます。ノート名を入力し、候補から選択してください。リンクはクリック可能な Wikilink として表示されます：`[[ノート名]]`。

特定の見出しにリンクすることもできます：`[[ノート名#見出し]]`。

## 4. 検索

Constellation には、SQLite FTS5 ベースの BM25 ランキング、構造化クエリフィルター、アラビア語最適化正規化を備えたハイブリッド多言語検索エンジンが搭載されています。検索はサイドバーツールバーからアクセスできます。

### 検索方法

サイドバーツールバーの検索アイコンをクリックするか、`Ctrl+Shift+F` で検索モードを有効にします。クエリを入力すると、短いディレイ（300ms）の後に結果が表示されます。`Escape` を押すか `×` ボタンをクリックすると、検索がクリアされファイルツリーに戻ります。

### 検索構文

| 構文 | 例 | 検索対象 |
|------|-----|---------|
| フリーテキスト | `プロジェクト管理` | タイトルまたは本文にそれらの単語を含むノート |
| タグフィルター | `#研究` | `#研究` タグが付いたノート |
| プロパティフィルター | `status=active` | frontmatter プロパティ `status` が `active` のノート |
| ウィキリンクフィルター | `links to [[気候]]` | `[[気候]]` にリンクしているノート |
| ライブラリ範囲 | `in:マイライブラリ` | 結果を特定のライブラリに限定 |
| 組み合わせ | `#研究 status=active 経済` | すべてのフィルターを同時に適用 |

### マッチタイプバッジ

各検索結果には、マッチがどのように見つかったかを示す色付きバッジが表示されます。バッジにはアクセシビリティのためにローカライズされた文字が表示されます（色覚対応）：

| バッジ | 色 | 意味 |
|--------|-----|------|
| **タ** | 青 | タイトルマッチ — 検索語がノート名に含まれている |
| **コ** | 緑 | コンテンツマッチ — 検索語がノート本文に含まれている |
| **セ** | 紫 | セマンティックマッチ — 概念的に関連（embeddingモデルが必要） |
| **プ** | 琥珀 | プロパティマッチ — frontmatter プロパティフィルターで検出 |
| **#** | ピンク | タグマッチ — タグフィルターで検出 |
| **ウ** | 水色 | ウィキリンクマッチ — ウィキリンクフィルターで検出 |

バッジ文字はサポートされている全15言語でローカライズされています。

### ピン留め結果（結果間のナビゲーション）

検索結果はクリック後も表示されたままです。開いたノートは結果リストでハイライトされ、どの結果を表示しているか確認できます。再検索せずに別の結果をクリックしてナビゲートできます。

検索をクリアするには、`Escape` を押すか `×` ボタンをクリックします。

### キーボードナビゲーション

| キー | アクション |
|------|-----------|
| `下矢印` | 次の結果を選択 |
| `上矢印` | 前の結果を選択 |
| `Enter` | 選択した結果を開く |
| `Escape` | 検索をクリアしてファイルツリーに戻る |

### 検索語のハイライト

検索結果からノートを開くと、検索語のすべての出現箇所がエディタでハイライトされます。アラビア語のダイアクリティカルマーク対応マッチングが機能し、「ادارة」を検索すると「إدارة」とすべてのダイアクリティカルバリエーションがハイライトされます。

### 検索履歴

検索フィールドが空の時にクリックすると、最近の検索（過去20件）が表示されます。各エントリにはクエリテキストと実行時間が表示されます。任意のエントリをクリックするとその検索を即座に再実行します。下部の「履歴をクリア」リンクですべての履歴を削除できます。

検索履歴はデバイスにローカル保存され、アプリの再起動間で保持されます。

## 5. スタービュー (GraphMind)

スタービューは、**GraphMind** エンジン（Pixi.js WebGL）を使用して、ノートをインタラクティブな3Dグラフとして可視化します。

### スタービューを開く

- サイドバーのグラフアイコンをクリック
- `Ctrl+G` を押す
- ミッションコントロール（`Ctrl+P`）> 「スタービュー」

### ナビゲーション

| 入力 | 操作 |
|------|------|
| **クリック＋ドラッグ** | グラフをパン |
| **スクロール** | ズームイン/アウト |
| **ノードをクリック** | ノートを開く |
| **ノードを右クリック** | コンテキストメニュー（開く、フォーカス、ピン留め、非表示） |
| **中クリック＋ドラッグ** | 3D回転 |
| **W/A/S/D** | 3D空間を飛行 |
| **0** | 回転を2Dにリセット |
| **Ctrl+F** | 検索＆ハイライト |
| **Space** | フォーカスモード切替 |

### レイアウトモード

`Ctrl+L` を押して切り替え：

- **オーガニック** — クラスターが自然に形成される力学モデルレイアウト
- **階層型** — トップダウンのツリーレイアウト
- **時系列** — 作成日順にタイムライン上に配置

### フォーカスモード

ノードを右クリック > **フォーカス**で、その近傍のみを表示します。調整項目：

- **深さ**（1～5ホップ）— 表示する接続レベル数
- **方向**（↔/←/→）— 全リンク、受信のみ、送信のみ

### 3D ナビゲーション

中クリック＋ドラッグで回転。W/A/S/D/Q/E でスターフィールドを飛行。コーナーの XYZ 軸ギズモで方向を確認できます。`0` を押してリセット。

### 設定

歯車アイコンをクリックして設定：

- **外観**: ノードサイズ、ラベル表示、フォントサイズ、リンクの太さ、孤立ノードの表示
- **物理**: 反発力、リンク力、リンク距離
- **AI**: セマンティックリンクしきい値（フェーズ2）

### 凡例

右下の凡例に、ライブラリ/フォルダの色がチェックボックス付きで表示され、表示/非表示を切り替えられます。

### 知識階層

スタービューは、抽象度に基づいてノートを8つの知識階層に自動分類します：

| 階層 | 説明 |
|------|------|
| **スナップショット** | 素早い、一時的なメモ |
| **ログ** | 日付付きの出来事や日記 |
| **トピック** | 1つのアイデアに関するアトミックな概念 |
| **マップ** | 他のトピックをつなぐ整理用ノート |
| **フレームワーク** | モデルや思考の枠組み |
| **原則** | 検証されたルールや公理 |
| **信条** | 基本的な価値観や信念 |
| **成果物** | 完成した最終的な作品 |

階層はノートのフロントマター、構造、リンクから自動的に決定されます。フロントマターに `stratum` プロパティを追加して、手動で分類を上書きできます。

### 成熟ライフサイクル

各ノートは、その発展度を反映する成熟ライフサイクルを経ます：

- **種** — 初期のアイデアや下書き
- **苗** — ノートが形を取り始め、いくつかのリンクを持つ
- **常緑** — 成熟し、レビュー済みで、十分にリンクされたノート
- **正典** — その分野における最終的で権威ある参照

成熟度はリンク数、レビュー日、編集頻度に基づいて自動的に更新されます。フロントマターの `maturity` プロパティで手動設定も可能です。

## 6. スプリットビュー

スプリットビューでは、メインウィンドウで複数のノートを並べて編集できます。

### スプリットビューを開く

- **コマンドパレット**: `Ctrl+P` で "Split View" と入力
- **キーボードショートカット**: 割り当てられたショートカットでモードを切り替え
- **サイクル**: オフ → 垂直（横並び） → 水平（上下） → オフ

### スプリットビューでの編集

各ペインは完全に独立したエディターです：
- フルツールバー（太字、斜体、見出し、配置など）
- パンくずナビゲーション（ライブラリ / ノート名）
- プロパティパネルとステージドロップダウン
- 保存サポート（`Ctrl+S` でフォーカスされたペインを保存）
- タイトル編集とファイル名変更

### ペインのリサイズ

ペイン間の仕切りをドラッグしてリサイズします。各仕切りは独立しており、3つ以上のノートを開いている場合、他に影響を与えずに隣接するペアをリサイズできます。垂直モードと水平モードの両方で動作します。

### フォーカス

任意のペインをクリックしてフォーカスします。フォーカスされたペインがキーボードショートカットを受け取り、右サイドバーパネル（プロパティ、バックリンクなど）で追跡されます。

## 7. インデックス

インデックスは、すべてのライブラリを横断する包括的な用語集です — すべての意味のある単語がアルファベット順に出現回数とともに表示されます。

### インデックスを開く

- **ドックボタン**: 左ドックのインデックスアイコン（本）をクリック
- **コマンドパレット**: `Ctrl+P` で "Index" と入力

### 多言語NLPパイプライン

インデックスはインデックス作成前に言語対応パイプラインでテキストを処理します：

- **アラビア語**: Lucene Light10アルゴリズム — タシュキール除去、ハムザ統一、定冠詞（الـ）除去、文法接尾辞除去
- **ヘブライ語**: 接頭辞除去（ב/ל/מ/ה/ו/כ/ש）
- **英語**: Porter系ステミング（複数形、動詞形、接尾辞）
- **フランス語/スペイン語/ポルトガル語/ドイツ語**: 言語固有の接尾辞除去
- **ロシア語/トルコ語/ヒンディー語/ペルシア語**: 形態論的接尾辞除去
- **全15言語**: ストップワードフィルタリング（冠詞、前置詞、接続詞）

### ブラウジング

- **言語タブ**: すべて、アラビア語、ヘブライ語、英語、#（特殊文字）を切り替え
- **アルファベットバー**: 文字をクリックしてその文字で始まる用語をフィルタリング — 用語数が更新され一致数を表示
- **同じ文字をもう一度クリック**するとフィルターがクリアされすべての用語が表示されます
- **ソートモード**: アルファベット順（デフォルト）または頻度順（最も多いものから）

### インデックスからの編集

用語の参照内の任意のノートをクリックすると、インデックスの横に分割プレビューペインで開きます。プレビューペインはフルエディターです — 編集、保存、プロパティの変更、ステージの昇格が可能です。検索用語はノート内でハイライトされ、自動的にスクロールされます。

`Ctrl+Click` でノートを通常のタブとして開きます。タブバーに「インデックスに戻る」ボタンが表示されます — クリックするとインデックスで中断した場所に正確に戻ります。

### セカンドスクリーン統合

セカンドスクリーンが開いている場合：
- **用語をクリック** → セカンドスクリーンがその用語を含むすべてのノートを分割ビューで表示（ノートリスト + エディター）
- **複数の用語をCtrl+Click** → セカンドスクリーンが比較モードを表示し、各用語が独自の列に配置されます

## 8. セカンドスクリーン

セカンドスクリーンは、現在のサイドバーモードに適応するモードベースのコンパニオンウィンドウです。

- **開く**: サイドバーのセカンドスクリーンアイコンをクリック、または `Ctrl+Shift+2`
- **自動終了**: メインウィンドウを閉じると、セカンドスクリーンも自動的に閉じます

### モードベースのコンパニオン

セカンドスクリーンは、メインウィンドウのアクティブなサイドバーモードに基づいてコンテンツを変更します：

| メインサイドバーモード | セカンドスクリーンの表示 |
|---|---|
| **ファイルエクスプローラー** | ユニバースダッシュボード — 統計、ライブラリの内訳、子ユニバース、タグ、最近編集/開いたノート |
| **ナビゲーター** | ノートをブラウズするための完全なナビゲータービュー |
| **スカイビュー** | ディレクトリ構造付きスカイビューツリー |
| **スタービュー** | バックリンク、フォワードリンク、タグ、ローカルグラフ付きスタービューコンパニオン |

### ユニバースダッシュボード（ファイルエクスプローラーモード）

メインウィンドウがファイルエクスプローラーモードの時、セカンドスクリーンは以下を含むダッシュボードを表示します：

- **統計カード** — ユニバース名、子ユニバース数、ライブラリ・フォルダ・ノートの合計
- **子ユニバース** — リンクされたライブラリとフォルダ/ノート数を含む各子ユニバース
- **ライブラリ** — 色分けされた統計ボックスにフォルダ/ノート数を含む各ライブラリ
- **最近編集** — 現在のセッションで変更したノート（保存時に追跡）
- **最近開いた** — 現在のセッションで開いたが編集していないノート
- **タグ** — ライブラリ全体のすべてのタグを数順でソート；タグをクリックして関連するすべてのノートを表示

### ダッシュボード連携

メインウィンドウでダッシュボードがアクティブな場合、アイテムをクリックするとセカンドスクリーンに送信されます：

- **最近編集/開いた**: ノートをクリックすると、セカンドスクリーンでフルエディターとして開きます
- **タグ**: タグをクリックすると、そのタグを使用するすべてのノートがスプリットビューで表示されます — 左側にノートリスト、右側にフルエディター

セカンドスクリーンでのすべての編集は、自動的にメインウィンドウに同期されます。

### セカンドスクリーンでのノート編集

セカンドスクリーンはフルノート編集をサポートします — メインウィンドウと同様に入力、保存、名前変更、プロパティ変更が可能です。変更は自動的にメインウィンドウに同期されます。

### 設定の同期

すべての視覚設定がセカンドスクリーンに即座に反映されます — 再起動不要：

- **言語**: インターフェース言語の変更が即座に適用
- **テーマ**: ライト/ダーク/システムモードが即座に切り替え
- **フォント**: インターフェースフォント、テキストフォント、等幅フォント、スクリプト固有フォント
- **フォントサイズ**: インターフェースとエディターの両方のフォントサイズ
- **エディター**: 読みやすい行幅、行番号、フローティングツールバー
- **アクセントカラー**: テーマのアクセントカラーの変更

## 18. RTL とアラビア語サポート

Constellation は、アラビア語、ヘブライ語、ペルシア語、ウルドゥー語、その他の RTL スクリプトをファーストクラスでサポートしています：

- **自動検出**: ノートの方向はコンテンツから自動的に検出されます
- **インターフェース**: アラビア語/ヘブライ語を選択すると完全な RTL インターフェース
- **エディター**: 正しいカーソル移動と選択による RTL テキスト編集
- **スタービュー**: アラビア語ラベルは適切なフォントフォールバックで右から左にレンダリング
- **凡例**: コンテンツ言語に基づいてドット/テキストの順序が反転
- **スクリプトフォント**: 設定でアラビア語、ヘブライ語、CJK フォントを個別に設定可能

### アラビア語の設定

1. **設定 > 一般 > 言語**でアラビア語を選択
2. 必要に応じて**設定 > 一般 > スクリプトフォント**で専用のアラビア語フォントを設定
3. アラビア語コンテンツを含むノートは自動的に RTL でレンダリングされます

## 20. ナレッジマップ

ナレッジマップは、知識ユニバース全体の構造、密度、成熟度を表示するラジアルサンバースト視覚化です。

### マップを開く

- **ドックボタン**: 左ドックのナレッジマップアイコンをクリック
- **コマンドパレット**: `Ctrl+P` で「Constellation Map」と入力

### 表示内容

- **中心**: ユニバース名と合計ノート数・単語数
- **最初のリング**: ライブラリ（各ライブラリの色で表示）。子ユニバースがある場合はここにも表示されます。
- **深いリング**: 各ライブラリ内のフォルダとサブフォルダ
- **最外部セグメント**: 個別ノート

### カラーモード

ドロップダウンで3つのモードを切り替え:
- **成熟度**: 種（灰色）→ 苗（薄緑）→ 常緑（緑）→ 正典（金）→ 枯れ
- **階層**: L1（青）→ L8（赤）— 知識の複雑さを表示
- **ライブラリ**: すべてのセグメントが親ライブラリの色を継承

### ドリルダウンナビゲーション

フォルダセグメントをクリックしてズームイン。パンくずリストでパスを確認。パンくずアイテムをクリックして戻るか、Escapeキーを押します。ノートセグメントをクリックしてエディタで開きます。

### マップに戻る

マップからノートを開いた後、タブバーに「マップに戻る」ボタンが表示されます。クリックすると元の場所に戻ります — ドリルダウンレベルが保持されます。

## 21. 認知エンジン

認知エンジンは、Constellation に組み込まれたインテリジェンスシステムで、ノートを分析し、アイデア間の隠れたパターンや関係を発見します。その根底にある哲学：

> 「データの量は問題ではありません。大切なのは、いくつのソースを保存するかではなく、そこからどのように知識を練り上げ、ひとつの意味ある認識へとつなげるかです。」

認知エンジンは9つの統合ツールで構成されています：タイプ付きリンク、知識階層、成熟ライフサイクル、テンション検出器、来歴チェーン、外在化エンジン、レビューパルス、トレイル、マルチレンズビュー。

---

### 17.1 タイプ付きリンク

#### これは何か？

タイプ付きリンクは、2つのノート間の関係の種類を記述するウィキリンクです。単に `[[ノート]]` と書く代わりに、`[[ノート|関係タイプ]]` と書くことで、つながりの本質を表現します——派生しているのか？矛盾しているのか？拡張しているのか？

#### なぜ重要か？

通常のリンクは「つながりがある」とだけ伝え、どのようなつながりかは示しません。タイプ付きリンクは、ノートのネットワークを参照の山から、思考構造・依存関係・推論を可視化する本物のナレッジマップへと変えます。

#### 使い方

1. エディタでノートを開く
2. 関係タイプ付きのウィキリンクを書く：`[[対象ノート|derives-from]]`
3. 対応タイプ：`derives-from`（由来）、`supports`（支持）、`contradicts`（矛盾）、`extends`（拡張）、`exemplifies`（例示）、`questions`（疑問）
4. 右サイドバーのノートプロパティからもタイプを追加可能

#### どこに表示されるか？

- **スタービュー（GraphMind）**：ノード間の色付きラベル付き線として
- **右サイドバー**：「バックリンク」タブにリンクタイプの表示付き
- **来歴タブ**：知識の系譜ツリー構築に使用

---

### 17.2 知識階層

#### これは何か？

認知エンジンは各ノートを8つの知識階層のいずれかに自動分類します：スナップショット、ログ、トピック、マップ、フレームワーク、原則、信条、成果物。分類はノートの構造、内容、リンク数に基づきます。

#### なぜ重要か？

各ノートの種類を知ることで、ライブラリ内の知識バランスが明らかになります。ノートの大半は一時的なスナップショットですか？それとも原則やフレームワークに発展していますか？コンテンツの本質への意識は、単なる情報収集ではなく真の知識構築への第一歩です。

#### 使い方

1. 分類は自動的に行われます——何もする必要はありません
2. 自動分類を上書きするには、フロントマターに `stratum` プロパティを追加：
   ```yaml
   ---
   stratum: framework
   ---
   ```
3. 使用可能な値：`snapshot`、`log`、`topic`、`map`、`framework`、`principle`、`conviction`、`artifact`

#### どこに表示されるか？

- **右サイドバー**：ノートプロパティの「階層」の下
- **スタービュー**：階層に応じたノードの色分け
- **設定 > 認知エンジン**：自動分類の有効/無効

---

### 17.3 成熟ライフサイクル

#### これは何か？

エンジンは各ノートの成熟度を4段階で追跡します：**種** → **苗** → **常緑** → **正典**。すべてのノートは種として始まり、コンテンツ、リンク、レビューの追加とともに徐々に成長します。

#### なぜ重要か？

成熟度は、生のアイデアと洗練された知識を区別します。今日の種は、十分な注意を払えば明日のリファレンスになり得ます。成熟度トラッキングは、さらなる発展と注意に値するノートの特定を助けます。

#### 使い方

1. 成熟度は以下に基づいて自動的に変化：語数、入出リンク数、最終更新日
2. 成熟度を手動設定するには、フロントマターに `maturity` プロパティを追加：
   ```yaml
   ---
   maturity: evergreen
   ---
   ```
3. 使用可能な値：`seed`（種）、`sapling`（苗）、`evergreen`（常緑）、`canonical`（正典）

#### どこに表示されるか？

- **右サイドバー**：タイトル横のアイコンで現在の成熟段階を表示
- **スタービュー**：ノードサイズとして——成熟したノートほどノードが大きい
- **設定 > 認知エンジン**：成熟度トラッキングの有効/無効

---

### 17.4 テンション検出器

#### これは何か？

テンション検出器は、関連するノートを検査し、2つ以上のノート間で主張や結論が矛盾している場合に警告します。`contradicts` タイプのリンク分析とノート間のテーマ的類似性に基づいて動作します。

#### なぜ重要か？

テンションは必ずしもエラーではありません——より深い思考への招待です。ライブラリ内の2つのアイデアが矛盾する場合、それは理解が進化したか、探求に値する複雑さが存在することを意味します。テンション検出は、矛盾した基盤の上に無意識に知識を積み上げることを防ぎます。

#### 使い方

1. 矛盾するノート間に `contradicts` タイプリンクを追加：`[[別のノート|contradicts]]`
2. エンジンはコンテンツ分析による暗黙のテンションも検出
3. サイドバーから検出されたテンションのリストを確認

#### どこに表示されるか？

- **右サイドバー**：矛盾が検出された場合の「テンション」タブ
- **スタービュー**：矛盾するノード間の赤い点線
- **通知パネル**：新しいテンション検出時のアラート

---

### 17.5 来歴チェーン

#### これは何か？

来歴チェーンは各アイデアの起源を追跡します——どこから来たのか、何から派生したのか。`[[ノート|derives-from]]` リンクを使用して、元のソースから現在の定式化に至るまでの知識の発展経路を示す系譜ツリーを構築します。

#### なぜ重要か？

アイデアの出所を知ることは、受信した知識（書籍、記事、講義から）と発見した知識（自分自身の結論と考察）を区別します。知識のソースへの意識は、アイデアの信頼性を評価し、時間の経過とともに思考がどのように形成されたかを理解するのに役立ちます。

#### 使い方

1. ソースから派生したノートを作成する際にリンクを追加：`[[元のソース|derives-from]]`
2. 多段階チェーンの構築が可能：ノート ← 由来 ← 由来 ← 元のソース
3. フロントマターに `source-type: received` を追加して外部ソースを分類

#### どこに表示されるか？

- **右サイドバー**：「来歴」タブに完全な系譜ツリーを表示
- **スタービュー**：リンク上の矢印の方向（ソースから派生へ）
- **ノートプロパティ**：来歴チェーンに基づく「受信」または「発見」分類

### 17.6 外在化エンジン

#### これは何か？

ノートが生のキャプチャから結晶化された洞察へと成熟する過程を追跡する段階的な形式化パイプラインです。各ノートには4つのステージのいずれかを割り当てることができます：

| ステージ | アイコン | 意味 |
|----------|----------|------|
| 一時的 | 🌱 | 素早いキャプチャ、一時的な思いつき |
| 文献 | 📖 | ソースから自分の言葉で書き直したもの |
| 永続 | 🔗 | アトミックなアイデア、1つのコンセプト、グラフに接続 |
| 統合 | ✨ | 複数の永続ノートを組み合わせたオリジナルの洞察 |

#### なぜ重要か？

ほとんどのアプリはすべてのノートを同じように扱います。外在化エンジンはその違いを可視化します — ライブラリのどれだけが生のキャプチャで、どれだけが真の理解なのかを一目で確認できます。

#### 使い方

1. ブレッドクラムバー（エディタの上）で、ステージドロップダウンを使用してステージを選択します。
2. またはプロパティを展開してそこのステージドロップダウンを使用します。どちらもファイルツリーと即座に同期します。
3. ノートを昇格するには、ドロップダウンを1つのステージから次のステージに変更します。フォーカスモードでは、下部の「永続に昇格」をクリックします。
4. ステージを削除するには、ドロップダウンから「— ステージ —」を選択します。

#### どこに表示されるか？

- **ブレッドクラムバー**：絵文字 + ステージ名のドロップダウン
- **プロパティパネル**：`stage` プロパティが存在する場合のドロップダウン
- **ファイルツリー**：ノート名の横に絵文字アイコン
- **フォーカスモードフッター**：「永続に昇格」ボタン

### 17.7 レビューパルス

#### これは何か？

レビューパルスは、拡大する間隔でノートを再浮上させるシステムです：最終レビューから1日、3日、7日、14日、30日後にノートを注意に戻します。`#assumption`や`#model`タグのついたノートをメンタルモデルチェックポイントとして監視し、キャプチャしたが一度も再訪していないノートの「未レビュー」キューも管理します。

#### なぜ重要か？

知識は再訪なしに衰退します。今日ノートを書いて、3週間後にはその存在を忘れています。間隔反復は認知科学でこの衰退と戦う最も確立された技法です。レビューパルスはこの原理を実際のノートに適用します。

#### 使い方

1. 左サイドバーの**レビューパルス**タブをクリックします。3つのセクションが表示されます：レビュー予定、メンタルモデルチェックポイント（`#assumption` / `#model`）、未レビュー。
2. ノートをクリックして開き、読みます。
3. 3つのアクションから選択します：
   - **レビュー済み**（チェックマーク）— 次の間隔で次のレビューをスケジュール（1 → 3 → 7 → 14 → 30日）。
   - **7日スヌーズ**（目のアイコン）— 間隔を進めずにノートを7日延期。
   - **却下**（アーカイブアイコン）— ノートをレビューキューから永久に削除。
4. コマンドパレットを開いて "Review due notes" と入力します。

#### どこに表示されるか？

- **左サイドバー**：レビューパルスタブに予定ノートのバッジカウント
- **コマンドパレット**：クイックアクセス用の "Review due notes" コマンド

### 17.8 トレイル

#### これは何か？

トレイルは、ノートの名前付き順序付きシーケンスです — 本の章や知識のガイドツアーの停留所のようなものです。ノートのfrontmatterに`trail: true`を追加し、ノート本文にウィキリンクを順番にリストすることで定義します。

#### なぜ重要か？

知識は常にウェブではありません。時にはパスです — 学習シーケンス、議論の進行、物語。トレイルはその順序を明示的にキャプチャし、非線形ライブラリに線形の次元を追加します。

#### 使い方

1. frontmatterに`trail: true`を含む新しいノートを作成します。
2. ノート本文に、希望の順序でウィキリンクをリストします。
3. トレイルに属するノートを開くと、ブレッドクラムバーにトレイル名と位置が表示されます（例：「マイトレイル 2/5」）。矢印ボタンで前後のノートに移動できます。
4. コマンドパレットを開いて "Open Trail" と入力すると、全トレイルが表示されます。

#### どこに表示されるか？

- **ブレッドクラムバー**：名前、位置、ナビゲーション矢印付きのトレイルインジケーター
- **コマンドパレット**："Open Trail" コマンドで全トレイルを一覧

### 17.9 マルチレンズビュー

#### これは何か？

マルチレンズビューは、フォルダ構造を変更したりノートを複製したりすることなく、異なる分類スキームでライブラリを表示できます。「レンズ」はプロパティやタグに基づいてノートを再編成する仮想的なグループ化です。組み込みレンズ：「ステージ別」（一時的/文献/永続/統合）と「トピック別」（タグによるグループ化）。設定でカスタムレンズを作成できます。

#### なぜ重要か？

フォルダ構造は単一の階層を強制しますが、知識は一つの木には収まりません。マルチレンズビューは、ファイルを移動せずに異なる視点を切り替えることができます。同じノートを、異なる組織的レンズで表示します。

#### 使い方

1. サイドバーで、ファイルツリーの上部にある**レンズドロップダウン**を見つけます（デフォルトは「フォルダ」）。
2. レンズを選択：「ステージ別」、「トピック別」、またはカスタムレンズ。サイドバーが即座に再編成されます。
3. デフォルトのファイルツリーに戻るには「フォルダ」を選択します。
4. カスタムレンズを作成するには：**設定 > ナレッジマネジメント**を開き、**レンズを作成**をクリックし、名前を付けてグループ化するfrontmatterプロパティを選択します。
5. またはコマンドパレットを使用："Create Lens" と入力します。

#### どこに表示されるか？

- **サイドバードロップダウン**：ファイルツリーの上部にあるレンズセレクター
- **設定 > ナレッジマネジメント**：カスタムレンズの作成、編集、削除
- **コマンドパレット**："Create Lens" コマンド

### 認知エンジンの設定

認知エンジンの全ツールは **設定 > 認知エンジン** で設定可能です：

- **階層分類** — 自動分類を有効/無効にする
- **成熟度トラッキング** — 成熟ライフサイクルの追跡を有効/無効にする
- **タイプ付きリンク** — リンク検出の感度しきい値を調整（0.0 ～ 1.0）
- **テンション検出器** — 自動テンション検出を有効/無効にする
- **手動上書き** — フロントマターに `stratum` と `maturity` プロパティを追加して自動分類を上書き
