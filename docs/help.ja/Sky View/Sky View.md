# Sky View

Sky Viewは、**GraphMind**エンジン（Pixi.js WebGL）を搭載し、ノートをノードとリンクのインタラクティブなネットワークとして表示します。各ノードが1つのノートで、各線がノート間の`[[wikilink]]`を表します。ノートのつながりが多いほど、そのノードは大きく表示されます。

## Sky Viewを開く

| 方法 | 操作 |
|--------|--------|
| **ミッションコントロール** | `Ctrl+P`を押して「star view」と入力 |
| **キーボード** | `Ctrl+G` |

`Escape`を押すとSky Viewを閉じます。

> [!note]
> Sky Viewのリボンアイコンは左ドックから削除されました。Sky Viewはキーボードショートカットまたはミッションコントロールからアクセスできるようになりました。Sky View（OrgChart）モードは、ノート管理サイドバーのタブとして利用できます。

---

## グラフを操作する

### 基本的な操作

| 入力 | 動作 |
|-------|----------|
| **パン** | 空白部分をクリックしてドラッグ |
| **ズーム** | スクロールホイール（2D）または`Ctrl+スクロール`（3D） |
| **ノードをドラッグ** | 任意のノードをクリックしてドラッグし、位置を変更 |
| **ホバー** | ステータスバーにノート名を表示し、つながったノードとエッジをハイライト |
| **ノードをクリック** | そのノートをエディタで開く |
| **ノードをダブルクリック** | そのノードにズームして中央に配置 |
| **ノードを右クリック** | コンテキストメニューを開く |

### コンテキストメニュー

任意のノードを右クリックすると、次の操作にアクセスできます：

| 操作 | 説明 |
|--------|-------------|
| **開く** | ノートをエディタで開きます |
| **フォーカス** | このノードを中心としたフォーカスモードに入ります |
| **ピン留め** | ノードを現在の位置にロックします。もう一度クリックするとピンを解除します。 |
| **非表示** | グラフからノードを非表示にします。隠れたノードを再表示するには、ツールバーの「すべて表示」を使用します。 |

## 3Dナビゲーション

Sky Viewは完全な3Dナビゲーションに対応しています — 星々の間を進むように、ノートの中を飛び回れます。

### 3Dモードに入る

**中クリックしてドラッグ**（または**Alt+クリックしてドラッグ**）すると、グラフを3D空間で回転できます。一度回転すると、3Dナビゲーションのコントロールが有効になります。

### 3Dコントロール

| 入力 | 操作 |
|-------|--------|
| **中クリックドラッグ** | X軸とY軸まわりに回転 |
| **Shift+中クリックドラッグ** | Z軸まわりに回転 |
| **W / 上矢印** | 前進（画面の奥へ） |
| **S / 下矢印** | 後退 |
| **A / 左矢印** | 左へ平行移動 |
| **D / 右矢印** | 右へ平行移動 |
| **Q** | 下へ移動 |
| **E** | 上へ移動 |
| **Ctrl+スクロール** | ズーム（視野角を変更） |
| **通常のスクロール** | カメラの向きに沿って前進／後退 |
| **0** | 回転をリセットしてフラットな2Dビューに戻す |
| **リセットボタン**（↺アイコン） | `0`を押すのと同じ |

### XYZ軸ギズモ

3Dモードでは、色分けされた軸ガイドが左下隅に表示されます：

| 軸 | 色 | 方向 |
|------|-------|-----------|
| **X** | 赤 | 左–右 |
| **Y** | 緑 | 上–下 |
| **Z** | 青 | 前–後（奥行き） |

ギズモはカメラと一緒に回転するため、常に自分の向きを把握できます。

### 3Dでのホバーとクリック

3Dでナビゲーションしている間も、ノードにホバーしたりクリックしたりできます。ステータスバーにノート名が表示され、クリックするとノートが開きます — 2Dモードとまったく同じです。

## レイアウトモード

Sky Viewには3つのレイアウトアルゴリズムがあります。`Ctrl+L`を押すか、ツールバーのレイアウトボタンを使って切り替えます。

| モード | 説明 | 適した用途 |
|------|-------------|----------|
| **オーガニック** | 力学ベースのレイアウト。リンク密度から自然にクラスタが現れます。 | 一般的な探索 — デフォルトのモードです。 |
| **階層** | トップダウンの有向非巡回グラフ（DAG）。 | 親子関係を持つ構造化されたライブラリ。 |
| **時系列** | 作成日に基づき、水平の時間軸に沿ってノードを配置。 | ノートがいつ作成され、ライブラリがどのように成長したかを把握。 |

モードを切り替えると、空間的な向きを保ったまま、なめらかなアニメーションでトランジションします。

> [!tip]
> 階層モードは、ツリー状の構造をたどるノート（たとえば、サブトピックにリンクするMOC）に特に役立ちます。時系列モードは、知的なタイムライン — 関連するノートのクラスタがいつ作成されたか — を明らかにします。

## フォーカスモード

フォーカスモードは、特定のノートとその近傍だけを表示します。動的でインタラクティブなローカルグラフです。

### フォーカスモードに入る

- **ノードを右クリック** → **フォーカス**
- **スペースを押す**と、現在アクティブなノートでフォーカスモードを切り替えます

### フォーカスのコントロール

フォーカスモードに入ると、上部にコントロールバーが表示されます：

| コントロール | 説明 |
|---------|-------------|
| **深さスライダー**（1–5） | 何ホップ分のつながりを表示するか。1 = 直接のリンクのみ、5 = 5段階先まで。 |
| **方向フィルター**（↔ / ← / →） | すべてのリンク、受信のみ、または送信のみを表示。 |
| **終了ボタン**（×） | 完全なSky Viewに戻る |

### ナビゲーションのパンくずリスト

フォーカスモードでノードをクリックしてたどっていくと、上部にナビゲーション経路を示すパンくずリストが表示されます。いずれかのパンくずをクリックすると、そのノートのローカルグラフに戻れます。

> [!tip]
> フォーカスモードと深さスライダーを組み合わせて、ノートの近傍を段階的に探索しましょう。深さ1から始めて直接のつながりを確認し、それから値を増やして二次・三次の関係を発見します。

## 検索ハイライト

`Ctrl+F`を押すと検索バーが開きます。クエリを入力すると、一致するノートがハイライトされます。

フィルターとは異なり、検索ハイライトは一致しないノードを削除せず**薄く**します。一致するノードがハイライトされる一方で、グラフ全体の構造と空間的な文脈はそのまま保たれます。

> [!tip]
> 検索は完全なグラフでもフォーカスモードでも機能します。3Dモードの最中にも検索できます。

---

## 設定パネル

ツールバーの歯車アイコン（⚙）をクリックすると、設定パネルが開きます。3つのタブがあります：

### グラフの外観

| コントロール | 説明 | 既定値 |
|---------|-------------|---------|
| **ノードサイズ** | すべてのノードを大きく、または小さくスケール | 1.5 |
| **ラベルの表示** | ラベルを表示するタイミング：ホバー時、常に、またはなし | ホバー時 |
| **ラベルのフォントサイズ** | ノート名ラベルのサイズ | 12 |
| **リンクの太さ** | エッジの線の幅 | 1 |
| **孤立ノートを表示** | リンクのないノートを含める | オン |

> **キャンバスの背景色。** バブルの背後の色は、（このパネルではなく）**設定 → スタイルセッター → Sky View → キャンバス → 背景**で設定します。サイドバーやパネルとは独立しているため、たとえばバブルを際立たせる深い色など、インターフェースのほかの部分を変えることなく、グラフに独自の背景を与えられます。未設定のままにすると、キャンバスはパネルのサーフェスに合わせられます。*外観とテーマ → Sky Viewのキャンバス*を参照してください。

### 物理演算

| コントロール | 説明 | 既定値 |
|---------|-------------|---------|
| **反発力** | ノードが互いに押し離す強さ | 50 |
| **リンク力** | リンクされたノードが引き合う強さ | 0.05 |
| **リンク距離** | リンクされたノード間の目標距離 | 30 |
| **シミュレーションを再加熱** | 現在の状態から力学レイアウトを再開 | — |

### AI

セマンティックAIリンクの設定（フェーズ2 — ローカルの埋め込みモデルが必要）。

| コントロール | 説明 |
|---------|-------------|
| **セマンティックリンクを表示** | AIが検出した破線のエッジを切り替え |
| **信頼度しきい値** | 類似度スコアでセマンティックリンクを絞り込むスライダー |

## 凡例

凡例は右下隅に表示され、ライブラリへの色の割り当てを示します。

### カラーモードの切り替え

凡例の上部にある**ライブラリ**または**フォルダ**ボタンをクリックすると、ノードの色分け方法を切り替えられます：

| モード | 色分け |
|------|----------|
| **ライブラリ** | 各ライブラリに固有の色が割り当てられます |
| **フォルダ** | 各トップレベルフォルダに固有の色が割り当てられます |

### 表示チェックボックス

各凡例エントリにはチェックボックスがあります。ライブラリまたはフォルダのチェックを外すと、そのノードがグラフから非表示になります。これにより、知識ベースの特定の部分集合に集中できます。

> [!tip]
> フォルダモードでは、フォルダ数が括弧内に表示されます。長いフォルダの一覧はスクロールできます。

## ステータスバー

左下のステータスバーには次が表示されます：

- **ノード数** — 表示中のノードの合計
- **エッジ数** — 表示中のエッジの合計
- **MOC数** — コンテンツマップ（つながりの多いハブとなるノート）の数
- **ホバー中のノート名** — ノードにホバーしたときに表示

## RTL対応

Sky Viewは、アラビア語、ヘブライ語、その他のRTL（右から左）の書記系に対する第一級のサポートを提供します：

- **ノードラベル**は書記系の方向を自動検出します — アラビア語のタイトルは右から左にレンダリングされます
- **凡例の項目**は、内容の言語に応じてドットとテキストの順序を入れ替えます
- **ツールチップとパネル**はRTLレイアウトを尊重します
- **アラビア語フォントのフォールバック** — 主フォントにアラビア語のグリフがない場合、ラベルにはシステムのアラビア語フォント（Noto Naskh Arabic、Segoe UI）が使用されます

## ピクチャーインピクチャー（PiP）オーバーレイ

Sky Viewを開いた状態で、ノート管理サイドバーで子ユニバース、ライブラリ、またはフォルダをクリックすると、メインのグラフの上にサイズ変更可能なオーバーレイとして**ピクチャーインピクチャー（PiP）**ウィンドウが表示されます。

### PiPに表示される内容

PiPは、選択したスコープに属するノードだけを含む、絞り込まれたサブグラフを表示します。たとえば、ライブラリをクリックすると、そのライブラリのノートとその相互のつながりだけが表示されます。

### PiPの機能

| 機能 | 説明 |
|---------|-------------|
| **絞り込まれたグラフ** | 選択したスコープのノードのみが表示されます |
| **絞り込まれた凡例** | PiPには関連する項目だけを示す独自の凡例があります |
| **サイズ変更可能** | 端または角をドラッグしてPiPウィンドウのサイズを変更します |
| **位置変更可能** | タイトルバーをドラッグして、PiPを画面上の任意の場所に移動します |

### モードをまたぐ選択の同期

いずれかのサイドバーモード（ツリー、リスト、またはOrgChart）で子ユニバース、ライブラリ、フォルダ、またはノートをクリックすると、Sky Viewのグラフ内の対応するノードがハイライトされます。この双方向の同期により、サイドバーで閲覧している間も空間的な感覚を保てます。

## 知識の層（Knowledge Strata）

Sky Viewは、ノードをその知識レベル（1〜8）に基づいて自動的にサイズ設定します：

- 小さなドット：単純なノート（データ、情報）
- 中サイズのノード：つながりのあるノート（命題、概念）
- 大きく輝くハブ：統合されたノート（理論、パラダイム、世界観）

より高いレベルのノードには、視覚的なコントラストのために補色の光のハロが付きます。これはライブラリに20以上のノートがあるときに有効になります。

---

## ノートの成熟度

ノードには、成熟度を示す色付きのリングが表示されます：

- リングなし：種（新しいノート）
- 薄い緑のリング：若木（成長中）
- 濃い緑のリング：常緑（よく確立されている）
- 金のリング：正典（権威ある参照）

成熟度は、ファイルツリー（左の枠線）とタブバー（色付きのドット）にも表示されます。

---

## 来歴の光（Provenance Glow）

Sky Viewのノードは、知識の起源を示す控えめな色の光を表示します：

- **青い光**：受容した知識 — ノートのソース系統が外部の参照（フロントマターにurl、author、またはdoiを持つノート）までたどれる場合
- **琥珀色の光**：発見した知識 — ノートのソース系統がユーザー自身のノートに由来する場合

## 技術ノート

Sky Viewは**GraphMind**エンジンを搭載しています。これは、専用のWebワーカーでd3-forceシミュレーションを実行するPixi.js WebGLレンダラーです。このアーキテクチャにより、次が保証されます：

- **60fpsのレンダリング** — 数千のノードがあっても
- **非ブロッキングのレイアウト** — 力学シミュレーションがUIをフリーズさせることはありません
- **ホバーは視覚のみ** — ホバーが物理演算の再計算を引き起こすことはありません
- **シミュレーションは安定すると停止** — ノードが位置を見つけると、物理エンジンは完全に停止します。ノードのドラッグまたは設定の変更だけが、これを再開させます。
