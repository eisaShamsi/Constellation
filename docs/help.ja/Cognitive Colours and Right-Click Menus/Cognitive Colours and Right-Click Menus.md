# 認知の色と右クリックメニュー

このトピックは、いっしょに到着した2つのことを扱います：**2つの新しいスタイルセッターのカテゴリー** — **プロパティ**（フロントマター内の小さなタグを再装飾）と**認知の色**（認知状態ごとに1つの色コントロール、アプリ全体で共有）— そして、ノート本文・フロントマターのプロパティ・検索結果で適切な操作をワンクリックで提供する**アプリ全体の右クリックメニュー**です。

> スタイルセッターは、**設定 → 外観 →「✦ スタイルセッターを開く」**から、または設定サイドバー内の独立した**スタイルセッター**タブから開く、フルページのデザインスタジオです。以下の2つのカテゴリーは、左側の*サーフェス*一覧の中で、インターフェース、エディタ、リンクなどと並んでいます。セッターの一般的な動作 — 検査、Keep / Discard / Reset、保存済みスタイル — については [[Appearance and Themes]] を参照してください。

---

## スタイルセッター → プロパティ

**プロパティ**カテゴリーは、ノートの**フロントマター**（YAMLプロパティブロック）の中に表示される小さなタグ — プロパティパネルやノート上部に表示される `tags` や `aliases` などのチップ — を再装飾します。これまではこれらは固定されていましたが、いまやあなた自身の手で形を整えられます。

**スタイルセッター**を開き、左の一覧で**プロパティ**をクリックします。中央にプロパティピルのライブプレビューが表示され、右側のコントロールをクリックして編集すると、プレビューが再装飾されます。2つの要素があります：

### プロパティタグ

通常のフロントマターのタグチップ（たとえば `tags` リスト内の各値）。4つのコントロール：

- **タグの背景** — チップの塗り色。
- **タグのテキスト** — チップ内のテキストの色。
- **タグの角丸** — チップの角の丸み（0 px = 四角、最大20 px = 完全な丸み）。
- **高さ** — チップの高さ（ピクセル単位、14〜32 px）。

### 分類ピル

分類スタイルの値に使われるピル。3つのコントロール：

- **背景** — ピルの塗り色。
- **テキスト** — ピル内のテキストの色。
- **角丸** — 角の丸み（0〜20 px）。

> **コントロールに触れるまで何も変わりません。** すべての値は、いま現在の見た目とまったく同じ状態から始まります。そのため、あなたが意図的に色を選んだりスライダーをドラッグしたりするまで、プロパティカテゴリーがノートの見た目を変えることはありません。**Keep** をクリックすると、この見た目がこのユニバースに保存されます。

## スタイルセッター → 認知の色

Constellationは、あなたの**認知の語彙**を色で描きます — ノートの*成熟度*、リンクの*確信*、アイデアが*どこから来たか*、それがライフサイクルのどの*ステージ*にあるか、そして検索結果が*なぜ*一致したか。問題は、これらの色がサーフェスごとに別々に決められていたことでした。「枯れかけ」のノートが、ファイルツリーではある緑、Sky Viewでは別の緑になりうるのです。**認知の色**カテゴリーは、**状態ごとに1つの色コントロール**を提供し、その状態を表示するすべてのものがそれに従います。

**スタイルセッター**を開き、左の一覧で**認知の色**をクリックします。編集中のセットに応じたカラー凡例が中央に表示され、右側のコントロールを選ぶと凡例がライブで更新されます。5つのセットがあります。

### 成熟度 — アイデアがどれだけ定まっているか

最も若いものから最も定まったものへ、5つの状態：**種**、**若木**、**常緑**、**正典**、**枯れかけ**。それぞれに1つの色が割り当てられ、ファイルツリーのノートのドット、タブの成熟度マーカー、ノートインスペクタで使われます。

### 確信 — リンクがどれだけ確かか

4つの状態：**仮説**、**証拠**、**確立**、**係争中**。それぞれに1つの色。

### 由来 — アイデアがどこから来たか

4つの状態：**受容**（出所から取り入れたもの）、**発見**（あなた自身のもの）、**混合**、**なし**。それぞれに1つの色。

### ステージ — ノートがライフサイクルのどこにあるか

順に6つの状態：**閃き**、**誕生**、**成長**、**成熟**、**休眠**、**保管**。それぞれに1つの色。

### 一致カテゴリー — 検索結果がなぜ一致したか

7種類の一致：**タイトル**、**本文**、**タグ**、**ウィキリンク**、**プロパティ**、**セマンティック**（完全一致の語ではなく意味に基づく一致）、**構造化**（プロパティクエリによる一致）。ここで設定した色は、エディタ内の検索ハイライト、一致バッジ、検索パネルの結果行のハイライトで共有されます。

### 「オンデマンドで統一」 — これを安全にするルール

認知の色は、意図的なルールに従います：**色を選ぶまで何も変わりません。** すべてのサーフェスは、いま現在の色を自身のフォールバックとして保持します。ここで状態の色を設定した瞬間、その状態を表示する**すべて**のサーフェスが一斉にあなたの色に切り替わります — ファイルツリー、タブ、インスペクタ、検索ハイライトなど。「常緑」を一度設定すれば、アプリ全体のすべての常緑マーカーが一致します。状態に触れずに残せば、以前とまったく同じ見た目のままです。

これこそが、このカテゴリーが既存の見た目を1つも変えずに出荷できる理由です。デフォルトでではなく、*オンデマンドで*統一するのです。**Keep** をクリックすると、あなたの色がこのユニバースに保存されます。

## アプリ全体の右クリックメニュー

Constellationは、いちばん欲しくなる3つの場所 — **ノート本文**、**フロントマターのプロパティ**、**検索結果** — でフルの右クリック（コンテキスト）メニューを提供するようになりました。各メニューは、クリックした場所で意味をなす操作だけを提示します。

### ノート本文を右クリック

ノートのテキスト内のどこかを右クリックすると、編集メニューが表示されます：

- **リンクを追加** / **外部リンクを追加** — 選択範囲を `[[ウィキリンク]]` または `[テキスト](url)` リンクで囲む（または、カーソル位置に挿入する）。
- **書式 ▸** — フライアウトのサブメニュー：太字、斜体、下線、取り消し線、ハイライト、インラインコード、数式、コメントの切り替え、上付き、下付き、書式をクリア。
- **段落 ▸** — フライアウト：箇条書きリスト、番号付きリスト、タスクリスト、見出しレベル **H1〜H6** と**本文**、引用。
- **挿入 ▸** — フライアウト：脚注、表、コールアウト、水平線、コードブロック、数式ブロック、画像。
- **クリップボード** — 切り取り、コピー、貼り付け、プレーンテキストとして貼り付け、すべて選択。
- **スタイル…** — 右クリックしたものそのものを再装飾できるよう、**エディタ**カテゴリーにフォーカスした**スタイルセッター**へ直接ジャンプします。

### フロントマターのプロパティを右クリック

プロパティパネル（またはノート上部のプロパティブロック）でプロパティの**行**を右クリックすると、フルの編集メニューに加えてプロパティ操作が表示されます：

- **値をコピー** — プロパティの値をクリップボードにコピー。
- **名前をコピー** — プロパティのキーをコピー。
- **プロパティを削除** — そのプロパティ行を削除。
- **プロパティを追加** — 新しい空のプロパティ行を追加。
- …続いて、ノート本文と同じ**書式 / 段落 / 挿入 / クリップボード**の項目、そして**スタイル…**項目（**プロパティ**カテゴリーにフォーカスしたスタイルセッターを開く）— つまりプロパティタグ上の「スタイル…」はノート本文ではなくプロパティタグを装飾します。

### 検索結果を右クリック

検索パネルの結果を右クリックすると、ファイルを危険にさらすことのない**安全な**ノート操作のセットが表示されます：

- **開く** — ノートを開く。
- **新しいタブで開く** — 開いているものと並べて開く。
- **ツリーで表示** — ファイルツリー内でノートをハイライトし、どこにあるかを確認できる。
- **リンクをコピー** / **パスをコピー** — ノートへのウィキリンク、またはそのファイルパスをコピー。
- **ブックマーク** — ノートをブックマークに追加。
- **エクスプローラーで表示** — オペレーティングシステムのファイルマネージャーでファイルを表示。
- **既定のアプリで開く** — システムがMarkdownに使うアプリでファイルを開く。
- **スタイル…** — **認知の色**カテゴリー（検索の一致色が置かれている場所）にフォーカスしたスタイルセッターを開く。

> **設計上、検索結果メニューには名前変更・移動・削除がありません。** 検索パネルはユニバース全体の結果を表示しますが、ファイルツリーの一瞬一瞬の最新コピーを自身では保持していません。そのため、そこでの破壊的な操作は古いビューに対して作用してしまうおそれがあります。Constellationは、ビューが常に最新であるファイルツリー（およびノートナビゲーター）にそれらの操作を留めています。検索メニューは、ノートへ安全に*たどり着く*ためのものであり、ライブラリを再構築するためのものではありません。

## 知っておくと便利

- **ローカルかつプライベート。** これらはすべて、あなた自身のノートと設定からあなたのデバイス上で計算されます。何もどこにも送信されません。
- **あなたの言語で話します。** すべてのメニュー項目、すべてのカテゴリー名、すべての状態ラベルは、あなたが選んだインターフェース言語で表示され、右から左へ書く言語では正しく反転します。認知状態の色そのものは普遍的です — 色はどの言語でも同じ状態を意味します。
- **「スタイル…」は常に正しいサーフェスに着地します。** 各「スタイル…」項目は、右クリックしたものに応じたカテゴリーにフォーカスしてスタイルセッターを開きます：ノート本文 → **エディタ**、プロパティ → **プロパティ**、検索結果 → **認知の色**。正しいコントロールを探し回る必要は決してありません。
