# アラビア語と混在スクリプトで書く

Constellation のエディタは「言語ファースト」で設計されています。アラビア語、ヘブライ語、ペルシア語、ウルドゥー語、そして二言語混在のノートは後付けの機能ではありません——キャレット（カーソル）、選択範囲、各段落の方向は、Windows 版 Microsoft Word と同じルールに従って動くため、これまでの操作の手癖がそのまま通用します。このトピックでは、右から左へ書くテキストや混在テキストで*書く*ことのすべてを扱います：キャレットの動き方、単語・文・行・段落・画面単位での選択のしかた、そして自動検出が意図と違うときに段落の方向を強制する方法です。

（Constellation がアラビア語をどう*理解*するか——語根、検索、形態解析エンジン——については、**アラビア語エンジン**のトピックをご覧ください。）

---

## キャレットの動き方

- **矢印キーは、画面上の位置ではなく、テキストの読み順に 1 文字ずつ移動します。** アラビア語だけ、あるいは英語だけのテキストでは、押した矢印のとおりに見えます。アラビア語と英語の継ぎ目（たとえば英単語を含むアラビア語の文）では、キャレットは書かれた順に 1 文字ずつ進み、継ぎ目を目に見えて「飛び越え」ます——この飛び越えは正しい動作で、境界でキャレットが動かなくなったように感じるのを防いでいるのです。
- **Home** は行の読み上の**先頭**——アラビア語の行なら*右*端——へ移動します。**End** は読み上の**末尾**——*左*端——へ移動します。どちらも **Shift** を併用すると、その端まで選択します。
- アラビア語の行で **Enter** を押すと、新しい行のキャレットは**右側**——自然な書き始めの位置——に置かれます。
- **アラビア語の行末にあるラテン文字の単語**でも、キャレットは方向を見失わず、はっきりした安定な位置を保ちます。

上記のルールはすべて、標準エディタでも、フォーカスモードでも、競合マージビューでも、まったく同じように働きます。

---

## 単位で選択する

テキストのあらゆる単位に素早い選択操作があり、どの言語でも、どんな混在でも使えます：

| 単位 | 操作 |
|---|---|
| **単語** | ダブルクリック |
| **文** | 文中のどこかを **Ctrl+クリック**——またはキャレットを文の中に置いて **Ctrl+Shift+S** |
| **行** | **Ctrl+L** |
| **段落** | **Ctrl+Shift+L**——またはトリプルクリック |
| **画面 1 ページ分** | **Shift+Page Down** / **Shift+Page Up** |
| **すべて** | **Ctrl+A** |

知っておくと役に立つ詳細：

- **文の選択はアラビア語の句読点を理解します。** 文は **؟ ۔ !** とピリオドで終わります——ただしアラビア語のセミコロン **؛** は文の*中*の区切りなので、選択は正しくその先まで続きます。3.14 のような小数が文を分断することはありません。
- **段落**とは、上下を空行に挟まれたテキストのブロックです——Word とまったく同じです。行と段落の選択はテキストにぴったり沿います：アラビア語の行では、ハイライトは空いた左側まで伸びず、単語のところで止まります。
- Ctrl+クリックは、このキーに以前割り当てられていた「カーソルを追加する」操作を*置き換え*ました——いまこのクリックが行うのは文の選択です。

## 段落単位で移動する

- **Ctrl+↓** は**次の**段落の先頭へジャンプし、**Ctrl+↑** は**現在の**段落の先頭へ移動します（もう一度押すと前の段落へ）。**Shift** を加えると、ジャンプしながら段落単位で選択していけます。これは Word の慣例で、「次」とは単にページの下の方向という意味です——アラビア語でも、英語でも、混在ノートでも同じように働きます。

---

## 段落の方向を強制する

Constellation は各行の方向を、行頭の文字から自動的に検出します。たいていはそれで正解です——しかし、上書きしたいときもあります：英語のブランド名で始まるアラビア語の段落や、ほぼ英語だけれど右から左に読ませたい段落などです。

**キーボードの右側の Ctrl+Shift を押して放す** → カーソルのある段落が **100% 右から左**になります。
**左側の Ctrl+Shift を押して放す** → **100% 左から右**になります。

これは Microsoft Word の慣例です。知っておきたいこと：

- **キーを放した瞬間に発動します**——2 つのキーを一緒に押し、間に何も押さずにそのまま放してください。だからこそ Ctrl+Shift+S、Ctrl+Shift+L をはじめとするショートカットは通常どおり働き続けます：3 つ目のキーが加わった瞬間、方向切り替えは身を引くのです。
- **これはハードオーバーライド（強制上書き）です**——自動検出に勝ち、段落全体（選択範囲が触れているすべての段落）に適用されます。
- **テキスト自体の中に**、目に見えない方向文字として保存されます。そのため、ノートを閉じても、アプリを再起動しても、同期しても維持されます——Word や Obsidian に貼り付けても、テキストと一緒に移動します。
- **Ctrl+Z 1 回で元に戻せます。** 同じ側をもう一度押しても、それ以上は何も起きません。
- **Markdown は安全なままです。** リストはリストのまま、見出しは見出しのまま、引用は引用のままです。コードブロック、テーブル、水平線には意図的に手を付けません。#タグで*始まる*行は自動検出の方向を保ちます（そこに強制マークを入れるとタグが壊れてしまうためです）——段落の残りの部分はきちんと切り替わります。

## フォントとインターフェース

- **スクリプトフォント**：**設定 → 言語**で、アラビア語、ヘブライ語、CJK のフォントを個別に設定できます。
- **スクリプトツールバー**：言語ごとの記号・句読点ボタンです。
- **タシュキール ハイライト**：エディタツールバーから、アラビア語のダイアクリティカルマークのハイライトを切り替えられます。
- インターフェース言語にアラビア語またはヘブライ語を選ぶと、アプリ全体が RTL に反転します。

## 用語集

- **読み順** — 画面上のどこに表示されるかに関係なく、文字が書かれ、読まれる順序。
- **継ぎ目（シーム）** — 同じ行の上で、右から左へ書く並びと左から右へ書く並びが接する境界。
- **ハードオーバーライド** — ユーザーが明示的に指定した方向。行頭文字による自動検出に勝ちます。
- **方向マーク** — オーバーライドをテキスト自体の中に保存する、目に見えない文字（RLM/LRM）。
