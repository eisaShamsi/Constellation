# レビューパルス

*(レビュアー — あなたの知識からの折り返し連絡リスト)*

レビューパルスは、Constellation が**いまどのノートに注意を向けるべきか、そしてなぜそうなのか**を教えてくれる場所です。さらに、それぞれに対して取るべき健全な一手を処方します。ほかのパネルはすべて、あなたが出向いて尋ねなければ答えてくれません(「私のグラフはどんな状態か? このノートは何とつながっているのか?」)。レビュアーだけが**あなたのもとへやって来る**唯一の存在です。劣化したノート、ずれてしまったノート、流れから外れてしまったノートを、緊急度の順に並べて差し出し、それぞれに平易な言葉の理由を添えてくれます。

これは医師の**折り返し連絡リスト**だと考えてください。ただ「どこか悪い」と言うのではなく、状態を診断し、治療法を処方し、どれくらい急ぎなのか、そして*なぜ*なのかを伝え、そのうえでより深い器具(エディター、360°インスペクター、カタロガー)へと引き継いで、実際の対処へと送り出します。

> **二つの面、ひとつの考え。** 完全な**レビュアー**(左ドックの 🕐 時計アイコン)は*ライブラリ全体*のキューです。右サイドバーの**レビュータブ**(同じ 🕐 アイコン)は*いま開いているノート*だけ、つまりそのノート自身の状態を表示します。両者は同じエンジンを共有しているので、あるノートはどちらでも同じ優先度を示します。

---

## レビュアーを開く

左端のドックにある **🕐 時計**アイコンをクリックします。レビュアーがウィンドウを二段組で満たします。

- **左 — キュー**。六つのレンズ(後述)に分類されています。すべてのレンズが常に一覧表示され、空のものは**0**とともにグレー表示されます。レンズの見出しをクリックすると折りたたみ/展開できます。
- **右 — 詳細ペイン**。選択したノートについて、何が問題か、その治療法、どれくらい急ぎか、そして取れる操作が表示されます。

キューのいずれかのノートをクリックすると、その詳細が右側に読み込まれます。ノートの**名前**(または **接続**)をクリックすると、エディターでそのノートが開きます。すると上部のタブ列に **‹ レビュアー** ボタンが現れ、いた場所へまっすぐ戻れます。

---

## 六つのレンズ

一つのノートが同時に複数のレンズに現れることもあります。各レンズはそれぞれ異なる問いに答えており、それらが単一のスコアに混ぜ合わされることは決してありません。

| レンズ | その意味 |
|---|---|
| 🥀 **陳腐化(Stale)** | このノートが*依拠している*別のノート(支持・矛盾・由来・部分・置換といった、支えとなるリンク)が、あなたがこのノートを最後にレビューした**あと**に変化しました。あなたのノートはもうそれと整合していないかもしれません。 |
| 🔄 **レビュー期限(Due for Review)** | レビュー間隔が経過しました。読み返して、いまも成り立っているか確認する時期です。 |
| 🧠 **メンタルモデルの確認点(Mental-Model Checkpoints)** | あなたが前提や模型として印を付けたノートです。*この見方をいまも持ち続けていますか?* |
| 🔗 **孤児 — つないでください(Orphan — connect me)** | 中身のある実体を持ちながら、**まだ何ともリンクしていない**ノートです。あなたの思考の網の外側にあります。孤児は雑物ではなく**警報**です。つなぐか、意図的な独立ノートとして印を付けてください。 |
| ⚠ **脆弱 — 支えを固めて(Fragile — shore me up)** | 多くのノートがこれに依拠しているのに、それ自身はわずかな支えしか持っていません。単一障害点です。もっと確かな地盤を与えてください。 |
| 📝 **未レビュー(Never reviewed)** | ライブラリにしばらく置かれていながら、まだ一度も最初の通読をしていないノートです。 |

## 詳細ペイン:診断 → 処方

ノートを選ぶと、右の段は上から下へ次のように読めます。

1. **タイトル + 要約。** ノートの一〜二文の要約が常にここに表示され(要約設定の如何にかかわらず)、*何を*見直すよう求められているのかが分かります。
2. **診断** — 平易な言葉での「なぜいま」。例:*「由来元の『証拠』が 2026-06-12 に変化しました。」*
3. **処方** — 取るべき健全な一手。例:*「『証拠』と照らし合わせてレビューしてください。自分の立場を整合させるか、更新します。」* 孤児の場合は:*「関連するノートに接続してください。あるいは意図的な独立ノートとして印を付けます。」*
4. **優先度** — 0 から 100 までの数値。**レシピ**として表示されます(下記)。
5. **事実** — その成熟度(種子 / 苗木 / 常緑 / 規範的 / 萎れ),その接続数(「12 入 ・ 4 出」),そして最後にレビューした時期。
6. **操作** + **引き継ぎ**(下記)。

---

## 読める優先度 — そして上書きできる優先度

優先度の数値はブラックボックスではありません。ノートの状況から算出され、**理由ごとに分割されたバー**として表示されます。それぞれにラベルが付き、合計はちょうどその数値になります。たとえば:

> **63**  ·  *時間的圧力 +31 ・ 依拠されている +14 ・ 成熟度 +10 ・ …*

これは二つのものを組み合わせています。古典的な「緊急 vs 重要」の分け方です。

- **緊急度** — どれだけ期限超過あるいは陳腐化しているか、そして変化がどれだけ破壊的だったか(あなたの足元に*矛盾*が着地するほうが、支持ノートが単にずれるよりも緊急です)。
- **重要度** — どれだけ多くのノートがそれに依存しているか、どれだけ成熟しているか、そして脆弱かどうか。

数値の主導権は常にあなたにあります。**スライダーをドラッグ**して自分の優先度を設定してください。するとそれは **「手動」** と印が付き、算出値が*いくつになる*はずかも示され、**「算出値にリセット」** で主導権をエンジンに返せます。あなたの上書きは、リセットするまで保持されます。

## ノートに対処する

各レンズは、それにふさわしい動詞を提示します。

- **✓ レビュー済み** — 読み返しました。確認が取れ、1・3・7・14・30 日のはしごで再スケジュールされます。(これが「最後のレビュー」を進める*唯一の*操作です。ノートを単に開いただけではレビューしたことにはなりません。)
- **🔗 接続**(孤児) — ノートを開いてリンクを追加できるようにします。
- **👁 7日スヌーズ** — 期限の来た時間ベースのノートを一週間隠します。(スヌーズが効くのは時間ベースのレンズだけです。陳腐化や脆弱は、一週間待っても直るものではありません。)
- **🗄️ 解除** — このノートのレビュー追跡をやめます。孤児の場合は **「独立として印付け」** と表示されます。*このノートは独り立ちするためのもので、孤児ではありません。*

底部の**引き継ぎ**は、思考の流れを離れることなく、より深い器具へ連れて行きます。**エディターで開く**、**完全な文脈(360°)**(そのノートの構造的な全体像)、そして**分類**(カタロガー)です。レビュアーが選別し、これらが説明します。

---

## ノート自身のレビュータブ

任意のノートを開き、右サイドバーの **🕐 レビュー** タブを選びます。*その*ノートの状態 — 期限 / 陳腐化 / 確認点 / 未レビュー — が、同じ優先度スライダー(既定では算出値、上書き可能、リセットあり)と、同じ ✓ / スヌーズ / 解除 の操作とともに表示されます。これは、上で述べたすべてをノート単位で見たものです。

---

## 設定 — 陳腐化の猶予期間

既定では、依存先が変化した翌日にノートが**陳腐化(Stale)**と印付けされます。それが気が早すぎる場合は、**設定 → レビュー**へ進み、**猶予期間**(日数、最小 1)を引き上げてください。すると依存先の変化は、あなたの最後のレビューからその日数が経過してから初めてノートに印を付けます。小さな編集を頻繁に行う方は、辛抱強い設定にしておくとよいでしょう。
