# Constellation Nervous System (CNS)

## これは何ですか？

Constellation Nervous System — UI 上の表記は**「知識の神経系」** — は、あなたのユニバースの**配線図**です。答える問いはただ一つ：

> **「私の思考はどんな『かたち』をしているか — その領域は、そのブリッジは、その沈黙は？」**

リンクグラフ全体にネットワーク分析を適用し、五つのレジスターで読み解きます：

- **領域** — あなたのリンクづけが実際に形づくった“界隈”（フォルダで宣言されたものではなく、分析が発見したもの）。
- **ブリッジ** — 構造をつなぎ留めているノート。これを切れば、領域はばらばらに崩れます。
- **ハブ** — 最も接続の多いノート（被リンクが最多のもの）。
- **盲点** — 触れ合うべきなのに触れていない、よく発達した領域のペア。それぞれに提案ブリッジのノートが添えられます。
- **構造的凝集度** — 配線全体がどれほど良く形づくられているかを示す 0–100 の総合スコア。

CNS が読むのは**構造だけ** — 誰が誰とつながっているか、です。流れ（リンクが何回たどられたか、どれだけ重みを増したか、主張がどれほど定まったか）は決して読みません。それは兄弟である**星座循環系（CCS）**の仕事です。二つは一つの解剖学をなします：CNS は神経、CCS は血液。両者がそろって初めて、「つながり」の問いに丸ごと答えられます。

## なぜ重要ですか？

Constellation の他のあらゆる接続サーフェス — バックリンク、アウトゴーイングリンク、星座循環系、知識の健全性 — は、**すでに作った**つながりを記録します。**盲点**のレジスターは、**まだ作っていない**つながりを指し示す唯一の計器です：それぞれ十分に発達していながら、間に結合組織のない、思考の二つの領域。その境界こそ、統合が起こる場所です。

そして、*宣言された*秩序（ライブラリとフォルダ）と*発見された*秩序（実際のリンクづけが形づくった領域）の違いを見せられるのは、CNS だけです。一つのライブラリが複数の領域を抱えているなら、その内側で思考はテーマごとに枝分かれしています。一つの領域が複数のライブラリにまたがっているなら、あなたのテーマはファイリングの枠を越えて生きています。

## 開き方

1. 左ドックの **CNS ボタン**（枝分かれする神経細胞のアイコン）をクリックします — 星座循環系の脈拍アイコンのすぐ隣にあります。
2. 重力井戸が全ウィンドウで開きます。大きなユニバースでは分析に少し時間がかかりますが、ウィンドウは応答したままです。
3. 閉じるには：右上の **×**、または **Esc**。

CCS から来ることもできます — CCS のヘッダーには **CNS ボタン**があります — そして戻る道もあります：CNS のパネルには **「循環 → 循環系」** の行があります。

## 重力井戸

レイアウトそのものが読み取りです — 装飾的なものは何一つありません：

- **中心からの距離 ＝ 構造的中心性。** 配線が経由するノートほど井戸の深くに座り、周縁的な思考は縁に座ります。
- **角度のセクター ＝ あなた自身の整理。** 各ライブラリが円の一切れを持ちます。位置は常に*あなたの*秩序に従います — 分析がノートを動かすことはありません。
- **ノードの色 ＝ ライブラリ** — ただし**領域レンズ**（後述）に切り替えると、ノードは発見された領域ごとに塗り替わります。色はレンズであり、位置は決して変わりません。
- **静けさが既定。** リンクは求めるまで隠れています：ノートにホバーまたはクリックすると接続が灯ります。検索でも灯ります。
- ヘッダーにはノード数とリンク数が、小さなキャプション — *「解決済みリンク · このユニバース」* — とともに表示されます。CNS が数えるのはグラフ上の既存ノート間で解決した接続であり、CCS と知識の健全性は記録されたすべてのリンクレコードを数えるからです。どちらの数字も正しく、答えている問いが違うだけです。

## 構造的凝集度

パネル最上段のカードは**構造的凝集度**スコア（0–100）— 配線全体がどれほど良く形づくられているか — で、その四つの成分も読み取れます：

- **モジュラリティ** — ノートがどれだけきれいに別個の領域へクラスター化されているか。
- **支配度** — 最大の領域がユニバースのどれだけを呑み込んでいるか（低いほど健全）。
- **エントロピー** — 思考が領域のあいだにどれほど均等に広がっているか。
- **リンク/ノート** — 平均接続度。

## 領域レンズ

ヘッダーの三つの円のボタンで**領域レンズ**を切り替えます：すべてのノードがライブラリ色から領域色へ塗り替わり、凡例には主要な領域が、発見された名前とサイズとともに並びます。オフに戻せばライブラリ色が帰ってきます。どちら向きに切り替えても、位置は動きません。

## パネルのレジスター

ダッシュボード格子のボタンで分析パネルが開きます：

- **概要** — 凝集度カード、ノート・リンク・孤立の数、ライブラリ別の内訳。
- **循環 → 循環系** — 流れ側のすべて（リンクの種類、信頼度、冷却、ライフサイクル）を引き継ぐ、CCS への渡し口。
- **領域** — 発見された界隈が大きい順に並び、それぞれにサイズと支配的な成熟度が添えられます。行に**ホバー**すると、井戸はその領域の外側をすべて白黒に沈めます。行を**クリック**すると**ピン留め**：作業のあいだ、その領域は灯ったままです — 内側では通常どおりノートにホバーやクリックができます（選択したノートの接続は、他の領域へ越境しても色を保ちます — その越境こそ、まさに見る価値のあるものだからです）。もう一度行をクリックするとピン留め解除。
- **トップブリッジ** — 中心性が最も高いノート。クリックすると選択され、中央に据えられます。
- **ハブ** — 被リンク数で最も接続の多いノート。ここが唯一の住まいです（かつての知識の健全性のカードはここへ引退しました）。
- **盲点** — 結合組織のない領域のペア。*領域 A ↮ 領域 B* と表記され、それぞれに最大三つの**提案ブリッジ**ノートが、クリックできるチップとして付きます。リストが空なら、それは朗報です。

## 操作

| 操作 | 効果 |
|---|---|
| **ノードにホバー** | ノートのタイトルがツールチップで表示され、そのリンクが灯ります。 |
| **ノードをシングルクリック** | 選択し、その近傍を灯します — 何も開きません。 |
| **ノードをダブルクリック** | エディタでノートを開きます。 |
| **空白をクリック** | 選択を解除します。 |
| **マウスホイール** | ズーム。**ドラッグ**でパン。四隅のボタンは、どのウィンドウサイズでも**画面に合わせる**を実行します。 |
| **領域の行にホバー / クリック** | 残りを白黒に沈めます / その状態をピン留めします。 |
| **ブリッジのチップ、またはハブ / トップブリッジの行をクリック** | そのノートを選択し、井戸の中央に据えます。 |
| **Esc** | CNS を閉じます。 |

## CNS が最も役立つ場面

- **統合の前に** — 盲点を開き、次に架けるべきギャップはどれか、と問う。
- **アーキテクチャの監査** — トップブリッジとハブが、どのノートが構造を担っているかを示します。凝集度は、全体が一つの身体なのか、散らばった島々なのかを告げます。
- **ファイリングと思考の突き合わせ** — ライブラリのセクターに対して、領域レンズを当てる。

## CNS と隣人たち

- **Sky View** — すべてを写す空間的な*絵*（あらゆる視覚語彙、自由な探索）。CNS は*計器*です：レイアウトそのものに分析が符号化されています。Sky View は空を見せ、CNS はその空が構造的に何を意味するかを告げます。
- **CCS** — 流れの側（重み、通過、冷却、確信、ライフサイクル）。CNS は決して流れを見せず、CCS は決してトポロジーを見せません。
- **知識の健全性** — 一目で見る集計カード。CNS は、その数字たちが棲んでいる配線そのものです。
- **健全性タブ（右サイドバー）** — ライブラリ単位の緊張の*リスト*（矛盾ペア、孤立ノート、タグクラスターのギャップ）。CNS の盲点はグラフレベルの領域幾何 — 異なる、補完的なギャップの読み方です。
- **360.3D** — 一つのノートの接続シグネチャ。CNS はユニバース全体です。
