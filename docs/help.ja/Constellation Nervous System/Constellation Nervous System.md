# Constellation Nervous System (CNS)

## これは何ですか?

**Constellation Nervous System** は宇宙の**接続トラバーサル**ビューです。Constellation Sight がノートの*形態*(ストラタム × 時間 × チャネルエンコーディング)を表示する一方で、CNS は*配線* — それらを接続するタイプ付きリンクグラフとそのグラフに隠された構造的パターンを表示します。

答えます:**「宇宙のアイデアはどのように接続されており、ギャップはどこにあるか?」**

ビューは 4 つの分析サーフェスを中心に構築されています:
- **宇宙の健康** — 知識がどれだけ接続、バランス、モジュラーかの全体およびメトリックごとのスコア。
- **コミュニティ** — 密に相互接続されたノートのグループ(「イデオロギークラスター」)。
- **主要な橋** — それ以外は分離されたコミュニティをリンクする少数のノート(「荷重を支える接続者」)。
- **ブラインドスポット** — 接続を期待するがまだない構造的ギャップ。

「Nervous System」という名前は解剖学的です:神経は生物の遠い部分間で信号を運ぶ接続経路です。CNS はタイプ付きリンクグラフを同じ方法で扱います。

## なぜ重要ですか?

ほとんどのノートアプリはリンクを配管(ここからそこに移動)として扱います。Constellation はそれらを**知識アーキテクチャ**として扱います:

- 多くの入力リンクを持つノートは**荷重を支えます** — 多くのアイデアがそれに依存。
- 2 つのコミュニティを橋渡しするノートは**合成点**。
- 内部リンクが弱いコミュニティは**脆弱**。
- 「ブラインドスポット」は構造が接続を持つべきだが持っていない場所 — 探索する価値のある仮説。

## 開き方

1. Constellation 左端のドックにある**ニューロンアイコン**(小さな分岐神経細胞の形 — 中央に細胞体、3 つの樹状突起分岐とシナプス末端)をクリックします。
2. CNS は全ウィンドウオーバーレイ、重力井戸スタイルで開きます — 力指向グラフ、各ノートはノード、各タイプ付きリンクはエッジ。
3. 閉じる:上部の **(×)** をクリック、または **Esc** を押します。

## 表示内容

### 宇宙の健康カード

宇宙の全体的な接続健康を示す要約パネル、複合スコア(例 **91 / 100**)の金色のロンデルと 4 つのメトリック:

- **Modularity** — ノートが個別のコミュニティにどれだけきれいにクラスター化されるか。
- **Dominance** — 1 つのコミュニティが宇宙を支配するか。
- **Entropy** — コミュニティサイズの多様性。
- **Connectivity** — ノートあたりの平均リンク。

各メトリックには色付きステータスピル:**HEALTHY**(緑)/ **CAUTION**(黄)/ **IMBALANCED**(赤)。

### 重力井戸

主要可視化:ノートがノードとして浮かび、リンクが引き寄せ、反発が押し離す。コミュニティはクラスターに自己組織化。

- **ノードサイズ** = リンク数。
- **ノード色** = コミュニティメンバーシップ。
- **エッジ** = 2 つのノート間のタイプ付きリンク。

### 主要な橋

最も多くの異なるコミュニティをリンクするノートのリスト — これらは合成点です。

### コミュニティ

検出されたノートクラスターのリスト。

### ブラインドスポット(構造的ギャップ)

提案された欠落接続 — グラフアルゴリズムがリンクされるべきと考えるノートのペア。

## インタラクション

CNS は **単クリック-プレビュー / ダブルクリック-開く** パターンを使用(Sight の単クリック-開くとは異なる):

| ジェスチャー | 効果 |
|---|---|
| **ノードに単クリック** | 選択。右側のサイドパネルがスライドし、タイトル、コミュニティ、中心性ランク、入出力リンクを表示。ノートは**開かれません**。 |
| **ノードにダブルクリック** | エディタでノートを開く。**「Return to CNS」** ボタンが表示。 |
| **ノードにホバー** | タイトルのツールチップ。 |
| **空白エリアをクリック** | 選択をクリア。 |
| **マウスホイール** | ズーム in/out。 |
| **クリック + ドラッグ** | パン。 |
| **リストでコミュニティをクリック** | 井戸でそのコミュニティのノートをハイライト。 |
| **主要な橋エントリをクリック** | 橋ノートにフォーカス。 |
| **Esc** | CNS を閉じる。 |

単クリックプレビューは意図的:多くのノートの詳細(およびその接続)をスキャンでき、エディタで各ノートを開くことを約束する必要はありません。

## CNS が最も役立つ時

- **接続密度の監査** — Universe Health が一目の読み取りを提供。
- **合成点を見つける** — Top Bridges が最も建築的作業をしているノートを表示。
- **存在を知らなかったコミュニティを発見** — グラフから出現するクラスター。
- **ブラインドスポットをパッチ** — グラフが 2 つのノートがリンクされるべきと示唆するがリンクされていない時。
- **再編成計画** — コミュニティは自然にフォルダ構造にマッピング。

## CNS vs Sight — どちらをいつ使うか

- **Sight** =「私の宇宙はどのように**形作られて**いるか?」空間 / カテゴリカル分析。
- **CNS** =「私の宇宙はどのように**接続されて**いるか?」ネットワーク / トポロジカル分析。

それらは補完的です:Sight は表面を読み、CNS はその下の配線を読みます。

## 関連サーフェス

- **Constellation Sight** — 姉妹可視化(ドックの目のアイコン)。
- **Sky View** — グラフビューでもあるが、異なる構築。
- **Backlinks / Outgoing Links パネル** — ノートごとの接続リスト。
