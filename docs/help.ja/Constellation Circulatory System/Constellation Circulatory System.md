# Constellation Circulatory System (CCS)

> **الجهاز الدوري** — 思考の脈拍。

たいていのツールが手渡すのは書類棚です。Constellation が手渡すのは**生きた思考の身体** — そして**星座循環系（CCS）**はその脈拍です。開いても、リンクの一覧は見えません。見えるのは、どのアイデアが最近の思考で**温かく**、どれが**冷えて**しまったか。**確信**がどこで岩盤へと固まりつつあり、**疑い**がどこでまだ生きているか。何に繰り返し戻り、何を一度つないだきり静かに見捨てたか。作ったきり二度とたどらなかったつながりは、まだ理解ではありません — 自分宛てに書いて忘れたメモです。CCS は一目で、あなたの思考が**まだ循環しているか**を告げます。

あなたの知識には神経系（**CNS** — どう配線されているか）と循環系（**CCS** — 生きているか）があります。二つは兄弟であり、「つながり」の問いにともに答えます：CNS は*構造*を読み（コミュニティ、ブリッジ、中心性）、CCS は*流れ*を読みます（重み、通過、ライフサイクル、信頼度）。支柱となっているブリッジが停滞しかけていることを CNS は決して教えてくれませんし、踏み固められたリンクがブリッジであることを CCS は決して教えてくれません。

## CCS の開き方

入口は三つ、どれも同じ場所へ通じます：

1. **ドック** — 左ドックの脈拍ラインのアイコン。CNS のすぐ下です。
2. **コマンドパレット** — 「Circulatory」と入力します。
3. **設定 → リンク → 関連** — 「循環系（CCS）」の「循環系を開く →」ボタン。

リンクがいくつあっても、CCS は一瞬で開きます：Constellation がバックグラウンドで新鮮に保っているスナップショット（知識の健全性と同じエンジン）を読むからです。アップデート後の最初の一回だけ、スナップショットの初回構築のあいだ、数秒間 *「知識の脈を測っています…」* と表示されることがあります。

ヘッダーにはスコープ（**この宇宙**）と、記録されたリンクの総数が表示されます。**「知識の健全性 →」** ボタンで集計カードのオーバーレイへ跳べます。知識の健全性側には、対になる **「循環系 →」** ボタンがあります。二つのサーフェスは連携しています — CCS が深い計器、知識の健全性が一目のカードです。

## 七つのレジスター

各レジスターは、あなたが自分の思考についてすでに発している問いです：

| レジスター | 問い | 表示されるもの |
|---|---|---|
| **生きているつながり** | *いま能動的に考えているのは何か？* | 最も多くたどった、まだ温かいリンク（90 日以内に通過）。通過回数と最終通過日つき。 |
| **支える推論** | *私の理解は何の上に載っているか？* | 獲得した重みが最も高い、温かいリンク — あなたの動脈です。重みはリンクを通過するたびに育ちます。 |
| **冷えつつある問い** | *戻らなくなったものは何か？* | かつてたどったのに 90 日以上触れていないリンク。冷たい順。これは招待であって、決して非難ではありません — 事実は休んでいてよいのです。 |
| **確信と疑い** | *私の思考はどれほど定まっているか？* | 信頼度の分布（仮説 → 証拠 → 確立 → 係争中）と、いま生きている係争中のリンク — あなたの進行中の論争。 |
| **つながりの一生** | *リンクはライフサイクルのどこにいるか？* | 五段階の全数調査：新規（未通過） · 萌芽（通過 1–2 回） · 確立（3–9 回） · 支柱（10 回以上） · 停滞（90 日以上たどられていない）。 |
| **引退した推論** | *脇に置いたものは何か — 蘇らせられるか？* | アーカイブされたリンク。各行に**「復元」**ボタンがあり、20 件を超えると**「すべて表示」**が現れます。 |
| **探究の行為** | *どんな種類の思考をしているか？* | タイプ付きリンクの分布（認知的行為の正準順）。加えて**「開かれた問い」**の行 — タイプ未指定のリンク、どう関わるかをまだ尋ねている問いたちです。 |

どの行をクリックしても、そのリンクが棲むノートが開きます。CCS を眺めても、表示される数字は決して変わりません — レジスターからノートを開いても、リンクをたどったことには数えられません。

## 引退した推論を復元する

1. CCS を開き、**「引退した推論」**へ。
2. 取り戻したい行の**「復元」**をクリックします。
3. 行はレジスターから去り、リンクはそのノートのバックリンク / アウトゴーイングリンクのパネルに再び現れます。

復元されたリンクは何も失いません。種類・注釈・信頼度・通過履歴のすべてが一緒に戻り、重みはその履歴から再計算されます。よく通ったリンクは、去ったときと同じ強さで戻ってきます。

## 鮮度のリズム

CCS が読むのはキャッシュされたスナップショットで、変更から数分のうちにバックグラウンドで更新されます。リンクをアーカイブまたは復元してすぐに CCS を開き直すと、一瞬だけ以前の数字が見えることがあります — 数字はその場で、ほどなく更新されます。あなたを待たせて再計算することは何もありません。パネルは常に一瞬で開きます。

## かつてのリンクダッシュボードはどこへ行ったか

右サイドバーの**リンクダッシュボード**タブは、CCS へ引退しました。その仕事は、より良い住まいへ移っています：最多通過 → **生きているつながり**、停滞 → **冷えつつある問い**、アーカイブと復元 → **引退した推論**、最多接続は**知識の健全性**に残り、孤立ノートは緊張パネル（右サイドバーの健全性タブ）に棲んでいます。クロスライブラリのリストと壊れたリンクのリストは、パネルとともに引退しました。
