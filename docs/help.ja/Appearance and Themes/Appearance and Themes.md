# 外観とテーマ

Constellationの外観は**設定**内の2か所から制御されます：

1. **外観** — テーマを選択または作成し、Obsidianのコミュニティレジストリからテーマをインポートし、グローバルなフォントとレイアウトの設定を調整します。
2. **Style Settings** — Constellationインターフェースのすべての可視部分を、ライブ調整可能なコントロール（スライダー、カラーピッカー、ドロップダウン）として公開する専用タブ。変更は即座に適用され、アクティブなテーマに保存されます。

これらを組み合わせることで、CSSを1行も編集することなく、アプリをワークフロー、画面サイズ、個人の好みに合わせて再構築できます。

## テーマ

**テーマ**とは、Constellationの見た目を定義する、色・設定・CSSの名前付きバンドルです。Constellationには6つの組み込みテーマが付属しています（Constellation Light/Dark、Nord Light/Dark、Solarized Light/Dark）。すべてライトモードとダークモードのペアになっています。

### テーマを選択

1. **設定 → 外観**を開きます。
2. **テーマ**グリッド内の任意のカードをクリックします。テーマが即座に適用されます。
3. アクティブなカードはアクセントの枠で強調表示されます。

### カスタムテーマを作成

1. テーマグリッド内の破線の**+ 新規テーマ**カードをクリックします。
2. 名前を付け、ライトまたはダークを選択し、5色を選びます（背景、サーフェス、テキスト、アクセント、ボーダー）。
3. **保存**をクリックします。テーマがグリッドに表示されます。

他のすべての変数（ホバー状態、シャドウ、ミュートテキスト）は、HSL計算を使用して5色から自動的に派生するため、重要なものだけを制御します。

### カスタムテーマを編集または削除

任意のカスタムテーマカードにカーソルを合わせます：
- **✏️（鉛筆）** — 名前、タイプ、または5つのコア色を変更するエディタを開きます。
- **✕（赤いX）** — 確認後、テーマを削除します。組み込みテーマは削除できません。アクティブなテーマを削除すると、Constellationはデフォルトに戻ります。

### Obsidianコミュニティテーマをインポート

**🟣 Obsidianテーマ**をクリックして200以上のコミュニティテーマを閲覧：
1. 名前または作者で検索。
2. **プレビュー**をクリックしてレイアウトのモックアップと5色のスウォッチを確認。
3. **インポート**をクリック — テーマのCSSがダウンロードされ、Constellation向けに適応され（セレクタshim + 変数抽出 + CodeMirrorシンタックスカラー）、カスタムテーマに追加されます。
4. テーマが**Style Settings**をサポートしている場合、カードに数が表示されます；インポート後、それらのオプションはStyle Settingsタブに表示されます。

## Style Settings

**Style Settings**タブは、Constellationのネイティブで、テーマに依存しないコントロールパネルです。エディタに加えて、クロームのすべての可視部分をカバーし、任意のテーマ（組み込み、カスタム、またはインポート）で動作します。

### 構成

セクションはデフォルトで折りたたまれています。シェブロンをクリックして展開：

- **Constellation — 色** — 背景とサーフェス、テキスト、アクセント
- **Constellation — タイポグラフィ** — インターフェース/ノート/コードフォントサイズ、H1–H6サイズ、見出しウェイト、行の高さ、段落間隔
- **Constellation — レイアウトと形状** — 角（小/中/大の半径）、ボーダー幅、シャドウ、エディタ行の長さ、サイド余白
- **Constellation — コンポーネント** — リボンドック、サイドバーアクションツールバー、レイアウトバー（ペイントグル）、トップバー/タブストリップ、ステータスバー、ファイルエクスプローラー、右サイドバー、ボタン、タグ、コールアウト
- **Constellation — エディタ** — リンク、コードとブロック、ブロック引用、カーソルと選択

### 値を変更

- **カラーピッカー** — スウォッチをクリックして色を選択。hexが横に表示されます。
- **スライダー** — ドラッグして調整。数値が単位（px、%、など）で表示されます。
- **スイッチ** — クリックしてクラスを切り替え（主にインポートしたテーマ用）。
- **ドロップダウン** — オプションを選択（リンク装飾スタイルなど）。
- **リセット矢印（↺）** — 各行の末尾にホバーで表示されます。クリックするとオーバーライドがクリアされ、テーマのデフォルトが復元されます。

### 保存の仕組み

- 変更はアクティブなテーマの**styleSettingsValues**に自動的に保存されます。
- 組み込みテーマがアクティブな状態でStyle Settingを変更すると、Constellationは組み込みをカスタムテーマに（`{Name} (custom)`として）**自動クローン**し、そこに変更を保存します。組み込みは変更されません。
- タブの下部にある**保存先:**ラベルは、現在どのテーマがオーバーライドを保持しているかを示します。
- アクティブなテーマのすべてのオーバーライドを消去するには、**すべてデフォルトにリセット**をクリックします。

### Style Settingsのインポート/エクスポート

Style Settingsタブの上部のツールバー：

- **📋 クリップボードから貼り付け** — ワンクリック：クリップボードを読み取り、有効なJSONをアクティブテーマにマージします。
- **⬆️ インポート/貼り付け** — テキストエリアを開きます；JSONを手動で貼り付け。**マージ**（追加/上書き）または**すべて置換**（消去し、貼り付けたもののみ使用）を選択。
- **📄 ファイルから** — ObsidianのStyle SettingsプラグインまたはConstellationの別のインストールからエクスポートされた`.json`ファイルを開きます。
- **📋 コピー** — 現在の値をプリティプリントされたJSONとしてクリップボードにコピーします。
- **⬇️ エクスポート** — 値を`{theme-name}-style-settings.json`として保存します。

JSON形式はObsidianのStyle Settingsプラグインと完全に一致 — 設定IDを文字列値にマップするフラットなオブジェクト：

```json
{
  "h1-size": "36",
  "interactive-accent": "#7c3aed",
  "my-themed-color@@light": "#ffffff",
  "my-themed-color@@dark": "#1e1e2e"
}
```

つまり、ObsidianからStyle SettingsをコピーしてConstellationに直接貼り付けること、またはその逆が可能です。

## 制御できるもの

すべての設定は上記の5つのブロックのいずれかに存在します。ハイライト：

### タイポグラフィ

- **インターフェースフォントサイズ** — サイドバー、ツールバー、メニュー
- **ノートフォントサイズ** — エディタ内の本文テキスト
- **コードフォントサイズ** — インラインコードとフェンス付きコードブロック
- **H1 – H6サイズ** — 各見出しレベルを個別に
- **見出しウェイト** — すべての見出しの軽さまたは太さ
- **行の高さ** — 通常（本文）と密（見出しと高密度UI）
- **段落間隔** — 段落間のギャップ

### シェルコンポーネント

- **リボンドック（左のアイコン）** — 幅、ボタンサイズ、アイコンサイズ、半径、色
- **サイドバーアクションツールバー** — 新規ノート/テーブル/フォルダアイコン — サイズ、色、高さ、背景
- **レイアウトバー（ペイントグル）** — 左/分割/右サイドバートグル — ボタンサイズ、アイコンサイズ、色、アクティブ状態色
- **トップバー/タブストリップ** — ノートがタブで開いているときのみ表示；ストリップの高さ、背景、タブの高さ/フォント/半径、アクティブおよび非アクティブタブ色を制御
- **ステータスバー** — 高さ、フォントサイズ、背景、テキスト色
- **右サイドバー（インスペクタ）** — 背景、タブ行の高さ、タブアイコンサイズ、色
- **ファイルエクスプローラー（左サイドバー）** — ユニバースノート行、子ユニバース（cUniverse）行、ライブラリ名、フォルダ、ノート — それぞれ独立したサイズ、ウェイト、色；加えて垂直行間隔

### エディタ

- **見出しサイズ**（H1–H6）とウェイト
- ノート本文の**行の高さ**
- **インラインコード** 背景、テキスト色、半径、フォントサイズ
- **リンクの色**（デフォルト + ホバー）と装飾スタイル（なし/下線/点線）
- **コールアウトバーの幅**と**コールアウトの半径**
- **カーソルの色**と**選択背景**

### 色（アプリのすべての色）

- 背景（プライマリ/代替）、サーフェス、ホバー背景、ボーダー、入力背景
- テキスト（通常/ミュート/淡い/アクセント上）、エラー/警告/成功状態
- アクセント（インタラクティブアクセント + ホバー）、アクセントテキスト

## よくある質問

### Windowsのタイトルバー（「Constellation v0.3.4 — …」）をスタイル設定できますか？

いいえ — そのバーはオペレーティングシステム（Windows/macOS/Linux）によって描画されます。ConstellationはそのCSSアクセスを持っていません。その下のすべては完全にスタイル設定可能です。

### サイドバー幅スライダーが機能しないのはなぜですか？

サイドバー幅は、サイドバーの端にあるドラッグハンドル（ドラッグしてサイズ変更）によって制御されます。競合する真実の源を避けるため、意図的にそのコントロールをStyle Settingsで複製していません。

### 私のStyle Settingsはどこにありますか？

`Universe/settings.json`内の`customThemes[i].styleSettingsValues`の下、各テーマにスコープされています。ユニバースと共に移動します — デバイス間でユニバースディレクトリを同期すると、スタイリングも一緒に来ます。

### テーマを誰かと共有できますか？

はい：
- **完全なテーマ** — テーマエディタで**エクスポート**をクリック。`.json`ファイルを共有。受信者はテーマグリッドで**↓ インポート**をクリックして選択します。
- **Style Settingsの値のみ** — Style Settingsタブで**エクスポート**をクリックしてスライダー/色の値のみをエクスポート（テーマ構造ではなく）。他人のテーマの上に個人的な調整を適用するのに便利。

### インポートしたObsidianテーマが壊れて見えます。どうしますか？

Obsidianテーマは複雑な場合があります。既知のケース：
- **HSL分割色**を使用するテーマ（Minimalなど） — 本リリース以降、Constellationでサポート。
- Obsidian固有のDOM構造に依存するテーマは、部分的にレンダリングされる場合があります。Constellationには最も一般的なセレクタをマップするクラスshimが含まれていますが、構造的なテーマでは、5つのコア色を調整するか、補正のためにStyle Settings値を手動で調整する必要がある場合があります。
