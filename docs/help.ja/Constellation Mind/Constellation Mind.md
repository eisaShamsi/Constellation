# Constellation Mind (عقل Constellation)

## これは何ですか?

Constellation Mindは、Constellationのローカル大規模言語モデル(LLM)レイヤーです — あなたのユニバースを知り、あなたのノートについてあなたと話すことができるAIアシスタントで、**そのいずれもクラウドに送信することはありません**。

他のすべての「ノート用AI」ツールと異なる3つの特徴があります:

1. **ローカルファースト。** モデルはあなたのデバイス上で動作します。あなたのノートは決して離れません。クラウドへのラウンドトリップはありません — チャットはローカルでオフラインでも使用可能です。
2. **アラビア語ファースト。** バンドルされたデフォルトモデルは**Fanar-1-9B**で、カタール計算研究所(QCRI)のアラビア語中心、スンニ派意識のあるモデルです。MSA + 湾岸方言のネイティブ能力を持ち、英語は唯一の言語ではなく第二言語です。
3. **出典に紐づく。** AIがあなたのノートについて行うすべての事実主張は、ソースノートを引用しなければなりません。幻覚された引用は、生成後のバリデーターによって捕捉されます(フェーズ1)。

## 本日出荷されるもの(フェーズ0b — 2026-05-24)

- **設定 → Mindパネル** — インストール可能なモデルをリストします(現在はFanar 1.9B Q4_K_M、約5 GiBのみ)、モデルをダウンロードして検証するインストールボタンを備えています。
- **モデルインストール** — GitHub Releaseからのチャンク化されたダウンロード(サードパーティクラウドなし)、各チャンクと組み立てられた全体でSHA-256検証済み。
- **実際の推論ランタイム** — `llama-cpp-2`(v1ではCPUのみ)がQ4_K_M GGUFをロードしてトークンをストリームします。
- **まだチャットサーフェスはありません** — それがフェーズ1(次のマイルストーン)です。今日はモデルをインストールして検証できますが、会話UIはMIG-048で着陸します。

## Fanarのインストール方法

1. **設定 → Mind**を開きます。
2. カタログで**Fanar 1.9B (Q4_K_M)**を見つけます。カードはサイズ(5.01 GiB)、ライセンス(防御的Gemmaノティスを伴うApache-2.0)、および「アクティブに設定」または「インストール」ボタンを表示します。
3. **インストール**をクリックします。プログレスバーは3つのフェーズでダウンロード + SHA検証 + 組み立てを表示します。
4. バッジが**インストール済み** + **アクティブ**に切り替わると、モデルは準備完了です。Fanarは`<app-data>/Constellation/models/fanar-1-9b-q4km-v1.gguf`に存在し、mmapによってバックアップされます(RAMへのコピーなし)。

それだけです。フェーズ1がチャットサーフェスを出荷するまで、インストールされたモデルはスタンバイ状態です。

## フェーズ1で来るもの(次のマイルストーン)

- **チャットサーフェス** — アラビア語または英語でFanarとあなたのユニバースについて話すConstellationパネル(メッセージごとにRTL対応)。
- **読み取りツール** — Mindは`search_notes`、`read_note`、`find_similar`、`list_recent`を呼び出して、回答を実際のノートに根拠付けることができます。
- **引用バリデーター** — すべての主張が実際のノートを引用します。捏造された`note:UUID`参照は、あなたに届く前に拒否されます。
- **アプリ起動時のプリウォーム** — Mindはバックグラウンドでロードされるので、最初のチャットで10秒のコールドロードを支払う必要はありません。
- **会話履歴** — ユニバースごとに保存され、ノートに昇格可能です。

完全なアーキテクチャについては`docs/Constellation-Mind-Concept-Paper-v1.1.md`を、フェーズ別ロードマップについては`docs/Constellation-Mind-Implementation-Plan-v1.0.md`を参照してください。

## 後で来るもの

- **フェーズ2 — ライトツール**(Mindがあなたの明示的な承認の下で編集 / 新しいノート / リンクを提案します)。
- **フェーズ2.5 — RoutedProvider + Jais**(G42/MBZUAIによる2番目のモデルJais-2-8BがFanarと共同デフォルトとして加わり、Mindはリクエストに基づいてそれらの間でルーティングします)。

- **フェーズ5 — クラウドオプトイン**(あなた自身のAnthropic / OpenAIキー、ユニバースごとのコスト上限とターンごとのエグレスログ付き)。

## プライバシーとデータフロー

- **モデルをインストールするときのみアウトバウンドHTTP** — Constellationはこのリポジトリの[`models/*` GitHub Releases](https://github.com/eisaShamsi/Constellation/releases)からモデルファイルをダウンロードします。テレメトリーなし。クラウド推論なし(まだ — それがフェーズ5で、あなたの明示的なオプトインがある場合のみ)。
- **ディスク上:** モデルのGGUF + どのモデルを持っているか、どれがアクティブかを追跡する`installed_models.json`レジストリ。
- **ランタイム時:** ロードされたモデルファイルはメモリマップされ、プロンプトとレスポンスはRAMにのみ存在します。

## トラブルシューティング

**インストールボタンの代わりに「まだ準備できていません」バッジ。** バンドルされたカタログにはそのモデルのプレースホルダーSHA-256があります。通常のConstellationインストールでこれが起こるべきではありません。これが見える場合、そのモデルバージョンに対してカタログが更新されていません。issueを開いてください。

**インストールが「パートX/Yをダウンロード中」でハングする。** ネットワークの問題。設定 → Mindからキャンセルし、インストールを再トリガーします — 部分的なチャンクは自動的にクリーンアップされます。

**インストールは成功するが、ファイルのSHA-256が一致しない。** ダウンロード時のビット反転。再インストールでフレッシュなものが取得されます。

**チャットサーフェスがない。** フェーズ1(MIG-048)はまだ出荷されていません。モデルは今日インストールおよび検証可能で、会話UIは次のリリースで着陸します。
