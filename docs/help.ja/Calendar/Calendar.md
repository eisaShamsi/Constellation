# カレンダー

**カレンダー**は全画面の月表示で、**左ドック**（カレンダーアイコン）から開きます。ノートや期限付きタスクがある日には、色付きの**ドット**が付きます。ヘッダーには、選択したカレンダーでの月が表示されます。**副カレンダー**を設定している場合は、その下のサブタイトルに、そのカレンダーで対応する範囲が表示されます（例えばグレゴリオ暦の月には、対応するヒジュラ暦の範囲「ズー・アル＝ヒッジャ 1447 – ムハッラム 1448 AH」が表示されます）。

## 日付をクリックする

それぞれの日のセルは操作できます。

| 操作 | 結果 |
|--------|--------|
| 空いている部分（または日付の数字）をクリック | その日の**デイリーノート**を開きます（なければ作成します）。すでにデイリーノートがある日付をクリックした場合は、その**ノートを開くだけ**で、重複は作成されません。 |
| ドットをクリック | その項目を開きます。1つの日に複数のノートやタスクがある場合は、ドットをクリックすると選べるように小さな**リスト**が表示されます。 |
| タスクのドットをクリック | そのタスクの行までスクロールした状態でノートが開き、すぐに編集できます。 |

### ドットの色

| ドットの色 | 意味 |
|-----------|---------|
| 金色 | その日の**デイリーノート** |
| 紫色 | その日に編集（または日付付け）された別の**ノート** |
| 赤色 | その日が期限の**タスク** |

ドットの色も、カレンダーのその他すべての部分も、**Style Setter → カレンダー**サーフェスでテーマ設定できます。

> [!tip]
> タスクリストでは、カレンダーから直接**タスクのチェックボックスをオンにして完了**することができます。完了したタスクはすぐに一覧から消えます。カレンダーに表示されるのは、自身に `📅 YYYY-MM-DD` の期限を持つタスクだけです（この日付によってどの日に配置されるかが決まります）。

## 文化暦（8種類）

**設定 → カレンダー**で**暦の体系**を設定でき、選ぶと月のグリッド全体がそれに切り替わります。

- **グレゴリオ暦**
- **ヒジュラ暦（イスラム暦）** — 正確な天文計算エンジン。聖月が強調表示され、イスラムの行事が記されます。
- **太陽ヒジュラ暦（ペルシャ暦）**
- **ヘブライ暦**
- **インド暦（サカ暦）**
- **仏暦**
- **中国暦** — *太陰太陽暦*
- **韓国暦** — *太陰太陽暦*

各セルには、選択した暦の日付（大きく）とグレゴリオ暦の日付（小さく）の両方、そして月相が表示されます。各月のヘッダーには、月の**名前、括弧内の番号、そして年**が表示されます。番号は、月の並び順に馴染みのない暦で役立ちます。

**中国暦と韓国暦**は*太陰太陽暦*で、ときどき**閏月**（闰六月 / 윤6월）が挿入されます。カレンダーはこれを独立したページとして表示するため、移動の際にスキップされたり二重になったりしません。

また、**週の始まり**（日曜/月曜）を選んだり、**週番号の列**を切り替えたりできます。

### ヒジュラ暦のオプション

**設定 → カレンダー →「ヒジュラ暦（イスラム暦）」**には、2つの追加コントロールがあります。

- **計算方法** — 真の新月に従う**天文計算（朔（さく）合）**（最も正確で、既定値）か、古典的な計算サイクルである**表式（al-Tawfīqāt al-Ilhāmiyyah、霊感的補正表）**。
- **月の補正** — **現地での月の目視観測**に合わせて、ヒジュラ暦の月の始まりを ±1 または ±2 日ずらします。ヒジュラ暦の年と月を選び、オフセットを選んで**Set**をクリックすると、その月とそれ以降のすべての月に補正が適用されます。設定した補正は一覧で表示され（それぞれ削除可能）、**Clear all**ボタンもあります。

両方の設定（および補正）は**ユニバースとともに**保存されるため、お使いのデバイス間で引き継がれます。

### 中国暦・韓国暦の表示オプション

韓国は中国の太陰暦を使用するため、両者の日付は同一です。違いは**文字（スクリプト）**と**年**の表し方です。どちらかを主カレンダーまたは副カレンダーにしている場合、**設定 → カレンダー**に2つの追加コントロールが表示されます。

- **年の表示** — 中国暦：干支 丙午年、単純な年、またはその両方／韓国暦：**檀紀（Dangi）**の 단기 4359、年、または干支 병오년。
- **月名** — *ネイティブ文字*（五月 / 5월）か、*音写*、つまりその月の発音を自分の言語で書いたもの（英語「Wǔyuè / Owol」／アラビア語「وُو-يوي / أوه-وُل」）。

## カレンダーのスタイル設定

**Style Setter**（左ドック、または**設定 → Style Setter**）を開いて**カレンダー**サーフェスを選ぶと、すべての部分を再スタイルできます。各要素はそれぞれ独自の**色と文字サイズ**を持ちます（日付の数字、相互参照の日付、月のピル、曜日ヘッダー、週番号、月のグリフ、今日のハイライト、グリッド線、ノート／タスク／行事のドット）。さらにカレンダーの**フォント**も設定できます。編集に合わせてフルサイズのライブプレビューが更新されます。**Keep**をクリックすると適用されます。

## デイリーノート

カレンダーはデイリーノートを十分に支えます。任意の日をクリックして開くか、**「Daily Note」**コマンド（コマンドパレット）を実行して今日へ移動できます。

> [!tip]
> **デイリーノートのファイル名は、表示している暦に関わらず常にグレゴリオ暦のまま**（`YYYY-MM-DD`）です。これにより、ファイルは可搬性を保ち、正しく並び替えられます。文化暦の日付はカレンダーに表示され、ノートのフロントマターに記録することもできます（下記参照）。

## ノートに文化暦の日付を記録する

オプトイン式の2つのツールが、ノートの**プロパティ**に文化暦の日付を書き込みます（ファイル名は常にグレゴリオ暦 `YYYY-MM-DD` のままです）。

- **デイリーノートへのヒジュラ暦スタンプ** — *設定 → カレンダー →「デイリーノートにヒジュラ暦の日付をスタンプする」*。オンにすると（ヒジュラ暦を**主または副**カレンダーにしている場合のみ利用可能）、**新規の**デイリーノートすべてに `hijri:` の行が付きます（例：`hijri: 1448-01-06`）。既存のノートは一切変更されません。
- **ノートのプロパティ内の「+ Hijri」** — 任意のノートの**プロパティ**を開き、日付にカーソルを合わせると、小さな**「+ Hijri」**ボタンが表示されます（さらに「+ Jalali」「+ Hebrew」なども表示されます。**選択したグレゴリオ暦以外の暦ごとに1つのボタン**です）。クリックすると、Constellation はノートのグレゴリオ暦の日付を読み取って対応する値を追加します（例：`jalali: 1405-03-30`）。韓国暦のボタンは**檀紀（Dangi）**の年を書き込みます。中国暦／韓国暦の**閏月**は `L` で示されます（例：`chinese: 2025-06L-17`）。ノートに日付プロパティがない場合は、ファイルの作成日が使われます。

> [!tip] RTL Support
> カレンダーのグリッドは、現在のテキスト方向に従います。RTL言語（アラビア語、ヘブライ語、ペルシャ語、ウルドゥー語）では、カレンダーのレイアウトもそれに合わせて調整されます。
