# Constellation Sight

## これは何ですか?

**Constellation Sight** は知識宇宙の**診断ツール**です。中央の**アンカードーム**がすべてのノートを**ストラタム**(思考の深さ)× **時間**(書かれた時)で位置付けて表示し、その横の4つの**ミニドーム**が同じ宇宙を異なるチャネルで再エンコードします:**信頼度 (Confidence)**、**ステージ (Stage)**、**行為 (Acts)**、**出所 (Provenance)**。

5つの補完的なレンズで1つの質問に答えます:**「私の認識的内容はどのように形作られ、組織されているか?」**

任意のドームの任意の星にカーソルを合わせると、同じノートが5つのサーフェスすべてで光ります — 星の周りの金色のリング、サイドバーの対応するチップの金色の色合い。サイドバーのチップをクリックすると、5つのビューすべてが絞り込まれます。Stage ミニ内の星に Shift+クリックすると、宇宙が即座にそのライフサイクルステージにフィルタリングされます。任意のミニドームの空白エリアをクリックすると、そのミニがフルサイズでプライマリスロットに「昇格」し、前のプライマリは空いたミニスロットに降格します。

## なぜ重要ですか?

ほとんどのノートアプリは書いたものを表示します。Constellation Sight は知っているものの**形**を表示します。

- あなたの思考はどこに**集中**していますか?(アンカーの密度グラデーション)
- 何がまだ**初期段階**で、何が**安定した基盤**か?(Stage ミニの色グラデーション)
- どのノートが**荷重を支え**、どれが**孤立**しているか?(Acts ミニのサイズエンコーディング)
- 各アイデアはどこから来たか — 自分の思考、読書、聴取、伝統?(Provenance ミニのセクターレイアウト)
- 結論にどれだけ**自信**がありますか?(Confidence ミニの不透明度グラデーション)

アンカーの中心にあるノート(高い接続性 → 荷重を支える)だが Stage ミニでシアン(`spark` — 火花が出たばかり)の場合、それは診断的な何かを伝えます:まだ成熟していない荷重を支えるアイデアです。

## 開き方

1. Constellation の左端のドックにある**目のアイコン**をクリックします。
2. アンカードームはほとんどの宇宙で 2–5 秒以内にレンダリングされます。
3. 閉じる:右上の **(×)** をクリック、または **Esc** を押します。

## 表示内容

### ヘッダーストリップ

Sight ビューの上部、左から右:
- **「Constellation Sight」** — タイトル。
- **「v6.1 — Coordinated Views (Phase 2)」** — バージョンサブタイトル。
- **金色の「X / Y notes」バッジ** — フィルターがアクティブな時のみ表示。
- **金色のスモールキャップス「EXTENDED」バッジ** — 拡張ビューがオンの時のみ表示。
- **「Reset View」ボタン** — レイアウトがデフォルトから変更された時のみ表示。
- **(×)** 閉じるボタン — 常に存在。

### アンカードーム(プライマリスロット)

中央の大きなクリーム色のドーム:
- **ストラタムリング** — 5つの同心円。最内 = 最も基礎的なノート;外縁 = 最新の火花。
- **カレンダーリム** — 外側に 12 ヶ月のラベル。
- **ストラタムラベル** — 上部のイタリック体テキスト。
- **星** — 各ノートが小さなクリーム色の点として、ストラタム × 時間で配置。
- **接続線** — ノート間のタイプ付きリンクのエッジ、星の下に低い不透明度で描画。
- **ホバーリング** — カーソルがホバーする星の周りの金色の円。

### 4つのミニドーム

右側、2×2 グリッド。デフォルトで非表示;**Ctrl+D**(セッションのみ)または **Ctrl+Shift+D**(永続 — 拡張ビュー参照)で表示。

各ミニは1つのエンコーディングで同じ宇宙をレンダリング:

1. **CONFIDENCE — 不透明度。** より自信のあるノートが明るく;暫定的なものはフェード。
2. **STAGE — 色(フルディスク)。** ライフサイクルステージごとのカテゴリカル色:
   - **シアン** = `spark`(火花が出たばかりのアイデア)
   - **オレンジ** = `birth`(形を取りつつある)
   - **バイオレット** = `growth`(活発に動いている)
   - **緑** = `maturity`(完全に形成された)
   - **黄** = `renewal`(最近再訪された)
   - **グレー** = `dormancy` / `archival`(非活動 / 閉鎖)
3. **ACTS — サイズ(上位十分位)。** リンク数のトップ 10% = 大きな点;残りは小さい。
4. **PROVENANCE — 5 セクター。** 星が 5 つの角度セクターに再配置:**Self / Read / Heard / Reasoned / Tradition**。

### 降格されたアンカー(ミニが昇格した時)

任意のミニをプライマリスロットに昇格すると、アンカーは空いたミニスロットに降格します。そこでは **「UNIVERSE — primary view」** というタイトルで**中性のクリーム色の点**としてレンダリングされます。

### ファセットサイドバー(左端)

折りたたみ可能なパネル、**6 つのフィルターファセットグループ**、それぞれライブカウント付きカテゴリーを表示:

- **Folder** — フォルダ階層
- **Library** — ライブラリ名
- **Stratum** — Foundation / Roots / Trunk / Branches / Twigs / Edge of Knowing
- **Confidence** — Hypothesis / Evidence / Established / Contested
- **Stage** — Spark / Birth / Growth / Maturity / Dormancy / Renewal / Archival
- **Provenance** — Self / Read / Heard / Reasoned / Tradition

エッジの **▶** をクリックして展開。任意のチップをクリックしてフィルターを切り替え。

## インタラクション

| ジェスチャー | 効果 |
|---|---|
| **星にホバー** | 5 つのサーフェスすべての同じ星の金色リング + サイドバーの対応するチップが金色に。 |
| **星に通常クリック** | エディタでノートを開く。**「Return to Sight」** ボタンが表示。 |
| **星に Shift+クリック** Stage / Confidence / Provenance ミニで | その星のカテゴリーのフィルターを切り替え。 |
| **星に Shift+クリック** Acts またはアンカーで | 効果なし。 |
| **ミニの空白エリアをクリック** | そのミニがプライマリスロットに昇格。 |
| **ホイールズーム(プライマリ)** | カーソルに向かってズーム。範囲:0.5× から 24×。 |
| **クリック+空白エリアをドラッグ** | ビューをパン。 |
| **Ctrl+0 / Cmd+0** | ズーム + パンをリセット。 |
| **Ctrl+D / Cmd+D** | ミニドームの表示を切り替え — **セッションのみ**。 |
| **Ctrl+Shift+D / Cmd+Shift+D** | **拡張ビュー** を切り替え — 永続。 |
| **サイドバーチップをクリック** | フィルターセットでファセットカテゴリーを切り替え。 |
| **Reset View ボタン** | アンカープライマリにズーム 1.0 で戻る。 |
| **Esc** | Sight を閉じる。 |

## ゴーストモード — ドームからの複数選択

任意のフィルターがアクティブな時、一致しない星は消える代わりに**低い不透明度(15%)**で表示されたままです。これは:

- 一致しない星がどこにあるかまだ**見える**ことを意味します。
- それらにホバーできます(金色リングが表示)。
- **Shift+クリックでカテゴリーをフィルターに追加**できます。

## 密度モード

可視(一致)星カウントが密度しきい値(デフォルト **5,000**)を超えると、ミニドームは**知覚密度レンダリング**に切り替わります。

## 拡張ビュー

**Ctrl+Shift+D**(Mac では **Cmd+Shift+D**)を押すと「拡張ビュー」が切り替わります — オンの時、ミニドームは Sight を開くたびにデフォルトで表示されます。状態は Sight の閉鎖、アプリの再起動、再起動を通じて永続します。

## Sight が最も役立つ時

- **知識形状の監査** — 執筆セッション後に Sight を開く。
- **ブラインドスポットを見つける** — ノートが少ないドームのセクターは探索する領域かもしれない。
- **荷重弱点を発見** — 中心位置の初期ステージ色のノート。
- **フィルタリングと検査** — Shift+クリックで宇宙を絞り込み;ミニを昇格してチャネルをフルサイズで研究。
- **認識的出所の追跡** — Provenance を昇格して知識がどのように調達されたかを確認。

## 関連サーフェス

- **Constellation Map** — サンバースト可視化。
- **Sky View** — グラフベースのリンク可視化。
