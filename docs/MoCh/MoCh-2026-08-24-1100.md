Written after the adversarial panel reported, because the block did not end where I thought it did.

I had this build finished. Tests green, binary built, tutorial approved after five rounds at the
inspector, records written. Then the panel — which the Boss made mandatory precisely because my

1. **The software was about to make my own mistake.** I spent this block correcting a note in three

   that `reconcile.rs` could publish one universe's count into another universe's window — the same
   wrong-universe error, made by the code, in front of the person who caught the paper version.
   Two early exits published the report without the universe check that the code immediately below
   them applies and explains in words.

2. **My app-killer fix was incomplete.** I had checked it carefully, reproduced it, enumerated
   every other site that destroys recovery state, and written it up as done. It asked whether a
   *tab* was open. The thing being protected is keyed to the *path* and deliberately outlives the
   tab. So the most ordinary sequence of all — a save fails, you close the tab, you delete the note
   later — went straight through it. That is the fourth time this one function has been fixed
   too narrowly.

Neither was a matter of opinion; both were checkable, and I checked them myself before accepting
them. The honest summary is that the gate caught what my own care did not, twice, on the same day
