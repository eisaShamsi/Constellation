## Lesson logged (→ migration checklist + orientation v2.24)
Test DB migrations under **live app concurrency**, not just an isolated copy. A one-time chunked DB worker MUST be `SQLITE_BUSY`-resilient AND coordinated with any other background DB user (here, the WAL checkpoint daemon).
