## 2 · The test that could not be run

His diagnosis was correct. Preview surfaces mount a real editor over a **synthetic** tab whose id

## 5 · The SME question

> *"From an UX perspective, is it practical to have the (x) repeated on both the tab and the
> page, on the normal note view? Give me SME opinion."*

My answer: the duplication is a symptom; the cause is that we never decided **what the × belongs
to**. A tab's × is unambiguous — the tab *is* the object dismissed. A page-header × is attached
to the note's identity row and reads as an action on the note, sitting beside a menu ending in
Delete. Closing is an act on the *set of open notes*, so by Form-Aligns-To-Purpose it belongs to
the tab strip; the header × exists only because split view has no strip.

Recommended: show the page × only when the note has no visible tab. **The Boss took the
recommendation.**
