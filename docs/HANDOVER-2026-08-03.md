## 5 · The one thing to internalise before touching this code

The triage named **"half a sweep"** — a fix applied to one branch and not its identical twin — as
the **dominant defect class in this codebase**, with eleven verified instances. I then committed
it **five times in a single session while fixing it**:

- wired Close into 1 of 6 note-action builders (not the file tree the Boss uses);
- hid one control and left its dead twin live;
- fixed the single-note vacate and not the folder vacate;
- made a read strict and left its write non-atomic;
- normalised one side of a path comparison and not the other.

**Every one was caught by an adversarial audit or by the Boss, not by me.**

The cure that held is a shape, not a patch: **replace the promise a caller must remember with a
structure that cannot forget.** A shared helper called from every site; then a *derived* value
(`isClosableTab` from `openTabs` membership); then one shared predicate (`vacatedBy`) consumed by
both halves. A prop is just another promise.

**Practically:** before calling any fix done, grep the whole ecosystem for every surface sharing
that behaviour and bring them all along in the same commit, behind one helper. Treat "one of N
identical sites changed" as an automatic inspection finding.
