# Template Studio — the kinds of note you keep writing

Constellation reads your whole Universe and finds the kinds of note you have
already been writing — groups of notes that share the same fields. Not folders,
not tags: shapes you fell into without declaring them. The Studio shows each
kind with real examples, proposes a name only when your own notes contain one,
and lets you keep a kind as a template.

**Nothing is written to your files by looking.** Only the Keep button writes.

## Opening it

Click the ruled-page icon in the left dock (between the Cataloger and the
Reviewer), or open the command palette and type "Kinds".

## Reading a kind

- **The left list**: every kind, biggest first — a count and the fields those
  notes share.
- **Notes like this**: five real notes of that kind. Click one to open it.
- **What do you call these?** If the box is pre-filled, that word came from your
  own material (your library names, tags, titles…) and the sentences beneath it
  show the evidence as plain counts. If the box is empty, no word recurred in
  enough of your notes in more than one place — naming it is yours.
- **What these notes carry**: the fields every note has, then chips for the
  fields only some have, each with its count. Tap a chip to include that field
  in the template.

## Keeping a kind

Type or accept a name and press **Keep**. The line under the button states
exactly what will be written — the file, the fields, the sections — before
anything touches disk. Keep never overwrites: if the name is taken you choose
**Rename it** or **Add these fields to it** (which only adds missing fields to
your existing template and never removes anything). **Undo** moves the new file
to the trash — and refuses politely if you have already edited it.

## The Studio remembers

A kept kind shows the name you gave it, with a check mark — even after a
restart. The memory lives in the template file itself (a `from_kind:` line),
not in the app, so it travels with your Universe.
