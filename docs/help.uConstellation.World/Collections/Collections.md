# Collections

A **Collection** is a named, saved basket of notes you **hand-pick** — the working set for a task. When you run a search, the results normally vanish the moment you close it. A Collection is your decision about *which of those results matter*, kept safe across restarts.

> [!tip] Your judgement, saved
> Search *finds* notes. A Collection *keeps* the ones you chose. Any note can sit in as many collections as you like — membership is by hand, not by rule.

Collections live in the **Search Hub** (the magnifying-glass icon in the dock). Under the search box are two tabs: **Results** and **Collections**.

## How Collections differ from their neighbours

Constellation already has surfaces that gather notes — Collections fills the one gap none of them cover:

- **Search** finds notes by a query. Its results are *temporary* and recomputed each time.
- **Bases** build a live **table** from a rule; membership is *automatic* — the Base decides.
- **The File Explorer** shows *where notes live* — the folder hierarchy, one home per note.
- **A Collection** is *hand-picked and persistent* — you choose each member, and a note can belong to many collections at once, wherever it lives.

## Making a collection and filling it

1. Open the **Search Hub** → the **Collections** tab → **+ New**, type a name, press **Enter**.
2. Go to the **Results** tab and run a search.
3. **Right-click** any result → **Add to collection ▸** → pick your collection (or **New collection…** to make one on the spot).

You can add notes the same way from the **file tree** — right-click a note → **Add to collection ▸**.

## Working with a collection

- The **dropdown** at the top switches between your collections.
- Click a note's **name** to open it. Each note shows its live details (title, library) and updates automatically when you edit it elsewhere.
- The **✕** on a row takes that note *out of the collection*. This never deletes the note itself — it only leaves the basket.
- **✎** renames the collection; **🗑** deletes it. (See **Starred** below — that one is permanent.)

### Filter chips

Below the header, four chips **narrow the view** to notes in a particular state — they never *add* notes, and combining chips means "match all":

- **Due** — the Review Pulse says this note is due for another look.
- **Unlinked** — the note has no incoming or outgoing links yet.
- **Contested** — the note has a "contradicts" link.
- **Forming** — the note's own stage is early (spark / birth / growth).

## Starred — your bookmarks

Bookmarks are now a special, permanent collection called **Starred**:

- It **can't be deleted**, and it also appears in the sidebar's **Bookmarks** section for one-click access.
- The **⭐ star** button works exactly as before — anything you star lands in Starred.
- Everything you had bookmarked before is **migrated in automatically** the first time you open this version. Your old bookmarks file is kept untouched as a backup.
- In the sidebar, each bookmark shows *where it lives* — **Linked Universe / library / folder** — on the far side of its row. **Right-click** a bookmark for Open, Open in new tab, Reveal in tree, **Remove bookmark**, Add to collection, and Copy.

> [!info] Nothing is ever moved or copied
> A Collection stores only *membership* — a list of which notes it holds. Your Markdown files stay exactly where they are; adding or removing a note from a collection never touches the file on disk.
