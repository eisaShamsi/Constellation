## Risk mitigation (per invariant)

**Typing latency untouched** — nothing added to `NotePane:517–531`'s `updateListener`; the rewrite is one-shot on an explicit gesture. **Zero hot-path `invoke()`** — no step touches the keystroke path; §5 is inside `index_note` (already post-save fire-and-forget). **Write-time derivation** — all 8 props derived at index time. **Body authoritative** — §7–§10 write only the `.md`; `note_links` never written directly for type/annotation. **No cascade clobber** — §7 refuses on `isCascading`/`cascadeFreeze` *before* dispatch (same gate `handleSave:250` uses). **Single content ownership (LL-014)** — dispatch→`editBody`→`compose`(path-refused)→`writeNote`; never read-modify-write (this is also why Backlinks is read-only for writes). **`row ≠ link`** — dedupe-aware disambiguation; `set_confidence`'s bulk WHERE left alone and explicitly not copied. **Editor-Parity** — every new link item also lands in FM+'s host-built menu. **RTL + ×15** — reuse the two proven anchoring/clamp patterns; §3 + §6 additionally *fix* existing untranslated strings. **macOS+Windows** — menus/popovers only, **no new keyboard chords at all**; clamping in JS px, not `vh`. **No silent failure** — §7 returns `Promise<SaveOutcome>` → `SaveHealthBanner`; §10 widens archive/confidence to report row counts + kills the two `catch {}`.

**Additional risk flagged, OUT OF SCOPE:** `BacklinksPanel.svelte:~190` (`linkMention`) does a raw `readNote`→`write_note` on a note that may be open+dirty, wrapped in `catch {}` — same class as the `b6310479`/`baae4533` clobber sweeps. **File it separately; do not widen this migration.**

## Rollback (asymmetric)

- **§1–§6 roll back free** (deletions, read-widening, extraction, one setting, one read-only popover, one Rust preservation fix). The DB is derived — a re-index rebuilds it. *Note:* reverting §5 restores the wipe, so revert it only together with §7–§10.
- **§7–§10 mutate the user's `.md` and DO NOT roll back.** A reverted build can't un-write `[[supports::X|reason]]` — but the tokens remain valid, parseable markdown, so data isn't broken, merely no longer UI-editable.
- **The lever:** `livingLinkWriteFlag.ts` — one const. Flag off: no gesture renders, no rewrite path reachable, §1–§6 keep working. A kill-switch that doesn't require reverting six commits.
- **A partial write must never leave** a rewritten token with the model marked clean — structurally unreachable (see §7).
