# Constellation Nervous System (CNS)

## 이것은 무엇입니까?

**Constellation Nervous System**은 우주의 **연결 순회** 뷰입니다. Constellation Sight가 노트의 *형태*(계층 × 시간 × 채널 인코딩)를 보여주는 반면, CNS는 *배선* — 그것들을 연결하는 유형화된 링크 그래프와 그 그래프에 숨겨진 구조적 패턴을 보여줍니다.

답변합니다: **"내 우주의 아이디어는 어떻게 연결되어 있고, 간격은 어디에 있는가?"**

뷰는 네 개의 분석 표면을 중심으로 구축됩니다:
- **우주 건강** — 지식이 얼마나 연결되고, 균형 잡히고, 모듈화되어 있는지에 대한 전체 및 메트릭별 점수.
- **커뮤니티** — 밀접하게 상호 연결된 노트의 그룹 ("이념적 클러스터").
- **주요 다리** — 그렇지 않으면 분리될 커뮤니티를 연결하는 소수의 노트 ("하중 지탱 커넥터").
- **사각지대** — 연결을 기대하지만 아직 가지지 않은 구조적 간격.

"Nervous System"이라는 이름은 해부학적입니다: 신경은 유기체의 먼 부분 간에 신호를 전달하는 연결 경로입니다. CNS는 유형화된 링크 그래프를 같은 방식으로 다룹니다.

## 왜 중요합니까?

대부분의 노트 앱은 링크를 배관으로 다룹니다 (여기서 저기로 이동). Constellation은 그것들을 **지식 아키텍처**로 다룹니다:

- 많은 들어오는 링크가 있는 노트는 **하중을 지탱**합니다 — 많은 아이디어가 그것에 의존.
- 두 커뮤니티를 연결하는 노트는 **합성 지점**.
- 내부 링크가 약한 커뮤니티는 **취약**.
- "사각지대"는 구조가 연결을 가져야 하지만 없는 곳 — 탐색할 가치가 있는 가설.

## 열기

1. Constellation 왼쪽 끝 독에서 **뉴런 아이콘**(작은 분기된 신경 세포 모양 — 중간에 세포체, 세 개의 수상돌기 분기 및 시냅스 단자)을 클릭합니다.
2. CNS는 전체 창 오버레이, 중력 우물 스타일로 열립니다 — 힘 지향 그래프, 각 노트는 노드, 각 유형화된 링크는 에지.
3. 닫기: 상단의 **(×)**를 클릭하거나 **Esc**를 누릅니다.

## 표시 내용

### 우주 건강 카드

우주의 전체 연결 건강을 보여주는 요약 패널, 복합 점수의 황금 론델 (예: **91 / 100**) 및 네 메트릭:

- **Modularity** — 노트가 별개의 커뮤니티로 얼마나 깔끔하게 클러스터되는지.
- **Dominance** — 한 커뮤니티가 우주를 지배하는지.
- **Entropy** — 커뮤니티 크기의 다양성.
- **Connectivity** — 노트당 평균 링크.

각 메트릭에는 색상 상태 알약이 있습니다: **HEALTHY** (녹색) / **CAUTION** (노랑) / **IMBALANCED** (빨강).

### 중력 우물

주요 시각화: 노트가 노드로 떠다니고, 링크가 그것들을 함께 끌어당기고, 반발이 그것들을 밀어냅니다. 커뮤니티는 클러스터로 자체 조직됩니다.

- **노드 크기** = 링크 수.
- **노드 색상** = 커뮤니티 멤버십.
- **에지** = 두 노트 사이의 유형화된 링크.

### 주요 다리

가장 많은 다른 커뮤니티를 연결하는 노트 목록 — 이것들이 합성 지점입니다.

### 커뮤니티

검출된 노트 클러스터 목록.

### 사각지대 (구조적 간격)

제안된 누락된 연결 — 그래프 알고리즘이 연결되어야 한다고 생각하는 노트 쌍.

## 상호작용

CNS는 **단일 클릭 미리보기 / 더블 클릭 열기** 패턴을 사용합니다 (Sight의 단일 클릭 열기와 다름):

| 제스처 | 효과 |
|---|---|
| **노드에 단일 클릭** | 선택합니다. 오른쪽 사이드 패널이 슬라이드 인하며 제목, 커뮤니티, 중심성 순위, 들어오는/나가는 링크를 표시. 노트는 **열리지 않음**. |
| **노드에 더블 클릭** | 에디터에서 노트를 엽니다. **"Return to CNS"** 버튼이 나타남. |
| **노드에 호버** | 제목이 있는 툴팁. |
| **빈 영역 클릭** | 선택 지움. |
| **마우스 휠** | 줌 in/out. |
| **클릭 + 드래그** | 팬. |
| **목록의 커뮤니티 클릭** | 우물에서 커뮤니티의 노트 강조. |
| **주요 다리 항목 클릭** | 다리 노트에 포커스. |
| **Esc** | CNS 닫기. |

단일 클릭 미리보기는 의도적입니다: 많은 노트의 세부정보(및 그 연결)를 스캔할 수 있으며 각각을 에디터에서 열 필요가 없습니다.

## CNS가 가장 유용한 경우

- **연결 밀도 감사** — Universe Health가 한눈에 보이는 읽기 제공.
- **합성 지점 찾기** — Top Bridges가 가장 많은 건축 작업을 하는 노트 표시.
- **존재를 몰랐던 커뮤니티 발견** — 그래프에서 나타나는 클러스터.
- **사각지대 패치** — 그래프가 두 노트가 연결되어야 한다고 제안하지만 연결되지 않은 경우.
- **재조직 계획** — 커뮤니티는 자연스럽게 폴더 구조에 매핑.

## CNS vs Sight — 언제 무엇을 사용

- **Sight** = "내 우주는 어떻게 **형성**되어 있는가?" 공간 / 범주 분석.
- **CNS** = "내 우주는 어떻게 **연결**되어 있는가?" 네트워크 / 위상 분석.

그들은 보완적입니다: Sight는 표면을 읽고, CNS는 그 아래의 배선을 읽습니다.

## 관련 표면

- **Constellation Sight** — 자매 시각화 (독의 눈 아이콘).
- **Sky View** — 그래프 뷰이지만 다르게 구축.
- **Backlinks / Outgoing Links 패널** — 노트당 연결 목록.
