# 아랍어 엔진

Constellation은 이 앱을 위해 처음부터 만든 5층 형태 분석 엔진으로 아랍어 텍스트를 해석합니다. 이는 기존 스테머의 이식이 아니라, 아랍어 어근·패턴·고유명사·외래어, 그리고 사용자 자신의 용어를 이해하는 네이티브 도구입니다. 엔진 자체는 구성할 필요가 없습니다. 모든 검색, 모든 링크, 모든 색인 항목 아래에서 조용히 동작합니다. 사용자가 *구성할 수 있는* 부분——그리고 이 도움말 주제가 다루는 부분——은 엔진이 사용자의 판단을 부르는 유일한 지점, 즉 설정의 **아랍어 엔진 재정의** 패널입니다.

---

## 왜 엔진이 존재하는가

아랍어는 템플릿 언어입니다. ك‑ت‑ب(「쓰다」)와 같은 단일 어근에서 كاتب(쓰는 사람), مكتوب(쓰인 것), كتاب(책), يكتب(그는 쓴다), كتبنا(우리는 썼다) 같은 수십 가지 표면형이 생성되며, 검색할 때 이 모두가 동일한 의미 핵심으로 수렴해야 합니다. 서투른 스테머는 이런 형태들을 훼손하거나(예를 들어 وائل을 ائل로 과도하게 벗겨 내거나) 그 연결 자체를 놓칩니다. Constellation의 엔진은 모든 아랍어 단어를 엄격한 우선순위에 따라 다섯 층을 통과시켜 이 두 가지 실패를 모두 피합니다:

1. **0 계층 — 사용자 재정의**(사용자가 제어하는 계층입니다)
2. **2 계층 — 보호 목록**(결코 손대서는 안 되는, 사람 손으로 선별된 약 1,200개의 고유명사·지명·외래어·기능어)
3. **3 계층 — 생성 FST**(약 7,000개 어근 × 158개 패턴을 전체 표면 어휘로 매핑하는, 컴파일된 유한 상태 변환기)
4. **3b 계층 — 캐스케이드**(음운 복원: 동화, 약어근, 함자 배치)
5. **5 계층 — 휴리스틱**(우아한 폴백——다른 모든 계층이 답을 거절할 때에만 발화하는 보수적인 접사 제거기)

둘 이상의 계층이 해석을 내놓은 경우, 순위 단계(4 계층)가 가장 좋은 분석 하나를 고릅니다. 이 순위는 사용자 재정의를 그 무엇보다 위에 놓습니다.

---

## 기능: 아랍어 엔진 재정의

### 이것은 무엇입니까

재정의 패널은 설정 안의 작은 표로, 특정 아랍어 표면형을 엔진이 어떻게 해석해야 하는지 사용자 자신의 말로 알려주는 곳입니다. 각 재정의에는 다음이 들어갑니다:

- **표면형** — 사용자가 입력하는 그대로의 아랍어 단어(예: وائل).
- **표제어** — 엔진이 반환해야 할 기본형(예: وائل).
- **어근** — 선택 사항. 단어에 고전 어근이 있는 경우 세 개 또는 네 개의 자음.
- **패턴** — 선택 사항. 형태 템플릿을 기록하고 싶다면 자유 텍스트 라벨(예: `فاعل`).
- **품사** — 고유명사 / 명사 / 형용사 / 부사 / 동사 / 조사 / 외래 / 미정.
- **메모** — 선택 사항. 미래의 자신을 위한 한 줄 맥락.

### 왜 중요한가

어떤 지식 네트워크에도 엔진이 사전으로는 알 수 없는 용어가 있습니다. 사용자 자신의 신조어, 동네 사람의 이름, 분야에서 쓰는 약어, 동료들이 특정한 철자를 선호하는 외래어 같은 것들입니다. 재정의가 없다면 엔진은 이런 표면형에 일반 분석을 적용하여 사소한 변형 하나로도 검색 결과가 산산이 흩어지게 됩니다. 재정의는 주권적인 답입니다——생성 FST, 캐스케이드, 휴리스틱 폴백을 모두 이깁니다. 4 계층의 순위는 재정의에 최상위 출처와 1.0 신뢰도를 부여하므로 다른 분석에 밀려나는 일이 없습니다.

재정의는 `<사용자의 Universe>/.constellation/arabic-overrides.json` 이라는 단일 JSON 파일에 저장됩니다. 이 파일은 평문이며 알파벳 순으로 정렬되고, `.tmp` + 이름 변경 쌍을 통해 원자적으로 기록되어, 편집 중 정전이 일어나도 손상되지 않습니다. 사용자의 것이므로 버전 관리에 넣거나, 차이를 비교하거나, 여러 기기 간에 공유할 수 있습니다.

### 사용 방법

**1단계: 패널 열기**

오른쪽 위 도구 모음의 기어 아이콘을 클릭하거나 `Ctrl + ,` / `Cmd + ,` 를 눌러 설정을 엽니다. 왼쪽 사이드바에서 **아랍어 재정의** 를 선택합니다——**언어** 바로 옆에 있습니다. 보이지 않으면 사이드바를 스크롤해 주십시오.

**2단계: 첫 재정의 추가하기**

**재정의 추가** 를 클릭합니다. 표면형, 표제어, 어근, 패턴, 품사, 메모 여섯 개의 필드를 가진 폼이 나타납니다. 표면형은 노트에 쓰는 그대로 입력하십시오——엔진은 내부에서 발음 부호와 alef 변형을 정규화하므로 정확히 일치시킬 필요는 없습니다. 돌려받고 싶은 표제어를 채워 주십시오. 어근과 패턴을 모르면 비워 두어도 됩니다; 엔진은 그래도 재정의를 사용합니다. 드롭다운에서 품사를 선택하거나 **미정** 으로 남겨 두십시오. **저장** 을 클릭합니다.

**3단계: 재색인 배너 지켜보기**

저장하는 순간 패널은 **재색인 중…** 을 표시하고, 엔진은 활성 Universe 안에서 그 표면형을 포함하는 모든 노트를 훑습니다. 일치하는 각 노트는 새 재정의 판정 아래 다시 토큰화됩니다. 스윕이 끝나면——전형적인 Universe에서는 보통 1초 이내——배너가 **노트 N개 재색인됨** 으로 바뀌고 3초 후 자동으로 사라집니다. 앱을 다시 시작할 필요도, 어떤 색인도 재구축할 필요도 없습니다.

**4단계: 검색으로 확인하기**

검색 허브(`Ctrl + K` / `Cmd + K`)를 열고 해당 표면형을 입력합니다. 이제 결과는 지정한 표제어를 반영해야 합니다: 표제어로 조회하면 표면형이 발견되고, 표면형으로 조회하면 표제어의 다른 굴절형들이 발견됩니다.

**5단계: 재정의 제거하기**

해당 재정의 행의 **×** 버튼을 클릭합니다. 항목은 즉시 디스크에서 제거되고, 같은 재색인 스윕이 역방향으로 실행됩니다——해당 표면형을 포함했던 노트가 엔진의 일반 분석 아래 다시 토큰화됩니다. 배너는 몇 개의 노트가 영향을 받았는지 알려줍니다.

### 보호 목록과의 상호작용

보호 목록(2 계층)에는 결코 벗겨서는 안 될 약 1,200개의 흔한 표면형이 이미 포함되어 있습니다—— وائل 같은 이름, فلسطين 같은 지명, إنترنت 같은 외래어입니다. 이런 것은 직접 추가할 필요가 없습니다; 엔진에 기본 탑재되어 있습니다. 재정의 패널은 사용자의 Universe에 *개인적인* 표면형에 사용하십시오: 자신만의 용어, 지역의 이름, 분야 특유의 외래어, 또는 엔진의 자동 해석에 동의하지 않는 경우 등입니다.

### Universe 간 상호작용

각 Universe는 고유한 재정의 파일을 가집니다. Universe를 전환하면 메모리 안의 활성 재정의 집합이 교체됩니다——엔진은 새 Universe의 `.constellation/` 폴더에서 JSON을 다시 불러옵니다. 파일이 없으면(새 Universe) 엔진은 재정의 집합을 비어 있는 것으로 다룹니다. 파일 형식이 잘못되어 있으면 엔진은 경고를 기록하고 로드를 거부하는 대신 빈 집합으로 폴백합니다.

### 파일을 손수 편집한다면

가능합니다. 파일 형식은 다음과 같습니다:

```json
[
  {
    "surface": "وائل",
    "lemma": "وائل",
    "root": null,
    "pattern": null,
    "pos": "ProperNoun",
    "note": "Personal name — never strip"
  }
]
```

git 친화적인 차이를 위해 항목들을 표면형 기준 알파벳 순으로 정렬해 주십시오. 엔진은 저장할 때마다 다시 정렬하므로, 수동 재배열은 UI를 통한 편집 후에는 살아남지 않습니다.

## 용어집

- **표면형** — 글로 쓰인 아랍어 단어. 붙어 있는 접어까지 포함합니다(예: الكتاب, بالكتاب, كتبنا).
- **표제어** — 굴절을 벗겨낸 단어의 인용형(예: كتاب).
- **어근** — 한 단어족이 공유하는 3 또는 4개의 자음으로 이루어진 의미의 핵(예: ك‑ت‑ب).
- **패턴** — 어근과 결합하여 표면형을 만들어 내는 모음과 접사의 템플릿(예: فاعل → كاتب).
- **FST** — 유한 상태 변환기. 엔진은 어근 × 패턴에서 전체 표면 어휘로의 매핑을 효율적으로 수행하는 데 이것을 사용합니다.
- **캐스케이드** — 동화, 약자음, 함자 배치를 처리하는 음운 복원 계층.
- **재정의** — 특정 표면형이 어떻게 해석되어야 하는지에 대한 사용자 자신의 판정; 다른 모든 계층을 이깁니다.
