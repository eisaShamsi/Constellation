# 우주 다이제스트

> *다이제스트를 당신 마음의 목차로 생각하세요 — 파일의 목록이 아니라 아이디어의 목록입니다.*

**우주 다이제스트**는 전체 지식 베이스를 *의미* 수준에서 훑어보는 장소입니다. 파일 트리(이름만) 또는 스타 뷰(모양만) 대신, 다이제스트는 각 노트 아래에 **그 노트가 무엇에 관한 것인지 말해주는 한 문장**을 보여줍니다. 행을 탭하면 여러 문장의 전체 요약이 인라인으로 확장됩니다. 하나도 열지 않고도 50개 노트의 본질을 1분 안에 읽을 수 있습니다.

이것은 파일 트리, 노트 내비게이터, 스타 뷰와 함께 **왼쪽 도크**에 있습니다 — Constellation이 내비게이션을 위해 제공하는 네 가지 방법 중 하나입니다.

---

## 다이제스트가 존재하는 이유

파일 트리는 당신이 *가지고 있는 것*을 알려줍니다. 검색은 당신이 *물어본 것*을 알려줍니다. 다이제스트는 당신이 *아는 것*을 알려줍니다.

우주가 수백 개의 노트를 넘어 성장하면 "각각을 열어 무엇을 말하는지 기억하는 것"이 불가능해집니다. 스크롤하는 속도로 각 노트의 **요지**를 읽을 방법이 필요하고, 더 신중하게 생각하고 싶은 순간에 어떤 요지든 전체 요약으로 확장할 방법이 필요합니다. 그것이 다이제스트입니다.

이것은 **노트 요약 생성기(NSC)** 코어 플러그인의 세 번째 기둥입니다:
- **기둥 1**: 요약 엔진(페이즈 1 / MIG-043).
- **기둥 2**: 노트가 나타나는 곳이면 어디든 요약을 배치하는 서비스(페이즈 2 / MIG-044 — 분류기, 검색 결과, 편집기 띠, 백링크, 발신 링크, 인덱스, 스타 뷰 호버).
- **기둥 3**: 이 뷰 — 우주 다이제스트(페이즈 3 / MIG-045).

---

## 다이제스트 열기

**왼쪽 사이드바**에서 **우주 다이제스트 아이콘**(모서리에 원이 있는 작은 목록)을 클릭합니다 — 줄에서 네 번째 아이콘으로, 파일 트리 / 노트 내비게이터 / 스타 뷰 옆에 있습니다. 사이드바가 다이제스트 패널로 전환됩니다.

다시 전환하려면 다른 세 아이콘 중 아무거나 클릭하거나 **Escape**를 누릅니다.

---

## 보이는 것

위에서 아래로:

1. **툴바.** 검색 입력 + 작은 시계 아이콘(정렬 토글, 기본값 "최신순").
2. **Library 헤더.** 대문자 보라색 막대 — 우주의 각 library마다 하나. 각각 library의 이름과 포함된 노트 수를 표시합니다.
3. **폴더 헤더.** 작은 흐릿한 레이블 — *노트를 포함하는* 각 폴더마다 하나. library 루트에 있는 노트는 폴더 헤더를 받지 않습니다.
4. **노트 행.** 각 행에는:
   - 왼쪽에 셰브론(▶) — 클릭하면 행이 확장됩니다.
   - 인터랙티브 강조 색상의 **노트 이름** — 클릭하면 편집기에서 **노트를 엽니다**.
   - 이름 아래의 희미한 이탤릭 줄 — **요약 헤드라인**(다른 모든 페이즈 1/2 표면에 나타나는 것과 동일).

---

## 전체 요약을 읽기 위해 행 확장

행 왼쪽의 **셰브론**(▶)을 클릭하거나 — **헤드라인 이탤릭 줄** 자체를 클릭합니다. 셰브론이 ▼로 회전하고, **여러 문장의 전체 요약**이 헤드라인 아래에 인라인으로 나타나며 필요한 만큼 자연스럽게 줄바꿈됩니다.

접으려면 셰브론(또는 헤드라인)을 다시 클릭합니다.

"셰브론을 클릭해 확장, 이름을 클릭해 열기" 분할은 두 제스처를 구별되게 유지합니다: 노트에 *관해 읽기* 위해 확장한 다음, 그것을 지나쳐 계속 스크롤할 수 있습니다; 이름을 클릭할 때만 노트가 실제로 열리고 포커스를 잡습니다.

---

## 필터링

상단의 **검색 입력**에 입력합니다. 입력함에 따라 목록이 좁혀집니다 — **이름, 헤드라인 또는 전체 요약**에 쿼리가 포함된 노트만 표시된 채로 남습니다. 일치하는 노트가 0개인 Library 헤더와 폴더 헤더는 완전히 사라집니다(빈 헤더 없음).

입력을 지워(× 버튼 또는 백스페이스) 전체 목록을 복원합니다.

필터는 **즉각적**입니다 — Constellation은 디스크나 데이터베이스에 닿지 않습니다. 이미 메모리에 있는 요약을 읽으므로 10,000 노트의 우주도 입력 속도로 필터링됩니다.

---

## 정렬: 최신순 또는 알파벳순

두 정렬 모드 사이를 토글하려면 툴바의 **시계 아이콘**을 클릭합니다:

- **최신순**(기본값) — 각 폴더 내에서 노트는 **생성 시간, 가장 최근 것이 먼저**의 순서로 나타납니다. library 내의 폴더는 포함된 가장 최근의 노트에 따라 정렬됩니다(가장 활발한 폴더가 먼저 나타나도록). *최근에 작업하고 있던 것*을 드러내기 때문에 기본값입니다.
- **알파벳순** — 폴더는 이름으로 정렬되고, 각 폴더 내의 노트는 이름으로 정렬됩니다. 다시 클릭하면 최신순으로 돌아갑니다.

토글은 세션당이며, 다이제스트를 닫고 다시 열면 최신순으로 돌아갑니다.

---

## 페더레이션: 자식 우주는 인라인으로 나타남

우주에 **링크된 자식 우주**(cUniverses)가 있으면, 자식 우주의 각 library는 부모 우주의 libraries와 함께 **자체의 동료 Library 헤더**로 다이제스트에 나타납니다. 다이제스트는 이 우주에서 도달 가능한 모든 것의 통합 뷰이지, 물리적으로 여기 있는 libraries만이 아닙니다.

(향후 Constellation 업데이트에서 자식 우주 libraries를 일시적으로 다이제스트에서 숨기는 켜기/끄기 토글이 추가될 예정입니다; 현재로서는 항상 나타납니다.)

---

## 거대한 우주에서 다이제스트가 빠르게 유지되는 방법

다이제스트는 **가상화**되어 있습니다: 전체 트리가 아니라 현재 스크롤포트에 보이는 행만 렌더링합니다. 10,000 노트의 우주는 50 노트의 우주만큼 부드럽게 스크롤됩니다. 행이 뷰로 스크롤될 때, 그 요약은 Constellation의 인-메모리 캐시에서 배치로 가져옵니다(다른 모든 페이즈 1/2 표면을 구동하는 것과 동일한 캐시 — 별도의 작업 없음, 별도의 저장 없음).

다이제스트는 결코 노트를 디스크에서 다시 읽지 않습니다. 결코 요약을 다시 계산하지 않습니다. 이는 엔진이 페이즈 1에서 채우는 동일한 `note_summaries` 테이블에 대한 **읽기** 뷰입니다.

## 일반적인 워크플로우

**"이번 주에 무엇을 작업했는지 보고 싶어요."**
정렬 = 최신순(기본값)으로 다이제스트를 엽니다. 가장 최근에 생성된 노트가 각 library/폴더의 상단에 나타납니다. 헤드라인을 스캔합니다.

**"X에 관해 반쯤 기억나는 노트를 찾고 있어요."**
다이제스트를 엽니다. X(노트의 제목, 헤드라인 또는 전체 요약에 나타날 단어)를 입력합니다. 목록이 후보로 좁혀집니다. 셰브론을 클릭해 전체 요약을 읽고, 이름을 클릭해 승자를 엽니다.

**"제 Library의 톱다운 리뷰를 쓰고 싶어요."**
다이제스트를 열고, 정렬 = 알파벳순. 헤드라인을 순서대로 걷습니다. 무언가 사로잡으면 셰브론을 클릭해 더 충실한 요약을 읽습니다. 이것을 새 MOC(Map of Content) 노트의 뼈대로 사용합니다.

**"처음으로 페더레이션된 cUniverse를 탐색하고 있어요."**
다이제스트를 엽니다. 자신의 libraries를 지나 cUniverse의 libraries로 스크롤합니다 — 그것들은 동료 행입니다. 헤드라인을 읽어 링크된 우주가 무엇을 포함하는지 알아봅니다, 그곳에서 아무것도 열지 않고.

## 다이제스트에 없는 것

- 행의 **마우스 오른쪽 버튼 컨텍스트 메뉴** — 새 탭에서 열기, 아카이브 등. (v1의 경우 주요 작업은 클릭-이름-열기 및 클릭-셰브론-확장입니다. 향후 업데이트에서 컨텍스트 메뉴가 추가됩니다.)
- **사용자 정의 그룹화** — v1의 경우 Library → 폴더가 유일한 계층화입니다. (아직 "태그별 그룹화" 또는 "단계별 그룹화"는 없습니다.)
- **드래그로 재정렬** — 다이제스트는 읽기 전용이며, 정렬은 규칙에서 나오는 것이지 수동 순서가 아닙니다.
- **분류기 같은 분류 제어** — 다이제스트는 *탐색* 뷰입니다; 분류는 **분류기**(별도의 패널)에 있습니다.

## 관련 항목

- **노트 요약** — 요약이 어디서 오는지, 우선순위 규칙(당신의 것이 이김), 그리고 그것을 표시하는 표면의 전체 목록.
- **분류기** — *모든 요약 만들기*의 본거지(Library의 모든 요약을 한 번에 미리 계산하여 다이제스트가 즉시 채워지도록).
- **스타 뷰** — 지식의 *형태* 뷰(버블 + 링크); 다이제스트는 보완적인 *의미* 뷰입니다.
- **지식 정식화** — Constellation이 단순히 파일 저장이 아니라 *연결*과 *요약*으로 지식을 조직하는 이유.
