# 외관 및 테마

Constellation의 모양은 **설정**에서 제어됩니다:

1. **외관** — 테마를 선택하거나 생성하고, Obsidian 커뮤니티 레지스트리에서 테마를 가져오고, 제목 정렬과 살아있는 링크 수명 주기를 조정합니다.
2. **스타일 세터(Style Setter)** — 설정 사이드바의 자체 탭이며, 이제 **모든 스타일링의 단일 home**입니다: 인터페이스 셸과 편집기의 모든 색상·크기·폰트·요소, 링크 타입 색상, 저장된 스타일. (이전의 **Style Settings** 탭은 폐기되고 여기로 완전히 병합되었습니다.)

이 둘은 함께 CSS를 한 줄도 편집하지 않고도 앱을 워크플로, 화면 크기 및 개인 취향에 맞게 재구성할 수 있게 해줍니다.

## 테마

**테마**는 Constellation의 모양을 정의하는 이름이 지정된 색상, 설정, CSS의 묶음입니다. Constellation에는 6개의 내장 테마가 함께 제공됩니다(Constellation Light/Dark, Nord Light/Dark, Solarized Light/Dark). 모두 라이트 및 다크 시스템 모드 간에 쌍을 이룹니다.

### 테마 선택

1. **설정 → 외관**을 엽니다.
2. **테마** 그리드에서 임의의 카드를 클릭합니다. 테마가 즉시 적용됩니다.
3. 활성 카드는 강조 테두리로 강조 표시됩니다.

### 사용자 정의 테마 생성

1. 테마 그리드에서 점선의 **+ 새 테마** 카드를 클릭합니다.
2. 이름을 지정하고, 밝음 또는 어두움을 선택하고, 다섯 가지 색상(배경, 표면, 텍스트, 강조, 테두리)을 선택합니다.
3. **저장**을 클릭합니다. 이제 테마가 그리드에 나타납니다.

다른 모든 변수(호버 상태, 그림자, 음소거 텍스트)는 HSL 수학을 사용하여 다섯 가지 색상에서 자동으로 파생되므로 중요한 것만 제어합니다.

### 사용자 정의 테마 편집 또는 삭제

사용자 정의 테마 카드 위에 마우스를 올려놓습니다:
- **✏️ (연필)** — 이름, 유형 또는 다섯 가지 핵심 색상을 변경하는 편집기를 엽니다.
- **✕ (빨간 X)** — 확인 후 테마를 삭제합니다. 내장 테마는 삭제할 수 없습니다. 활성 테마를 삭제하면 Constellation은 기본값으로 돌아갑니다.

### Obsidian 커뮤니티 테마 가져오기

**🟣 Obsidian 테마**를 클릭하여 200개 이상의 커뮤니티 테마를 탐색하세요:
1. 이름 또는 작성자로 검색.
2. **미리보기**를 클릭하여 레이아웃 및 5색 스와치의 목업을 확인.
3. **가져오기**를 클릭 — 테마의 CSS가 다운로드되어 Constellation용으로 조정되고(선택자 shim + 변수 추출 + CodeMirror 구문 색상) 사용자 정의 테마에 추가됩니다.
4. 테마가 **Style Settings**를 지원하는 경우 카드에 개수가 표시됩니다; 해당 옵션은 가져오기 후 스타일 세터에 나타납니다.

## Style Settings → 이제 스타일 세터 안으로

> **참고:** 독립된 **Style Settings** 탭은 폐기되었습니다. 거기 있던 모든 컨트롤은 이제 **스타일 세터**(설정 사이드바의 자체 탭) 안에 있으며, 스타일 세터는 그것들을 모두 — 그리고 그 이상(탐색 경로, 노트 미리보기, 우주 패널, 문자 체계별 폰트)을 — 다룹니다. 아래 설명은 이 스타일링 표면을 다루며, 이제 스타일 세터를 통해 열립니다.

이 스타일링 표면은 Constellation의 네이티브, 테마에 구애받지 않는 제어판입니다. 편집기 외에도 모든 가시적 chrome을 다루며 모든 테마(내장, 사용자 정의 또는 가져온)에서 작동합니다.

### 구성 방식

섹션은 기본적으로 접혀 있습니다. 쉐브론을 클릭하여 확장합니다:

- **Constellation — 색상** — 배경 및 표면, 텍스트, 강조
- **Constellation — 타이포그래피** — 인터페이스/노트/코드 폰트 크기, H1–H6 크기, 제목 굵기, 줄 높이, 단락 간격
- **Constellation — 레이아웃 및 모양** — 모서리(작은/중간/큰 반경), 테두리 너비, 그림자, 편집기 줄 길이, 측면 여백
- **Constellation — 구성 요소** — 리본 도크, 사이드바 액션 툴바, 레이아웃 바(창 토글), 상단 바/탭 스트립, 상태 바, 파일 탐색기, 오른쪽 사이드바, 버튼, 태그, 콜아웃
- **Constellation — 편집기** — 링크, 코드 및 블록, 블록 인용, 커서 및 선택

### 값 변경

- **색상 선택기** — 스와치를 클릭하고 색상을 선택합니다. hex가 옆에 표시됩니다.
- **슬라이더** — 드래그하여 조정합니다. 숫자 값이 단위(px, % 등)로 표시됩니다.
- **스위치** — 클릭하여 클래스를 켜고 끕니다(주로 가져온 테마용).
- **드롭다운** — 옵션을 선택합니다(링크 장식 스타일 등).
- **재설정 화살표(↺)** — 각 행 끝에서 호버 시 나타납니다. 클릭하면 재정의가 지워지고 테마의 기본값이 복원됩니다.

### 저장 작동 방식

- 변경 사항은 활성 테마의 **styleSettingsValues**에 자동으로 저장됩니다.
- 내장 테마가 활성화된 상태에서 Style Setting을 변경하면 Constellation이 내장을 사용자 정의 테마로 (`{Name} (custom)`로) **자동 복제**한 다음 거기에 변경 사항을 저장합니다. 내장은 그대로 유지됩니다.
- 탭 하단의 **저장 위치:** 레이블은 현재 어떤 테마가 재정의를 보유하고 있는지 표시합니다.
- 활성 테마의 모든 재정의를 지우려면 **모두 기본값으로 재설정**을 클릭합니다.

### 스타일 값 가져오기/내보내기

스타일 값 상단의 툴바:

- **📋 클립보드에서 붙여넣기** — 원클릭: 클립보드를 읽고 유효한 JSON을 활성 테마에 병합합니다.
- **⬆️ 가져오기/붙여넣기** — 텍스트 영역을 엽니다; 수동으로 JSON을 붙여넣습니다. **병합**(추가/재정의) 또는 **모두 바꾸기**(지우고, 붙여넣은 것만 사용)를 선택합니다.
- **📄 파일에서** — Obsidian의 Style Settings 플러그인 또는 다른 Constellation 설치에서 내보낸 `.json` 파일을 엽니다.
- **📋 복사** — 현재 값을 예쁜 형식의 JSON으로 클립보드에 복사합니다.
- **⬇️ 내보내기** — 값을 `{theme-name}-style-settings.json`으로 저장합니다.

JSON 형식은 Obsidian의 Style Settings 플러그인과 정확히 일치합니다 — 설정 ID를 문자열 값에 매핑하는 평면 객체:

```json
{
  "h1-size": "36",
  "interactive-accent": "#7c3aed",
  "my-themed-color@@light": "#ffffff",
  "my-themed-color@@dark": "#1e1e2e"
}
```

이는 Obsidian에서 Style Settings를 복사하여 Constellation에 바로 붙여넣을 수 있거나 그 반대도 가능함을 의미합니다.

## 제어할 수 있는 것

모든 설정은 위의 다섯 블록 중 하나에 있습니다. 주요 기능:

### 타이포그래피

- **인터페이스 폰트 크기** — 사이드바, 툴바, 메뉴
- **노트 폰트 크기** — 편집기의 본문 텍스트
- **코드 폰트 크기** — 인라인 코드 및 펜스 코드 블록
- **H1 – H6 크기** — 각 제목 수준 개별적으로
- **제목 굵기** — 모든 제목의 가벼움 또는 굵기
- **줄 높이** — 일반(본문) 및 촘촘함(제목 및 밀집된 UI)
- **단락 간격** — 단락 간 간격

### 셸 구성 요소

- **리본 도크(왼쪽 아이콘)** — 너비, 버튼 크기, 아이콘 크기, 반경, 색상
- **사이드바 액션 툴바** — 새 노트/테이블/폴더 아이콘 — 크기, 색상, 높이, 배경
- **레이아웃 바(창 토글)** — 왼쪽/분할/오른쪽 사이드바 토글 — 버튼 크기, 아이콘 크기, 색상, 활성 상태 색상
- **상단 바/탭 스트립** — 노트가 탭에 열려 있을 때만 표시; 스트립 높이, 배경, 탭 높이/폰트/반경, 활성 및 비활성 탭 색상 제어
- **상태 바** — 높이, 폰트 크기, 배경, 텍스트 색상
- **오른쪽 사이드바(인스펙터)** — 배경, 탭 행 높이, 탭 아이콘 크기, 색상
- **파일 탐색기(왼쪽 사이드바)** — 우주 노트 행, 자식 우주(cUniverse) 행, 라이브러리 이름, 폴더, 노트 — 각각 독립적인 크기, 굵기, 색상; 수직 행 간격 추가

### 편집기

- **제목 크기**(H1–H6) 및 굵기
- 노트 본문의 **줄 높이**
- **인라인 코드** 배경, 텍스트 색상, 반경, 폰트 크기
- **링크 색상**(기본 + 호버) 및 장식 스타일(없음/밑줄/점선)
- **콜아웃 바 너비** 및 **콜아웃 반경**
- **커서 색상** 및 **선택 배경**

### 색상(앱의 모든 색상)

- 배경(기본/대체), 표면, 호버 배경, 테두리, 입력 배경
- 텍스트(일반/음소거/희미/강조 위), 오류/경고/성공 상태
- 강조(대화형 강조 + 호버), 강조 텍스트

## 스타일 세터(Style Setter)

**스타일 세터**는 **모든 스타일링의 단일 home**이며, 인터페이스 전체를 위한 전체 화면 디자인 스튜디오입니다. 설정을 하나씩 조정하며 결과를 머릿속으로 상상하는 대신, 실제 인터페이스가 디자인하는 동안 즉시 업데이트되는 모습을 확인합니다.

**여는 방법:** 설정 사이드바에서 **스타일 세터(✦)** 탭을 클릭합니다. 또는 아이콘 도크의 설정 톱니바퀴 위에 있는 **조준선(✛)** 아이콘을 클릭하면 바로 검사 모드로 들어갑니다 — 그 상태에서 앱의 어느 부분이든 마우스를 올렸다가 클릭하면 그 요소의 컨트롤로 곧장 이동합니다. 패널은 크기 조절이 가능합니다.

컨트롤은 왼쪽에 **카테고리**로 정리됩니다: **인터페이스**(파일 트리, 상태 바, 우주 패널), **구성 요소**(아이콘 바, 툴바, 탭, 버튼, 태그), **편집기**(노트 — 탐색 경로, 제목, 링크, 코드, 인용구, 그리고 색상·폰트·크기를 가진 노트 미리보기), **일반**(색조, 강조 색상, 모서리, 문자 체계별 폰트), 그리고 **링크**(링크 타입 색상과 너비). 맨 아래에는 한 번의 클릭으로 적용할 수 있는 **저장된 스타일**이 나타납니다.

**편집 내용을 보는 두 가지 방식.** **편집기** 카테고리는 **가운데에 노트 미리보기**를 표시합니다 — 제목, 링크, 또는 페이지를 클릭하면 해당 컨트롤이 오른쪽에 나타나고 즉시 업데이트됩니다. 반면 **나머지 모든 카테고리**는 패널을 한쪽으로 붙이고 반투명하게 만들어, 편집 내용이 **실제 앱에 라이브로** 미리보기됩니다(초록색 **● live** 태그가 이를 나타냅니다): 상태 바 색상이나 아이콘 바 너비를 바꾸면 실제 셸이 드래그하는 그대로 스타일링되는 것이 보입니다.

**링크.** 링크 카테고리는 각 타입을 실제 색상의 **알약(pill)**으로 표시합니다 — 알약을 클릭하면 다시 색을 칠합니다(모든 곳에서 라이브로) — 그리고 **링크 색칠**과 **레이블 표시** 토글, **알약 모양**, 재사용 가능한 **저장된 색상** 팔레트가 함께 있습니다.

**모양 저장하기.** **Keep**를 누르면 모양이 **이 우주에 맞게** 저장됩니다(재시작 후에도 유지됨); **Discard**(또는 **✕** / **Esc**)를 누르면 저장하지 않은 편집을 버리고 앱이 이전 상태로 돌아갑니다; **Reset**을 누르면 꾸밈없는 기본 테마로 돌아갑니다. Keep를 누르기 전까지는 아무것도 디스크에 저장되지 않습니다.

**모양 재사용하기 — 스타일로 저장.** 목록 상단의 "draft:" 칸에 이름을 입력하고 **+ Save current as a style**를 누르면, **저장된 스타일** 목록(왼쪽 아래)에 나타납니다. 이는 모든 우주에 걸쳐 전역이며, 단순한 테마가 아니라 세터에서 디자인한 모양을 담습니다. 저장된 스타일을 클릭하면 적용되고, 그 행 위에 마우스를 올리면 **↻ 업데이트**, **⤓ 내보내기**, **✎ 이름 변경**, **✕ 삭제**가 나타납니다. (내장 테마는 **설정 → 외관**에 남아 있고, 세터는 저장된 스타일과 라이브 모양을 담당합니다.)

## 자주 묻는 질문

### Windows 제목 표시줄("Constellation v0.3.4 — …")을 스타일링할 수 있습니까?

아니요 — 해당 막대는 운영 체제(Windows/macOS/Linux)에서 그립니다. Constellation은 이에 대한 CSS 접근 권한이 없습니다. 그 아래의 모든 것은 완전히 스타일링 가능합니다.

### 사이드바 너비는 어떻게 바꾸나요?

사이드바 너비는 사이드바 가장자리의 **드래그 핸들**로 제어됩니다(드래그하여 크기 조정) — 슬라이더가 아닙니다. 충돌하는 진실의 원천을 피하기 위해 너비 슬라이더는 스타일 세터에서 의도적으로 제거했습니다(드래그 핸들과 중복되었기 때문).

### 내 스타일링은 어디에 저장되나요?

스타일 세터에서 **Keep**로 저장한 것은 우주 설정 안에 **우주별로**(우주 단위 스타일 재정의로) 저장되어 우주 디렉토리를 따라다닙니다 — 장치 간에 동기화하면 스타일링이 함께 옵니다. 반면 **저장된 스타일**은 모든 우주에 걸쳐 전역입니다.

### 테마를 누군가와 공유할 수 있습니까?

예:
- **전체 테마** — 테마 편집기에서 **내보내기**를 클릭합니다. `.json` 파일을 공유합니다. 받는 사람은 테마 그리드에서 **↓ 가져오기**를 클릭하고 선택합니다.
- **저장된 스타일** — **스타일 세터**에서 저장된 스타일의 행 위에 마우스를 올리고 **⤓ 내보내기**를 클릭하면 `.constellation-style.json` 파일로 공유됩니다(모양만 — 비밀이나 경로는 포함하지 않음). 받는 사람은 스타일 목록에서 **Import…**를 클릭하여 추가합니다.

### 가져온 Obsidian 테마가 망가져 보입니다. 이제 어떻게 합니까?

Obsidian 테마는 복잡할 수 있습니다. 알려진 경우:
- **HSL 분할 색상**을 사용하는 테마(Minimal 같은) — 이 릴리스부터 Constellation에서 지원됩니다.
- Obsidian의 특정 DOM 구조에 의존하는 테마는 부분적으로 렌더링될 수 있습니다. Constellation에는 가장 일반적인 선택자를 매핑하는 클래스 shim이 포함되어 있지만, 매우 구조적인 테마는 다섯 가지 핵심 색상을 조정하거나 보상을 위해 Style Settings 값을 수동으로 조정해야 할 수 있습니다.
