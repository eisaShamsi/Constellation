# Constellation Sight

## 이것은 무엇입니까?

**Constellation Sight**는 지식 우주를 위한 **진단 도구**입니다. 중앙 **앵커 돔**은 각 노트를 **계층**(사고의 깊이)과 **시간**(작성 시기)으로 배치하여 표시하고, 옆의 네 개의 **미니 돔**은 동일한 우주를 다양한 채널을 통해 재인코딩합니다: **신뢰도 (Confidence)**, **단계 (Stage)**, **행위 (Acts)**, **출처 (Provenance)**.

다섯 개의 보완 렌즈로 하나의 질문에 답합니다: **"내 인식 콘텐츠는 어떻게 형성되고 조직되어 있는가?"**

어떤 돔의 어떤 별 위에 커서를 놓으면 같은 노트가 다섯 표면 모두에서 빛납니다 — 별 주위의 황금 링, 사이드바의 해당 칩의 황금 색조. 사이드바의 칩을 클릭하면 다섯 뷰 모두가 좁아집니다. Stage 미니의 별을 Shift+클릭하면 우주가 즉시 그 수명 주기 단계로 필터링됩니다. 어떤 미니 돔의 빈 공간을 클릭하면 전체 크기로 기본 슬롯으로 "승격"되며, 이전 기본은 빈 미니 슬롯으로 강등됩니다.

## 왜 중요합니까?

대부분의 노트 앱은 작성한 내용을 보여줍니다. Constellation Sight는 알고 있는 것의 **형태**를 보여줍니다.

- 사고가 어디에 **집중**되어 있습니까? (앵커의 밀도 그라데이션)
- 무엇이 아직 **초기 단계**이고 무엇이 **안정한 기반**입니까? (Stage 미니의 색상 그라데이션)
- 어떤 노트가 **하중을 지탱**하고 어떤 것이 **고립**되어 있습니까? (Acts 미니의 크기 인코딩)
- 각 아이디어가 어디서 왔습니까 — 자신의 사고, 독서, 청취, 전통? (Provenance 미니의 섹터 레이아웃)
- 결론에 대해 얼마나 **자신**이 있습니까? (Confidence 미니의 불투명도 그라데이션)

앵커 중심에 위치한 노트(높은 연결성 → 하중 지탱)지만 Stage 미니에서 시안(`spark` — 막 점화된)인 경우, 진단적인 무언가를 알려줍니다: 아직 성숙하지 않은 하중 지탱 아이디어입니다.

## 열기

1. Constellation의 왼쪽 끝 독에서 **눈 아이콘**을 클릭합니다.
2. 앵커 돔은 대부분의 우주에서 2–5초 이내에 렌더링됩니다.
3. 닫기: 오른쪽 상단의 **(×)**를 클릭하거나 **Esc**를 누릅니다.

## 표시 내용

### 헤더 스트립

Sight 뷰의 상단, 왼쪽에서 오른쪽:
- **"Constellation Sight"** — 제목.
- **"v6.1 — Coordinated Views (Phase 2)"** — 버전 부제.
- **금색 "X / Y notes" 배지** — 필터가 활성화된 경우에만 표시.
- **금색 작은 대문자 "EXTENDED" 배지** — 확장 뷰가 켜진 경우에만 표시.
- **"Reset View" 버튼** — 레이아웃이 변경된 경우에만 표시.
- **(×)** 닫기 버튼 — 항상 존재.

### 앵커 돔 (기본 슬롯)

중앙의 크림색 어두운 배경 큰 돔:
- **계층 링** — 5개의 동심원. 가장 안쪽 = 가장 기초적인 노트; 외부 가장자리 = 가장 최근의 불꽃.
- **달력 가장자리** — 외부 주위에 12개월 라벨.
- **계층 라벨** — 상단의 이탤릭 텍스트.
- **별** — 각 노트가 계층 × 시간으로 배치된 작은 크림색 점.
- **연결선** — 노트 간의 유형화된 링크 가장자리, 별 아래 낮은 불투명도.
- **호버 링** — 커서가 호버하는 모든 별 주위의 금색 원.

### 네 개의 미니 돔

오른쪽, 2×2 그리드. 기본적으로 숨김; **Ctrl+D**(세션만) 또는 **Ctrl+Shift+D**(영구 — 확장 뷰 참조)로 표시.

각 미니는 하나의 인코딩으로 동일한 우주를 렌더링:

1. **CONFIDENCE — 불투명도.** 더 자신감 있는 노트가 더 밝고; 잠정적인 노트가 희미해짐.
2. **STAGE — 색상 (전체 디스크).** 수명 주기 단계별 범주 색상:
   - **시안** = `spark` (방금 점화된 아이디어)
   - **주황** = `birth` (형태를 갖춤)
   - **보라** = `growth` (적극적으로 움직임)
   - **녹색** = `maturity` (완전히 형성됨)
   - **노랑** = `renewal` (최근 재방문)
   - **회색** = `dormancy` / `archival` (비활성 / 종료)
3. **ACTS — 크기 (상위 10분위).** 링크 수 상위 10% = 더 큰 점; 나머지는 작음.
4. **PROVENANCE — 5개 섹터.** 별이 5개 각도 섹터로 재배치: **Self / Read / Heard / Reasoned / Tradition**.

### 강등된 앵커 (미니가 승격될 때)

미니를 기본 슬롯으로 승격하면 앵커가 빈 미니 슬롯으로 내려갑니다. 거기서 **"UNIVERSE — primary view"**라는 제목의 **중립 크림색 점**으로 렌더링됩니다.

### 패싯 사이드바 (왼쪽 가장자리)

접을 수 있는 패널, **6개 필터 패싯 그룹**, 각각 라이브 카운트가 있는 범주를 표시:

- **Folder** — 폴더 계층
- **Library** — 라이브러리 이름
- **Stratum** — Foundation / Roots / Trunk / Branches / Twigs / Edge of Knowing
- **Confidence** — Hypothesis / Evidence / Established / Contested
- **Stage** — Spark / Birth / Growth / Maturity / Dormancy / Renewal / Archival
- **Provenance** — Self / Read / Heard / Reasoned / Tradition

가장자리의 **▶**를 클릭하여 확장. 어떤 칩이든 클릭하여 필터로 토글.

## 상호작용

| 제스처 | 효과 |
|---|---|
| **별 위에 호버** | 5개 표면 모두의 같은 별에 금색 링 + 사이드바의 해당 칩 금색 색조. |
| **별에 일반 클릭** | 에디터에서 노트 열기. **"Return to Sight"** 버튼이 나타남. |
| **별에 Shift+클릭** Stage / Confidence / Provenance 미니에서 | 해당 별 범주의 필터를 토글. |
| **별에 Shift+클릭** Acts 또는 앵커에서 | 효과 없음. |
| **미니의 빈 영역 클릭** | 그 미니가 기본 슬롯으로 승격. |
| **휠 줌 (기본)** | 커서 쪽으로 줌. 범위: 0.5× ~ 24×. |
| **빈 영역 클릭+드래그** | 뷰 팬. |
| **Ctrl+0 / Cmd+0** | 줌 + 팬 재설정. |
| **Ctrl+D / Cmd+D** | 미니 돔 가시성 토글 — **세션만**. |
| **Ctrl+Shift+D / Cmd+Shift+D** | **확장 뷰** 토글 — 영구. |
| **사이드바 칩 클릭** | 필터 세트에서 패싯 범주를 토글. |
| **Reset View 버튼** | 줌 1.0으로 앵커 기본으로 돌아감. |
| **Esc** | Sight 닫기. |

## 고스트 모드 — 돔에서 다중 선택

모든 필터가 활성화되면, 일치하지 않는 별이 사라지는 대신 **낮은 불투명도(15%)**로 표시된 상태로 유지됩니다. 이는:

- 일치하지 않는 별이 어디에 있는지 여전히 **볼** 수 있음을 의미합니다.
- 그것들 위에 호버할 수 있습니다 (금색 링이 나타남).
- **Shift+클릭하여 카테고리를 필터에 추가**할 수 있습니다.

## 밀도 모드

가시(일치) 별 수가 밀도 임계값(기본 **5,000**)을 초과하면 미니 돔이 **지각 밀도 렌더링**으로 전환됩니다.

## 확장 뷰

**Ctrl+Shift+D**(Mac에서는 **Cmd+Shift+D**)를 누르면 "확장 뷰"가 토글됩니다 — 켜지면 미니 돔이 Sight를 열 때마다 기본적으로 표시됩니다. 상태는 Sight 닫기, 앱 재시작 및 재부팅을 통해 영구적입니다.

## Sight가 가장 유용한 경우

- **지식 형태 감사** — 작성 세션 후 Sight를 엽니다.
- **사각지대 찾기** — 노트가 적은 돔의 섹터는 탐색할 영역일 수 있습니다.
- **하중 약점 발견** — 중앙에 위치한 초기 단계 색상 노트.
- **필터링 및 검사** — Shift+클릭으로 우주 좁히기; 미니를 승격하여 전체 크기로 채널 연구.
- **인식 출처 추적** — Provenance를 승격하여 지식이 어떻게 출처되었는지 확인.

## 관련 표면

- **Constellation Nervous System (CNS)** — 보완 시각화 (Sight 눈 아이콘 옆의 뉴런 아이콘).
- **Constellation Map** — 선버스트 시각화.
- **Sky View** — 그래프 기반 링크 시각화.
- **Index 패널** — 용어 브라우저.
