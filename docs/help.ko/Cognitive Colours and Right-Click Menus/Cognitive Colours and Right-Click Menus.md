# 인지 색상 및 우클릭 메뉴

이 항목은 함께 도착한 두 가지를 다룹니다: **두 개의 새로운 스타일 세터 카테고리** — **속성**(프론트매터의 작은 태그를 다시 스타일링)과 **인지 색상**(인지 상태마다 하나의 색상 컨트롤, 앱 전체에서 공유) — 그리고 노트 본문, 프론트매터 속성, 검색 결과에서 알맞은 동작을 한 번의 클릭으로 제공하는 **앱 전체의 우클릭 메뉴**입니다.

> 스타일 세터는 **설정 → 외관 → "✦ 스타일 세터 열기"** 또는 설정 사이드바의 자체 **스타일 세터** 탭에서 여는 전체 화면 디자인 스튜디오입니다. 아래의 두 카테고리는 인터페이스, 편집기, 링크 등과 함께 *표면(Surfaces)* 목록의 왼쪽에 자리합니다. 세터의 일반적인 동작 — 검사(Inspect), 유지(Keep) / 버리기(Discard) / 재설정(Reset), 저장된 스타일 — 에 대해서는 [[Appearance and Themes]]를 참고하세요.

---

## 스타일 세터 → 속성

**속성** 카테고리는 노트의 **프론트매터**(YAML 속성 블록) 안에 나타나는 작은 태그를 다시 스타일링합니다 — 속성 패널과 노트 상단에서 `tags`, `aliases` 같은 것에 대해 보이는 칩입니다. 지금까지는 고정되어 있었지만, 이제 사용자가 직접 모양을 빚을 수 있습니다.

**스타일 세터**를 열고 왼쪽 목록에서 **속성**을 클릭합니다. 가운데에는 속성 배지의 라이브 미리보기가 표시되며, 오른쪽의 컨트롤을 클릭하면 편집하는 대로 미리보기가 다시 스타일링됩니다. 두 가지 요소가 있습니다:

### 속성 태그

평범한 프론트매터 태그 칩(예를 들어 `tags` 목록의 각 값)입니다. 네 가지 컨트롤:

- **태그 배경** — 칩의 채움 색상.
- **태그 텍스트** — 칩 안 텍스트의 색상.
- **태그 모서리 반경** — 칩 모서리가 얼마나 둥근지 (0 px = 사각형, 최대 20 px = 완전히 둥근 형태).
- **높이** — 칩의 높이(픽셀, 14–32 px).

### 분류 배지

분류(taxonomy) 스타일 값에 사용되는 배지입니다. 세 가지 컨트롤:

- **배경** — 배지의 채움 색상.
- **텍스트** — 배지 안 텍스트 색상.
- **모서리 반경** — 모서리 둥글기 (0–20 px).

> **컨트롤을 건드리기 전까지는 아무것도 바뀌지 않습니다.** 모든 값은 정확히 오늘 보이는 모습에서 시작하므로, 속성 카테고리는 사용자가 의도적으로 색상을 고르거나 슬라이더를 드래그하기 전까지 노트를 똑같은 모습으로 둡니다. **유지(Keep)**를 클릭하면 이 우주에 맞게 모습이 저장됩니다.

## 스타일 세터 → 인지 색상

Constellation은 사용자의 **인지 어휘**를 색으로 칠합니다 — 노트의 *성숙도*, 링크의 *확신도*, 아이디어가 *어디에서 왔는지*, 그것이 생애의 어떤 *단계*에 있는지, 그리고 검색 결과가 *왜* 일치했는지. 문제는 그 색상들이 각 표면에서 따로 결정되었다는 점이었습니다: "시드는" 노트가 파일 트리에서는 한 가지 초록, 스카이 뷰에서는 또 다른 초록일 수 있었습니다. **인지 색상** 카테고리는 **상태마다 하나의 색상 컨트롤**을 제공하며, 그 상태를 보여 주는 모든 것이 그 색상을 따릅니다.

**스타일 세터**를 열고 왼쪽 목록에서 **인지 색상**을 클릭합니다. 가운데에는 편집 중인 집합의 색상 범례가 표시되며, 오른쪽의 컨트롤을 고르면 범례가 라이브로 갱신됩니다. 다섯 가지 집합이 있습니다.

### 성숙도 — 아이디어가 얼마나 자리 잡았는지

가장 어린 것부터 가장 자리 잡은 것까지 다섯 가지 상태: **씨앗**, **묘목**, **상록**, **정본**, **시듦**. 각각 하나의 색상을 가지며, 파일 트리의 노트 점, 탭의 성숙도 표식, 노트 인스펙터에서 사용됩니다.

### 확신도 — 링크가 얼마나 확실한지

네 가지 상태: **가설**, **증거**, **확립됨**, **논쟁 중**. 각각 하나의 색상.

### 출처 — 아이디어가 어디에서 왔는지

네 가지 상태: **수신**(출처에서 가져옴), **발견**(사용자 자신의 것), **혼합**, **없음**. 각각 하나의 색상.

### 단계 — 노트가 생애의 어느 자리에 있는지

순서대로 여섯 가지 상태: **발화**, **탄생**, **성장**, **성숙**, **휴면**, **보관**. 각각 하나의 색상.

### 일치 범주 — 검색 결과가 왜 일치했는지

일곱 가지 일치 종류: **제목**, **본문**, **태그**, **위키링크**, **속성**, **의미**(정확한 단어가 아니라 의미 기반 일치), **구조화**(속성 질의 일치). 여기서 설정한 색상은 편집기 내 검색 강조, 일치 배지, 검색 패널 결과 행의 강조에서 공유됩니다.

### "요청 시 통일" — 이것을 안전하게 만드는 규칙

인지 색상은 의도된 규칙을 따릅니다: **색상을 고르기 전까지는 아무것도 바뀌지 않습니다.** 모든 표면은 오늘 가진 색상을 자신의 폴백으로 유지합니다. 사용자가 여기서 어떤 상태의 색상을 설정하는 순간, 그 상태를 보여 주는 **모든** 표면이 한꺼번에 사용자의 색상으로 맞춰집니다 — 파일 트리, 탭, 인스펙터, 검색 강조 등. "상록"을 한 번 설정하면 앱 전체의 모든 상록 표식이 일치합니다. 어떤 상태를 건드리지 않고 두면 이전과 정확히 똑같이 보입니다.

그래서 이 카테고리는 기존의 어떤 모습도 바꾸지 않고 출시될 수 있습니다: 기본값으로가 아니라 *요청 시* 통일하기 때문입니다. **유지(Keep)**를 클릭하면 색상이 이 우주에 맞게 저장됩니다.

## 앱 전반의 우클릭 메뉴

Constellation은 이제 사용자가 가장 자주 원하는 세 곳에서 완전한 우클릭(컨텍스트) 메뉴를 제공합니다: **노트 본문**, **프론트매터 속성**, **검색 결과**. 각 메뉴는 클릭한 위치에서 의미가 있는 동작만 제공합니다.

### 노트 본문 우클릭

노트의 텍스트 어디에서나 우클릭하면 편집 메뉴가 나타납니다:

- **링크 추가** / **외부 링크** — 선택 영역을 감싸거나(또는 커서 위치에 삽입) `[[위키링크]]` 또는 `[텍스트](url)` 링크로 만듭니다.
- **서식 ▸** — 펼침 하위 메뉴: 굵게, 기울임, 밑줄, 취소선, 하이라이트, 인라인 코드, 인라인 수식, 주석 전환, 위 첨자, 아래 첨자, 서식 지우기.
- **문단 ▸** — 펼침 메뉴: 글머리 목록, 번호 목록, 작업 목록, 제목 수준 **제목 1–제목 6**과 **본문**, 그리고 인용.
- **삽입 ▸** — 펼침 메뉴: 각주, 표, 콜아웃, 가로선, 코드 블록, 수식 블록, 이미지.
- **클립보드** — 잘라내기, 복사, 붙여넣기, 텍스트로 붙여넣기, 모두 선택.
- **스타일…** — **편집기** 카테고리에 초점을 맞춘 **스타일 세터**로 곧장 이동하므로, 방금 우클릭한 바로 그것을 다시 스타일링할 수 있습니다.

### 프론트매터 속성 우클릭

속성 패널(또는 노트 상단의 속성 블록)에서 속성 **행**을 우클릭하면, 전체 편집 메뉴 위에 속성 동작이 더해집니다:

- **값 복사** — 속성의 값을 클립보드에 복사합니다.
- **이름 복사** — 속성의 키를 복사합니다.
- **속성 제거** — 그 속성 행을 삭제합니다.
- **속성 추가** — 새로운 빈 속성 행을 추가합니다.
- …그 뒤에 노트 본문과 동일한 **서식 / 문단 / 삽입 / 클립보드** 항목, 그리고 **속성** 카테고리에 초점을 맞춘 스타일 세터를 여는 **스타일…** 항목이 이어집니다 — 그래서 속성 태그 위의 "스타일…"은 노트 본문이 아니라 속성 태그를 스타일링합니다.

### 검색 결과 우클릭

검색 패널의 결과를 우클릭하면 **안전한** 노트 동작 모음이 나옵니다 — 파일을 절대 위험에 빠뜨리지 않는 것들입니다:

- **열기** — 노트를 엽니다.
- **새 탭에서 열기** — 지금 가진 것과 나란히 엽니다.
- **파일 트리에 표시** — 파일 트리에서 노트를 강조하여 어디에 있는지 보여 줍니다.
- **링크 복사** / **경로 복사** — 노트로의 위키링크 또는 파일 경로를 복사합니다.
- **북마크** — 노트를 북마크에 추가합니다.
- **시스템 탐색기에서 표시** — 운영 체제의 파일 관리자에서 파일을 보여 줍니다.
- **기본 앱에서 열기** — 시스템이 마크다운에 사용하는 앱으로 파일을 엽니다.
- **스타일…** — **인지 색상** 카테고리(검색 일치 색상이 있는 곳)에 초점을 맞춘 스타일 세터를 엽니다.

> **설계상, 검색 결과 메뉴에는 이름 변경, 이동, 삭제가 없습니다.** 검색 패널은 우주 전체에 걸친 결과를 보여 주며, 파일 트리의 매 순간 최신 사본을 자체적으로 유지하지 않으므로, 거기서의 파괴적 동작은 오래된 보기에 작용할 수 있습니다. Constellation은 그런 작업을 보기가 항상 최신인 파일 트리(및 노트 내비게이터)에 둡니다. 검색 메뉴는 라이브러리를 재구성하기 위한 것이 아니라, 노트로 안전하게 *도달하기* 위한 것입니다.

## 알아두면 좋은 것

- **로컬이며 비공개입니다.** 이 모든 것은 사용자 기기에 있는 사용자 자신의 노트와 설정에서 계산됩니다. 아무것도 어디로도 전송되지 않습니다.
- **당신의 언어로 말합니다.** 모든 메뉴 항목, 모든 카테고리 이름, 모든 상태 레이블은 선택한 인터페이스 언어로 나타나며 오른쪽에서 왼쪽으로 쓰는 언어에서는 올바르게 좌우 반전됩니다. 인지 상태 색상 자체는 보편적입니다 — 한 색상은 모든 언어에서 같은 상태를 뜻합니다.
- **"스타일…"은 항상 올바른 표면에 도착합니다.** 각 "스타일…" 항목은 우클릭한 것에 해당하는 카테고리에 초점을 맞춰 스타일 세터를 엽니다: 노트 본문 → **편집기**, 속성 → **속성**, 검색 결과 → **인지 색상**. 올바른 컨트롤을 찾아 헤맬 필요가 전혀 없습니다.
