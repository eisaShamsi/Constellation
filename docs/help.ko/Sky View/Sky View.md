# Sky View

Sky View는 **GraphMind** 엔진(Pixi.js WebGL)으로 구동되어 노트를 노드와 링크로 이루어진 인터랙티브 네트워크로 표시합니다. 각 노드는 하나의 노트이며, 각 선은 노트 간의 `[[위키링크]]`를 나타냅니다. 노트가 가진 연결이 많을수록 그 노드는 더 크게 표시됩니다.

## Sky View 열기

| 방법 | 동작 |
|--------|--------|
| **Mission Control** | `Ctrl+P`를 누른 뒤 "star view"를 입력 |
| **키보드** | `Ctrl+G` |

Sky View를 닫으려면 `Escape`를 누르세요.

> [!note]
> Sky View 리본 아이콘은 왼쪽 독에서 제거되었습니다. 이제 Sky View는 키보드 단축키나 Mission Control을 통해 사용할 수 있습니다. Sky View(조직도) 모드는 노트 관리 사이드바의 탭으로 제공됩니다.

## 그래프와 상호작용하기

### 기본 상호작용

| 입력 | 동작 |
|-------|----------|
| **팬(이동)** | 빈 공간을 클릭한 채 드래그 |
| **확대/축소** | 스크롤 휠(2D) 또는 `Ctrl+스크롤`(3D) |
| **노드 드래그** | 임의의 노드를 클릭한 채 드래그하여 위치 이동 |
| **호버** | 상태 표시줄에 노트 이름을 표시하고 연결된 노드와 엣지를 강조 |
| **노드 클릭** | 해당 노트를 편집기에서 열기 |
| **노드 더블클릭** | 해당 노드로 확대하며 중앙에 맞춤 |
| **노드 우클릭** | 컨텍스트 메뉴 열기 |

### 컨텍스트 메뉴

임의의 노드를 우클릭하면 다음 항목에 접근할 수 있습니다:

| 동작 | 설명 |
|--------|-------------|
| **열기** | 노트를 편집기에서 엽니다 |
| **포커스** | 이 노드를 중심으로 포커스 모드에 진입합니다 |
| **고정** | 노드를 현재 위치에 고정합니다. 다시 클릭하면 고정이 해제됩니다. |
| **숨기기** | 그래프에서 노드를 숨깁니다. 숨겨진 노드를 다시 표시하려면 툴바의 "모두 표시"를 사용하세요. |

## 3D 탐색

Sky View는 완전한 3D 탐색을 지원합니다 — 별 사이를 항해하듯 노트 사이를 날아다닐 수 있습니다.

### 3D 모드 진입하기

**가운데 버튼 클릭 후 드래그**(또는 **Alt+클릭 후 드래그**)하면 그래프를 3D 공간에서 회전시킬 수 있습니다. 한 번 회전하면 3D 탐색 컨트롤이 활성화됩니다.

### 3D 컨트롤

| 입력 | 동작 |
|-------|--------|
| **가운데 버튼 드래그** | X축과 Y축을 중심으로 회전 |
| **Shift+가운데 버튼 드래그** | Z축을 중심으로 회전 |
| **W / 위쪽 화살표** | 앞으로 비행(화면 안쪽으로) |
| **S / 아래쪽 화살표** | 뒤로 비행 |
| **A / 왼쪽 화살표** | 왼쪽으로 평행 이동 |
| **D / 오른쪽 화살표** | 오른쪽으로 평행 이동 |
| **Q** | 아래로 이동 |
| **E** | 위로 이동 |
| **Ctrl+스크롤** | 확대/축소(시야각 변경) |
| **일반 스크롤** | 카메라 방향을 따라 앞/뒤로 비행 |
| **0** | 평면 2D 보기로 회전 초기화 |
| **초기화 버튼**(↺ 아이콘) | `0`을 누르는 것과 동일 |

### XYZ 축 기즈모

3D 모드에서는 왼쪽 아래 모서리에 색상으로 구분된 축 가이드가 나타납니다:

| 축 | 색상 | 방향 |
|------|-------|-----------|
| **X** | 빨강 | 좌–우 |
| **Y** | 초록 | 상–하 |
| **Z** | 파랑 | 앞–뒤(깊이) |

기즈모는 카메라와 함께 회전하므로 항상 자신의 방향을 파악할 수 있습니다.

### 3D에서 호버 및 클릭

3D로 탐색하는 동안에도 노드 위에 마우스를 올리거나 클릭할 수 있습니다. 노트 이름이 상태 표시줄에 표시되며, 클릭하면 노트가 열립니다 — 2D 모드와 똑같습니다.

## 레이아웃 모드

Sky View는 세 가지 레이아웃 알고리즘을 제공합니다. `Ctrl+L`을 누르거나 툴바의 레이아웃 버튼을 사용하여 서로 전환할 수 있습니다.

| 모드 | 설명 | 적합한 용도 |
|------|-------------|----------|
| **유기적** | 힘 기반(force-directed) 레이아웃. 링크 밀도에 따라 군집이 자연스럽게 형성됩니다. | 일반적인 탐색 — 기본 모드입니다. |
| **계층적** | 위에서 아래로 향하는 방향성 비순환 그래프(DAG). | 상위–하위 관계가 있는 구조화된 라이브러리. |
| **시간순** | 노드를 생성 날짜에 따라 가로 시간축을 따라 배치합니다. | 노트가 언제 생성되었고 라이브러리가 어떻게 성장했는지 확인. |

모드를 전환하면 공간적 방향감을 유지하는 부드러운 애니메이션 전환이 일어납니다.

> [!tip]
> 계층적 모드는 트리 형태의 구조를 따르는 노트(예: 하위 주제로 연결되는 MOC)에 특히 유용합니다. 시간순 모드는 지적 타임라인을 드러내 줍니다 — 관련된 노트 군집이 언제 생성되었는지 보여줍니다.

## 포커스 모드

포커스 모드는 특정 노트와 그 주변만을 보여줍니다. 동적이고 인터랙티브한 로컬 그래프입니다.

### 포커스 모드 진입하기

- **노드 우클릭** → **포커스**
- 현재 활성 노트에 대해 포커스 모드를 켜고 끄려면 **Space를 누르세요**

### 포커스 컨트롤

포커스 모드에서는 상단에 컨트롤 바가 나타납니다:

| 컨트롤 | 설명 |
|---------|-------------|
| **깊이 슬라이더**(1–5) | 몇 단계의 연결까지 표시할지 설정합니다. 1 = 직접 링크만, 5 = 다섯 단계 깊이까지. |
| **방향 필터**(↔ / ← / →) | 모든 링크, 수신만, 또는 발신만 표시합니다. |
| **종료 버튼**(×) | 전체 Sky View로 돌아갑니다 |

### 탐색 경로(브레드크럼)

포커스 모드에서 노드를 차례로 클릭하면, 상단에 탐색 경로를 보여주는 브레드크럼이 나타납니다. 임의의 브레드크럼을 클릭하면 해당 노트의 로컬 그래프로 되돌아갈 수 있습니다.

> [!tip]
> 포커스 모드와 깊이 슬라이더를 함께 사용하면 노트의 주변을 점진적으로 탐색할 수 있습니다. 깊이 1에서 시작하여 직접 연결을 본 다음, 값을 늘려 2차·3차 관계를 발견하세요.

## 검색하여 강조하기

`Ctrl+F`를 눌러 검색 바를 엽니다. 쿼리를 입력하면 일치하는 노트가 강조됩니다.

필터와 달리, 검색하여 강조하기는 일치하지 않는 노드를 제거하지 않고 **흐리게** 표시합니다. 일치하는 노드가 강조되는 동안에도 전체 그래프 구조와 공간적 맥락은 그대로 유지됩니다.

> [!tip]
> 검색은 전체 그래프와 포커스 모드 모두에서 작동합니다. 3D 모드에서도 검색할 수 있습니다.

## 설정 패널

툴바의 톱니바퀴 아이콘(⚙)을 클릭하면 설정 패널이 열립니다. 세 개의 탭으로 구성됩니다:

### 그래프 모양

| 컨트롤 | 설명 | 기본값 |
|---------|-------------|---------|
| **노드 크기** | 모든 노드를 더 크게 또는 더 작게 조절 | 1.5 |
| **레이블 표시** | 레이블이 나타날 시점: 호버 시, 항상, 또는 표시 안 함 | 호버 시 |
| **레이블 글꼴 크기** | 노트 이름 레이블의 크기 | 12 |
| **링크 두께** | 엣지 선의 굵기 | 1 |
| **고립된 노트 표시** | 링크가 없는 노트도 포함 | 켜기 |

> **캔버스 배경색.** 버블 뒤의 색상은 이 패널이 아니라 **설정 → 스타일 세터 → Sky View → 캔버스 → 배경**에서 설정합니다. 이 색상은 사이드바/패널과 독립적이므로, 나머지 인터페이스를 바꾸지 않고도 그래프에 고유한 배경을 부여할 수 있습니다 — 예를 들어 버블이 도드라지도록 짙은 색을 줄 수 있습니다. 설정하지 않으면 캔버스는 패널 표면과 동일한 색을 따릅니다. *외관 및 테마 → Sky View 캔버스*를 참조하세요.

### 물리

| 컨트롤 | 설명 | 기본값 |
|---------|-------------|---------|
| **척력** | 노드가 서로 밀어내는 강도 | 50 |
| **링크 힘** | 연결된 노드가 서로 끌어당기는 강도 | 0.05 |
| **링크 거리** | 연결된 노드 간의 목표 거리 | 30 |
| **시뮬레이션 재가열** | 현재 상태에서 힘 레이아웃을 다시 시작 | — |

### AI

의미적 AI 링크 설정(2단계 — 로컬 임베딩 모델 필요).

| 컨트롤 | 설명 |
|---------|-------------|
| **의미적 링크 표시** | AI가 감지한 파선 엣지를 켜고 끄기 |
| **신뢰도 임계값** | 유사도 점수로 의미적 링크를 필터링하는 슬라이더 |

## 범례

범례는 오른쪽 아래 모서리에 나타나며, 라이브러리에 할당된 색상을 보여줍니다.

### 색상 모드 전환

범례 상단의 **라이브러리** 또는 **폴더** 버튼을 클릭하면 노드의 색상 지정 방식을 전환할 수 있습니다:

| 모드 | 색상 지정 |
|------|----------|
| **라이브러리** | 각 라이브러리가 고유한 색상을 가짐 |
| **폴더** | 각 최상위 폴더가 고유한 색상을 가짐 |

### 표시 여부 체크박스

각 범례 항목에는 체크박스가 있습니다. 라이브러리나 폴더의 체크를 해제하면 해당 노드가 그래프에서 숨겨집니다. 이를 통해 지식 베이스의 특정 부분 집합에 집중할 수 있습니다.

> [!tip]
> 폴더 모드에서는 폴더 개수가 괄호 안에 표시됩니다. 긴 폴더 목록은 스크롤할 수 있습니다.

## 상태 표시줄

왼쪽 아래 상태 표시줄은 다음을 보여줍니다:

- **노드 수** — 현재 보이는 전체 노드 수
- **엣지 수** — 현재 보이는 전체 엣지 수
- **MOC 수** — 콘텐츠 지도(연결성이 높은 허브 노트)의 개수
- **호버한 노트 이름** — 노드 위에 마우스를 올렸을 때 표시됨

## 키보드 단축키

| 단축키 | 동작 |
|----------|--------|
| `Ctrl+G` | Sky View 열기 |
| `Escape` | Sky View 닫기 |
| `Ctrl+F` | 검색하여 강조하기 켜고 끄기 |

| `Q/E` | 3D 공간에서 아래/위로 이동 |

## RTL 지원

Sky View는 아랍어, 히브리어 및 기타 RTL(오른쪽에서 왼쪽) 문자를 일급으로 지원합니다:

- **노드 레이블**은 문자 방향을 자동으로 감지합니다 — 아랍어 제목은 오른쪽에서 왼쪽으로 렌더링됩니다
- **범례 항목**은 콘텐츠 언어에 따라 점/텍스트 순서를 뒤집습니다
- **툴팁과 패널**은 RTL 레이아웃을 따릅니다
- **아랍어 글꼴 폴백** — 기본 글꼴에 아랍어 글리프가 없을 경우, 레이블은 시스템 아랍어 글꼴(Noto Naskh Arabic, Segoe UI)을 사용합니다

## 픽처-인-픽처(PiP) 오버레이

Sky View가 열려 있는 상태에서 노트 관리 사이드바의 자식 유니버스, 라이브러리, 또는 폴더를 클릭하면, 메인 그래프 위에 크기 조절이 가능한 오버레이로 **픽처-인-픽처(PiP)** 창이 나타납니다.

### PiP가 보여주는 것

PiP는 선택한 범위에 속하는 노드만 담은 필터링된 하위 그래프를 표시합니다. 예를 들어, 라이브러리를 클릭하면 해당 라이브러리의 노트와 그들 사이의 상호 연결만 표시됩니다.

### PiP 기능

| 기능 | 설명 |
|---------|-------------|
| **필터링된 그래프** | 선택한 범위의 노드만 나타남 |
| **필터링된 범례** | PiP는 관련 항목만 보여주는 자체 범례를 가짐 |
| **크기 조절 가능** | 가장자리나 모서리를 드래그하여 PiP 창의 크기를 조절 |
| **위치 이동 가능** | 제목 표시줄을 드래그하여 PiP를 화면 어디로든 이동 |

### 모드 간 선택 동기화

어느 사이드바 모드(트리, 목록, 또는 조직도)에서든 자식 유니버스, 라이브러리, 폴더, 또는 노트를 클릭하면 Sky View 그래프에서 해당 노드가 강조됩니다. 이 양방향 동기화는 사이드바를 탐색하는 동안에도 공간적 인식을 유지하는 데 도움이 됩니다.

## 지식 계층(Knowledge Strata)

Sky View는 노드의 지식 수준(1–8)에 따라 노드 크기를 자동으로 조정합니다:

- 작은 점: 단순한 노트(데이텀, 정보)
- 중간 노드: 연결된 노트(명제, 개념)
- 크게 빛나는 허브: 종합 노트(이론, 패러다임, 세계관)

상위 수준의 노드에는 시각적 대비를 위해 보색의 글로우 후광이 있습니다. 이는 라이브러리에 20개 이상의 노트가 있을 때 활성화됩니다.

---

## 노트 성숙도(Note Maturity)

노드는 성숙도를 나타내는 색상 링을 표시합니다:

- 링 없음: 씨앗(새 노트)
- 연두색 링: 묘목(성장 중)
- 짙은 초록색 링: 상록(잘 정착됨)
- 금색 링: 정본(권위 있는 참조)

성숙도는 파일 트리(왼쪽 테두리)와 탭 바(색상 점)에도 표시됩니다.

---

## 출처 글로우(Provenance Glow)

Sky View의 노드는 지식의 출처를 나타내는 은은한 색상 글로우를 보여줍니다:

- **파란 글로우**: 수신된 지식 — 노트의 출처 사슬이 외부 참조로 거슬러 올라갑니다(프론트매터에 url, author, 또는 doi가 있는 노트)
- **호박색 글로우**: 발견된 지식 — 노트의 출처 사슬이 사용자 자신의 노트에서 비롯됩니다

## 기술적 참고 사항

Sky View는 **GraphMind** 엔진으로 구동됩니다. 이는 전용 웹 워커(Web Worker)에서 d3-force 시뮬레이션을 실행하는 Pixi.js WebGL 렌더러입니다. 이 아키텍처는 다음을 보장합니다:

- **60fps 렌더링** — 수천 개의 노드에서도 유지
- **비차단 레이아웃** — 힘 시뮬레이션이 UI를 절대 멈추게 하지 않음
- **호버는 시각 전용** — 호버는 결코 물리 재계산을 유발하지 않음
- **시뮬레이션은 안정화 후 멈춤** — 노드가 자기 위치를 찾으면 물리 엔진은 완전히 정지합니다. 노드를 드래그하거나 설정을 변경할 때만 다시 시작됩니다.
