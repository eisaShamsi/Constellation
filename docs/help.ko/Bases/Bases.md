# 베이스 (Bases)

**베이스(Base)**는 노트 집합을 라이브 테이블로 바꿉니다: **노트당 한 행, 속성당 한 열**. 아무것도 복사되거나 옮겨지지 않습니다 — 테이블은 노트를 제자리에서 읽어 들여 지금 이 순간의 상태 그대로 반영합니다.

> [!tip] 기본은 강력하면서도 단순하게
> 베이스는 친숙하고 깔끔한 모습으로 열립니다 — 노트의 이름과 당신이 관심 있는 필드만 표시됩니다. 별자리의 더 깊은 인지적 열은 언제나 **클릭 한 번 거리**에 있지만, 첫 화면을 어수선하게 만드는 일은 결코 없습니다. 얼마나 많은 구조를 끌어올지는 당신이 결정합니다.

> [!info] 비파괴적
> 베이스는 스스로 노트를 바꾸지 않습니다. 베이스는 쿼리를 담은 작은 `.base` 파일입니다 — "이 노트들을, 이 열들과 함께, 이 순서로 보여 줘." 당신의 Markdown 파일은 있던 그 자리에 정확히 그대로 남아 있습니다.

## 베이스를 사용하는 두 가지 방법

**1. 전체 탭으로.** `.base` 파일을 열면 인터랙티브 테이블로 탭을 가득 채웁니다.

**2. 노트 안에서.** 어떤 노트에든 펜스 코드 블록을 넣으면 인라인으로 렌더링됩니다:

````markdown
```base
view: table
```
````

둘 다 같은 엔진으로 구동되므로 동일하게 동작합니다.

---

## 베이스 만들기

사이드바에서 **새 베이스**("+" / 새 베이스 동작)를 사용하세요. 별자리가 작은 **YAML** `.base` 파일을 대신 작성해 줍니다:

```yaml
schema: 1
lens: My Notes
scope:
  libraries: all
  federation: auto
columns:
  - dimension: note.name
view: table
```

| 필드 | 의미 |
|-------|---------|
| `schema` | 형식 버전 (현재 `1`). |
| `lens` | 테이블 상단에 표시되는 이름. |
| `scope.libraries` | `all`, 또는 포함할 특정 라이브러리 목록. |
| `scope.federation` | `auto` — 연결된 유니버스(cUniverse)의 노트도 함께 포함합니다. |
| `columns` | 표시할 열. 새 베이스는 노트 **이름**만으로 시작합니다. |
| `view` | `table` (테이블이 베이스 뷰입니다). |

이 파일을 손으로 직접 편집할 일은 거의 없습니다 — 테이블 자체의 컨트롤(아래 참조)이 모든 변경 사항을 파일에 자동으로 다시 기록해 줍니다.

## 테이블

- **이름 열** — 항상 첫 번째입니다. 노트의 이름을 클릭하면 노트가 열립니다.
- **일치하는 모든 노트가 한 행이 됩니다.** **행 수 제한이 없습니다.** 테이블은 *가상화*되어 있어 — 지금 화면에 보이는 행만 그립니다 — 수천 개의 노트를 담은 베이스도 즉시 열리고 부드럽게 스크롤됩니다.
- **셀별 방향** — 각 값은 자신의 좌→우 또는 우→좌 문자 체계를 스스로 감지하므로, 여러 언어가 섞인 테이블도 올바르게 읽힙니다.
- 바닥글에는 쿼리에 걸린 시간이 표시됩니다.

## 테이블에서 노트 찾기

### 이 베이스 검색

머리글의 **검색 상자**는 입력하는 대로 테이블을 필터링합니다. 노트의 **이름**뿐 아니라 **보이는 모든 열**의 텍스트도 함께 일치시키므로, 눈에 보이는 어떤 값으로든 행을 찾을 수 있습니다. 필터링하는 동안 제목 옆의 개수 배지에는 **`일치 / 전체`**가 표시되고(예: `4/7684`), 검색을 지우면 다시 전체 개수로 돌아갑니다.

검색은 **모든 문자 체계**에서 동작합니다 — 아랍어를 입력하면 아랍어 제목을 찾을 수 있고, 다른 언어도 마찬가지입니다. 모든 행이 이미 메모리에 들어 있기 때문에, 수천 개의 노트를 담은 베이스에서도 필터링이 즉시 이루어집니다.

### 문자 레일

베이스에 **행이 50개 이상** 있으면, 테이블 가장자리를 따라 가느다란 문자 띠가 나타납니다. 그 문자들은 **당신의 실제 노트 제목의 첫 글자**로 만들어집니다 — 그래서 영어 제목에는 **A–Z**를, 아랍어에는 **أ ب ت …**를, 당신이 가진 다른 어떤 문자 체계에도 알맞은 글자를 표시합니다. (우→좌 인터페이스에서는 레일이 자동으로 올바른 쪽에 자리합니다.)

**문자를 클릭하면** 그 글자로 시작하는 첫 번째 노트로 바로 이동합니다. 테이블이 아직 이름순으로 정렬되어 있지 않다면, 문자를 클릭할 때 **먼저 이름순으로 정렬한 뒤** 이동합니다 — 그래서 문자는 언제나 당신이 기대하는 대로 동작합니다.

### 행 오른쪽 클릭

**아무 행이나 오른쪽 클릭하면** 표준 노트 메뉴가 나옵니다: **열기**, **새 탭에서 열기**, **북마크**, **경로 복사** / **이름 복사**, **파일 트리에서 보기**, **기본 앱에서 열기**, **시스템 탐색기에서 보기**, **스타일…**. 이름 바꾸기, 이동, 삭제는 여기서 일부러 제공하지 않습니다 — 그런 작업은 목록이 안전하게 새로 고쳐지는 파일 트리에서 하세요.

## 열 — 추가, 제거, 순서 변경

### 열 추가

**+ 열 추가**를 클릭하세요. 선택기는 두 그룹으로 나뉩니다:

- **내 필드** — 별자리가 당신의 노트에서 찾아낸 frontmatter 속성들(예: `status`, `maturity`, `author`). 이것은 *당신의* 데이터입니다.
- **별자리** — 앱이 항상 알고 있는 내장 필드: **이름**, **경로**, **생성일**, **요약**.

입력을 시작하면 목록이 필터링됩니다. 이미 테이블에 들어 있는 필드는 표시가 되어 있어 두 번 추가하지 않도록 해 줍니다.

### 열 제거

열 머리글 위에 마우스를 올리고 **×**를 클릭하세요.

### 열 순서 변경

**열 머리글을 누른 채 옆으로 끌어 보세요.** 열 전체가 들립니다(흐릿해지고 머리글에 잡기 윤곽선이 나타납니다). 그리고 세로선이 열이 놓일 위치를 표시합니다. 놓으면 이동합니다. 이름 열은 첫 번째 열로 고정되어 그대로 유지됩니다.

모든 추가, 제거, 순서 변경은 자동으로 `.base` 파일에 다시 저장됩니다.

---

## 정렬

**열 머리글을 클릭하면 그 열로 정렬됩니다.** 클릭할 때마다 **오름차순 → 내림차순 → 해제**로 순환합니다(화살표가 현재 방향을 보여 줍니다).

두 개 이상의 열로 정렬하려면 **정렬** 패널을 여세요:

- 여러 열을 추가하세요 — 첫 번째가 기본 정렬이고, 다음 열들이 동순위를 가릅니다.
- 각 단계를 오름차순과 내림차순 사이에서 전환하세요.
- 단계를 위나 아래로 옮겨 우선순위를 바꾸거나, 제거하세요.

## 테이블에서 노트 편집하기

**당신의** frontmatter 열 중 하나의 셀을 더블클릭하면 편집할 수 있습니다:

- **자유 텍스트 필드** — 새 값을 입력하세요. **Enter**는 저장, **Escape**는 취소입니다.
- **목록형 필드**(`maturity` 등) — 유효한 값들이 **자연스러운 순서**대로 담긴 **드롭다운**이 나타납니다(`maturity`의 경우: *seed → sapling → evergreen → canonical*). 하나를 고르거나, 직접 입력하세요.

변경 사항은 디스크에 있는 해당 노트의 YAML frontmatter에 곧바로 기록되고, 테이블은 제자리에서 갱신됩니다.

> [!note] 읽기 전용 열
> **이름**과 **생성일**(그리고 나머지 내장 별자리 열들)은 자동으로 계산되므로 편집할 수 없습니다. 여기서는 당신 자신의 frontmatter 필드만 바꿀 수 있습니다.

## 이전 형식의 베이스 열기

Obsidian에서 넘어왔거나, 이전 버전의 별자리에서 넘어왔다면, 기존 `.base` 파일은 이전 형식을 사용합니다.

**당신의 파일은 절대 건드리지 않습니다.** 별자리가 그런 파일을 열면, 형식이 이전 것이라는 차분한 안내를 보여 주고 **별자리 베이스로 변환** 버튼을 제공합니다. 변환은 **당신이 그 버튼을 클릭할 때만** 일어납니다 — 파일을 제자리에서 새 YAML 형식으로 업그레이드합니다(가능한 것은 그대로 옮겨 옵니다: 이름, 열, 단순 텍스트 필터). 변환을 선택하기 전까지 원본 파일은 있던 그대로 정확히 남아 있습니다.

## 페더레이션

베이스는 유니버스를 인식합니다. `federation: auto`이면 연결된 유니버스(cUniverse)의 노트를 당신 자신의 노트와 함께 포함합니다. 연결된 유니버스에 있는 노트는 읽기 전용입니다 — 베이스에서 보고 정렬할 수는 있지만, 편집은 당신이 소유한 노트로 제한됩니다.

---

## 로컬 우선 & 파일이 앱보다 우선

베이스는 자체 데이터를 전혀 갖고 있지 않습니다. 당신이 보는 모든 값은 당신의 디스크에 있는 실제 `.md` 파일에서 라이브로 읽어 온 것입니다. `.base` 파일을 삭제해도 당신의 노트는 전혀 영향을 받지 않습니다 — 베이스는 이미 갖고 있는 노트를 향해 겨누는 렌즈일 뿐입니다.

## 키보드 & 마우스

| 동작 | 하는 일 |
|--------|--------------|
| 검색 상자에 **입력** | 이름과 보이는 모든 열로 행 필터링 (모든 문자 체계) |
| 레일의 문자 **클릭** | 그 글자로 시작하는 첫 노트로 이동 (필요하면 먼저 이름순 정렬) |
| 행 **오른쪽 클릭** | 노트 메뉴: 열기 · 북마크 · 복사 · 파일 트리에서 보기 · 스타일 |
| 열 머리글 **클릭** | 그 열로 정렬 (오름차순 → 내림차순 → 해제) |
| 열 머리글 **끌기** | 그 열의 순서 변경 |
| 머리글의 × **클릭** | 그 열 제거 |
| frontmatter 셀 **더블클릭** | 편집 (목록 필드는 드롭다운) |
| **Enter** | 편집 저장 |
| **Escape** | 편집 취소 |
| 노트 이름 **클릭** | 노트 열기 |
