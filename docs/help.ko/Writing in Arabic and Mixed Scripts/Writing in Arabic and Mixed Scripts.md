# 아랍어와 혼합 스크립트로 글쓰기

Constellation의 편집기는 처음부터 언어 우선으로 설계되었습니다. 아랍어, 히브리어, 페르시아어, 우르두어, 그리고 두 언어가 섞인 노트는 나중에 덧붙인 기능이 아닙니다 — 커서, 선택, 각 문단의 방향이 모두 Windows의 Microsoft Word와 같은 규칙을 따르므로, 몸에 익은 습관이 그대로 통합니다. 이 항목은 오른쪽에서 왼쪽으로 쓰는 텍스트와 혼합 텍스트로 *글을 쓰는* 일의 모든 것을 다룹니다: 커서가 어떻게 움직이는지, 단어·문장·줄·문단·화면 단위로 어떻게 선택하는지, 그리고 자동 감지가 원하는 결과가 아닐 때 문단의 방향을 어떻게 강제로 지정하는지.

(Constellation이 아랍어를 *이해하는* 방식 — 어근, 검색, 형태 분석 엔진 — 은 **아랍어 엔진(Arabic Engine)** 항목을 참고하세요.)

---

## 커서가 움직이는 방식

- **화살표 키는 화면상의 한 칸이 아니라, 읽기 순서를 따라 텍스트의 한 글자씩 이동합니다.** 순수 아랍어나 순수 영어에서는 누른 화살표 그대로 움직이는 것처럼 보입니다. 아랍어와 영어가 만나는 이음매(예를 들어 영어 단어가 들어 있는 아랍어 문장)에서는 커서가 쓰인 순서대로 글자를 하나씩 밟아 가며 이음매를 눈에 띄게 "건너뜁니다" — 이 건너뜀은 올바른 동작이며, 경계에서 커서가 갇힌 것처럼 느껴지지 않게 해 주는 장치입니다.
- **Home**은 줄의 읽기 **시작점**으로 갑니다 — 아랍어 줄에서는 *오른쪽* 끝입니다. **End**는 읽기 **끝점** — *왼쪽* 끝 — 으로 갑니다. 어느 쪽이든 **Shift**를 함께 누르면 그 끝까지 선택됩니다.
- 아랍어 줄에서 **Enter**를 누르면 새 줄의 커서가 **오른쪽**에 놓입니다 — 자연스러운 글쓰기 위치입니다.
- **아랍어 줄 끝에 있는 라틴 문자 단어**에서도 커서가 방향을 잃지 않고 또렷하고 안정적으로 유지됩니다.

위의 모든 규칙은 표준 편집기, 포커스 모드, 충돌 병합 보기에서 완전히 동일하게 작동합니다.

## 단위별 선택

어떤 언어로 쓰였든, 어떻게 섞여 있든, 모든 텍스트 단위에 빠른 선택 방법이 있습니다:

| 단위 | 방법 |
|---|---|
| **단어** | 더블 클릭 |
| **문장** | 문장 안 아무 곳이나 **Ctrl+클릭** — 또는 커서를 문장 안에 두고 **Ctrl+Shift+S** |
| **줄** | **Ctrl+L** |
| **문단** | **Ctrl+Shift+L** — 또는 트리플 클릭 |
| **한 화면** | **Shift+Page Down** / **Shift+Page Up** |
| **전체** | **Ctrl+A** |

알아 두면 좋은 세부 사항:

- **문장 선택은 아랍어 문장 부호를 이해합니다.** 문장은 **؟ ۔ !** 와 마침표에서 끝납니다 — 하지만 아랍어 세미콜론 **؛** 는 문장 *안의* 쉼이므로, 선택이 그 너머까지 올바르게 이어집니다. 3.14 같은 소수는 결코 문장을 가르지 않습니다.
- **문단**은 위아래가 빈 줄로 둘러싸인 텍스트 블록입니다 — Word와 정확히 같습니다. 줄·문단 선택은 텍스트에 딱 붙습니다: 아랍어 줄에서는 강조 표시가 비어 있는 왼쪽 공간까지 늘어나지 않고 단어에서 멈춥니다.
- Ctrl+클릭은 그 키에 있던 예전의 "커서 하나 추가" 제스처를 *대체*합니다 — 이제 그 클릭은 문장 선택입니다.

## 문단 단위 이동

- **Ctrl+↓**는 **다음** 문단의 시작으로 건너뛰고, **Ctrl+↑**는 **현재** 문단의 시작으로 갑니다(한 번 더 누르면 이전 문단으로). **Shift**를 더하면 건너뛰면서 문단 단위로 선택됩니다. 이것은 Word의 방식이며, "다음"은 단순히 페이지에서 더 아래쪽을 뜻합니다 — 아랍어, 영어, 혼합 노트에서 완전히 동일하게 작동합니다.

## 문단 방향 강제 지정

Constellation은 각 줄의 방향을 첫 글자들로부터 자동으로 감지합니다. 대부분은 그것으로 정확히 맞습니다 — 하지만 때로는 직접 정하고 싶을 때가 있습니다: 영어 브랜드 이름으로 시작하는 아랍어 문단이라든지, 대부분 영어이지만 오른쪽에서 왼쪽으로 읽히길 원하는 문단 같은 경우입니다.

**키보드 오른쪽에 있는 Ctrl+Shift를 눌렀다 떼면** → 커서가 있는 문단이 **100% 오른쪽에서 왼쪽**이 됩니다.
**왼쪽에 있는 Ctrl+Shift를 눌렀다 떼면** → **100% 왼쪽에서 오른쪽**이 됩니다.

이것은 Microsoft Word의 방식입니다. 알아 둘 점:

- **키를 뗄 때 발동합니다** — 두 키를 함께 눌렀다가 그대로 놓으세요. 그 사이에 다른 키를 누르면 안 됩니다. Ctrl+Shift+S, Ctrl+Shift+L을 비롯한 다른 모든 단축키가 평소처럼 계속 작동하는 이유가 바로 이것입니다: 세 번째 키가 끼어드는 순간 방향 전환은 물러섭니다.
- **강제 재정의입니다** — 자동 감지를 이기며, 문단 전체(또는 선택 영역이 걸친 모든 문단)에 적용됩니다.
- **텍스트 자체 안에 보이지 않는 방향 문자로 저장됩니다.** 그래서 노트를 닫아도, 앱을 재시작해도, 동기화를 거쳐도 유지되며 — 텍스트를 Word나 Obsidian에 붙여 넣어도 함께 따라갑니다.
- **Ctrl+Z 한 번으로 되돌립니다.** 같은 쪽을 두 번 눌러도 추가로 아무 일도 일어나지 않습니다.
- **Markdown은 안전합니다.** 목록은 목록으로, 제목은 제목으로, 인용은 인용으로 남습니다. 코드 블록, 표, 수평선은 의도적으로 건드리지 않습니다. #태그로 *시작하는* 줄은 자동 방향을 유지하고(그 자리에 강제 방향 문자를 넣으면 태그가 깨집니다) — 문단의 나머지는 그대로 뒤집힙니다.

## 글꼴과 인터페이스

- **스크립트 글꼴**: **설정 → 언어**에서 아랍어, 히브리어, CJK 글꼴을 각각 따로 설정합니다.
- **스크립트 도구 모음**: 언어별 기호·문장 부호 버튼.
- **타쉬킬 강조**: 편집기 도구 모음에서 아랍어 발음 부호 강조를 켜고 끕니다.
- 인터페이스 언어로 아랍어나 히브리어를 선택하면 앱 전체가 RTL로 뒤집힙니다.

## 용어 풀이

- **읽기 순서** — 화면 위 어디에 놓이든 상관없이, 글자가 쓰이고 읽히는 순서.
- **이음매** — 같은 줄 위에서 오른쪽에서-왼쪽 구간과 왼쪽에서-오른쪽 구간이 만나는 경계.
- **강제 재정의** — 사용자가 직접 지정한 방향으로, 첫 글자 기반의 자동 감지를 이깁니다.
- **방향 문자** — 사용자의 재정의를 텍스트 자체 안에 저장하는 보이지 않는 문자(RLM/LRM).
