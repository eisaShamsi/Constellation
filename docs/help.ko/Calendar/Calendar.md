# 캘린더

**캘린더**는 전체 화면 월 보기로, **왼쪽 독**(캘린더 아이콘)에서 엽니다. 노트나 마감 예정 작업이 있는 날에는 색이 있는 **점**이 표시됩니다. 헤더에는 선택한 캘린더 기준의 월이 표시되며, **보조 캘린더**를 설정해 두었다면 그 아래 부제목에 해당 캘린더의 대응 범위가 함께 표시됩니다(예를 들어, 그레고리력의 한 달에 그 히즈리력 범위 "Dhul-Hijjah 1447 – Muharram 1448 AH"가 표시됨).

## 날짜 클릭하기

각 날짜 칸은 상호작용이 가능합니다:

| 동작 | 결과 |
|--------|--------|
| 빈 공간(또는 날짜 숫자)을 클릭 | 그날의 **데일리 노트**를 열거나 만듭니다. 이미 데일리 노트가 있는 날짜를 클릭하면 그냥 **열기**만 하며, 절대 중복을 만들지 않습니다. |
| 점을 클릭 | 해당 항목을 엽니다. 한 날에 여러 노트나 작업이 있으면, 점을 클릭하면 골라서 열 수 있는 작은 **목록**이 나타납니다. |
| 작업 점을 클릭 | 노트를 열되 **그 작업의 줄로 스크롤된 상태**로 바로 편집할 수 있게 합니다. |

### 점 색상

| 점 색상 | 의미 |
|-----------|---------|
| 금색 | 그날의 **데일리 노트** |
| 보라색 | 그날 편집된(또는 날짜가 지정된) 다른 **노트** |
| 빨간색 | 그날 마감인 **작업** |

모든 점 색상은 — 그리고 캘린더의 다른 모든 부분도 — **스타일 세터 → 캘린더** 표면에서 테마로 바꿀 수 있습니다.

> [!tip]
> 작업 목록에서는 캘린더에서 바로 **작업의 체크박스를 체크해 완료** 처리할 수 있으며, 완료된 작업은 즉시 사라집니다. 자체적으로 `📅 YYYY-MM-DD` 마감일을 가진 작업만 캘린더에 나타납니다(그 날짜가 작업을 특정 날에 배치합니다).

## 문화권 캘린더(여덟 가지)

**설정 → 캘린더**에서 **캘린더 체계**를 설정할 수 있으며, 그러면 월 격자 전체가 그 체계로 전환됩니다:

- **그레고리력**
- **히즈리력(이슬람력)** — 정밀한 천문 엔진을 사용하며, 신성한 달이 강조되고 이슬람 행사가 표시됩니다.
- **태양 히즈리력(페르시아력)**
- **히브리력**
- **인도력(사카력)**
- **불기**
- **중국력** — *태음태양력*
- **한국력** — *태음태양력*

각 칸에는 선택한 캘린더 날짜(크게)와 그레고리력 날짜(작게)가 모두 표시되며, 달의 위상도 함께 나옵니다. 각 월 헤더에는 그 달의 **이름, 괄호 안의 번호, 그리고 연도**가 표시됩니다 — 번호는 월 순서가 익숙하지 않은 캘린더에서 도움이 됩니다.

**중국력과 한국력**은 *태음태양력*이라 가끔 **윤달**(闰六月 / 윤6월)을 끼워 넣는데, 캘린더는 이를 별도의 페이지로 보여 주므로 탐색 시 건너뛰거나 두 번 나오는 일이 없습니다.

**주 시작 요일**(일요일/월요일)을 선택하고 **주 번호 열**을 켜고 끌 수도 있습니다.

### 히즈리력 옵션

**설정 → 캘린더 → "히즈리력(이슬람력)"** 아래에는 추가 컨트롤이 두 가지 있습니다:

- **계산 방식** — 실제 초승달을 따르는 **천문 방식(삭, Lunar Conjunction)**(가장 정확하며 기본값), 또는 고전적 산술 주기인 **표 방식(al-Tawfīqāt al-Ilhāmiyyah, 영감받은 조정표)**.
- **월 보정** — **현지의 달 관측**에 맞추기 위해 히즈리력 한 달의 시작을 ±1일 또는 ±2일 조정합니다. 히즈리력 연도와 월을 고르고, 오프셋을 선택한 뒤 **설정**을 클릭하면, 그 보정이 해당 월과 그 이후 모든 월에 적용됩니다. 적용한 보정은 목록으로 표시되며(각각 제거 가능), **모두 지우기** 버튼이 있습니다.

두 설정(그리고 보정 내용)은 **유니버스와 함께** 저장되므로 여러 기기를 넘나들며 따라다닙니다.

### 중국력·한국력 표시 옵션

한국은 중국 음력을 사용하므로 두 캘린더의 날짜는 동일합니다 — 둘을 구분하는 것은 **문자**와 **연도**입니다. 둘 중 하나가 주 캘린더나 보조 캘린더일 때, **설정 → 캘린더**에 추가 컨트롤이 두 가지 나타납니다:

- **연도 표시** — 중국력: 육십갑자 丙午年, 평이한 연도, 또는 둘 다 / 한국력: **단기** 4359, 연도, 또는 육십갑자 병오년.
- **월 이름** — *고유 문자*(五月 / 5월), 또는 *발음 표기* — 그 달의 발음을 사용자 자신의 언어로 적은 것(한국어 "Wǔyuè / Owol"; 아랍어 "وُو-يوي / أوه-وُل").

## 캘린더 꾸미기

**스타일 세터**(왼쪽 독, 또는 **설정 → 스타일 세터**)를 열고 **캘린더** 표면을 선택하면 모든 부분을 다시 꾸밀 수 있습니다 — 각 요소(날짜 숫자, 상호 참조 날짜, 월 알약, 요일 헤더, 주 번호, 달 글리프, 오늘 강조, 격자선, 그리고 노트/작업/행사 점)마다 자체 **색상과 글자 크기**를 가지며, 캘린더 **글꼴**도 설정합니다. 편집하는 동안 전체 크기의 실시간 미리보기가 갱신되며, **유지**를 클릭하면 적용됩니다.

## 데일리 노트

캘린더는 데일리 노트를 온전히 지원합니다: 아무 날이나 클릭해 열거나, **"데일리 노트"** 명령(명령 팔레트)을 실행해 오늘로 바로 이동하세요.

> [!tip]
> **데일리 노트 파일 이름은 표시되는 캘린더와 관계없이 항상 그레고리력**(`YYYY-MM-DD`)을 유지합니다 — 그래야 파일이 이식성을 유지하고 올바르게 정렬됩니다. 문화권 날짜는 캘린더에 표시되며, 노트의 프런트매터에 기록할 수도 있습니다(아래 참고).

## 노트에 문화권 날짜 기록하기

두 가지 선택형 도구가 노트의 **속성**에 문화권 날짜를 기록합니다(파일 이름은 항상 그레고리력 `YYYY-MM-DD`를 유지합니다):

- **데일리 노트 히즈리 스탬프** — *설정 → 캘린더 → "데일리 노트에 히즈리 날짜 스탬프 찍기."* 켜면(히즈리력이 **주 캘린더나 보조 캘린더**일 때만 사용 가능), 모든 **새** 데일리 노트에 `hijri:` 줄이 들어갑니다(예: `hijri: 1448-01-06`). 이미 가지고 있는 노트는 절대 건드리지 않습니다.
- **노트 속성의 "+ Hijri"** — 아무 노트의 **속성**을 열고 날짜 위에 마우스를 올리면 작은 **"+ Hijri"** 버튼이 나타납니다(여기에 더해 "+ Jalali", "+ Hebrew" 등 — **선택한 비그레고리력 캘린더마다 버튼 하나씩**). 클릭하면 Constellation이 노트의 그레고리력 날짜를 읽어 대응 값을 추가합니다(예: `jalali: 1405-03-30`). 한국력 버튼은 **단기** 연도를 적으며, 중국력/한국력의 **윤달**은 `L`로 표시됩니다(예: `chinese: 2025-06L-17`). 노트에 날짜 속성이 없으면 파일의 생성 날짜를 사용합니다.

> [!tip] RTL 지원
> 캘린더 격자는 현재 텍스트 방향을 따릅니다. RTL 언어(아랍어, 히브리어, 페르시아어, 우르두어)에서는 캘린더 레이아웃이 그에 맞게 조정됩니다.
