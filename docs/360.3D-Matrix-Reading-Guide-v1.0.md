# Reading the 360.3D Stratification Matrix — A Practical Guide

**Version 1.0 | 2026-05-02**

**Author of facts**: Eisa ALSHAMSI (project owner, designer, IT Boss)
**Maintainer**: Claude (consultant / engineer / SME)

This is a teaching guide. It assumes you've already opened the 360.3D Inspector at least once and are looking at a matrix. Your goal: turn the matrix from a riddle into an instrument — to look at any note and read its standing, its connection geometry, its gaps, and your next action, in about 30 seconds.

If you want the philosophy first, read [`docs/360.3D-Concept-Paper-v1.0.md`](docs/360.3D-Concept-Paper-v1.0.md). If you want the link layer the matrix reads, see [`docs/Living-Links-Guide-v1.0.md`](docs/Living-Links-Guide-v1.0.md). This guide is for the act of reading.

## 1. What you're looking at

Open a note, click the **360° Inspector** dock button on the left ribbon. The full-window view has four parts:

```
┌──────────────────────────────────────────────────────────────────┐
│  HEADER:        🧠  360.3D  <note name>                       ×  │
├──────────────────────────────────────────────────────────────────┤
│  DIMENSIONS:   STRATUM  MATURITY  ORIGIN  STAGE  REVIEW  ...     │
│                L7        evergreen received    spark   Due  ...  │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  THE MATRIX                                                      │
│  ┌─────┬───────┬───────┬───────┬───────┬───────┬───────┬───────┐ │
│  │     │ SUPP. │ CONTR.│ CAUSES│ DERIV.│ GENER.│ EXEMP.│ PART  │ │
│  │     │       │       │       │       │       │       │  OF   │ │
│  ├─────┼───────┼───────┼───────┼───────┼───────┼───────┼───────┤ │
│  │ L8  │       │       │       │       │       │       │       │ │
│  │ L7  │ ●●●●  │       │       │       │       │       │       │ │
│  │ L6  │       │       │       │       │       │       │       │ │
│  │ L5  │       │       │       │       │       │       │       │ │
│  │ L4  │       │       │       │       │       │       │       │ │
│  │ L3  │       │       │       │       │       │       │       │ │
│  │ L2  │       │       │       │       │       │       │       │ │
│  │ L1  │       │       │       │       │       │       │       │ │
│  └─────┴───────┴───────┴───────┴───────┴───────┴───────┴───────┘ │
│                                                                  │
├──────────────────────────────────────────────────────────────────┤
│  HUD:  ⬆ N outbound   ⬇ N inbound   📝 N words                   │
│        ⚠ Orphan  ⚠ Fragile  ⚠ N blind spots  ⚡ N tensions       │
└──────────────────────────────────────────────────────────────────┘
```

(Plus an Untyped column on the right and a Σ row-totals column on the far right; omitted for clarity above.)

**Vertical axis (rows)**: the 8 strata of intellectual altitude — `L8 Worldview` at the top down to `L1 Datum` at the bottom. The active note's own stratum is highlighted in purple — that's "where you are."

**Horizontal axis (columns)**: the 7 typed link directions — `Supports`, `Contradicts`, `Causes`, `Derives From`, `Generalizes`, `Exemplifies`, `Part Of` — plus an `Untyped` column for plain wikilinks.

**Each cell**: connections at that `(stratum, type)` intersection, drawn as small coloured dots. Cells with no connections render diagonal stripes.

**Column headers carry warning glyphs** when applicable:
- ⚠ **red** on a column = **blind spot** (you've never used this typed direction).
- ⚠ **yellow** on `Derives From` = **fragile** (load-bearing on thin foundation).
- ⚡ **brown** on `Contradicts` = **tensions** (active contradicts pointing at this note).

The same icons appear in the bottom HUD as chips. Visual continuity: see the chip, find the icon at the top of the column it belongs to.

## 2. The three reads

The matrix delivers exactly three things, per [`360.3D-Concept-Paper-v1.0.md §4`](docs/360.3D-Concept-Paper-v1.0.md):

| Read | Question it answers | What you look at |
|---|---|---|
| **Position** | Where am I? | Active row + the dimension strip's stratum / maturity / stage / origin / review cells. |
| **Connection Profile** | What surrounds me? | Column totals along the top + the row distribution of dots in your active row. |
| **Absence** | What's missing? | Red blind-spot columns + diagonal-striped empty rows + striped cells inside otherwise-populated rows. |

Stage 3 of the matrix tutorial walked each in turn (see [`SESSION-LOG-2026-05-02.md`](lab/reports/SESSION-LOG-2026-05-02.md)). The next four sections are the practical moves.

---

## 3. Read 1 — Position (vertical)

Look at:
- The dimension strip's `STRATUM` cell — e.g. `L7 Paradigm`. That's the matrix's classification.
- The matrix's purple-highlighted row — same stratum, visualised.
- The maturity, origin, stage, and review cells next to stratum.

Ask:
1. Where is the highlight — top, middle, bottom of the matrix?
2. Does the stratum agree with my intuition for this note? An L7 Paradigm should feel like a paradigm to me. An L4 Concept should feel like a concept.
3. Is the maturity in step with the stratum? An evergreen at L7 with `birth` stage is suspicious — a mature concept should rarely still be in birth.

The position read is short. It's the anchor for the next two.

---

## 4. Read 2 — Connection Profile (horizontal)

Look at the row of column totals across the top (under the type names). Ignore the cells for now.

Ask:
1. Which typed column has the largest total (excluding Untyped)?
2. What's the Supports vs Contradicts ratio?
3. Where does Untyped sit relative to the typed totals?
4. Are there typed columns showing zero? (The HUD chip `⚠ N blind spots` confirms; the red column header makes it visible at a glance.)

Read the Supports vs Contradicts asymmetry first — it's the most diagnostic single comparison. A note with high Supports and zero Contradicts is one-sided thinking. A note with rough parity has been challenged. A note with more Contradicts than Supports is in active argument with itself — that's not weakness; that's living thinking.

The Untyped vs typed ratio answers a different question: how *committed* is your thinking around this note? Untyped at 90 % of total + typed at 10 % means most connections exist on autopilot. Typed-dominant means you've declared what each connection means.

---

## 5. Read 3 — Absence (gaps)

The hardest read but often the most useful. Look at three layers of absence:

1. **Red column headers** — typed directions you've never used for this note.
2. **Striped rows** (entire rows where the row total Σ is 0) — strata your thinking around this note doesn't reach.
3. **Striped cells inside otherwise-populated rows or columns** — surprising local gaps.

Ask:
1. Are the blind spots **deliberate** (a Datum note shouldn't generalize because it shouldn't) or **oversights** (a Concept note with no Contradicts because you haven't tested it)?
2. Which strata is your thinking absent from? For an L7 Paradigm note, a striped L3 Proposition row means your paradigm hasn't been broken into specific claims.
3. Are there two adjacent populated layers with a gap between them? **A gap between L1 and L4 with L2/L3 empty is a structural problem.** Knowledge usually ascends layer by layer; skipping middle stages suggests the note wasn't built methodically.

Empty cells aren't decoration. They're the most actionable signal the matrix carries.

## 6. The integrated read — 30 seconds, one paragraph

The three reads above aren't three separate reads. They're one cognitive moment in three layers. The matrix's design promise is that you can read all three at once.

**Practice:** open the matrix on a note. Don't isolate any layer. Look at the whole thing. In 30–60 seconds, write a single paragraph that captures:

- Where this note stands.
- The shape of its connection geometry.
- What's most absent.

You'll know you've built the trained eye when:
- Step 1 (position) takes a glance.
- Step 2 (profile) takes 5–10 seconds.
- Step 3 (absence) takes 10–20 seconds.
- The integrated paragraph forms naturally rather than being assembled piece-by-piece.

## 7. From reading to action

A read isn't useful unless it produces a next action. Generic actions ("think more about this") don't count. The action must be **matrix-traceable** — point to a feature of the matrix that justifies it.

**Concrete action examples**, each derived from a specific matrix feature:

- "Add a `contradicts` link from this note to [a specific neighbour]" — derived from a populated `Supports` column with `Contradicts` empty.
- "Write an L3 Proposition note that bridges the L1 datums to the L4 concept" — derived from a gap between L1 and L4 with L2/L3 empty.
- "Trace a `derives-from` chain to find this note's source" — derived from an empty `Derives From` column on a `received`-origin note.
- "Promote N Untyped wikilinks to typed forms" — derived from Untyped much larger than total typed.
- "Rewrite from scratch following research methodology" — derived from a hollow middle (heavy L1 + thin L2-L4 + asserted L7).

If you can't write an action that points back to a specific matrix feature, you haven't read the matrix yet — you've stared at it. Try again.

## 8. Mental shapes catalogue

Patterns recur across notes. Recognising them shortens the read.

### 8.1 Vertical shapes (Read 1)

| Shape | What you see | What it means |
|---|---|---|
| **Top-heavy** | Bulk of dots at L6-L8 above the active row. | Note is grounded mid-tier, thinking reaches toward principles, theory, paradigm. Common for syntheses. |
| **Bottom-heavy** | Bulk of dots at L1-L3 below the active row. | Note sits high but its connections are mostly raw data. The note hasn't yet been linked into higher-altitude thinking. |
| **Peer-cluster** | Dots concentrated at the active row itself. | Note connects horizontally to similar-altitude neighbours. Common when developing a coherent layer. |
| **Span** | Dots across all 8 rows, roughly even. | Note is integrated across the full hierarchy. Rare and load-bearing when present. |
| **Sparse** | 1-3 rows have dots; rest striped. | Either an early-stage note OR a deliberately narrow one. Confirm with the maturity field. |
| **Hollow middle** | Heavy bottom (L1-L2), heavy top (L6-L8), thin middle (L3-L5). | The note jumps over its own derivation layer. **Often a methodological flaw** — the kind of note that should be rewritten from scratch. |

### 8.2 Horizontal shapes (Read 2)

| Shape | What you see | What it means |
|---|---|---|
| **Echo chamber** | Supports very high, Contradicts zero, Causes / Derives From present. | You've collected agreement; you haven't tested the note against opposition. |
| **Adversarial** | Contradicts as large as or larger than Supports. | The note is alive — you've challenged it. Common for mature evergreens. |
| **Causal frame** | Causes column dominant; Supports / Contradicts modest. | The note's role is mechanistic — A → B → C — rather than evaluative. |
| **Hierarchy frame** | Generalizes / Exemplifies / Part Of dominate. | The note's role is structural — what it abstracts from, what instantiates it, what it's part of. |
| **Source frame** | Derives From dominant. | Note descends through many layers; synthesis of upstream sources. |
| **Uncommitted hub** | Untyped massively dominant (10×+ the typed totals). | Many connections exist; almost none are typed. The note is a magnet but you haven't declared what the relationships mean. |

### 8.3 Absence shapes (Read 3)

| Shape | What you see | What it means |
|---|---|---|
| **Untested** | Many populated columns, zero in `Contradicts`. | The note has been built up but never challenged. |
| **Ungrounded** | Top three rows populated, bottom three empty. | Thinking is abstract; nothing connects it to data or facts. |
| **Disconnected from peers** | Connections at L8 + L1 but the active note's own row is sparse. | Thinking jumps over the peer level. |
| **Narrow taxonomy** | Generalizes / Exemplifies / Part Of all empty. | Note has logical connections (supports / contradicts / causes / derives-from) but no structural / hierarchical ones. |
| **Solitary causal** | Causes column populated, almost everything else empty. | You've traced the mechanism but not what supports or challenges it. |

### 8.4 Composite signs (Read 6 — integrated)

These are patterns that only emerge when you read all three layers together.

| Composite | What you see | What it means |
|---|---|---|
| **Hollow middle on a research note** | Bottom-heavy + huge L1 row + L2/L3 nearly empty + asserted L7. | The note didn't ascend from data through proposition and concept. **Almost certainly built without research methodology.** |
| **Echo at high stratum** | Top-heavy + Supports-dominant + zero Contradicts. | A worldview-tier note that has never been challenged. Either everyone agrees (rare) or you haven't sought disagreement. |
| **Orphan worldview** | L8 highlighted + Σ very low + many blind spots. | A high-stratum claim with little support beneath it. May be fragile, may be founding — distinguish by checking neighbours. |
| **Datum hub** | L1 highlighted + Σ very high (200+) + many inbound dots. | A foundational fact that many notes derive from. Often correct; check Fragile flag (high inbound, low derives-from). |

## 9. What the matrix is NOT for

Per [`360.3D-Concept-Paper-v1.0.md §6`](docs/360.3D-Concept-Paper-v1.0.md):

- **Not a graph view.** Sky View is the graph. The matrix is a position view.
- **Not a list of links.** Backlinks/Outgoing panels are link lists. The matrix shows link counts but doesn't enumerate the links inline (use click-to-navigate or click-to-expand a typed cell to see specific note titles).
- **Not analytics.** Sight does centrality / community / structural-gap analytics across the library. The matrix doesn't compute new metrics — it displays measurements already taken by the Cognitive Engine.
- **Not a hierarchy view.** OrgChart is the parent-child tree. The matrix shows the note's stratum but doesn't navigate the full taxonomy.
- **Not a comparison view.** The matrix is one note's standing in itself, not "how does this note compare to other notes." If you want comparison, open a different note in the matrix and remember the previous shape.
- **Not a narrative or trail player.** Trails has its own surface. The matrix may show trail membership as a fact but doesn't play the trail.

If you find yourself trying to answer one of those questions inside the matrix, stop — the matrix isn't the right surface. Open the right tool.

## 10. Worked example: الإدريسي (Al-Idrisi) — the hollow-middle case

A real note from the project owner's library, used as the closing test (S3.6) of the matrix tutorial.

**What the matrix shows:**

- Stratum: **L7 Paradigm**. Maturity: evergreen. Stage: birth. Origin: discovered, depth 1. Review: Due.
- Σ grand total: **378** connections.
- Column totals: Supports = 4, Contradicts = **0** (red blind spot, ⚠), Causes = **0** (⚠), Derives From = 15, Generalizes = **0** (⚠), Exemplifies = **0** (⚠), Part Of = 6, Untyped = 353.
- Row totals: L8 = 4, L7 = **111**, L6 = 19, L5 = 12, L4 = 4, L3 = **2**, L2 = **1**, L1 = **225**.
- HUD: 4 blind spots.

**Read 1 — Position.** Active row L7 Paradigm. The matrix is calling this a paradigm note.

**Read 2 — Connection Profile.** The top column header tells the whole story:
- Untyped 353 / typed total ~25. **Massively uncommitted hub** — almost all connections are plain wikilinks.
- Supports 4, Contradicts 0. **Echo-chamber pattern** at the typed layer.
- Four out of seven typed directions are blind spots (Contradicts, Causes, Generalizes, Exemplifies). **Narrow taxonomy.**

**Read 3 — Absence.** This is where the matrix earns its keep:
- L1 = 225, L2 = 1, L3 = 2. **Hollow middle.**
- The note has 225 connections to raw data, almost nothing in the L2 / L3 derivation layers, then a thin scaffolding through L4-L6 to its asserted L7 stratum.

**Integrated read (one paragraph):**

> Al-Idrisi is classified L7 Paradigm with 378 deduped connections, but the typed layer is almost entirely blank: only Supports, Derives From, and Part Of are declared, with Contradicts / Causes / Generalizes / Exemplifies all blind spots. The vertical distribution is the more striking finding — 225 datums sit at L1 with only 1 connection at L2 and 2 at L3, then a thin column up through L4-L6 to the L7 active row. The note didn't ascend from data through proposition and concept layer by layer. It asserted L7 with raw data hanging directly underneath.

**Action (matrix-traceable):**

> The L1-to-L4 hollow middle is a methodological flaw. If this note were a research work, it was not prepared according to approved research methodologies. Rewrite from scratch — start at L1, build L2 / L3 / L4 deliberately, and only then revisit whether L7 is the right altitude.

(That action came directly from the matrix shape. The Inspector adjudicated the note's structural validity.)

## 11. Worked example: Al-Tabari — the missing-stages case

A second real note. Used as the synthesis test (S3.4).

**What the matrix shows:**

- Stratum: L7 Paradigm.
- Populated columns: Supports, Derives From, Exemplifies (with some content).
- Empty columns: Contradicts (or near-empty), Generalizes (blind spot).
- Vertical: gap between L1 and L4 (L2, L3 nearly empty); some content at L5, L6, L7; less above.

**Integrated read:**

> Al-Tabari sits at L7 with supportive, derives-from, and exemplifies links populated, but no balance with contradicts or generalizes. There's a gap from L1 to L4 — the note jumps from raw data straight to concepts without intermediate propositions or information.

**Action (matrix-traceable):**

> Two moves. First, study the opposite side of this note — find or write notes that contradict it, and link them. Second, check the development steps: was this note built layer by layer, or did I jump over information / proposition / concept? If hasty, redo the derivation chain.

## 12. Tips for building the trained eye

You don't see the matrix as an instrument the first time you open it. Like a stethoscope or an X-ray, it takes practice. From the project-owner's S3.4.3 finding:

> "To find the gaps, maybe around a minute. To interpret the matrix, you need a trained eye. It will happen over time."

Practical exercises to build the eye faster:

1. **Open the matrix on three different notes per day for a week.** Each time, write a one-sentence read. Don't worry about being right — the act of articulating builds pattern-recognition.

2. **Start with the absence read.** Counter-intuitively, gaps are easier to spot than presence at first. Look for red columns, then striped rows, then empty cells in populated rows. The absences tell you where to look in the rest of the matrix.

3. **Pair the matrix with the Backlinks / Outgoing panels.** When the matrix surfaces a finding ("Contradicts is empty"), open the panels to confirm — you should see no contradicts links. Each verification compounds your trust in the matrix.

4. **Check your read against your prior knowledge.** If the matrix tells you something that contradicts your sense of the note, **the matrix is more likely right than your memory**. Audit the actual links before deciding.

5. **Compare two notes you've worked on.** Open one in the matrix; close. Open the other; close. The contrast between the two shapes is what builds the catalogue of mental shapes.

6. **Use the `?` help icons.** Each stratum, type, dimension, and HUD warning has a `?` icon next to it. Hover (or click to pin). The tooltip explains the cognitive role of that element. Read these the first few times you open the matrix.

7. **Ignore counts; read shapes.** Beginners count dots. Experts read the geometry — the row distribution, the column dominance, the diagonal-stripe density. Counts matter, but the shape is what tells you the story.
