# 外观与主题

Constellation 的外观在**设置**中控制：

1. **外观** — 选择或创建主题、从 Obsidian 社区注册表导入主题，并调整标题对齐和链接生命周期（衰减）等少量首选项。
2. **样式设计器（Style Setter）** — 设置侧边栏中它自己的专用选项卡，现在是**所有样式设计的唯一归宿**：界面外壳和编辑器的每一种颜色、尺寸、字体和元素，加上链接类型颜色和已保存样式。（此前独立的 **Style Settings** 选项卡已退役，并完全并入其中。）

它们共同让你按照自己的工作流程、屏幕大小和个人品味重塑应用 — 无需编辑一行 CSS。

## 主题

**主题**是一组命名的颜色、设置和 CSS，定义 Constellation 的外观。Constellation 自带六个内置主题（Constellation Light/Dark、Nord Light/Dark、Solarized Light/Dark），全部在浅色和深色系统模式之间配对。

### 选择主题

1. 打开**设置 → 外观**。
2. 单击**主题**网格中的任何卡片。主题立即应用。
3. 活动卡片以强调边框突出显示。

### 创建自定义主题

1. 在主题网格中单击虚线的**+ 新建主题**卡片。
2. 为其命名，选择浅色或深色，并选择五种颜色（背景、表面、文本、强调、边框）。
3. 单击**保存**。你的主题现在出现在网格中。

所有其他变量（悬停状态、阴影、静音文本）使用 HSL 数学从你的五种颜色自动派生，因此你只控制重要的内容。

### 编辑或删除自定义主题

将鼠标悬停在任何自定义主题卡片上：
- **✏️（铅笔）** — 打开编辑器以更改名称、类型或五种核心颜色。
- **✕（红 X）** — 确认后删除主题。内置主题无法删除。如果删除活动主题，Constellation 将恢复为默认值。

### 导入 Obsidian 社区主题

单击**🟣 Obsidian 主题**浏览 200 多个社区主题：
1. 按名称或作者搜索。
2. 单击**预览**查看布局和五色色样的模型。
3. 单击**导入** — 主题的 CSS 下载，适配 Constellation（选择器 shim + 变量提取 + CodeMirror 语法颜色），并添加到你的自定义主题中。
4. 如果主题支持 **Style Settings**，其卡片上会显示计数；导入后，这些选项会出现在 Style Settings 选项卡中。

## Style Settings ← 现已并入样式设计器

> **注意：** 独立的 **Style Settings** 选项卡已**退役**。它曾经拥有的每一个控件，现在都位于**样式设计器**（设置侧边栏中它自己的选项卡）内 — 样式设计器涵盖它们的全部，并且更多（导航路径、笔记摘要、宇宙面板、按书写系统区分的字体）。下面的清单描述的就是这个样式设计面，现在通过样式设计器打开。

这个样式设计面是 Constellation 的原生、主题无关的控制面板。它涵盖了外壳的每个可见部分以及编辑器，并适用于任何主题（内置、自定义或导入）。

### 组织方式

各部分默认折叠。单击 V 形符号展开：

- **Constellation — 颜色** — 背景和表面、文本、强调
- **Constellation — 排版** — 界面/笔记/代码字体大小、H1–H6 大小、标题字重、行高、段落间距
- **Constellation — 布局与形状** — 圆角（小/中/大半径）、边框宽度、阴影、编辑器行长度、侧边距
- **Constellation — 组件** — 功能区 dock、侧边栏操作工具栏、布局栏（窗格切换）、顶栏/选项卡条、状态栏、文件浏览器、右侧栏、按钮、标签、标注框
- **Constellation — 编辑器** — 链接、代码和块、块引用、光标和选择

### 更改值

- **颜色选择器** — 单击色样，选择颜色。hex 显示在旁边。
- **滑块** — 拖动以调整。数值显示在单位（px、% 等）中。
- **开关** — 单击以切换类（主要用于导入的主题）。
- **下拉菜单** — 选择选项（链接装饰样式等）。
- **重置箭头（↺）** — 在每行末尾悬停时出现。单击清除你的覆盖并恢复主题的默认值。

### 保存的工作方式

- 更改自动保存到活动主题的 **styleSettingsValues**。
- 如果你在内置主题处于活动状态时更改 Style Setting，Constellation 会**自动克隆**内置主题到你的自定义主题中（作为 `{Name} (custom)`），然后将更改保存到那里。内置主题保持不变。
- 选项卡底部的**保存至：**标签显示当前哪个主题持有你的覆盖。
- 单击**全部重置为默认值**以擦除活动主题上的每个覆盖。

### 导入/导出 Style Settings

Style Settings 选项卡顶部的工具栏：

- **📋 从剪贴板粘贴** — 一键：读取剪贴板并将有效的 JSON 合并到活动主题。
- **⬆️ 导入/粘贴** — 打开文本区域；手动粘贴 JSON。选择**合并**（添加/覆盖）或**全部替换**（擦除，仅使用粘贴的内容）。
- **📄 从文件** — 打开从 Obsidian 的 Style Settings 插件或另一个 Constellation 安装导出的 `.json` 文件。
- **📋 复制** — 将当前值作为格式化的 JSON 复制到剪贴板。
- **⬇️ 导出** — 将值保存为 `{theme-name}-style-settings.json`。

JSON 格式与 Obsidian 的 Style Settings 插件完全匹配 — 一个将设置 ID 映射到字符串值的扁平对象：

```json
{
  "h1-size": "36",
  "interactive-accent": "#7c3aed",
  "my-themed-color@@light": "#ffffff",
  "my-themed-color@@dark": "#1e1e2e"
}
```

这意味着你可以从 Obsidian 复制你的 Style Settings 并直接粘贴到 Constellation，反之亦然。

## 你可以控制的内容

每个设置都位于上述五个块之一。重点：

### 排版

- **界面字体大小** — 侧边栏、工具栏、菜单
- **笔记字体大小** — 编辑器中的正文
- **代码字体大小** — 内联代码和围栏代码块
- **H1 – H6 大小** — 每个标题级别单独设置
- **标题字重** — 所有标题的轻度或粗度
- **行高** — 正常（正文）和紧凑（标题和密集 UI）
- **段落间距** — 段落之间的间隔

### 外壳组件

- **功能区 dock（左侧图标）** — 宽度、按钮大小、图标大小、半径、颜色
- **侧边栏操作工具栏** — 新建笔记/表格/文件夹图标 — 大小、颜色、高度、背景
- **布局栏（窗格切换）** — 左/分割/右侧边栏切换 — 按钮大小、图标大小、颜色、活动状态颜色
- **顶栏/选项卡条** — 仅当笔记在选项卡中打开时可见；控制条高度、背景、选项卡高度/字体/半径、活动和非活动选项卡颜色
- **状态栏** — 高度、字体大小、背景、文本颜色
- **右侧栏（检查器）** — 背景、选项卡行高、选项卡图标大小、颜色
- **文件浏览器（左侧栏）** — 宇宙笔记行、子宇宙（cUniverse）行、库名、文件夹、笔记 — 每个都有独立的大小、字重和颜色；加上垂直行间距

### 编辑器

- **标题大小**（H1–H6）和字重
- 笔记正文的**行高**
- **内联代码** 背景、文本颜色、半径、字体大小
- **链接颜色**（默认 + 悬停）和装饰样式（无/下划线/点状）
- **标注框条宽度**和**标注框半径**
- **光标颜色**和**选择背景**

### 颜色（应用中的每种颜色）

- 背景（主要/备用）、表面、悬停背景、边框、输入背景
- 文本（正常/静音/微弱/在强调上）、错误/警告/成功状态
- 强调（交互强调 + 悬停）、强调文本

## 样式设计器（Style Setter）

**样式设计器**是**所有样式设计的唯一归宿** — 面向你整个界面的全页设计工作室。无需逐项调整设置再凭空想象结果，你改动一个控件，就能看到你的**真实应用**随之重新着色。

**打开方式：** 单击设置侧边栏中的**样式设计器**（✦）选项卡；或单击图标栏中设置齿轮上方的**检视准星（✛）**，直接进入检视模式 —— 然后把鼠标悬停到应用的任意部分并单击，即可跳转到该元素的控件。面板可调整大小。

控件在左侧按**类别**组织：

- **界面（Interface）** — 文件树、状态栏、宇宙栏。
- **组件（Components）** — 图标栏 dock、工具栏、顶栏与选项卡、按钮、标签、标注框。
- **编辑器（Editor）** — 笔记本身：导航路径、标题、链接、内联代码、块引用，以及笔记摘要（标题下方的斜体行 — 它自己的颜色、字体、大小、字重和斜体开关）。
- **全局（Global）** — 背景与文本色阶、强调色阶、字体与间距、圆角与边框，以及按书写系统区分的字体。
- **链接（Links）** — 链接类型颜色及其显示方式（见下文）。

左侧列表下方是你的**已保存样式** — 单击其一即可一次性应用整套外观（见下文“将外观保存为命名样式”）。*（内置主题在“设置 → 外观”中选取，不在这里。）*

**查看改动的两种方式。**

- **编辑器类别**在**中央显示一个笔记预览**。单击某个标题、链接或页面，它的控件就出现在右侧；预览即时更新。
- **其他所有类别**会把面板停靠到一侧并变为半透明，你的改动直接显示在**真实应用上，实时呈现**：改动状态栏颜色或图标栏宽度，实际的侧边栏、dock、选项卡和状态栏会**随你拖动**重新着色。顶栏中绿色的 **● live** 标记提醒你正在编辑真实界面。

**链接类别。** 链接类别把链接类型颜色和形状集中在一处。八种类型（supports、contradicts……）每种都显示为它真实的彩色**药丸（pill）**——**单击一个药丸即可重新着色**，改动会实时反映到各处（编辑器中的链接，以及反向链接 / 出向链接面板中的药丸）。列表上方是开关——**为链接着色**和**显示类型标签**——以及**药丸形状**（圆角、高度、标签字重）。一个**已保存颜色**调色板会记住你选过的每种颜色，方便在任意元素上复用。

**Keep（保留）、Discard（丢弃）、Reset（重置）。** 当你满意时，单击**Keep**（右上角）将外观**保存到当前宇宙** —— 重启后依然保留。**Discard**（或直接用 **✕** / **Esc** 关闭）丢弃未保存的改动，真实应用随即恢复到已保存的外观。**Reset** 将一切清回朴素主题。在你按下 Keep 之前，不会有任何内容写入磁盘。

**将外观保存为命名样式。** 要复用某个外观，可把它保存为一个名字：在顶部的 **“draft:”** 输入框中键入名称，单击**“+ Save current as a style”**（左下角）。它会加入你的**已保存样式**列表 —— 应用级全局（可在每个宇宙间复用），并且捕获的是你在设计器中设计出的外观，而不仅仅是一个主题。**单击某个已保存样式即可应用它。** 将鼠标悬停在已保存样式的行上可使用其操作：**↻ 更新**（用你*当前*的外观覆盖该样式 —— 保留其名称）、**⤓ 导出**（以 `.constellation-style.json` 文件分享）、**✎ 重命名**、**✕ 删除**。

> 内置主题（Midnight、Daylight……）位于**设置 → 外观**，不在设计器中 —— 设计器持有你的**已保存样式**和当前宇宙的实时外观。

## 常见问题

### 我可以设置 Windows 标题栏的样式（"Constellation v0.3.4 — …"）吗？

不可以 — 该栏由操作系统（Windows/macOS/Linux）绘制。Constellation 没有对它的 CSS 访问权限。它下面的所有内容都可以完全设置样式。

### 我如何更改侧边栏宽度？

侧边栏宽度由侧边栏边缘的**拖动手柄**控制（拖动以调整大小） —— 没有滑块。我们故意把宽度滑块从样式设计器中移除了，因为它重复了拖动手柄（以避免冲突的真相来源）。

### 我的样式存储在哪里？

你在样式设计器中用 **Keep** 保存的内容，会**按宇宙**（宇宙级别的样式覆盖）存储在宇宙设置中，因此它随宇宙目录一起旅行 —— 如果你在设备间同步宇宙，你的样式也会一起来。而**已保存样式**是应用级全局的。

### 我可以与某人共享主题吗？

可以：
- **完整主题** — 在主题编辑器中，单击**导出**。共享 `.json` 文件。接收者在主题网格上单击**↓ 导入**并选择它。
- **已保存样式** — 在**样式设计器**中，将鼠标悬停在某个已保存样式的行上，单击**⤓ 导出**，即可将其作为 `.constellation-style.json` 文件分享（仅外观 —— 不含任何机密或路径）。接收者在样式列表中单击 **Import…** 即可添加。

### 导入的 Obsidian 主题看起来损坏了。现在怎么办？

Obsidian 主题可能很复杂。已知情况：
- 使用 **HSL 拆分颜色**的主题（如 Minimal）— 从此版本开始在 Constellation 中支持。
- 依赖 Obsidian 特定 DOM 结构的主题可能部分呈现。Constellation 包含一个类 shim，映射最常见的选择器，但非常结构化的主题可能需要调整五个核心颜色或手动调整 Style Settings 值以补偿。
