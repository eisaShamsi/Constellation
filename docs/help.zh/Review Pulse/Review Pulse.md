# 复习脉搏

*(复习器——你的知识回访清单)*

复习脉搏是 Constellation 告诉你**此刻哪些笔记需要你的关注、为什么需要**的地方——并为每一条开出一剂健康的处方。其他每一个面板回答的都是你必须主动去问的问题（"我的图谱状况如何？这条笔记连接到了什么？"）。复习器是唯一**主动来找你**的面板：它把那些已经衰退、漂移或脱离联系的笔记浮现出来，按紧急程度排序，每一条都附带一句平实易懂的原因。

不妨把它想成医生的**回访清单**。它不只是说"哪里出了问题"——它会诊断病情、开出疗方、告诉你有多紧急以及*为什么*，然后把你交接给更深层的仪器（编辑器、360° 检视器、编目器）去采取行动。

> **两个界面，一个理念。** 完整的**复习器**（左侧停靠栏中的 🕐 时钟图标）是*整个文库*的队列。右侧边栏中的**复习标签页**（同一个 🕐 图标）只显示*你当前打开的那条笔记*——它自己的状态。两者共用同一个引擎，所以一条笔记在两处显示的优先级相同。

---

## 打开复习器

点击最左侧停靠栏中的 **🕐 时钟**图标。复习器会以两栏布局填满窗口：

- **左侧——队列**，按六个透镜分组（见下文）。每个透镜始终列出；空的透镜会变灰并标注 **0**。点击透镜标题可折叠或展开它。
- **右侧——详情面板**，对应你选中的笔记：哪里出了问题、疗方是什么、有多紧急，以及可采取的操作。

点击队列中的任意笔记，即可在右侧加载其详情。点击笔记的**名称**（或 **连接**）可在编辑器中打开它——此时顶部标签栏会出现一个 **‹ 复习器** 按钮，让你径直回到原来的位置。

---

## 六个透镜

一条笔记可以同时出现在多个透镜中——每个透镜回答的是不同的问题，它们绝不会被糅合成单一的分数。

| 透镜 | 含义 |
|---|---|
| 🥀 **陈旧** | 这条笔记所*倚靠*的某条笔记（一条承重链接——支持、矛盾、衍生自、属于、取代）在你上次复习本笔记**之后**发生了变化。你的笔记可能已与它无法调和。 |
| 🔄 **到期复习** | 复习间隔已过——是时候重读并确认它是否依然成立。 |
| 🧠 **心智模型检查点** | 你标记为假设或模型的一条笔记。*你是否仍持此见？* |
| 🔗 **孤立——连接我** | 一条有实质内容、但**尚无任何东西链接到它**的笔记。它游离于你的思维之网之外。孤立是一记**警报**，而非杂物：连接它，或将它标记为有意为之的独立笔记。 |
| ⚠ **脆弱——为我加固** | 许多笔记倚靠着这一条，但它自身的支撑却很少。一个单点故障——给它更坚实的根基。 |
| 📝 **从未复习** | 一条在你文库中已存放一段时间、但你从未通读过一遍的笔记。 |

---

## 详情面板：诊断 → 处方

当你选中一条笔记时，右栏自上而下依次呈现：

1. **标题 + 摘要。** 此处始终显示该笔记的一两句话摘要（依你的摘要设置而定），让你知道被请去重访的*是什么*。
2. **诊断**——平实易懂的"为何此刻"，例如*"衍生自的'证据'于 2026-06-12 发生了变化。"*
3. **处方**——那一件该做的健康之事，例如*"对照'证据'复审它——调和你的立场，或更新它。"* 对于孤立笔记：*"将它连接到一条相关笔记——或将它标记为有意独立。"*
4. **优先级**——一个 0 到 100 之间的数字，以**配方**形式呈现（见下文）。
5. **事实**——它的成熟度（种子 / 幼苗 / 常青 / 典范 / 凋零）、它的连接（"12 进 · 4 出"），以及你上次复习它的时间。
6. **操作** + **交接**（见下文）。

---

## 看得懂的优先级——也能由你推翻

优先级数字不是一个黑箱。它由笔记的处境计算得出，并以**一根拆分成各项理由的条带**呈现，每一项都有标签，且恰好相加得出该数字——例如：

> **63**  ·  *时间压力 +31 · 被依赖 +14 · 成熟度 +10 · …*

它综合了两样东西，也就是经典的"紧急 vs 重要"之分：

- **紧急性**——它逾期或陈旧到什么程度，以及那次变化有多具破坏性（一条*矛盾*在你脚下落地，比一条支持性笔记仅仅有所挪移要紧急得多）。
- **重要性**——有多少笔记依赖它、它有多成熟，以及它是否脆弱。

这个数字始终由你做主。**拖动滑块**即可设定你自己的优先级；随后它会被标注为**"手动"**，向你显示计算值*本应*是多少，并提供**"重置为计算值"**以把控制权交还给引擎。你的覆盖会一直保留，直到你重置它。

## 对一条笔记采取行动

每个透镜都提供恰当的动作：

- **✓ 已复习**——你已重读过它；它得到确认，并按 1·3·7·14·30 天的阶梯重新排程。（这是*唯一*会推进"上次复习"的操作——仅仅打开一条笔记不算复习它。）
- **🔗 连接**（孤立笔记）——打开笔记，让你添加一条链接。
- **👁 暂搁 7 天**——把一条到期的笔记隐藏一周。（暂搁只适用于基于时间的透镜；一条陈旧或脆弱的笔记不是等上一周就能修好的。）
- **🗄️ 忽略**——停止为复习而追踪这条笔记。对于孤立笔记，它显示为**"标记为独立"**——*这条笔记本就该独立存在，它并非孤立。*

底部的**交接**带你前往更深层的仪器，而不打断你的思路：**在编辑器中打开**、**完整脉络（360°）**（笔记的完整结构全景），以及**分类**（编目器）。复习器负责分诊；这些仪器负责解释。

---

## 笔记自己的复习标签页

打开任意笔记，然后点开右侧边栏中的 **🕐 复习** 标签页。它显示*那一条*笔记的状态——到期 / 陈旧 / 检查点 / 从未复习——配有同样的优先级滑块（默认为计算值，可覆盖，可重置）和同样的 ✓ / 暂搁 / 忽略 操作。它是上述一切的逐笔记视图。

---

## 设置——陈旧宽限期

默认情况下，一条笔记会在其某个依赖发生变化的次日被标记为**陈旧**。如果这太急切，可前往 **设置 → 复习**，调高**宽限期**（以天为单位，最小为 1）：这样一来，只有当你上次复习之后已经过去了那么多天，依赖变化才会标记该笔记。如果你常做许多细小的编辑，就把它设得耐心些。
