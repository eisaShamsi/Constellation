*(Constellation 认知内容引擎 — CECE)*

Source Review 面板是 Constellation 请求你审阅由 **Constellation 认知内容引擎**(CECE)生成的分类的位置。队列中的每张卡片显示一篇笔记 + 引擎对该笔记如何融入你知识分类法的解读。你可以「接受」「编辑」「拒绝」或选择「同级消歧」芯片 — 随着时间推移,引擎将学习你的 Library 的形态。

本主题解释 Source Review 卡片的每个部分、彩色圆点的含义、何时信任引擎,以及如何在不无尽滚动的情况下浏览数百张卡片。

## CECE 实际做什么

当你对一篇笔记进行分类(右键单击 →「建议 Source 和内容类型」,或通过设置 → 运行扫描按钮)时,CECE 对该笔记运行 **六个独立的分类器**。每个分类器通过自己的透镜读取笔记 — frontmatter、引用、词干、链接的笔记、相似的笔记、AI 判断 — 并对两个问题进行投票:

- **Source(水平轴)**:这条知识 *来自哪里*?例如:证言(有人告诉我的)、感知(我看到的)、推理(我推导出来的)、启示(神圣文本),还有八种。
- **内容类型(垂直轴)**:这是 *哪种* 知识?例如:认知状态(怀疑 / 确定 / 信念)、语义内容(概念 / 命题 / 事实 / 理论)、感官输入、符号实体、高阶构造(世界观 / 教义)。

两个轴是 **独立的**。一篇关于「我怀疑登月事件」的笔记在 source 轴上是证言(有人报告了它),在内容类型轴上是认知状态/怀疑(用户对它的立场)。

分类器投票后,**综合层** 将它们的投票合并为每个轴一个分类,带有三种置信度体制之一:

- **一致同意** — 每个发言的分类器都同意
- **多数赞成** — 大多数同意,一个持异议(卡片显示异议者的名字)
- **意见分歧** — 没有明确多数;引擎「拒绝分配」并请求 *你* 来挑选

一切都在 **你的设备上** 运行。笔记从未离开 Constellation。

## 用平实语言解释两个轴

### Source — *这条知识来自哪里?*

十一个可能的值加 *不可分类*:

- **感知** — 第一手感官观察
- **推理** — 从前提推理(演绎、归纳、类比)
- **证言** — 他人的报告(引用、文献、引用的来源)
- **集体传承** — 许多独立见证人的趋同报告(逊尼派的 *al-tawatur*)
- **比较** — 通过类比已知案例的知识(法律 *qiyās*、科学类比)
- **公设** — 推理至最佳解释(*arthapatti*)
- **非感知** — 关于缺席的知识
- **记忆** — 对过去经验的回忆
- **天赋倾向** — 经验之前的认知(*fitrah*)
- **灵感** — 神秘或创造性的领悟(*kashf*)
- **启示** — 神圣文本或先知传承(*al-wahy*)
- **不可分类** — 退出此分类

### 内容类型 — *这是哪种知识?*

五个顶层分支及子分支:

- **感官输入** — 原始信号(视觉、听觉、化学等)
- **符号实体** — 符号、记号、代码
- **语义内容** — 概念、命题、事实、想法、信息
- **认知状态** — 怀疑、信念、意见、确定、知识、错觉
- **高阶构造** — 理论、教义、世界观、范式

两个轴在每个顶层值下都有几个细化层(例如,*epistemic-states/knowledge/by-content/propositional* 是一个叶节点)。

## 六个分类器

每个分类器是 CECE 读取笔记的一个 *透镜*。Source Review 卡片在右上角将它们显示为 **六个小型彩色圆点**。将鼠标悬停在任何圆点上可查看其名称 + 状态。

| 圆点 | 分类器 | 它读取什么 |
|---|---|---|
| 🔵 蓝色 | **你的 frontmatter**(用户权威) | 你已经设置的 `sources:` 和 `content_type:` 字段。如果你已经亲自分类了笔记,这个透镜具有 *绝对权威* — 综合采纳你的选择并跳过其他人。 |
| 🌹 玫瑰色 | **引用与结构**(结构性) | 引用、块引用、代码块、定理标记、定义短语(「X 的概念被定义为…」)、图引用。读取笔记的结构形态。 |
| 🟡 琥珀色 | **词干与词汇**(语言性) | 阿拉伯语词根分析(CAE)、表面关键词匹配、跨语言术语等价(Bridge)。捕捉纯嵌入会遗漏的阿拉伯语感知分类。 |
| 🟢 青色 | **链接的笔记**(图) | 指向其他已分类笔记的类型化 Living Links(`[[Note\|supports]]`、`[[Note\|contradicts]]` 等)。当邻居聚集时,从邻居继承分类。 |
| 🟣 紫色 | **相似的笔记**(语义) | 与你已分类笔记的嵌入相似度(k-Nearest-Neighbor)。当此笔记的内容向量与已分类笔记聚集时,引入共识。 |
| 🟢 绿色 | **AI 判断**(推理) | 运行语法约束推理的本地 LLM(Qwen3-4B Q5_K_M)。*尚未激活* — 模型接线推迟到后续版本。今天此圆点在每张卡片上保持沉默。 |

### 圆点状态

- **填充** — 已发言 + 同意综合结论
- **环形** — 已发言 + 对综合结论持异议(此透镜选择了不同的)
- **虚线轮廓** — 沉默(此透镜对此笔记无信号)

圆点群组是一目了然的集成健康度指标。所有六个圆点都填充的卡片是引擎可能的最强分类(罕见)。带有一两个环形圆点的卡片正在诚实地展示其推理 — 透镜们意见不一致。

## 三种置信度体制

分类器投票后,CECE 用三种体制之一标记每个轴:

- **一致同意** — 每个发言的分类器都选择了相同的主要值。卡片没有特殊药丸标记。
- **多数赞成(一项异议)** — 大多数同意;一个异议者按名字显示。卡片头部有紫色「多数赞成」药丸标记。
- **意见分歧** — 没有明确多数。卡片有金色「分类器意见分歧 — 需要你的判断」药丸标记、**金色左边框**,以及供你挑选的同级消歧表单(带芯片)。

每个轴独立获得自己的体制。一张卡片在水平上可以是一致同意 + 在垂直上是意见分歧(反之亦然)。头部药丸标记总结两个轴中最差的体制。

## 同级消歧 (Sibling Disambiguation)

当一个轴意见分歧时,CECE 拒绝猜测,而是将候选值显示为提示下方的 **单选芯片**:

> *「分类器在这些候选项之间产生分歧。请选择最适合此笔记的一个:」*

你点击一个芯片 → 引擎将该选择写入笔记的 frontmatter,从队列中移除卡片,并更新每个 Library 的可靠性数据。

如果另一个轴已经确定(一致同意或多数赞成),CECE *也会* 同时写入该轴的值 — 因此一次芯片点击完成两个轴,而不仅仅是你选择的那个。同一张卡片不会询问你两次。

如果两个轴都意见分歧,你需要为每个轴挑选一个芯片(两次点击)。

## 推理追溯

每张卡片都有一个 **「▸ 为什么是这个分类?」** 切换(如果打开则显示「▾ 隐藏推理」)。展开后,每个发言的分类器显示一行:

- 与圆点群组匹配的 **透镜颜色圆点**
- **分类器标签**(例如「词干与词汇」)
- 方括号中的 **自报置信度**:`[high]` `[medium]` `[low]`
- 解释发动了什么的 **一行推理**(例如,*「语言匹配:垂直 → semantic-contents/concept(权重 0.80)」*)
- 推理下方的 **友好规则芯片**,如 `Surface keyword match`、`Side-channel preference rule`、`Arabic root match (CAE)` — 这些是每个分类器触发的具体规则

在你的 **前 50 次审阅** 期间,追溯在每张卡片上自动展开,以便你可以建立何时信任引擎的直觉。之后,追溯在一致同意的卡片上折叠为按需,在多数赞成 + 意见分歧的卡片上保持自动展开(在分歧具有信息价值的地方)。

你可以在设置 → Intelligence → CECE → 推理追溯可见性中随时覆盖此默认值:

- **始终显示** — 在每张卡片上打开
- **仅在分歧时(默认)** — 在意见分歧 + 多数赞成的卡片上打开,加上前 50 次审阅
- **始终隐藏** — 需要手动点击才能展开

## 队列构成筛选器

在计数条上方有 **五个芯片**,根据每张卡片需要你做出的决定类型对队列进行切片:

| 芯片 | 显示 |
|---|---|
| **全部** *(默认)* | 完整队列 |
| **两个轴都需要你判断** | 水平和垂直都意见分歧的卡片 |
| **Source 需要你判断** | 水平意见分歧 + 垂直已确定的卡片 |
| **内容类型需要你判断** | 垂直意见分歧 + 水平已确定的卡片 |
| **分类器已达成一致** | 没有任何轴意见分歧的卡片 — 快速橡皮图章候选 |

每个芯片显示其桶的计数(例如,*「Source 需要你判断 (43)」*)。空桶变暗并禁用。点击芯片会重新渲染可见的卡片;计数条和「全部批准」数学始终在 **完整** 队列上操作,无论激活的筛选器为何,因此你始终可以看到真实总数。

筛选器解决了当你的队列有数百张卡片时的大海捞针问题。想首先清除所有橡皮图章候选?点击 **分类器已达成一致**,然后点击 **全部批准**。想专注于最难的情况?点击 **两个轴都需要你判断**。

## 每张卡片的操作

每张卡片底部都有四个操作(在意见分歧的卡片上为三个,因为消歧替代了接受/编辑):

- **接受** — 将引擎的综合主要值写入笔记 frontmatter 的两个轴,从队列中移除卡片。更新每个分类器的可靠性。
- **编辑** — 为两个轴打开树选择器;手动选择值。相同的可靠性更新。
- **拒绝** — 不写入任何内容即清除卡片。如果你稍后重新分类,引擎将重新建议。(拒绝 *不* 更新可靠性 — 用户「不想要这些中的任何一个」作为反馈信号是模糊的。)
- **同级消歧芯片** — 在意见分歧的卡片上,点击候选芯片之一。写入选择的值(如果其他轴已确定,则自动写入)。

## 信任校准期

你对 CECE 分类卡片的前 **50 次审阅** 是 *信任校准期*。在此期间,推理追溯在每张卡片上自动展开(无论体制如何),面板顶部的安静横幅提醒你:*「在你再审阅 {N} 张卡片之前,将一直显示推理追溯 — 帮助你了解何时信任分类器。」*

50 次审阅后,横幅消失,追溯折叠为默认的按需行为。如果你想保持始终打开或始终关闭,可以通过设置覆盖。

校准期的要点:CECE 是一个概率系统,你纠正它时它会变得更好(每个 Library 的可靠性)。在前 50 次审阅期间看到 *为什么* 每个分类器以那种方式投票,可以让你建立自己的直觉,知道在这个特定 Library 的内容上其结论何时值得信赖。

## 每个 Library 的校准

设置 → Intelligence → CECE → **每个 Library 的校准** 打开一个只读表格,显示每个分类器在活动 Library 上每个轴的准确度:

```
分类器              水平            垂直
─────────         ──────          ────
你的 frontmatter   12/12 (100%)    4/4 (100%)
引用              18/22 (82%)     6/8 (75%)
词干              24/28 (86%)     20/26 (77%)
链接的笔记         3/4 (均匀)      2/3 (均匀)
相似的笔记         14/19 (74%)     12/19 (63%)
AI 判断           — (未运行)       — (未运行)
```

数字是正确数 / 总数。当分类器在该 Library × 轴上有 20+ 修正后,百分比才会显示(稳定准确度数据的阈值)。在阈值以下,标签显示 **(均匀)** — 在足够数据累积之前,分类器以均匀加权的投票贡献。

不同的 Library 可能具有截然不同的分类器准确度。语言分类器在阿拉伯语为主的 Library 中表现优异;图分类器在密集链接的 Library 中表现优异。综合层使用每个 Library 的校准数据来加权投票 — 因此在 *这个* Library 中 70% 的时间都错的分类器在下一轮综合中其投票被下调权重。

## 后台分类

Source Review 队列可以以两种方式增长:

1. **手动**(默认) — 你右键单击一篇笔记 →「建议 Source 和内容类型」,或触发设置 → 运行分类扫描。
2. **后台** — 设置 → Intelligence → CECE → 后台分类。两种模式:
   - **笔记保存时** — 你停止输入后约 1.5 秒自动分类每篇笔记(借助现有的防抖保存;从不每键击发动)。
   - **应用启动时** — 每次启动扫描一次未分类的笔记。

后台分类默认 **关闭**。两种后台模式都在后台线程上运行 + 发出进度事件;输入保持即时;你可以从 Source Review 面板头部取消。

## 常见工作流程

**「我刚安装了 CECE — 从哪里开始?」**
打开 Source Review 面板。从你的文件树中右键单击 5-10 篇笔记 →「建议 Source 和内容类型」以启动队列。一次点击一张卡片。在你的前 50 次审阅期间,推理追溯会自动展开 — 阅读它。5-10 张卡片后,你将开始看到哪些分类器在你的内容上是可靠的。

**「我的队列有 1,200 张卡片 — 我应该专注于哪里?」**
使用筛选芯片。从 **分类器已达成一致**(橡皮图章候选)开始 → 点击全部批准来清除它们。然后是 **Source 需要你判断** + **内容类型需要你判断**,处理每个需要一项决定的意见分歧情况。**两个轴都需要你判断** 是最难的集合;留到最后。

**「我怎么知道何时接受 vs 拒绝 vs 编辑 vs 消歧?」**
- **接受** — 当综合主要值与你对笔记的解读一致时。
- **拒绝** — 当任何建议都不合适时(例如,引擎遗漏了你知道的关于笔记的某些内容)。
- **编辑** — 当你想要不在任何建议中的值时。
- **同级消歧芯片** — 当卡片意见分歧且其中一个候选项正确时。

**「我怎么看出我最信任哪些分类器?」**
打开设置 → Intelligence → CECE → 每个 Library 的校准。表格显示你在此 Library 上做出的修正中每个分类器的准确度。
