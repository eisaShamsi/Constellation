# Sky View

Sky View 将你的笔记显示为一张由节点和链接组成的交互式网络，由 **GraphMind** 引擎（Pixi.js WebGL）驱动。每个节点代表一篇笔记，每条线代表笔记之间的一个 `[[wikilink]]`（维基链接）。一篇笔记的连接越多，它的节点就显示得越大。

## 打开 Sky View

| 方法 | 操作 |
|--------|--------|
| **指挥中心** | 按 `Ctrl+P`，输入“star view” |
| **键盘** | `Ctrl+G` |

按 `Escape` 关闭 Sky View。

> [!note]
> Sky View 的功能区图标已从左侧停靠栏移除。现在可通过键盘快捷键或指挥中心打开 Sky View。Sky View（组织图）模式作为一个标签页位于笔记管理侧边栏中。

---

## 与图谱交互

### 基本交互

| 输入 | 行为 |
|-------|----------|
| **平移** | 在空白处按住并拖动 |
| **缩放** | 滚轮（2D）或 `Ctrl+滚轮`（3D） |
| **拖动节点** | 按住并拖动任意节点以重新定位 |
| **悬停** | 在状态栏显示笔记名称，并高亮相连的节点和连线 |
| **单击节点** | 在编辑器中打开该笔记 |
| **双击节点** | 放大并将视图居中到该节点 |
| **右击节点** | 打开右键菜单 |

### 右键菜单

右击任意节点可以使用：

| 操作 | 说明 |
|--------|-------------|
| **打开** | 在编辑器中打开该笔记 |
| **聚焦** | 进入以该节点为中心的聚焦模式 |
| **固定** | 将节点锁定在当前位置。再次单击可取消固定。 |
| **隐藏** | 从图谱中隐藏该节点。使用工具栏中的“显示全部”可恢复已隐藏的节点。 |

## 3D 导航

Sky View 支持完整的 3D 导航——像在星辰之间穿行一样飞越你的笔记。

### 进入 3D 模式

**按住鼠标中键并拖动**（或 **Alt+按住并拖动**）可在 3D 空间中旋转图谱。一旦发生旋转，3D 导航控制即被激活。

### 3D 控制

| 输入 | 操作 |
|-------|--------|
| **按住中键拖动** | 绕 X 轴和 Y 轴旋转 |
| **Shift+按住中键拖动** | 绕 Z 轴旋转 |
| **W / 上箭头** | 向前飞行（进入屏幕深处） |
| **S / 下箭头** | 向后飞行 |
| **A / 左箭头** | 向左平移 |
| **D / 右箭头** | 向右平移 |
| **Q** | 向下移动 |
| **E** | 向上移动 |
| **Ctrl+滚轮** | 缩放（改变视野范围） |
| **普通滚轮** | 沿相机方向向前/向后飞行 |
| **0** | 重置旋转，回到平面 2D 视图 |
| **重置按钮**（↺ 图标） | 等同于按 `0` |

### XYZ 坐标轴指示器

处于 3D 模式时，左下角会出现一个用颜色区分的坐标轴向导：

| 坐标轴 | 颜色 | 方向 |
|------|-------|-----------|
| **X** | 红色 | 左—右 |
| **Y** | 绿色 | 上—下 |
| **Z** | 蓝色 | 前—后（深度） |

该指示器会随相机一同旋转，因此你始终清楚自己的方位。

### 在 3D 中悬停和单击

在 3D 中导航时，你仍可以悬停和单击节点。笔记名称会显示在状态栏中，单击即可打开笔记——与 2D 模式完全一样。

## 布局模式

Sky View 提供三种布局算法。按 `Ctrl+L` 或使用工具栏中的布局按钮可在它们之间切换。

| 模式 | 说明 | 适用场景 |
|------|-------------|----------|
| **有机** | 力导向布局。簇群会根据链接密度自然涌现。 | 常规探索——默认模式。 |
| **层级** | 自上而下的有向无环图（DAG）。 | 具有父子关系的结构化资料库。 |
| **时间线** | 节点按创建日期沿水平时间轴排列。 | 查看笔记的创建时间以及资料库的成长过程。 |

切换模式会触发一个流畅的动画过渡，并保持你的空间方位感。

> [!tip]
> 层级模式对于遵循树状结构的笔记尤其有用（例如，链接到子主题的内容地图）。时间线模式则揭示你的思想时间线——相关笔记的簇群是何时创建的。

## 聚焦模式

聚焦模式只显示某一篇特定笔记及其邻域。它是一张动态、可交互的局部图谱。

### 进入聚焦模式

- **右击节点** → **聚焦**
- **按空格键**可对当前活动笔记切换聚焦模式

### 聚焦控制

进入聚焦模式后，顶部会出现一个控制栏：

| 控件 | 说明 |
|---------|-------------|
| **深度滑块**（1–5） | 显示多少跳连接。1 = 仅直接链接，5 = 五层深度。 |
| **方向筛选**（↔ / ← / →） | 显示所有链接、仅传入或仅传出。 |
| **退出按钮**（×） | 返回完整的 Sky View |

### 导航面包屑

当你在聚焦模式中逐个单击节点时，顶部会出现一条面包屑路径，显示你的导航轨迹。单击任意面包屑即可跳回该笔记的局部图谱。

> [!tip]
> 将聚焦模式与深度滑块结合使用，可逐步探索一篇笔记的邻域。从深度 1 开始查看直接连接，然后增大深度以发现第二度和第三度关系。

## 搜索高亮

按 `Ctrl+F` 打开搜索栏。输入查询内容即可高亮匹配的笔记。

与筛选不同，搜索高亮会**淡化**不匹配的节点，但不会将它们移除。这样你在高亮匹配节点的同时，仍保留完整的图谱结构和空间上下文。

> [!tip]
> 搜索在完整图谱和聚焦模式中均可使用。你也可以在 3D 模式下进行搜索。

## 设置面板

单击工具栏中的齿轮图标（⚙）打开设置面板。它包含三个标签页：

### 图表外观

| 控件 | 说明 | 默认值 |
|---------|-------------|---------|
| **节点大小** | 将所有节点整体放大或缩小 | 1.5 |
| **标签可见性** | 标签何时显示：悬停时、始终显示或从不显示 | 悬停时 |
| **标签字体大小** | 笔记名称标签的大小 | 12 |
| **连线粗细** | 连线的宽度 | 1 |
| **显示孤立笔记** | 包含没有链接的笔记 | 开 |

> **画布背景颜色。** 节点（气泡）背后的颜色在 **设置 → 样式设计器 → Sky View → 画布 → 背景** 中设置（不在本面板中）。它独立于你的侧边栏/面板，因此你可以为图谱设置专属背景——例如用一种深色让气泡更突出——而不改变界面的其余部分。若不设置，画布将与面板表面颜色一致。参见 *外观与主题 → Sky View 画布*。

### 物理模拟

| 控件 | 说明 | 默认值 |
|---------|-------------|---------|
| **排斥力** | 节点相互推开的强度 | 50 |
| **连接弹力** | 相连节点相互吸引的强度 | 0.05 |
| **连接距离** | 相连节点之间的目标距离 | 30 |
| **重新加热模拟** | 从当前状态重新启动力导向布局 | — |

### AI

语义 AI 链接的设置（第二阶段——需要本地嵌入模型）。

| 控件 | 说明 |
|---------|-------------|
| **显示语义链接** | 切换 AI 检测出的虚线连线 |
| **置信度阈值** | 用滑块按相似度分数筛选语义链接 |

## 图例

图例显示在右下角，展示各资料库的颜色分配。

### 颜色模式切换

单击图例顶部的 **资料库** 或 **文件夹** 按钮，可切换节点的着色方式：

| 模式 | 着色 |
|------|----------|
| **资料库** | 每个资料库获得一种独特的颜色 |
| **文件夹** | 每个顶级文件夹获得一种独特的颜色 |

### 可见性复选框

每个图例条目都有一个复选框。取消勾选某个资料库或文件夹，即可从图谱中隐藏其节点。这让你能够专注于知识库中的特定子集。

> [!tip]
> 处于文件夹模式时，文件夹数量会显示在括号中。较长的文件夹列表可以滚动查看。

## RTL（从右到左）支持

Sky View 为阿拉伯语、希伯来语及其他从右到左的文字提供一流的支持：

- **节点标签**自动检测文字方向——阿拉伯语标题从右向左渲染
- **图例项**根据内容语言翻转圆点/文字的顺序
- **工具提示和面板**遵循 RTL 布局
- **阿拉伯语字体回退**——当主字体缺少阿拉伯文字形覆盖时，标签会使用系统阿拉伯语字体（Noto Naskh Arabic、Segoe UI）

## 画中画（PiP）叠加层

当 Sky View 处于打开状态，并且你在笔记管理侧边栏中单击某个子宇宙、资料库或文件夹时，主图谱之上会出现一个可调整大小的 **画中画（PiP）** 叠加窗口。

### PiP 显示的内容

PiP 显示一张经过筛选的子图谱，其中只包含属于所选范围的节点。例如，单击某个资料库时，只会显示该资料库的笔记及其相互连接。

### PiP 功能

| 功能 | 说明 |
|---------|-------------|
| **筛选后的图谱** | 只显示所选范围内的节点 |
| **筛选后的图例** | PiP 拥有自己的图例，只显示相关条目 |
| **可调整大小** | 拖动边缘或四角可调整 PiP 窗口的大小 |
| **可重新定位** | 拖动标题栏可将 PiP 移动到屏幕上的任意位置 |

### 跨模式选择同步

在任意侧边栏模式（树形、列表或组织图）中单击某个子宇宙、资料库、文件夹或笔记，都会在 Sky View 图谱中高亮相应的节点。这种双向同步能帮助你在侧边栏浏览的同时保持空间方位感。

## 知识层级（Knowledge Strata）

Sky View 会根据笔记的知识级别（1–8）自动调整节点大小：

- 小圆点：简单笔记（数据、信息）
- 中等节点：已连接的笔记（命题、概念）
- 大而发光的枢纽：综合性笔记（理论、范式、世界观）

更高级别的节点带有一圈互补色的辉光光晕以形成视觉对比。当某个资料库拥有 20 篇以上笔记时，此功能即会启用。

---

## 笔记成熟度（Note Maturity）

节点会显示一圈表示成熟度的彩色光环：

- 无光环：种子（新笔记）
- 浅绿色光环：树苗（成长中）
- 浓绿色光环：常青（根基稳固）
- 金色光环：权威（权威性参考）

成熟度也会在文件树（左侧边框）和标签栏（彩色圆点）中显示。

---

## 来源辉光（Provenance Glow）

Sky View 中的节点会显示一层淡淡的颜色辉光，表示该知识的来源：

- **蓝色辉光**：接收的知识——该笔记的来源链可追溯到外部参考（其 frontmatter 中含有 url、author 或 doi 的笔记）
- **琥珀色辉光**：发现的知识——该笔记的来源链源自用户自己的笔记

## 技术说明

Sky View 由 **GraphMind** 引擎驱动，这是一个 Pixi.js WebGL 渲染器，其 d3-force 模拟运行在一个专用的 Web Worker 中。该架构确保：

- **60fps 渲染**——即使面对数千个节点
- **非阻塞布局**——力导向模拟永远不会冻结界面
- **悬停仅为视觉效果**——悬停永远不会触发物理重新计算
- **模拟在稳定后停止**——一旦节点找到各自的位置，物理引擎便完全停止。只有拖动节点或更改设置才会重新启动它。
