# 日历

**日历**是一个整页的月视图，从**左侧停靠栏**（日历图标）打开。有笔记或有到期任务的日期会用彩色**圆点**标记。标题栏以您所选的日历显示当前月份；如果您设置了**辅助日历**，下方的副标题会显示该日历对应的范围（例如，公历的某个月会显示其对应的回历跨度，"Dhul-Hijjah 1447 – Muharram 1448 AH"）。

## 点击某一天

每个日期单元格都可交互：

| 操作 | 结果 |
|--------|--------|
| 点击空白处（或日期数字） | 打开——或创建——那一天的**每日笔记**。点击一个已经有每日笔记的日期只会**打开**它；绝不会创建副本。 |
| 点击圆点 | 打开对应的具体条目。如果某一天有多篇笔记或多个任务，点击圆点会显示一个小**列表**供您选择。 |
| 点击任务圆点 | 打开笔记并**滚动到该任务所在的行**，可立即编辑。 |

### 圆点颜色

| 圆点颜色 | 含义 |
|-----------|---------|
| 金色 | 那一天的**每日笔记** |
| 紫色 | 当天编辑过（或注明日期）的另一篇**笔记** |
| 红色 | 当天到期的**任务** |

所有圆点颜色——以及日历的其他每个部分——都可在 **Style Setter → 日历** 界面中设置主题。

> [!tip]
> 在任务列表中，您可以直接从日历**勾选任务的复选框来完成它**——已完成的任务会立即从列表中消失。只有自身带有 `📅 YYYY-MM-DD` 到期日的任务才会出现在日历上（正是这个日期决定了它落在哪一天）。

## 文化日历（八种）

在**设置 → 日历**中，您可以设置**日历系统**，整个月历网格都会随之切换：

- **公历**
- **回历（伊斯兰历）**——采用精确的天文引算引擎；圣月会被高亮，伊斯兰节日会被标记。
- **波斯历（太阳回历）**
- **希伯来历**
- **印度历（萨卡历）**
- **佛历**
- **中国农历**——*阴阳历*
- **韩国历**——*阴阳历*

每个单元格同时显示所选日历的日期（大字）和公历日期（小字），并附带月相。每个月份标题会显示月份**名称、括号中的序号以及年份**——序号有助于辨认那些月份顺序不常见的日历。

**中国农历和韩国历**是*阴阳历*：它们有时会插入一个**闰月**（闰六月 / 윤6월），日历会将其单独显示为一页，因此导航既不会跳过也不会重复。

您还可以选择**每周起始日**（周日/周一）并切换**周数列**。

### 回历选项

在**设置 → 日历 → "回历（伊斯兰历）"**下方有两个额外的控制项：

- **计算方法**——**天文（朔月合相）**，依据真实的新月（最精确，默认值），或**表算（al-Tawfīqāt al-Ilhāmiyyah，灵感校正表）**，即古典的算术周期。
- **月份校正**——将某个回历月份的起始日微调 ±1 或 ±2 天，以匹配**当地的实际观月**。选择回历的年份和月份，选定一个偏移量，然后点击 **Set（设置）**；该校正会应用于该月份及其之后的每个月份。您的所有校正都会列出（每一项均可删除），并附带一个 **Clear all（全部清除）**按钮。

这两项设置（以及您的各项校正）都会**随宇宙一同保存**，因此可以跨设备同步。

### 中国农历和韩国历的显示选项

韩国沿用中国农历，因此两者的日期完全相同——区分它们的是**文字**与**年份**。当其中任一历法作为您的主日历或辅助日历时，**设置 → 日历**会显示两个额外的控制项：

- **年份显示**——中国农历：六十甲子 丙午年、纯年份、或两者并列；韩国历：**檀纪**纪年 단기 4359、年份、或六十甲子 병오년。
- **月份名称**——*本地文字*（五月 / 5월），或*音译*——即用您自己的语言写出该月份的读音（英文 "Wǔyuè / Owol"；阿拉伯文 "وُو-يوي / أوه-وُل"）。

## 为日历设置样式

打开 **Style Setter**（左侧停靠栏，或**设置 → Style Setter**）并选择**日历**界面，即可重新设置每个部分的样式——每个元素都有自己的**颜色和文字大小**（日期数字、交叉参照日期、月份药丸标签、星期标题、周数、月相符号、今日高亮、网格线，以及笔记/任务/事件圆点），还有日历的**字体**。一个实时、全尺寸的预览会随您的编辑而更新；点击 **Keep（保留）**即可应用。

## 每日笔记

日历为每日笔记提供完整支持：点击任意一天即可打开它，或运行 **"Daily Note（每日笔记）"** 命令（命令面板）跳转到今天。

> [!tip]
> **每日笔记的文件名始终保持公历格式**（`YYYY-MM-DD`），无论显示的是哪种日历——这样您的文件就能保持可移植性并正确排序。文化日期会显示在日历中，也可以记录到笔记的 frontmatter 中（见下文）。

## 在笔记中记录文化日期

有两个可选启用的工具能把文化日期写入笔记的**属性**（文件名始终保持公历 `YYYY-MM-DD`）：

- **每日笔记回历戳记**——*设置 → 日历 → "在每日笔记中戳记回历日期。"* 开启后（仅当回历是您的**主日历或辅助日历**时可用），每一篇**新建**的每日笔记都会获得一行 `hijri:`，例如 `hijri: 1448-01-06`。已有的笔记绝不会被改动。
- **笔记属性中的 "+ Hijri"**——打开任意笔记的**属性**，将鼠标悬停在日期上，就会出现一个小巧的 **"+ Hijri"** 按钮（还有 "+ Jalali"、"+ Hebrew" 等——**您每选择一种非公历日历，就有一个对应按钮**）。点击它，Constellation 会读取笔记的公历日期并添加对应的值，例如 `jalali: 1405-03-30`。韩国历按钮写入的是**檀纪**年；中国农历/韩国历的**闰月**会用 `L` 标记（例如 `chinese: 2025-06L-17`）。如果笔记没有日期属性，则使用文件的创建日期。

> [!tip] RTL Support
> 日历网格会遵循当前的文字方向。在从右往左书写的语言（阿拉伯文、希伯来文、波斯文、乌尔都文）中，日历布局会相应调整。
