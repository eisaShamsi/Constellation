# 库

**库**把你的一组笔记变成一张实时表格：**每篇笔记一行，每个属性一列**。没有任何东西被复制或移动 —— 表格就地读取你的笔记，并按它们此刻的样子如实呈现。

> [!tip] 默认即强大且简洁
> 库打开时熟悉而清爽 —— 只有你笔记的名称和你关心的字段。星座更深层的、认知性的列始终**触手可及（一键之遥）**，但它们从不挤占第一屏。要拉入多少结构由你决定。

> [!info] 非破坏性
> 库从不擅自改动你的笔记。它是一个小小的 `.base` 文件，内含一条查询 —— “显示这些笔记，带这些列，按这个顺序。”你的 Markdown 文件原封不动地待在原地。

---

## 使用库的两种方式

**1. 作为一个完整的标签页。** 打开一个 `.base` 文件，它会以一张可交互的表格填满整个标签页。

**2. 在笔记内部。** 在任意笔记中放入一个围栏代码块，它就会内联渲染：

````markdown
```base
view: table
```
````

两者由同一个引擎驱动，因此行为完全一致。

---

## 创建一个库

使用侧边栏中的**新建库**（“+” / 新建库 操作）。星座会为你写出一个小巧的 **YAML** `.base` 文件：

```yaml
schema: 1
lens: My Notes
scope:
  libraries: all
  federation: auto
columns:
  - dimension: note.name
view: table
```

| 字段 | 含义 |
|-------|---------|
| `schema` | 格式版本（当前为 `1`）。 |
| `lens` | 显示在表格顶部的名称。 |
| `scope.libraries` | `all`，或一个要纳入的特定资料库列表。 |
| `scope.federation` | `auto` —— 同时纳入任何已链接宇宙（cUniverse）中的笔记。 |
| `columns` | 要显示的列。新建的库仅以笔记**名称**开始。 |
| `view` | `table`（表格即库视图）。 |

你很少需要手动编辑它 —— 表格自身的控件（见下文）会把每一处改动替你写回文件。

---

## 表格

- **名称列** —— 始终排在第一位。点击某篇笔记的名称即可打开它。
- **每篇匹配的笔记成为一行。** **没有行数上限。** 表格是*虚拟化*的 —— 它只绘制当前在屏幕上的行 —— 因此一个覆盖数千篇笔记的库能瞬间打开并流畅滚动。
- **逐单元格方向** —— 每个值都会侦测自身是从左到右还是从右到左的文字，因此混合语言的表格能够正确阅读。
- 页脚显示查询耗时多久。

## 在表格中查找一篇笔记

### 在本库中搜索

标题栏中的**搜索框**会在你输入时即时筛选表格。它既匹配一篇笔记的**名称**，*也*匹配**每一个可见列**的文本，因此你可以凭任何看得见的值来找到某一行。筛选期间，标题旁的计数徽章会显示 **`匹配数 / 总数`**（例如 `4/7684`）；清空搜索框后，它会恢复为纯粹的总数。

搜索在**每一种文字**下都有效 —— 输入阿拉伯语即可找到阿拉伯语标题，其余语言同理。由于每一行都已在内存中，即使一个库有数千篇笔记，筛选也是瞬时的。

### 字母栏

当一个库有 **50 行或以上**时，一条纤细的字母条会沿着表格的边缘出现。它的字母由你**实际笔记标题的首字母**构成 —— 因此英文标题会显示 **A–Z**，阿拉伯语会显示 **أ ب ت …**，你拥有的任何其他文字也会显示相应的正确字母。（在从右到左的界面中，字母栏会自动落在正确的一侧。）

**点击某个字母即可跳转**到以它开头的第一篇笔记。如果表格尚未按名称排序，点击某个字母会**先按名称排序**，再跳转 —— 这样字母的含义始终与你预期的一致。

### 右键点击某一行

**右键点击任意一行**即可调出标准的笔记菜单：**打开**、**在新选项卡中打开**、**加入书签**、**复制路径** / **复制名称**、**在文件树中显示**、**用默认应用打开**、**在系统资源管理器中显示**，以及**样式…**。重命名、移动和删除在这里被刻意*不*提供 —— 请从文件树中进行这些操作，那里的列表会安全地刷新。

## 列 —— 添加、移除、重新排序

### 添加列

点击 **+ 添加列**。选择器分为两组：

- **你的字段** —— 星座在你笔记中找到的 frontmatter 属性（例如 `status`、`maturity`、`author`）。这些是*你的*数据。
- **星座** —— 应用始终知道的内置字段：**名称**、**路径**、**创建时间**和**摘要**。

开始输入即可筛选列表。已在表格中的字段会被标记，以免你重复添加。

### 移除列

将鼠标悬停在某个列标题上，然后点击 **×**。

### 重新排序列

**按住并向侧方拖动列标题。** 整列会被提起（它会变暗，标题显示出可抓取的轮廓），一条竖线标示出它将落到何处。松开即可移动它。名称列始终固定为第一列。

每一次添加、移除和重新排序都会自动保存回 `.base` 文件。

---

## 排序

**点击列标题以按其排序。** 每次点击循环切换**升序 → 降序 → 关闭**（一个箭头显示当前方向）。

要按多个列排序，请打开**排序**面板：

- 添加若干列 —— 第一列是主排序，后续各列用于打破并列。
- 在升序与降序之间翻转任意层级。
- 上移或下移各层级以更改优先级，或将其移除。

## 从表格中编辑笔记

双击你**自己的** frontmatter 列中的某个单元格即可编辑它：

- **自由文本字段** —— 输入新值；**Enter** 保存，**Escape** 取消。
- **列表型字段**（如 `maturity`）—— 会出现一个**下拉菜单**，按**其自然顺序**列出有效值（对 `maturity` 而言：*seed → sapling → evergreen → canonical*）。选一个，或输入你自己的。

改动会直接写入磁盘上那篇笔记的 YAML frontmatter，表格随即就地更新。

> [!note] 只读列
> **名称**和**创建时间**（以及其他内置的星座列）是为你计算出来的，因此它们不可编辑。此处只能更改你自己的 frontmatter 字段。

## 打开一个较旧的库

如果你从 Obsidian，或从星座的早期版本切换过来，你现有的 `.base` 文件使用的是较旧的格式。

**你的文件绝不会被触碰。** 当星座打开这样一个文件时，它会显示一条平和的提示，说明该格式较旧，并提供一个**转换为星座库**按钮。转换**仅在你点击它时**才发生 —— 它会就地把文件升级为新的 YAML 格式（尽其所能地携带过来：名称、列，以及简单的文本筛选）。在你选择转换之前，原始文件会被原封不动地保留。

---

## 联邦

库具备宇宙感知能力。在 `federation: auto` 下，它会把任何已链接宇宙（cUniverse）中的笔记与你自己的笔记一并纳入。位于已链接宇宙中的笔记是只读的 —— 你可以在库中查看并排序它们，但编辑仅限于你拥有的笔记。

---

## 本地优先 & 文件高于应用

库自身不持有任何数据。你看到的每个值都来自你磁盘上一个真实的 `.md` 文件，实时读取。删除 `.base` 文件，你的笔记将完全不受影响 —— 库只是你指向自己已有笔记的一面镜头。

## 键盘与鼠标

| 操作 | 作用 |
|--------|--------------|
| 在搜索框中**输入** | 按名称及任意可见列筛选行（任意文字） |
| **点击**字母栏上的某个字母 | 跳转到以它开头的第一篇笔记（如有需要会先按名称排序） |
| **右键点击**某一行 | 笔记菜单：打开 · 加入书签 · 复制 · 显示 · 样式 |
| **点击**列标题 | 按其排序（升序 → 降序 → 关闭） |
| **拖动**列标题 | 重新排序该列 |
| **点击**标题上的 × | 移除该列 |
| **双击** frontmatter 单元格 | 编辑它（列表字段显示下拉菜单） |
| **Enter** | 保存编辑 |
| **Escape** | 取消编辑 |
| **点击**某篇笔记的名称 | 打开该笔记 |
