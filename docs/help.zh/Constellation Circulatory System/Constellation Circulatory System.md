# Constellation Circulatory System (CCS)

> **الجهاز الدوري** —— 你思考的脉搏。

大多数工具递给你一个文件柜。Constellation 递给你的是一具**活着的思想之躯**——而 CCS 就是它的脉搏。打开它，你看到的不会是一张链接清单。你会看到哪些想法因近期的思考而**温热**、哪些已经**变冷**；你的**确信**在哪里正硬化为基岩，你的**怀疑**在哪里仍然鲜活；你不断回到什么，又把什么连接过一次便悄悄丢下。一条建立之后再没走过的连接还算不上理解——那只是一张你写给自己、又忘掉的便条。CCS 让你一眼看出：你的思考**是否仍在循环**。

你的知识有一套神经系统（**CNS**——它如何接线），也有一套循环系统（**CCS**——它是否活着）。它们是同胞，共同回答"连接"之问：CNS 读*结构*（社区、桥梁、中心性）；CCS 读*流动*（重量、走访、生命周期、置信度）。CNS 永远不会告诉你一座承重的桥正在变陈；CCS 也永远不会告诉你一条被磨亮的链接是一座桥。

## 打开 CCS

三扇门，走哪扇都一样：

1. **停靠栏** —— 左侧停靠栏中的脉搏线图标，就在 CNS 正下方。
2. **命令面板** —— 输入"循环"（命令名为"星座循环系统（CCS）"）。
3. **设置 → 链接 → 相关** ——"循环系统（CCS）"一栏的"打开循环系统 →"按钮。

无论你有多少链接，CCS 都即开即现：它读取的是 Constellation 在后台持续保鲜的一份快照（与知识健康共用同一引擎）。更新后的第一次打开可能会显示*"正在为你的知识把脉…"*几秒钟——仅此一次，发生在快照首次构建之时。

页眉显示范围（**本宇宙**）和已记录链接的总数。**知识健康 →** 按钮跳到计数卡片浮层；知识健康那边也带有对应的**循环系统 →** 按钮跳回来。两个表面相互配合——CCS 是深度仪器，知识健康是一眼速览的卡片。

## 七个登记册

每个登记册都是一个你本来就会对自己的思考发出的问题：

| 登记册 | 问题 | 它显示什么 |
|---|---|---|
| **活跃的连接** | *我此刻正在主动思考什么？* | 你走访最多、仍然温热的链接（90 天内走访过），附走访次数与最近走访日期。 |
| **承重的推理** | *我的理解建立在什么之上？* | 挣得重量最高的温热链接——你的动脉。每走访一次链接，重量便增长一分。 |
| **正在冷却的追问** | *我不再回访什么？* | 你曾走过、却已 90 天以上未碰的链接，最冷的排最前。这是一份邀请，绝非指控——事实有权安歇。 |
| **确信与怀疑** | *我的思考有多安定？* | 置信度的分布（假设 → 证据 → 已确立 → 存争议），加上现存的存争议链接——你正在进行的争论。 |
| **一条连接的一生** | *我的链接处于生命周期的哪个阶段？* | 五级普查：新建（从未走访）· 萌发（走访 1–2 次）· 确立（3–9 次）· 承重（10 次以上）· 陈旧（闲置 90 天以上）。 |
| **退役的推理** | *我搁置了什么——还能复苏吗？* | 已归档的链接，每行带一个**恢复**按钮；超过二十条时出现**显示全部**。 |
| **探究的行为** | *我在进行哪些类型的思考？* | 你的类型化链接按认知行为标准顺序的分布，外加一行**开放的追问**——你的未定类型链接，那些仍在追问彼此如何关联的问题。 |

点击任何一行都会打开那条链接所在的笔记。浏览 CCS 绝不会改动它所显示的数字——从登记册里打开笔记，不算走访那条链接。

## 恢复退役的推理

1. 打开 CCS → **退役的推理**。
2. 在想要找回的那一行点击**恢复**。
3. 该行离开登记册；这条链接重新出现在笔记的反向链接 / 出链面板中。

恢复后的链接什么也不会丢失——类型、注释、置信度和完整的走访历史都随之归来，重量则根据这段历史重新计算：一条走访频繁的链接，回来时与离开时同样有分量。

## 保鲜节奏

CCS 读取的是一份缓存快照，在事情发生变化后的一两分钟内于后台刷新。如果你归档或恢复了一条链接并立刻重开 CCS，可能会短暂看到先前的数字——它们会在片刻之内原位更新。等待期间没有任何重新计算；面板永远即开即现。

## 旧"链接面板"去了哪里

右侧边栏的**链接面板**标签页已退役并入 CCS。它的职责各得其所：走访最多 → **活跃的连接**；陈旧 → **正在冷却的追问**；已归档 + 恢复 → **退役的推理**；连接最多留在**知识健康**；孤立笔记住在张力面板（右侧边栏的健康标签页）。跨库列表与失效链接列表随该面板一并退役。
