# Constellation 用户手册

**版本 0.3.4 | 2026年3月**

Constellation 是一款用于管理 Markdown 笔记库的个人知识管理（PKM）桌面应用程序。基于 Tauri v2、SvelteKit 和 Rust 构建，可在 Windows、macOS 和 Linux 上原生运行，并完整支持阿拉伯语和 RTL。

## 1. 入门指南

### 安装

从 [Constellation 发布页面](https://github.com/eisaShamsi/Constellation/releases) 下载最新安装程序：

- **Windows**：`.exe`（NSIS）或 `.msi` 安装程序
- **macOS**：`.dmg` 磁盘映像
- **Linux**：`.AppImage` 或 `.deb` 包

### 首次启动

首次打开 Constellation 时，**宇宙设置向导**将引导您完成以下步骤：

1. **选择语言** — 支持15种语言
2. **创建或导入库** — 指向现有的 Markdown 文件文件夹，或从零开始
3. **命名宇宙** — 宇宙是所有库的容器

### 界面概览

| 元素 | 说明 |
|------|------|
| **侧边栏（功能区）** | 导航按钮：文件树、搜索、星图视图、日历、模板、设置 |
| **文件树** | 浏览库中的笔记和文件夹 |
| **编辑器** | 阅读和编辑 Markdown 笔记 |
| **标签栏** | 以标签页方式打开多个笔记 |
| **状态栏** | 字数、字符数、阅读时间 |

## 2. 宇宙与库

### 什么是宇宙？

**宇宙**是容纳所有库的顶级容器。可以将其视为工作空间或库集合。

### 什么是库？

**库**是计算机上包含 Markdown（`.md`）文件的文件夹。您可以在一个宇宙中拥有多个库——例如，一个用于工作笔记，一个用于个人笔记。

### 管理库

- **添加库**：设置 > 库 > 添加库，或将文件夹拖入应用
- **移除库**：设置 > 库 > 点击库名旁的移除按钮
- **库设置**：每个库可以有自己的外观设置（字体、颜色）

### 子宇宙

您可以在宇宙中嵌套宇宙。**子宇宙**是被父宇宙引用的另一个宇宙文件夹。子宇宙中的笔记会在星图视图中与您的笔记一同显示，跨库链接以虚线表示。

## 3. 创建和编辑笔记

### 创建笔记

| 方法 | 操作 |
|------|------|
| **键盘** | `Ctrl+N` |
| **文件树** | 右键点击文件夹 > 新建笔记 |
| **任务控制** | `Ctrl+P` > "新建笔记" |

### 编辑器模式

Constellation 提供两种编辑器模式，可在**设置 > 编辑器 > 编辑器类型**中选择：

#### Markdown 编辑器（CodeMirror）

面向高级用户的默认编辑器，可直接编写 Markdown：

- **实时预览** — 输入时内联渲染格式
- **源码模式** — 显示原始 Markdown 语法
- **格式工具栏** — 选中文本时出现
- **斜杠命令** — 输入 `/` 快速插入
- **Wikilink 自动补全** — 输入 `[[` 链接笔记
- **多光标** — `Alt+Click` 或 `Ctrl+D`

#### 文档编辑器（TipTap）

带有可视化工具栏的所见即所得文字处理体验：

- 加粗、斜体、下划线、删除线、高亮
- 标题（H1～H3）、文本对齐
- 无序列表、有序列表、任务列表
- 引用块、代码块、水平线
- 表格（插入、添加/删除行列）
- 链接和图片

两种编辑器都保存为标准 Markdown 文件。您可以随时切换而不会丢失数据。

### 文本格式快捷键

| 快捷键 | 操作 |
|--------|------|
| `Ctrl+B` | 加粗 |
| `Ctrl+I` | 斜体 |
| `Ctrl+Shift+S` | 删除线 |
| `Ctrl+Shift+H` | 高亮 |
| `Ctrl+K` | 插入 Wikilink |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` | 重做 |

### 链接笔记

输入 `[[` 打开笔记自动补全。开始输入笔记名称并从建议中选择。链接将显示为可点击的 Wikilink：`[[笔记名称]]`。

您还可以链接到特定标题：`[[笔记名称#标题]]`。

## 4. 星图视图 (GraphMind)

星图视图使用 **GraphMind** 引擎（Pixi.js WebGL）将笔记可视化为交互式3D图谱。

### 打开星图视图

- 点击侧边栏中的图谱图标
- 按 `Ctrl+G`
- 任务控制（`Ctrl+P`）> "星图视图"

### 导航

| 输入 | 操作 |
|------|------|
| **点击 + 拖拽** | 平移图谱 |
| **滚轮** | 缩放 |
| **点击节点** | 打开笔记 |
| **右键点击节点** | 上下文菜单（打开、聚焦、固定、隐藏） |
| **中键 + 拖拽** | 3D旋转 |
| **W/A/S/D** | 在3D空间中飞行 |
| **0** | 重置旋转到2D |
| **Ctrl+F** | 搜索并高亮 |
| **Space** | 切换聚焦模式 |

### 布局模式

按 `Ctrl+L` 循环切换：

- **有机布局** — 集群自然涌现的力导向布局
- **层级布局** — 自上而下的树形布局
- **时间轴布局** — 按创建日期排列在时间轴上

### 聚焦模式

右键点击节点 > **聚焦**，仅显示其邻域。可调整：

- **深度**（1～5跳）— 显示多少层连接
- **方向**（↔/←/→）— 所有链接、仅入链、仅出链

### 3D 导航

中键拖拽进行旋转。使用 W/A/S/D/Q/E 在星空中飞行。角落的 XYZ 轴辅助指示器显示您的方向。按 `0` 重置。

### 设置

点击齿轮图标进行设置：

- **外观**：节点大小、标签显示、字体大小、链接粗细、显示孤立节点
- **物理**：排斥力、链接力、链接距离
- **AI**：语义链接阈值（第二阶段）

### 图例

右下角图例显示库/文件夹颜色，带有复选框可切换显示/隐藏。

## 5. 第二屏幕

打开单独的窗口以并排查看笔记。

- **打开**：点击侧边栏的第二屏幕图标，或按 `Ctrl+Shift+N`
- **同步**：笔记在第二屏幕中独立打开。字体和主题设置适用于两个窗口。
- **笔记宽度**：通过工具栏中的宽度滑块调整

## 6. 属性和前置数据

笔记顶部可以包含 YAML 前置数据：

```yaml
---
tags: [project, active]
date: 2026-03-19
status: in-progress
---
```

Constellation 会自动检测属性类型：

| 类型 | 示例 |
|------|------|
| **文本** | `author: John` |
| **数字** | `priority: 5` |
| **日期** | `date: 2026-03-19` |
| **列表** | `tags: [a, b, c]` |
| **复选框** | `done: true` |
| **链接** | `related: [[Other Note]]` |

切换属性显示：**设置 > 编辑器 > 文档中的属性**（显示 / 隐藏 / 源码）。

## 7. 模板

创建可重复使用的笔记模板：

1. 在库中创建模板文件夹
2. 在**设置 > 模板**中设置模板文件夹路径
3. 创建新笔记时从模板选择器中选择模板

模板支持变量：

| 变量 | 替换内容 |
|------|----------|
| `{{date}}` | 当前日期 |
| `{{time}}` | 当前时间 |
| `{{title}}` | 笔记标题 |
| `{{clipboard}}` | 剪贴板内容 |

## 8. 表格

### Markdown 表格

手动输入 Markdown 表格或使用 `/table` 斜杠命令：

```markdown
| 表头 1 | 表头 2 |
|--------|--------|
| 单元格 1 | 单元格 2 |
```

### 表格工具栏

当光标在表格内时，会出现浮动工具栏：

- 添加/删除行和列
- 列对齐（左对齐、居中、右对齐）
- 使用 `Tab` / `Shift+Tab` 在单元格间导航

### 文档编辑器中的表格

文档编辑器（TipTap）提供可视化表格体验：

- 点击表格按钮插入
- 使用下拉菜单管理行/列
- 拖拽边框调整列宽

## 9. 任务

Constellation 支持笔记中的任务复选框：

```markdown
- [ ] 未完成任务
- [x] 已完成任务
```

在实时预览模式下，复选框可以点击。任务可以在所有库中搜索和筛选。

## 10. 导入工具

从其他 PKM 工具导入笔记：

- **Obsidian** — 完整 Wikilink 兼容导入库

前往**设置 > 导入工具**开始导入。

## 15. RTL 和阿拉伯语支持

Constellation 为阿拉伯语、希伯来语、波斯语、乌尔都语及其他 RTL 文字提供一流支持：

- **自动检测**：笔记方向根据内容自动检测
- **界面**：选择阿拉伯语/希伯来语时提供完整的 RTL 界面
- **编辑器**：支持正确光标移动和选择的 RTL 文本编辑
- **星图视图**：阿拉伯语标签以正确的字体回退从右向左渲染
- **图例**：根据内容语言翻转圆点/文本顺序
- **文字字体**：在设置中可独立配置阿拉伯语、希伯来语和 CJK 字体

### 设置阿拉伯语

1. 前往**设置 > 通用 > 语言**，选择阿拉伯语
2. 可选择在**设置 > 通用 > 文字字体**中设置专用阿拉伯语字体
3. 包含阿拉伯语内容的笔记将自动以 RTL 方式渲染

## 16. 安全与隐私

- **所有数据保存在本地** — 无云同步、无遥测、无追踪
- **Markdown 文件** — 您的笔记是完全属于您的纯文本文件
- **无需账户** — Constellation 完全离线运行
- **可选更新** — 在设置中手动检查更新
- **开源** — 在 [github.com/eisaShamsi/Constellation](https://github.com/eisaShamsi/Constellation) 查看代码
