# Constellation 用户手册

**版本 0.3.4 | 2026年3月**

Constellation 是一款用于管理 Markdown 笔记库的个人知识管理（PKM）桌面应用程序。基于 Tauri v2、SvelteKit 和 Rust 构建，可在 Windows、macOS 和 Linux 上原生运行，并完整支持阿拉伯语和 RTL。

## 1. 入门指南

### 安装

从 [Constellation 发布页面](https://github.com/eisaShamsi/Constellation/releases) 下载最新安装程序：

- **Windows**：`.exe`（NSIS）或 `.msi` 安装程序
- **macOS**：`.dmg` 磁盘映像
- **Linux**：`.AppImage` 或 `.deb` 包

### 首次启动

首次打开 Constellation 时，**宇宙设置向导**将引导您完成以下步骤：

1. **选择语言** — 支持15种语言
2. **创建或导入库** — 指向现有的 Markdown 文件文件夹，或从零开始
3. **命名宇宙** — 宇宙是所有库的容器

### 界面概览

| 元素 | 说明 |
|------|------|
| **侧边栏（功能区）** | 导航按钮：文件树、搜索、星图视图、日历、模板、设置 |
| **文件树** | 浏览库中的笔记和文件夹 |
| **编辑器** | 阅读和编辑 Markdown 笔记 |
| **标签栏** | 以标签页方式打开多个笔记 |
| **状态栏** | 字数、字符数、阅读时间 |

## 2. 宇宙与库

### 什么是宇宙？

**宇宙**是容纳所有库的顶级容器。可以将其视为工作空间或库集合。

### 什么是库？

**库**是计算机上包含 Markdown（`.md`）文件的文件夹。您可以在一个宇宙中拥有多个库——例如，一个用于工作笔记，一个用于个人笔记。

### 管理库

- **添加库**：设置 > 库 > 添加库，或将文件夹拖入应用
- **移除库**：设置 > 库 > 点击库名旁的移除按钮
- **库设置**：每个库可以有自己的外观设置（字体、颜色）

### 子宇宙

您可以在宇宙中嵌套宇宙。**子宇宙**是被父宇宙引用的另一个宇宙文件夹。子宇宙中的笔记会在星图视图中与您的笔记一同显示，跨库链接以虚线表示。

### 自动重新打开

Constellation 会记住您最后活跃的宇宙，并在启动时自动重新打开。如果宇宙已被移动或路径已更改，Constellation 会自动检测并修复路径。

### 可移动宇宙

Constellation 的宇宙完全可移动。您可以将宇宙文件夹移动到任何位置——不同的驱动器、U盘或另一台电脑——Constellation 在重新打开时会自动检测并修复所有内部路径。

移动宇宙的步骤：
1. 关闭 Constellation
2. 将宇宙文件夹移动或复制到新位置
3. 打开 Constellation → 显示欢迎界面（旧路径已失效）
4. 选择**打开现有宇宙**并指向新位置
5. 所有笔记和库立即显示——路径自动修复

宇宙文件夹结构遵循 Obsidian 模式：笔记直接存放在根文件夹中，配置存放在 `.constellation/` 中。

## 3. 创建和编辑笔记

### 创建笔记

| 方法 | 操作 |
|------|------|
| **键盘** | `Ctrl+N` |
| **文件树** | 右键点击文件夹 > 新建笔记 |
| **任务控制** | `Ctrl+P` > "新建笔记" |

### 编辑器模式

Constellation 提供两种编辑器模式，可在**设置 > 编辑器 > 编辑器类型**中选择：

#### Markdown 编辑器（CodeMirror）

面向高级用户的默认编辑器，可直接编写 Markdown：

- **实时预览** — 输入时内联渲染格式
- **源码模式** — 显示原始 Markdown 语法
- **格式工具栏** — 选中文本时出现
- **斜杠命令** — 输入 `/` 快速插入
- **Wikilink 自动补全** — 输入 `[[` 链接笔记
- **多光标** — `Alt+Click` 或 `Ctrl+D`

#### 文档编辑器（TipTap）

带有可视化工具栏的所见即所得文字处理体验：

- 加粗、斜体、下划线、删除线、高亮
- 标题（H1～H3）、文本对齐
- 无序列表、有序列表、任务列表
- 引用块、代码块、水平线
- 表格（插入、添加/删除行列）
- 链接和图片

两种编辑器都保存为标准 Markdown 文件。您可以随时切换而不会丢失数据。

### 标注 (Callouts)

创建样式化的标注块，用于注释、警告、提示和其他说明：

```markdown
> [!note] 重要信息
> 标注内容写在这里。

> [!warning] 请注意
> 此操作无法撤消。

> [!tip]- 点击展开
> 可折叠的标注内容。
```

支持的类型：`note`、`tip`、`warning`、`danger`、`success`、`question`、`failure`、`bug`、`example`、`quote`、`abstract`。每种类型都有独特的颜色和图标。在类型后添加 `-` 使其可折叠（初始为折叠状态），或 `+`（初始为展开状态）。

### 高亮语法

用双等号包裹文本以高亮显示：

```markdown
这是笔记中的==高亮文本==。
```

在实时预览中，`==` 标记会隐藏，文本以黄色背景显示。

### 代码块

围栏代码块以背景颜色和语言标签显示：

````markdown
```javascript
const greeting = "Hello, world!";
```
````

语言名称以徽章形式显示在代码块上方。

### 图片嵌入

在笔记中直接嵌入图片：

```markdown
![替代文本](https://example.com/image.png)   — 外部 URL
![[photo.jpg]]                                 — 资料库中的本地文件
```

在实时预览中，图片会内联渲染。本地图片必须在您的资料库文件夹中。外部图片需要互联网连接。

### 表格工具栏

当光标位于 markdown 表格内时，会出现一个浮动工具栏，包含：

- **+ 行 / + 列** — 添加行或列
- **- 行 / - 列** — 删除行或列
- **对齐** — 按列设置左对齐、居中或右对齐
- **排序** — 按当前列升序或降序排序
- **Tab / Shift+Tab** — 在表格单元格之间导航

### 文本格式快捷键

| 快捷键 | 操作 |
|--------|------|
| `Ctrl+B` | 加粗 |
| `Ctrl+I` | 斜体 |
| `Ctrl+Shift+S` | 删除线 |
| `Ctrl+Shift+H` | 高亮 |
| `Ctrl+K` | 插入 Wikilink |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` | 重做 |

### 链接笔记

输入 `[[` 打开笔记自动补全。开始输入笔记名称并从建议中选择。链接将显示为可点击的 Wikilink：`[[笔记名称]]`。

您还可以链接到特定标题：`[[笔记名称#标题]]`。

## 4. 星图视图 (GraphMind)

星图视图使用 **GraphMind** 引擎（Pixi.js WebGL）将笔记可视化为交互式3D图谱。

### 打开星图视图

- 点击侧边栏中的图谱图标
- 按 `Ctrl+G`
- 任务控制（`Ctrl+P`）> "星图视图"

### 导航

| 输入 | 操作 |
|------|------|
| **点击 + 拖拽** | 平移图谱 |
| **滚轮** | 缩放 |
| **点击节点** | 打开笔记 |
| **右键点击节点** | 上下文菜单（打开、聚焦、固定、隐藏） |
| **中键 + 拖拽** | 3D旋转 |
| **W/A/S/D** | 在3D空间中飞行 |
| **0** | 重置旋转到2D |
| **Ctrl+F** | 搜索并高亮 |
| **Space** | 切换聚焦模式 |

### 布局模式

按 `Ctrl+L` 循环切换：

- **有机布局** — 集群自然涌现的力导向布局
- **层级布局** — 自上而下的树形布局
- **时间轴布局** — 按创建日期排列在时间轴上

### 聚焦模式

右键点击节点 > **聚焦**，仅显示其邻域。可调整：

- **深度**（1～5跳）— 显示多少层连接
- **方向**（↔/←/→）— 所有链接、仅入链、仅出链

### 3D 导航

中键拖拽进行旋转。使用 W/A/S/D/Q/E 在星空中飞行。角落的 XYZ 轴辅助指示器显示您的方向。按 `0` 重置。

### 设置

点击齿轮图标进行设置：

- **外观**：节点大小、标签显示、字体大小、链接粗细、显示孤立节点
- **物理**：排斥力、链接力、链接距离
- **AI**：语义链接阈值（第二阶段）

### 图例

右下角图例显示库/文件夹颜色，带有复选框可切换显示/隐藏。

### 知识层级

星图视图根据抽象程度自动将笔记分为八个知识层级：

| 层级 | 描述 |
|------|------|
| **快照** | 快速、临时的笔记 |
| **日志** | 有日期的事件和日记 |
| **主题** | 关于单个想法的原子概念 |
| **地图** | 连接其他主题的组织性笔记 |
| **框架** | 模型和思维框架 |
| **原则** | 经过验证的规则和公理 |
| **信念** | 基本价值观和信念 |
| **作品** | 已完成的最终成果 |

层级根据笔记的前置数据、结构和链接自动确定。您可以通过在前置数据中添加 `stratum` 属性来手动覆盖分类。

### 成熟度生命周期

每个笔记都经历一个反映其发展程度的成熟度生命周期：

- **种子** — 初始想法或原始草稿
- **幼苗** — 笔记开始成形，有一些链接
- **常青** — 成熟、经过审查且连接良好的笔记
- **经典** — 该领域的最终权威参考

成熟度会根据链接数量、审查日期和编辑频率自动更新。您也可以通过前置数据中的 `maturity` 属性手动设置。

## 5. 分屏视图

分屏视图允许您在主窗口中并排编辑多个笔记。

### 打开分屏视图

- **命令面板**：`Ctrl+P` 然后输入 "Split View"
- **键盘快捷键**：使用指定快捷键在模式之间切换
- **循环**：关闭 → 垂直（并排）→ 水平（上下）→ 关闭

### 在分屏视图中编辑

每个窗格是一个完全独立的编辑器，包含：
- 完整工具栏（加粗、斜体、标题、对齐等）
- 面包屑导航（库 / 笔记名称）
- 属性面板和阶段下拉菜单
- 保存支持（`Ctrl+S` 保存当前聚焦的窗格）
- 标题编辑和文件重命名

### 调整窗格大小

拖动窗格之间的分隔条来调整大小。每个分隔条是独立的——打开3个或更多笔记时，您可以调整任意相邻对的大小而不影响其他窗格。垂直和水平模式均可使用。

### 聚焦

点击任何窗格以聚焦。聚焦的窗格接收键盘快捷键，并被右侧边栏面板（属性、反向链接等）跟踪。

## 6. 索引

索引是跨所有库的综合术语词汇表——每个有意义的词汇，按字母顺序排列并附有出现次数。

### 打开索引

- **停靠按钮**：点击左侧停靠栏中的索引图标（书本）
- **命令面板**：`Ctrl+P` 然后输入 "Index"

### 多语言 NLP 管道

索引在建立索引之前通过语言感知管道处理文本：

- **阿拉伯语**：Lucene Light10 算法——移除变音符号、统一哈姆扎、去除定冠词（الـ）、移除语法后缀
- **希伯来语**：前缀移除（ב/ל/מ/ה/ו/כ/ש）
- **英语**：Porter 类词干提取（复数、动词形式、后缀）
- **法语/西班牙语/葡萄牙语/德语**：语言特定后缀移除
- **俄语/土耳其语/印地语/波斯语**：形态后缀移除
- **全部 15 种语言**：停用词过滤（冠词、介词、连词）

### 浏览

- **语言标签**：在全部、阿拉伯语、希伯来语、英语或 #（特殊字符）之间切换
- **字母栏**：点击字母以筛选以该字母开头的术语——术语计数会更新显示匹配数量
- **再次点击相同字母**可清除筛选并显示所有术语
- **排序模式**：按字母顺序（默认）或按频率（最常见的排在前面）

### 从索引编辑

点击术语引用中的任何笔记，在索引旁的分屏预览窗格中打开。预览窗格是一个完整的编辑器——您可以编辑、保存、更改属性和提升阶段。搜索术语在笔记中高亮显示并自动滚动到该位置。

按 `Ctrl+Click` 将笔记作为普通标签页打开。标签栏中会出现"返回索引"按钮——点击它可以准确返回到您在索引中离开的位置。

### 第二屏幕集成

当第二屏幕打开时：
- **点击一个术语** → 第二屏幕在分屏视图中显示包含该术语的所有笔记（笔记列表 + 编辑器）
- **Ctrl+Click 多个术语** → 第二屏幕显示比较模式，每个术语在各自的列中

## 7. 第二屏幕

第二屏幕是一个基于模式的伴随窗口，可适应您当前的侧边栏模式。

- **打开**：点击侧边栏的第二屏幕图标，或按 `Ctrl+Shift+2`
- **自动关闭**：当您关闭主窗口时，第二屏幕会自动关闭

### 基于模式的伴随

第二屏幕根据主窗口中活动的侧边栏模式更改其内容：

| 主侧边栏模式 | 第二屏幕显示 |
|---|---|
| **文件浏览器** | 宇宙仪表板——统计数据、库详情、子宇宙、标签、最近编辑/打开的笔记 |
| **导航器** | 用于浏览笔记的完整导航器视图 |
| **天空视图** | 带目录结构的天空视图树 |
| **星图视图** | 带反向链接、正向链接、标签和本地图谱的星图视图伴随 |

### 宇宙仪表板（文件浏览器模式）

当主窗口处于文件浏览器模式时，第二屏幕显示一个仪表板，包含：

- **统计卡片** — 宇宙名称、子宇宙数量、库、文件夹和笔记总数
- **子宇宙** — 每个子宇宙及其关联库和文件夹/笔记数量
- **库** — 每个库在彩色统计框中显示文件夹/笔记数量
- **最近编辑** — 当前会话中您修改过的笔记（保存时跟踪）
- **最近打开** — 当前会话中您打开但未编辑的笔记
- **标签** — 所有库中的所有标签按数量排序；点击标签查看所有使用它的笔记

### 仪表盘交互

当仪表盘在主窗口中处于活动状态时，点击项目会将其发送到第二屏幕：

- **最近编辑/打开**：点击笔记可在第二屏幕上以完整编辑器打开
- **标签**：点击标签可在分屏视图中显示所有使用该标签的笔记——左侧为笔记列表，右侧为完整编辑器

第二屏幕上的所有编辑会自动同步回主窗口。

### 在第二屏幕中编辑笔记

第二屏幕支持完整的笔记编辑——像主窗口一样输入、保存、重命名和更改属性。更改会自动同步回主窗口。

### 设置同步

所有视觉设置会立即传播到第二屏幕——无需重启：

- **语言**：界面语言更改立即生效
- **主题**：亮色/暗色/系统模式立即切换
- **字体**：界面字体、文本字体、等宽字体和脚本专用字体
- **字体大小**：界面和编辑器字体大小
- **编辑器**：可读行宽、行号、浮动工具栏
- **强调色**：主题强调色更改

## 8. 属性和前置数据

笔记顶部可以包含 YAML 前置数据：

```yaml
---
tags: [project, active]
date: 2026-03-19
status: in-progress
---
```

Constellation 会自动检测属性类型：

| 类型 | 示例 |
|------|------|
| **文本** | `author: John` |
| **数字** | `priority: 5` |
| **日期** | `date: 2026-03-19` |
| **列表** | `tags: [a, b, c]` |
| **复选框** | `done: true` |
| **链接** | `related: [[Other Note]]` |

切换属性显示：**设置 > 编辑器 > 文档中的属性**（显示 / 隐藏 / 源码）。

## 9. 模板

创建可重复使用的笔记模板：

1. 在库中创建模板文件夹
2. 在**设置 > 模板**中设置模板文件夹路径
3. 创建新笔记时从模板选择器中选择模板

模板支持变量：

| 变量 | 替换内容 |
|------|----------|
| `{{date}}` | 当前日期 |
| `{{time}}` | 当前时间 |
| `{{title}}` | 笔记标题 |
| `{{clipboard}}` | 剪贴板内容 |

## 10. 表格

### Markdown 表格

手动输入 Markdown 表格或使用 `/table` 斜杠命令：

```markdown
| 表头 1 | 表头 2 |
|--------|--------|
| 单元格 1 | 单元格 2 |
```

### 表格工具栏

当光标在表格内时，会出现浮动工具栏：

- 添加/删除行和列
- 列对齐（左对齐、居中、右对齐）
- 使用 `Tab` / `Shift+Tab` 在单元格间导航

### 文档编辑器中的表格

文档编辑器（TipTap）提供可视化表格体验：

- 点击表格按钮插入
- 使用下拉菜单管理行/列
- 拖拽边框调整列宽

## 11. 任务

Constellation 支持笔记中的任务复选框：


## 19. 认知引擎

认知引擎是 Constellation 内置的智能系统，用于分析笔记并发现想法之间隐藏的模式和关联。其核心理念：

> "数据的多少并不重要。重要的不是你存储了多少来源，而是你如何从中提炼知识，并将其连接成一个有意义的统一认知。"

认知引擎由九个集成工具组成：类型链接、知识层级、成熟度周期、张力检测器、来源链、外化引擎、复习脉搏、路径和多镜头视图。

---

### 17.1 类型链接

#### 是什么？

类型链接是携带关系类型的维基链接，用于描述两个笔记之间的关系性质。不是简单地写 `[[笔记]]`，而是写 `[[笔记|关系类型]]` 来表达连接的本质——它是派生的吗？矛盾的？扩展的？

#### 为什么重要？

普通链接只说"这里有连接"，却不说是什么连接。类型链接将你的笔记网络从一堆引用转变为真正的知识地图，使思维结构、依赖关系和推理链条清晰可见。

#### 如何使用

1. 在编辑器中打开笔记
2. 写带关系类型的维基链接：`[[目标笔记|derives-from]]`
3. 支持的类型：`derives-from`（派生自）、`supports`（支持）、`contradicts`（矛盾）、`extends`（扩展）、`exemplifies`（例证）、`questions`（质疑）
4. 也可以通过右侧边栏的笔记属性添加类型

#### 在哪里可见？

- **星图视图（GraphMind）**：节点之间带颜色和标签的连线
- **右侧边栏**："反向链接"标签页中显示每个链接的类型
- **来源标签页**：用于构建知识谱系树

---

### 17.2 知识层级

#### 是什么？

认知引擎自动将每个笔记分类到八个知识层级之一：快照、日志、主题、地图、框架、原则、信念、作品。分类基于笔记的结构、内容和链接数量。

#### 为什么重要？

了解每个笔记的类型揭示了你知识库中的知识平衡。你的大部分笔记是转瞬即逝的快照，还是已经演化为原则和框架？对内容本质的这种觉察，是从单纯的信息积累走向真正知识构建的第一步。

#### 如何使用

1. 分类自动进行——无需任何操作
2. 若要覆盖自动分类，在前置数据中添加 `stratum` 属性：
   ```yaml
   ---
   stratum: framework
   ---
   ```
3. 可用值：`snapshot`、`log`、`topic`、`map`、`framework`、`principle`、`conviction`、`artifact`

#### 在哪里可见？

- **右侧边栏**：笔记属性中的"层级"项
- **星图视图**：根据层级显示不同颜色的节点
- **设置 > 认知引擎**：启用/禁用自动分类

---

### 17.3 成熟度周期

#### 是什么？

引擎以四个阶段跟踪每个笔记的成熟度：**种子** → **幼苗** → **常青** → **经典**。每个笔记从种子开始，随着内容、链接和审查的增加逐步成长。

#### 为什么重要？

成熟度区分了原始想法和精炼知识。今天的种子如果得到足够关注，明天就可能成为参考经典。成熟度追踪帮助你识别值得进一步发展和关注的笔记。

#### 如何使用

1. 成熟度根据以下因素自动变化：字数、入链和出链数量、最后修改日期
2. 若要手动设置成熟度，在前置数据中添加 `maturity` 属性：
   ```yaml
   ---
   maturity: evergreen
   ---
   ```
3. 可用值：`seed`（种子）、`sapling`（幼苗）、`evergreen`（常青）、`canonical`（经典）

#### 在哪里可见？

- **右侧边栏**：标题旁的图标显示当前成熟阶段
- **星图视图**：以节点大小表示——笔记越成熟，节点越大
- **设置 > 认知引擎**：启用/禁用成熟度追踪

---

### 17.4 张力检测器

#### 是什么？

张力检测器检查关联笔记，当两个或多个笔记之间的主张或结论相互矛盾时向你发出警告。它依赖于 `contradicts` 类型链接的分析以及笔记间的主题相似性。

#### 为什么重要？

张力不一定是错误——它们是深度思考的邀请。当知识库中两个想法相互矛盾时，意味着你的理解在进化，或者存在值得探索的复杂性。检测张力防止你在不知不觉中在矛盾的基础上构建知识。

#### 如何使用

1. 在矛盾的笔记之间添加 `contradicts` 类型链接：`[[其他笔记|contradicts]]`
2. 引擎也会通过内容分析检测隐含的张力
3. 从侧边栏查看检测到的张力列表

#### 在哪里可见？

- **右侧边栏**：检测到矛盾时的"张力"标签页
- **星图视图**：矛盾节点之间的红色虚线
- **通知面板**：检测到新张力时的提醒

---

### 17.5 来源链

#### 是什么？

来源链追踪每个想法的起源——它从哪里来，由什么派生。使用 `[[笔记|derives-from]]` 链接构建谱系树，展示知识从原始来源到当前表述的演化路径。

#### 为什么重要？

了解想法的来源区分了接收的知识（来自书籍、文章、讲座）和发现的知识（你自己的结论和思考）。对知识源头的这种觉察帮助你评估想法的可靠性，并理解你的思维是如何随时间形成的。

#### 如何使用

1. 创建派生自某来源的笔记时添加链接：`[[原始来源|derives-from]]`
2. 可以构建多层级链条：笔记 ← 派生自 ← 派生自 ← 原始来源
3. 在前置数据中添加 `source-type: received` 来分类外部来源

#### 在哪里可见？

- **右侧边栏**："来源"标签页显示完整谱系树
- **星图视图**：链接上箭头的方向（从来源指向派生）
- **笔记属性**：基于来源链的"接收的"或"发现的"分类

### 17.6 外化引擎

#### 是什么？

一个渐进式形式化管道，追踪笔记从原始捕获到结晶洞察的成熟过程。每个笔记可以被分配四个阶段之一：

| 阶段 | 图标 | 含义 |
|------|------|------|
| 闪念 | 🌱 | 快速捕获，一闪而过的想法 |
| 文献 | 📖 | 用自己的话从来源重写 |
| 永久 | 🔗 | 原子化想法，一个概念，连接到你的图谱 |
| 综合 | ✨ | 结合多个永久笔记的原创洞察 |

#### 为什么重要？

大多数应用对所有笔记一视同仁。外化引擎使区别可见——你可以一目了然地看到你的库中有多少是原始捕获，有多少是真正的理解。

#### 如何使用

1. 在面包屑栏（编辑器上方），使用阶段下拉菜单选择一个阶段。
2. 或展开属性并使用那里的阶段下拉菜单。两者都会与文件树即时同步。
3. 要提升笔记，将下拉菜单从一个阶段更改为下一个。在专注模式下，点击底部的"提升为永久"。
4. 要移除阶段，从下拉菜单中选择"— 阶段 —"。

#### 在哪里可见？

- **面包屑栏**：带有表情符号 + 阶段名称的下拉菜单
- **属性面板**：当 `stage` 属性存在时显示下拉菜单
- **文件树**：笔记名称旁的表情符号图标
- **专注模式页脚**："提升为永久"按钮

### 17.7 复习脉搏

#### 这是什么？

复习脉搏是一个间隔重现系统，以递增的间隔将笔记重新带回您的注意力：最后一次复习后1天、3天、7天、14天、30天。它还监控带有 `#assumption` 或 `#model` 标签的笔记作为心智模型检查点，并维护一个"从未复习"队列，用于捕获但从未重新访问的笔记。

#### 为什么重要？

知识在没有重新访问的情况下会衰退。您今天写了一条笔记，三周后就忘记了它的存在。间隔重复是认知科学中对抗这种衰退最成熟的技术。复习脉搏将这一原理应用于您的实际笔记。

#### 如何使用

1. 点击左侧边栏中的**复习脉搏**标签页。您将看到三个部分：待复习、心智模型检查点（`#assumption` / `#model`）、和从未复习。
2. 点击任何笔记打开并阅读。
3. 选择三个操作之一：
   - **已复习**（勾选标记）— 按下一个间隔安排下次复习（1 → 3 → 7 → 14 → 30天）。
   - **推迟7天**（眼睛图标）— 不推进间隔，将笔记推迟7天。
   - **移除**（归档图标）— 永久从复习队列中移除笔记。
4. 打开命令面板输入 "Review due notes" 直接跳转到待复习笔记。

#### 在哪里可见？

- **左侧边栏**：复习脉搏标签页，带有待复习笔记数量的徽章
- **命令面板**："Review due notes" 命令用于快速访问

### 17.8 路径

#### 这是什么？

路径是笔记的命名有序序列——就像书的章节或知识导览的站点。通过在笔记的 frontmatter 中添加 `trail: true`，然后在笔记正文中按顺序列出维基链接来定义。

#### 为什么重要？

知识并不总是一张网。有时它是一条路径——学习序列、论证推进、叙事。路径明确地捕获这种顺序，为您的非线性库添加线性维度。

#### 如何使用

1. 创建一个 frontmatter 中包含 `trail: true` 的新笔记。
2. 在笔记正文中，按所需顺序列出维基链接。
3. 当打开属于某条路径的笔记时，面包屑栏显示路径名称和位置的指示器（例如"我的路径 2/5"）。箭头按钮可导航至上一条和下一条笔记。
4. 打开命令面板输入 "Open Trail" 查看所有路径。

#### 在哪里可见？

- **面包屑栏**：带有名称、位置和导航箭头的路径指示器
- **命令面板**："Open Trail" 命令列出所有路径

### 17.9 多镜头视图

#### 这是什么？

多镜头视图让您通过不同的分类方案查看您的库——无需更改文件夹结构或复制笔记。"镜头"是基于属性或标签重新组织笔记的虚拟分组。内置镜头："按阶段"（瞬时/文献/永久/综合）和"按主题"（按标签分组）。可以在设置中创建自定义镜头。

#### 为什么重要？

文件夹结构强制使用单一层次结构，但知识不适合放在一棵树中。多镜头视图让您在不移动文件的情况下在不同视角之间切换。相同的笔记，通过不同的组织镜头查看。

#### 如何使用

1. 在侧边栏中，找到文件树顶部的**镜头下拉菜单**（默认为"文件夹"）。
2. 选择镜头："按阶段"、"按主题"或自定义镜头。侧边栏立即重新组织。
3. 选择"文件夹"返回默认文件树。
4. 创建自定义镜头：打开**设置 > 知识管理**，点击**创建镜头**，命名并选择用于分组的 frontmatter 属性。
5. 或使用命令面板：输入 "Create Lens"。

#### 在哪里可见？

- **侧边栏下拉菜单**：文件树顶部的镜头选择器
- **设置 > 知识管理**：创建、编辑和删除自定义镜头
- **命令面板**："Create Lens" 命令

### 认知引擎设置

认知引擎的所有工具可在 **设置 > 认知引擎** 中配置：

- **层级分类** — 启用或禁用自动分类
- **成熟度追踪** — 启用或禁用成熟度生命周期追踪
- **类型链接** — 调整链接检测灵敏度阈值（0.0 – 1.0）
- **张力检测器** — 启用或禁用自动张力检测
- **手动覆盖** — 在前置数据中添加 `stratum` 和 `maturity` 属性以覆盖自动分类
