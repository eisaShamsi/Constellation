# 用阿拉伯语与混合文字写作

Constellation 的编辑器从底层就是为多语言而生的：阿拉伯语、希伯来语、波斯语、乌尔都语以及双语笔记并非附加功能——光标、选区以及每个段落的方向都遵循与 Windows 版 Microsoft Word 相同的规则，因此您的肌肉记忆可以直接沿用。本主题涵盖关于*书写*从右到左文本及混合文本的方方面面：光标如何移动，如何按词、句、行、段落或整屏选择，以及在自动方向检测不符合预期时如何强制指定段落方向。

（关于 Constellation 如何*理解*阿拉伯语——词根、搜索与形态引擎——请参阅**阿拉伯语引擎**（Arabic Engine）主题。）

---

## 光标如何移动

- **方向键按文本的阅读顺序逐字符移动**——而不是按屏幕上的位置移动。在纯阿拉伯语或纯英语文本中，效果与您按下的箭头完全一致。而在阿拉伯语与英语的接缝处（比如一句阿拉伯语中夹着一个英文单词），光标会按书写顺序逐字符前进，并在接缝处明显地"跳"过去——这个跳跃是正确的行为，正是它避免了光标在交界处卡住的感觉。
- **Home** 移到该行的阅读**起点**——阿拉伯语行的*右*端。**End** 移到阅读**终点**——*左*端。配合 **Shift** 按下任一键，即可选择到相应一端。
- 在阿拉伯语行上按 **Enter**，新行的光标出现在**右侧**——自然的书写位置。
- **阿拉伯语行末的拉丁单词**会保持清晰、稳定的光标位置，而不会迷失方向。

以上每条规则在标准编辑器、专注模式和冲突合并视图中的表现完全一致。

## 按单位选择

任何语言、任何混排之下，每种文本单位都有快捷选择方式：

| 单位 | 操作 |
|---|---|
| **词** | 双击 |
| **句子** | 在句中任意位置 **Ctrl+单击**——或将光标置于句内后按 **Ctrl+Shift+S** |
| **行** | **Ctrl+L** |
| **段落** | **Ctrl+Shift+L**——或三击 |
| **一屏** | **Shift+Page Down** / **Shift+Page Up** |
| **全部** | **Ctrl+A** |

值得了解的细节：

- **句子选择理解阿拉伯语标点。**句子在 **؟ ۔ !** 和句号处结束——而阿拉伯语分号 **؛** 是句*内*的停顿，因此选择会正确地越过它继续。像 3.14 这样的小数永远不会把句子截断。
- **段落**指上下各有一个空行的文本块——与 Word 完全一致。行选择与段落选择紧贴文本：在阿拉伯语行上，高亮止于文字本身，而不会延伸到左侧的空白区域。
- Ctrl+单击*取代*了该键原先的"添加光标"手势——现在这一点击执行的是句子选择。

## 按段落移动

- **Ctrl+↓** 跳到**下一**段的开头；**Ctrl+↑** 跳到**当前**段的开头（再按一次跳到上一段）。加上 **Shift** 可在跳转的同时逐段选择。这是 Word 的惯例，"下一段"就是页面上更靠下的那一段——在阿拉伯语、英语和混合笔记中的行为完全一致。

## 强制指定段落方向

Constellation 会根据每一行开头的字符自动检测该行的方向。通常这个结果恰到好处——但有时您想推翻它：比如一段以英文品牌名开头的阿拉伯语段落，或一段您希望按从右到左阅读的以英文为主的段落。

**按下并松开键盘右侧的 Ctrl+Shift** → 光标所在的段落变为 **100% 从右到左**。
**按下并松开键盘左侧的 Ctrl+Shift** → **100% 从左到右**。

这是 Microsoft Word 的惯例。需要了解的几点：

- **它在松开按键时触发**——同时按下这两个键，松开，中间不要按任何其他键。正因如此，Ctrl+Shift+S、Ctrl+Shift+L 以及其他所有快捷键都不受影响：一旦有第三个键加入，方向切换便会自动让位。
- **它是硬性覆盖**——它胜过自动检测，并作用于整个段落（或选区触及的每一个段落）。
- **它以一个不可见的方向字符保存在文本内部**，因此关闭笔记、重启应用、同步之后都依然有效——即使把文本粘贴到 Word 或 Obsidian 中，它也会随文本一起迁移。
- **一次 Ctrl+Z 即可撤销。**连续按同一侧两次不会产生额外效果。
- **Markdown 安然无恙。**列表还是列表，标题还是标题，引用还是引用。代码块、表格和水平分割线被有意排除在外。以 #标签*开头*的行保留其自动方向（在那里强制加标记会破坏标签）——段落的其余部分仍会翻转。

## 字体与界面

- **文字字体**：在**设置 → 语言**中独立配置阿拉伯语、希伯来语和 CJK 字体。
- **文字工具栏**：特定语言的符号与标点按钮。
- **变音符号高亮**：在编辑器工具栏中切换阿拉伯语变音符号（Tashkeel）高亮。
- 将阿拉伯语或希伯来语选为界面语言时，整个应用会翻转为 RTL 布局。

---

## 术语表

- **阅读顺序**——字符被书写和阅读的顺序，与它们在屏幕上的位置无关。
- **接缝**——同一行中从右到左文本段与从左到右文本段之间的交界。
- **硬性覆盖**——您显式设定的方向，胜过基于首字母的自动检测。
- **方向标记**——把您的覆盖保存在文本内部的不可见字符（RLM/LRM）。
