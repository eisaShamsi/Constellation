# Constellation Nervous System (CNS)

## 这是什么?

**Constellation Nervous System** 是您宇宙的**连接遍历**视图。当 Constellation Sight 显示笔记的*形态*(层级 × 时间 × 通道编码)时,CNS 显示*接线* — 连接它们的类型化链接图以及该图中隐藏的结构模式。

它回答:**"我宇宙中的想法是如何连接的,差距在哪里?"**

视图围绕四个分析表面构建:
- **宇宙健康** — 您知识连接、平衡和模块化程度的整体和按指标的分数。
- **社区** — 密集互联笔记的组("意识形态集群")。
- **主要桥梁** — 链接其他分离社区的少数笔记("承载连接器")。
- **盲点** — 您期望连接但尚未拥有的结构差距。

名称"Nervous System"是解剖学的:神经是连接路径,在生物体的远端部分之间传递信号。CNS 以相同方式对待您的类型化链接图。

## 为什么重要?

大多数笔记应用将链接视为管道(从这里跳到那里)。Constellation 将它们视为**知识架构**:

- 有许多传入链接的笔记是**承载的** — 许多想法依赖它。
- 桥接两个社区的笔记是**综合点**。
- 内部链接弱的社区是**脆弱**的。
- "盲点"是结构应该有连接但没有的地方 — 一个值得探索的假设。

## 如何打开

1. 点击 Constellation 左侧停靠栏中的**神经元图标**(小的分支神经细胞形状 — 中间细胞体,有三个树突分支和突触末端)。
2. CNS 以全窗覆盖、重力井风格打开 — 力导向图,其中每个笔记是节点,每个类型化链接是边。
3. 关闭:点击顶部的 **(×)**,或按 **Esc**。

## 您看到什么

### 宇宙健康卡

总结面板显示您宇宙的整体连接健康,带有组合分数的金色圆形(例如 **91 / 100**)和四个指标:

- **Modularity** — 您的笔记如何整洁地聚类到不同社区。
- **Dominance** — 一个社区是否主导宇宙。
- **Entropy** — 社区规模的多样性。
- **Connectivity** — 每笔记的平均链接。

每个指标都有彩色状态药丸:**HEALTHY**(绿色)/ **CAUTION**(黄色)/ **IMBALANCED**(红色)。

### 重力井

主可视化:笔记浮动为节点,链接将它们拉到一起,排斥将它们推开。社区自组织为集群。

- **节点大小** = 链接计数。
- **节点颜色** = 社区成员资格。
- **边** = 两个笔记之间的类型化链接。

### 主要桥梁

链接最多不同社区的笔记列表 — 这些是您的综合点。

### 社区

检测到的笔记集群列表。

### 盲点(结构差距)

建议的缺失连接 — 算法认为应该链接但未链接的笔记对。

## 交互

CNS 使用**单击-预览 / 双击-打开**模式(与 Sight 的单击-打开不同):

| 手势 | 效果 |
|---|---|
| **单击节点** | 选择它。右侧面板滑入,带标题、社区、中心性排名、传入/传出链接。笔记**不会**打开。 |
| **双击节点** | 在编辑器中打开笔记。出现 **"Return to CNS"** 按钮。 |
| **悬停节点** | 带标题的工具提示。 |
| **点击空白区域** | 清除选择。 |
| **鼠标滚轮** | 缩放 in/out。 |
| **点击 + 拖动** | 平移。 |
| **点击列表中的社区** | 在井中突出显示社区的笔记。 |
| **点击主要桥梁条目** | 聚焦于桥梁笔记。 |
| **Esc** | 关闭 CNS。 |

单击预览是有意的:它让您扫描许多笔记的详细信息(和它们的连接),而无需承诺在编辑器中打开每一个。

## 何时 CNS 最有用

- **审计您的连接密度** — Universe Health 提供一目了然的读数。
- **找到您的综合点** — Top Bridges 显示做最多架构工作的笔记。
- **发现您不知道存在的社区** — 从图中出现的集群。
- **修补盲点** — 当图建议两个笔记应该链接但未链接时。
- **规划重组** — 社区自然映射到文件夹结构。

## CNS vs Sight — 何时使用哪个

- **Sight** = "我的宇宙如何**形状**?"空间 / 类别分析。
- **CNS** = "我的宇宙如何**连接**?"网络 / 拓扑分析。

它们是互补的:Sight 阅读表面;CNS 阅读下面的接线。

## 相关表面

- **Constellation Sight** — 姐妹可视化(停靠栏中的眼睛图标)。
- **Sky View** — 也是图视图,但构建方式不同。
- **Backlinks / Outgoing Links 面板** — 每笔记连接列表。
