# Constellation Nervous System (CNS)

## 这是什么？

Constellation Nervous System（界面中显示为"知识神经系统"）是**你宇宙的接线图**。它回答一个问题：

> **"我的思考是什么形状——它的区域、它的桥梁、它的沉默之处？"**

它对你的整张链接图施以网络分析，并通过五个登记册来解读：

- **区域** —— 你的链接实际形成的街区（由分析发现，而非由文件夹宣告）。
- **桥梁** —— 撑住整个结构的笔记：剪断它们，区域便分崩离析。
- **枢纽** —— 你连接最多的笔记（入链最多）。
- **盲点** —— 各自发育良好、本该相触却未相触的区域对，每对都附有建议的桥梁笔记。
- **结构凝聚度** —— 一个 0–100 的综合分，衡量整张接线的总体成形程度。

CNS 只读**结构**——谁连着谁。它从不读流动（一条链接被走过多少次、长得多重、主张有多安定）：那是它的同胞——**循环系统（CCS）**——的工作。两者同属一副解剖：CNS 是神经，CCS 是血液。合在一起，它们才完整回答"连接"之问。

## 为什么重要？

Constellation 里其他所有连接表面——反向链接、出链、循环系统、知识健康——记录的都是你**已经建立**的连接。盲点登记册是唯一指向你**尚未建立**的连接的仪器：你思考中的两个区域，各自发育良好，彼此之间却没有连接组织。综合，恰恰发生在那条边界上。

而且只有 CNS 能让你看见你*宣告的*秩序（库与文件夹）和*被发现的*秩序（你的实际链接所形成的区域）之间的差异。当一个库里容纳了好几个区域，说明你在其中的思考已分化成多个主题；当一个区域横跨多个库，说明你的某个主题散落在你的归档之中。

## 如何打开

1. 点击左侧停靠栏中的 **CNS 按钮**（分叉的神经细胞图标）——它就在循环系统的脉搏图标旁边。
2. 重力井全窗打开。在大型宇宙上，分析需要片刻；窗口保持响应。
3. 关闭：右上角的 **×**，或按 **Esc**。

你也可以从 CCS 抵达这里——它的页眉带有一个 **CNS 按钮**（"知识神经系统 →"）——也可以原路返回：CNS 的面板里有一行 **"循环 → 循环系统"**。

## 重力井

布局本身就是解读——其中没有任何装饰成分：

- **离中心的距离 = 结构中心性。** 你的接线所途经的笔记沉在井的深处；边缘的思考停在井沿。
- **角度扇区 = 你自己的组织方式。** 每个库占据圆周的一个扇片。位置永远跟随*你的*秩序——分析从不挪动任何一篇笔记。
- **节点颜色 = 库** ——直到你切换**区域透镜**（见下文），节点才改按所属区域上色。颜色是透镜；位置永不改变。
- **静止时的安宁。** 链接保持隐藏，直到你召唤：悬停或点击一篇笔记点亮它的连接，或运行一次搜索。
- 页眉显示节点数与链接数，并附一行小字——*"已解析连接 · 当前宇宙"*——因为 CNS 统计的是图上现存笔记之间得以解析的连接，而 CCS 和知识健康统计的是每一条已记录的链接记录。两个数字都是真的；它们回答的是不同的问题。

## 结构凝聚度

面板顶部的卡片是**结构凝聚度**评分（0–100）——整张接线的总体成形程度——其四种成分一目了然：

- **模块性** —— 你的笔记聚成彼此分明的区域有多干净利落。
- **支配度** —— 最大的区域吞掉了宇宙的多少（越低越健康）。
- **熵** —— 你的思考在各区域间铺开得有多均匀。
- **链接/笔记** —— 平均连接度。

## 区域透镜

页眉的三圆圈按钮切换**区域透镜**：每个节点的颜色从库色换成区域色，图例列出最大的几个区域，附其被发现的名字和规模。关掉后库色回归。无论开关，位置都不移动。

## 面板登记册

仪表格按钮打开分析面板：

- **概览** —— 凝聚度卡片，笔记/链接/孤立计数，以及按库的分布。
- **循环 → 循环系统** —— 把流动侧的一切（链接类型、置信度、冷却、生命周期）移交给 CCS 的入口。
- **区域** —— 被发现的街区，从大到小排列，每个区域标注规模与主导成熟度。**悬停**某一行，井中该区域之外的一切都褪成黑白。**点击**某一行将它**钉住**：在你工作期间该区域保持点亮——你可以照常在其中悬停、点击笔记（被选中笔记的连接即使跨入其他区域也保留颜色——这些跨越恰恰最值得一看）。再次点击该行取消钉住。
- **顶级桥梁** —— 中心性最高的笔记。点击一条即可选中并居中它。
- **枢纽** —— 按入链计连接最多的笔记。这是它们唯一的家（旧的知识健康卡片已退役至此）。
- **盲点** —— 没有连接组织的区域对，写作*区域 A ↮ 区域 B*，每对最多附三篇**建议的桥梁**笔记，呈可点击的小标签。空列表是好消息。

## 交互

| 手势 | 效果 |
|---|---|
| **悬停节点** | 工具提示显示笔记标题；它的链接亮起。 |
| **单击节点** | 选中并点亮它的邻域——不会打开任何东西。 |
| **双击节点** | 在编辑器中打开该笔记。 |
| **点击空白处** | 清除选择。 |
| **鼠标滚轮** | 缩放。**拖动**平移。四角按钮在任何窗口尺寸下**适应屏幕**。 |
| **悬停 / 点击"区域"中的一行** | 其余部分褪成黑白 / 钉住这层减淡。 |
| **点击桥梁小标签或"枢纽"/"顶级桥梁"行** | 选中该笔记并在井中居中。 |
| **Esc** | 关闭 CNS。 |

## CNS 何时最有用

- **综合之前** —— 打开"盲点"，问一问哪道缺口该由你去架桥。
- **审计架构** —— "顶级桥梁"与"枢纽"显示哪些笔记承载着结构；"结构凝聚度"告诉你整体是一具身体，还是散落的群岛。
- **用思考校验归档** —— 让区域透镜对照库扇区。

## CNS 与它的邻居

- **Sky View** —— 万物的空间*图景*（全部视觉词汇，自由探索）。CNS 是*仪器*：它的布局本身编码着分析。Sky View 给你看天空；CNS 告诉你这片天空在结构上意味着什么。
- **CCS** —— 流动侧（重量、走访、冷却、确信、生命周期）。CNS 从不显示流动；CCS 从不显示拓扑。
- **知识健康** —— 一眼可读的计数卡片。CNS 是这些计数所栖身的接线。
- **健康标签页（右侧边栏）** —— 按库的张力*清单*（矛盾对、孤立笔记、标签簇缺口）。CNS 的盲点是图层面的区域几何——另一种互补的缺口读法。
- **360.3D** —— 单篇笔记的连接签名。CNS 是整个宇宙。
