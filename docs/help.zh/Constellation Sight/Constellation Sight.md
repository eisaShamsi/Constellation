# Constellation Sight

## 这是什么?

**Constellation Sight** 是您知识宇宙的**诊断工具**。中央**锚定穹顶**显示每条笔记按**层级**(思考深度)和**时间**(写作时间)定位,旁边的四个**迷你穹顶**通过不同通道重新编码同一宇宙:**信心 (Confidence)**、**阶段 (Stage)**、**行动 (Acts)**、**来源 (Provenance)**。

它通过五个互补镜头回答一个问题:**"我的认知内容是如何塑造和组织的?"**

将光标悬停在任何穹顶中的任何星星上,同一笔记会在所有五个表面上亮起 — 星星周围的金色环、侧边栏中匹配标签的金色色调。点击侧边栏标签,所有五个视图都会缩小。Shift+点击阶段迷你穹顶中的星星,宇宙立即过滤到该生命周期阶段。点击任何迷你穹顶的空白区域,它会"晋升"到主插槽的完整尺寸,而之前的主穹顶降级到腾出的迷你插槽。

## 为什么重要?

大多数笔记应用显示您写了什么。Constellation Sight 显示您所知的**形状**。

- 您的思考**集中**在哪里?(锚定中的密度梯度)
- 哪些仍处于**早期阶段** vs **稳定基础**?(阶段迷你的颜色梯度)
- 哪些笔记**承载** vs **孤立**?(行动迷你的大小编码)
- 每个想法来自哪里 — 您自己的思考、阅读、听闻、传统?(来源迷你的扇区布局)
- 您对结论有多**自信**?(信心迷你的不透明度梯度)

位于锚定中心的笔记(高连接性 → 承载)但在阶段迷你中为青色(`spark` — 刚刚激发)告诉您一些诊断性的内容:一个尚未成熟的承载理念。

## 如何打开

1. 点击 Constellation 左边停靠栏中的**眼睛图标**。
2. 锚定穹顶在大多数宇宙中 2–5 秒内渲染。
3. 关闭:点击右上角的 **(×)**,或按 **Esc**。

## 您看到什么

### 标题栏

Sight 视图顶部,从左到右:
- **"Constellation Sight"** — 标题。
- **"v6.1 — Coordinated Views (Phase 2)"** — 版本副标题。
- **金色"X / Y notes"徽章** — 仅在过滤器活动时可见。
- **金色小型大写"EXTENDED"徽章** — 仅在扩展视图打开时可见。
- **"Reset View"按钮** — 仅在布局已更改时可见。
- **(×)** 关闭按钮 — 始终存在。

### 锚定穹顶(主插槽)

中央的大型奶油色深底穹顶:
- **层级环** — 5 个同心圆。最内 = 您最基础的笔记;外缘 = 您最新的火花。
- **日历边** — 周围 12 个月份标签。
- **层级标签** — 顶部斜体文字。
- **星星** — 每条笔记绘制为小奶油色点,按层级 × 时间定位。
- **连接线** — 笔记之间的类型化链接边,低不透明度位于星星下方。
- **悬停环** — 光标悬停的任何星星周围的金色圆圈。

### 四个迷你穹顶

右侧,2×2 网格。默认隐藏;通过 **Ctrl+D**(仅会话)或 **Ctrl+Shift+D**(持久 — 见扩展视图)显示。

每个迷你通过一种编码渲染相同宇宙:

1. **CONFIDENCE — 不透明度。** 您更自信的笔记更亮;尝试性笔记淡化。
2. **STAGE — 颜色(全盘)。** 按生命周期阶段的分类颜色:
   - **青色** = `spark`(刚激发的想法)
   - **橙色** = `birth`(正在成形)
   - **紫色** = `growth`(主动运动中)
   - **绿色** = `maturity`(完全成形)
   - **黄色** = `renewal`(最近重访)
   - **灰色** = `dormancy` / `archival`(非活动 / 关闭)
3. **ACTS — 大小(前十分位)。** 链接数前 10% 的笔记 = 较大点;其余保持小。
4. **PROVENANCE — 5 个扇区。** 星星重新定位到 5 个角度扇区:**Self / Read / Heard / Reasoned / Tradition**。

### 降级的锚定(当迷你被晋升时)

如果您将任何迷你晋升到主插槽,锚定下降到腾出的迷你插槽。在那里它渲染为**中性奶油色点**,标题为 **"UNIVERSE — primary view"**。

### 切面侧边栏(左边缘)

可折叠面板,具有 **6 个切面过滤器组**,每个显示带实时计数的类别:

- **Folder** — 文件夹层级
- **Library** — 库名称
- **Stratum** — Foundation / Roots / Trunk / Branches / Twigs / Edge of Knowing
- **Confidence** — Hypothesis / Evidence / Established / Contested
- **Stage** — Spark / Birth / Growth / Maturity / Dormancy / Renewal / Archival
- **Provenance** — Self / Read / Heard / Reasoned / Tradition

点击边缘的 **▶** 展开。点击任何标签切换为过滤器。

## 交互

| 手势 | 效果 |
|---|---|
| **悬停星星** | 所有 5 个表面上的同一星星周围金色环 + 侧边栏中匹配标签的金色色调。 |
| **普通点击星星** | 在编辑器中打开笔记。出现 **"Return to Sight"** 按钮。 |
| **Shift+点击星星** 在 Stage / Confidence / Provenance 迷你中 | 切换该星星类别的过滤器。 |
| **Shift+点击星星** 在 Acts 或锚定上 | 无效果。 |
| **点击迷你的空白区域** | 该迷你晋升到主插槽。 |
| **滚轮缩放(主)** | 朝向光标缩放。范围:0.5× 到 24×。 |
| **点击+拖动空白区域** | 平移视图。 |
| **Ctrl+0 / Cmd+0** | 重置缩放 + 平移。 |
| **Ctrl+D / Cmd+D** | 切换迷你穹顶可见性 — **仅会话**。 |
| **Ctrl+Shift+D / Cmd+Shift+D** | 切换**扩展视图** — 持久。 |
| **点击侧边栏标签** | 在过滤器集中切换切面类别。 |
| **Reset View 按钮** | 返回锚定主在缩放 1.0。 |
| **Esc** | 关闭 Sight。 |

## 幽灵模式 — 从穹顶多选

当任何过滤器活动时,不匹配的星星保持可见但以**低不透明度(15%)**渲染而不是消失。这意味着:

- 您仍然可以看到不匹配星星所在的位置。
- 可以悬停它们(金色环出现)。
- 可以 **Shift+点击将它们的类别添加到过滤器**。

## 密度模式

当可见(匹配)星星计数超过密度阈值(默认 **5,000**)时,迷你穹顶切换到**感知密度渲染**。

## 扩展视图

按 **Ctrl+Shift+D**(或 Mac 上的 **Cmd+Shift+D**)切换"扩展视图" — 打开时,迷你穹顶在每次打开 Sight 时默认可见。状态在 Sight 关闭、应用重启和系统重启之间持久。

## 何时 Sight 最有用

- **审计知识形状** — 写作会话后打开 Sight。
- **找到盲点** — 笔记少的穹顶扇区可能是要探索的领域。
- **发现承载弱点** — 中心位置的早期阶段颜色笔记告诉您依赖未成熟的事物。
- **过滤和检查** — Shift+点击缩小宇宙;晋升迷你以完整尺寸研究通道。
- **追踪认知来源** — 晋升 Provenance 以查看您的知识如何来源。
