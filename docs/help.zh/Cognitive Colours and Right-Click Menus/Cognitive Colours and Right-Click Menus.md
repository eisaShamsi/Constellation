# 认知色彩与右键菜单

本主题涵盖一同到来的两件事：**两个新的样式设计器类别** — **属性**（重新设计前置数据中那些小标签的样式）和 **认知色彩**（每种认知状态一个颜色控件，在整个应用中共享）— 以及把恰当操作放到一键之遥的**全应用范围右键菜单**，作用于笔记正文、前置数据的某个属性，以及搜索结果。

> 样式设计器是你从**设置 → 外观 → "✦ 打开样式设计器"**，或从设置侧边栏中它自己的**样式设计器**选项卡打开的全页设计工作室。下面两个类别位于左侧*界面（Surfaces）*列表中，与界面、编辑器、链接等并列。关于设计器的通用行为 — 检视（Inspect）、Keep（保留）/ Discard（丢弃）/ Reset（重置）、已保存样式 — 见 [[Appearance and Themes]]。

---

## 样式设计器 → 属性

**属性**类别重新设计那些出现在一篇笔记**前置数据**（它的 YAML 属性区块）里的小标签的样式 — 即你在属性面板和笔记顶部为 `tags`、`aliases` 之类看到的小药丸。在此之前这些是固定的；现在它们由你来塑形。

打开**样式设计器**，在左侧列表中单击**属性**。中央显示属性药丸的实时预览；单击右侧的某个控件，预览会随你的编辑而重新呈现。两个元素：

### 属性标签

普通的前置数据标签药丸（例如 `tags` 列表中的每个值）。四个控件：

- **标签背景** — 药丸的填充颜色。
- **标签文字** — 药丸内文字的颜色。
- **标签圆角** — 药丸的圆角程度（0 px = 方角，最大到 20 px = 完全圆角）。
- **高度** — 药丸的高度，以像素计（14–32 px）。

### 分类徽章

用于分类法式（taxonomy）值的药丸。三个控件：

- **背景** — 药丸的填充颜色。
- **文字** — 药丸内的文字颜色。
- **圆角** — 圆角程度（0–20 px）。

> **在你触碰某个控件之前，什么都不会变。** 每个值都从你今天看到的样子精确开始，因此在你刻意挑选一种颜色或拖动一个滑块之前，属性类别会让你的笔记看起来完全一致。单击 **Keep（保留）** 即可为此宇宙保存这套外观。

## 样式设计器 → 认知色彩

Constellation 用颜色描绘你的**认知词汇** — 一篇笔记的*成熟度*、一条链接的*置信度*、一个想法*来自何处*、它处在生命的哪个*阶段*，以及一条搜索结果*为何*匹配。麻烦在于，过去这些颜色在每个界面上都是各自决定的：一篇"枯萎"的笔记在文件树里可能是一种绿色，而在天空视图里又是另一种绿色。**认知色彩**类别给你**每种状态一个颜色控件**，凡是显示该状态的地方都会随之而变。

打开**样式设计器**，在左侧列表中单击**认知色彩**。中央显示你正在编辑的那一组的颜色图例；在右侧挑选一个控件，图例会实时更新。共有五组。

### 成熟度 — 一个想法有多稳固

五种状态，从最年轻到最稳固：**种子（Seed）**、**幼苗（Sapling）**、**常青（Evergreen）**、**权威（Canonical）**、**枯萎（Wilting）**。每种得到一个颜色，由文件树的笔记圆点、选项卡的成熟度标记，以及笔记检视器使用。

### 置信度 — 一条链接有多确定

四种状态：**假设（Hypothesis）**、**证据（Evidence）**、**已确立（Established）**、**存争议（Contested）**。每种一个颜色。

### 来源 — 一个想法来自何处

四种状态：**接收（Received）**（取自某个来源）、**发现（Discovered）**（你自己的）、**混合（Mixed）**，以及**无（None）**。每种一个颜色。

### 阶段 — 一篇笔记处在其生命的哪个位置

六种状态，按顺序：**萌发（Spark）**、**诞生（Birth）**、**成长（Growth）**、**成熟（Maturity）**、**休眠（Dormancy）**、**归档（Archival）**。每种一个颜色。

### 匹配类别 — 一条搜索结果为何匹配

七种匹配：**标题（Title）**、**内容（Content）**、**标签（Tag）**、**维基链接（Wikilink）**、**属性（Property）**、**语义（Semantic）**（一种基于含义、而非精确词语的匹配），以及**结构化（Structured）**（一种属性查询匹配）。你在这里设置的颜色，会由编辑器内的搜索高亮、匹配徽章，以及搜索面板中结果行上的高亮共享。

### "按需统一" — 让这一切安全的规则

认知色彩遵循一条刻意设计的规则：**在你挑选一种颜色之前，什么都不会变。** 每个界面都把它今天的颜色保留为自己的回退值。一旦你在这里设置了某种状态的颜色，**每一个**显示该状态的界面都会立即对齐到你的颜色 — 文件树、选项卡、检视器、搜索高亮，等等。把"常青"设置一次，整个应用中的每一个常青标记便达成一致。让某种状态保持不动，它看起来就和之前一模一样。

这正是该类别可以在不改变任何现有外观的情况下交付的原因：它*按需*统一，从不默认统一。单击 **Keep（保留）** 即可为此宇宙保存你的颜色。

## 遍布全应用的右键菜单

Constellation 现在在你最常需要的三个地方为你提供完整的右键（上下文）菜单：**笔记正文**、**前置数据属性**，以及**搜索结果**。每个菜单只提供在你点击之处说得通的操作。

### 右键点击笔记正文

在一篇笔记的文字内的任意处右键点击，即可得到编辑菜单：

- **添加链接** / **添加外部链接** — 把选中内容包裹（或在光标处插入）为一个 `[[wikilink]]` 或一个 `[文字](url)` 链接。
- **格式 ▸** — 一个弹出子菜单：粗体、斜体、下划线、删除线、高亮、行内代码、数学、切换注释、上标、下标、清除格式。
- **段落 ▸** — 一个弹出菜单：项目符号列表、编号列表、任务列表，标题级别 **H1–H6** 和**正文**，以及块引用。
- **插入 ▸** — 一个弹出菜单：脚注、表格、标注框、水平分隔线、代码块、数学块、图像。
- **剪贴板** — 剪切、复制、粘贴、粘贴为纯文本、全选。
- **样式…** — 直接跳进聚焦于**编辑器**类别的**样式设计器**，让你为你刚刚右键点击的那个东西重新设计样式。

### 右键点击前置数据属性

在属性面板（或笔记顶部的属性区块）中右键点击某个属性**行**，你会在完整编辑菜单之上得到属性操作：

- **复制值** — 把该属性的值复制到剪贴板。
- **复制名称** — 复制该属性的键名。
- **移除属性** — 删除该属性行。
- **添加属性** — 添加一个新的空属性行。
- …接着是与笔记正文相同的**格式 / 段落 / 插入 / 剪贴板**各项，以及一个打开聚焦于**属性**类别的样式设计器的**样式…**项 — 因此在某个属性标签上的"样式…"设计的是属性标签的样式，而不是笔记正文。

### 右键点击搜索结果

在搜索面板中右键点击某个结果，得到一组**安全**的笔记操作 — 那些绝不会让你的文件陷入风险的操作：

- **打开** — 打开笔记。
- **在新选项卡中打开** — 在你已有内容旁边打开它。
- **在树中显示** — 在文件树中高亮该笔记，让你看到它身处何处。
- **复制链接** / **复制路径** — 复制指向该笔记的维基链接，或它的文件路径。
- **加入书签** — 把该笔记加入你的书签。
- **在资源管理器中显示** — 在你操作系统的文件管理器中显示该文件。
- **用默认应用打开** — 用你系统用于 Markdown 的任意应用打开该文件。
- **样式…** — 打开聚焦于**认知色彩**类别（搜索匹配颜色所在之处）的样式设计器。

> **按设计，搜索结果菜单没有重命名、移动或删除。** 搜索面板显示来自你整个宇宙各处的结果，且不保留它自己分秒同步的文件树副本，因此在那里做破坏性操作可能作用于一个过时的视图。Constellation 把那些操作保留在文件树（文件浏览器）中 — 那里的视图始终是最新的，重命名、移动和删除都在此进行；文件树还可以一次选中多篇笔记，用一条批量操作栏为它们统一加标签、移动或删除。搜索菜单是用来安全地*抵达*一篇笔记的，而不是用来重构你的资料库。

## 须知

- **本地且私密。** 这一切都是在你的设备上、从你自己的笔记和设置计算得出的。没有任何内容被发送到任何地方。
- **它会说你的语言。** 每一个菜单项、每一个类别名称、每一个状态标签，都会以你所选的界面语言显示，并为从右到左的语言正确地镜像。认知状态的颜色本身是通用的 — 一种颜色在每一种语言中都代表同一种状态。
- **"样式…"始终落在正确的界面上。** 每一个"样式…"入口都会打开聚焦于你右键点击之物所属类别的样式设计器：笔记正文 → **编辑器**，属性 → **属性**，搜索结果 → **认知色彩**。你永远不必去四处寻找正确的控件。
