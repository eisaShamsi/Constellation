# 分类器

> *「按知识类型与来源对每条笔记进行分类。」*

**分类器**是分类工作的宇宙级主页。它是一个从左侧停靠栏打开的全页视图,把你通过 Constellation 知识分类法阅读笔记所需的一切汇集到一处:一个扫描整个 Library 的控件、一种按需对任意单条笔记进行分类的方式、一个生成笔记摘要的按钮,以及一个实时审阅队列 — 你在其中对每条建议进行「接受」「编辑」「拒绝」或消歧。

如果你用过右侧边栏的 **Source Review** 面板,那你已经认识这些卡片了。分类器是同一个引擎、同样的卡片,只是从狭窄的边栏标签页升级出来,占据整个窗口 — 外加边栏标签页从未有过的两样东西:一个笔记选择器和一个「生成全部摘要」按钮。

---

## 「分类器」(房间) vs「分类器组件」(透镜) — 命名小贴士

英文里这两个名字 (The Cataloger / the catalogers) 故意长得很像,但它们指的是不同的东西:

- **分类器**(大写 *T* 的 The Cataloger,即本视图)是*场所* — 分类工作发生的全页房间。
- **分类器组件**(小写复数的 the catalogers)是引擎内部的*六个透镜* — frontmatter、引用、词干、链接的笔记、相似的笔记和 AI 判断 — 每一个都读取笔记并投票。六个中有五个今天已激活;第六个 (AI 判断) 已构建但尚未开启。

所以:你打开**分类器**(房间),而在其内部由**分类器组件**(六个透镜)来阅读。六透镜机制在 **Source Review** 主题中有完整说明 — 本主题讲的是那个房间。

---

## 这是什么

分类器回答一个问题:**「我宇宙中的每条笔记是如何分类的 — 还有哪些需要我来决定?」**

它围绕自上而下堆叠的四样东西构建:

1. **带三个操作的头部** — *分类笔记…*、*生成全部摘要* 和 *开始扫描*。
2. **进度条** — 仅在 Library 扫描运行时出现,显示进展到哪一步。
3. **审阅队列** — 与 Source Review 面板相同的接受 / 编辑 / 拒绝 / 消歧卡片,现在是全宽的。
4. **每张卡片下的笔记摘要** — 该笔记的简短平实语言概要,让你无需打开就能做出决定(见下文 *笔记摘要*,以及专门的 **Note Summaries** 主题)。

一切都在**你的设备上**运行。笔记从未离开 Constellation。

---

## 为什么重要

分类是 Constellation 把一堆 `.md` 文件变成*有形态*知识体的方式 — 每条笔记都放置在两个轴上(知识来自哪里,以及它是哪种知识)。这个形态正是为 **Constellation Sight**、**认知元数据**面板和分类法感知搜索提供动力的东西。

但分类是一项决策密集的工作。当你有数百条未分类的笔记时,从一个细窄的边栏标签页里做这件事 — 一次一条笔记,没法召唤特定笔记 — 是很慢的。分类器的存在就是为了让这项工作变得「可以坐下来做」:打开它一次,给它整个屏幕,在一次专注的会话中处理完你的 Library。笔记选择器让你按名称拉入任意笔记;摘要让你无需离开房间就能判断一张卡片;扫描控件批量为队列填充内容。

## 如何打开

1. 在**左侧停靠栏**(窗口最边缘的垂直图标条)中,点击**层叠卡片图标** — 三张小卡片层叠在一起。它位于其他工作区图标之间,例如 Sight 的眼睛和 Nervous System 的神经元。
2. 分类器以**全页视图**打开,接管内容区。
3. 关闭:点击头部右上角的 **(×)**,或按 **Esc**。你会回到原来的位置。

> **关于 Esc 的说明:** 如果 *分类笔记…* 搜索弹出框处于打开状态,按 **Esc** 仅关闭该弹出框,分类器保持打开。再按一次 **Esc**(弹出框已关闭时)才会关闭分类器本身。

## 你看到什么

### 头部 — 三个操作

在分类器顶部,三个控件并排排列:

| 控件 | 它做什么 |
|---|---|
| **分类笔记…** | 打开一个小搜索框。键入任意笔记标题的几个字母,从结果中选取它,引擎当场对它进行分类 — 无需先打开笔记。新建议出现在下方队列中。 |
| **生成全部摘要** | 为每条尚未拥有摘要的笔记预先计算一段简短摘要。在后台静默运行;进度显示在窗口底部的状态栏中;你可以随时取消。(详见 **Note Summaries** 主题。) |
| **开始扫描** | 一次性对你的**整个活动 Library** 运行引擎,为每条尚未分类的笔记排入一条建议。运行时,按钮显示 *Running…*,头部下方出现一个进度条。 |

### 进度条

紧接在头部下方,一个细条**仅在 Library 扫描运行时**出现。它显示已处理多少条笔记,让你看着扫描完成。没有扫描运行时,该条隐藏,队列就紧贴在头部下方。

### 审阅队列

分类器的主体是**审阅队列** — 与 Source Review 面板里所见相同的卡片,只是全宽。每张卡片显示一条笔记、引擎对该笔记如何融入你分类法的解读 (Source × 内容类型)、六个分类器小圆点,以及你可以采取的操作:

- **接受** — 将引擎的建议写入笔记并清除卡片。
- **编辑** — 自己从树中选取值。
- **拒绝** — 不写入任何内容即清除卡片。
- **消歧** — 在「意见分歧」的卡片上,从候选芯片中选取正确的值。

卡片的完整机制 — 彩色圆点、置信度体制、同级消歧、队列筛选芯片、「全部批准」以及每个 Library 的校准 — 记录在 **Source Review** 主题中。分类器就是嵌入了那个面板;卡片在边栏和全页视图之间没有任何变化。

### 每张卡片下的笔记摘要

每张卡片标题下方有一行简短的**摘要** — 几句话告诉你这条笔记讲的是什么,让你无需打开笔记就能判断卡片。这由**笔记摘要生成器 (NSC)** 产生;见下一节和 **Note Summaries** 主题。

## 对单条笔记进行分类 — 笔记选择器

*分类笔记…* 按钮解决了一个简单问题:在边栏标签页里,你只能对当前打开的那条笔记进行分类。分类器没有「打开的笔记」,所以它给你一种按名称召唤任意笔记的方式。

**要对一条笔记进行分类:**

1. 点击 **分类笔记…**。一个搜索框落下,带有占位提示 *搜索笔记…*。
2. 开始键入笔记的标题。短暂停顿后,匹配的笔记出现在列表中(最多十条)。
3. 点击你想要的笔记。引擎对它进行分类,弹出框关闭,该笔记的一张新卡片出现在下方队列中。
4. 如果出错(罕见的引擎错误),消息会出现在弹出框内,让你知道分类没有运行。

你不必打开笔记,也不会丢失你在队列中的位置。这是对你心中特定笔记进行分类的最快方式。

---

## 分类器内部的笔记摘要 (NSC)

队列中的每张卡片都带有其笔记的简短**摘要**,显示在标题下方。摘要由**笔记摘要生成器 (NSC)** 产生,并遵循一条铁律:**如果你写了摘要,引擎就用你的;只有在你没写时它才会生成一段。**

优先级顺序是:

1. **你的 frontmatter 摘要** — 笔记属性中的 `summary:`、`description:`、`abstract:` 或 `excerpt:` 字段。完全按你所写使用。
2. **你的摘要 callout** — 笔记正文中的 `> [!summary]`、`> [!abstract]` 或 `> [!tldr]` 块。完全按你所写使用,连同变音符号一并保留。
3. **生成的摘要** — 仅当上述两者你都没写时。Constellation 读取笔记,找出其最核心的句子,并按原始顺序显示前三句。

引擎**从不把生成的摘要写回你的笔记** — 你的 `.md` 文件才是真实来源,分类器只会*读取*它们。

**生成全部摘要**按钮在后台为整个 Library 预先计算摘要,这样卡片会立即显示其摘要,而不是在你滚动时才填入。完整细节 — 包括生成摘要是如何产生的,以及当摘要看起来有误时该怎么办 — 在 **Note Summaries** 主题中。

---

## 分类器*不*做什么

- **它默认不在后台自动分类。** 扫描是你*启动*的东西。(在设置 > 智能 > CECE 中有一个可选的后台模式,默认关闭 — 见 **Source Review**。)
- **它不调用任何云服务。** 五个激活的分类器组件都是启发式的、本地的。第六个透镜 (AI 判断,一个本地语言模型) 已纳入设计但尚未开启,所以今天它在每张卡片上都保持沉默。
- **它不改变你笔记的措辞。** 接受一张卡片写入的是分类*属性*(`sources:` 和 `content_type:` frontmatter 字段)。它从不编辑你的散文,也从不把生成的摘要写入文件。

## 常见工作流程

**「我刚第一次打开分类器 — 从哪里开始?」**
点击 **开始扫描**,为 Library 中每条未分类的笔记排入一条建议。看着进度条填满。然后处理队列,接受引擎判断正确的那些,并对「意见分歧」的那些进行消歧。每张卡片下的摘要让你能快速决定。

**「我想分类某条特定笔记,而不是整个 Library。」**
点击 **分类笔记…**,键入它的标题,点击它。一张卡片出现在队列中。接受或编辑它。

**「我的卡片要过一会儿才显示摘要。」**
点击一次 **生成全部摘要**。它在后台预先计算每条笔记的摘要(进度在状态栏中)。完成后,摘要会立即出现。

**「队列有数百张卡片 — 我该如何聚焦?」**
使用队列上方的筛选芯片(记录在 **Source Review** 中):先用 *分类器已达成一致* 和 *全部批准* 清除简单的,然后处理「意见分歧」的卡片。

## 相关主题

- **Source Review** — 卡片本身:六个分类器组件、彩色圆点、置信度体制、同级消歧、队列筛选器、「全部批准」以及每个 Library 的校准。分类器嵌入了这个面板。
- **Note Summaries** — 每张卡片下的摘要行是如何产生的、作者优先的优先级,以及 *生成全部摘要* 回填。
- **认知引擎** — 分类所属的更广泛的知识形成哲学。
- **认知元数据** — 分类写入的 `sources:` 和 `content_type:` 属性,以及如何阅读它们。
- **Constellation Sight** — 由 Source × 内容类型分类提供动力的空间视图。
