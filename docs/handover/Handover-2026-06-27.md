**Canonical rules this established (don't regress):**
1. Never put `COALESCE(col, expr)` in a WHERE on `note_meta` — it kills the index AND drags `body_text` through a scan. Resolve names via `idx_note_name_lower`.
2. Any multi-second derived-data command must be `#[tauri::command(async)]` and read via `read_db`/`with_read_conn` — never SYNC on the IPC thread holding the writer `db` lock.

**State of the Boss's DB:** `idx_note_name_lower` was created on the live DB during de-risk, so the Boss sees no one-time index-build cost on next boot. Other large existing DBs pay a ~21 s one-time build (same pattern as `idx_note_boot_snapshot`, `IF NOT EXISTS`).
