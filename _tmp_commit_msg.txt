MIG-077 A3-R1/R2: rich CONTEXTUAL right-click menu + apply to OrgChart

Boss steer after the thin-A3 gate: a one-command menu is useless; menus must be
rich AND contextual ("adapt to each type of function"). Re-scopes Phase A for the
note/folder/library surfaces (Plan ADDENDUM, 2026-06-14).

NEW contextMenuBuilder.ts — buildContextMenu(target, actions): one shared source,
contextual output by (object kind x surface capability). An item is emitted only
when its callback is provided AND fits the kind; group-based separators stay clean
no matter which items are present. Each surface passes the callbacks it can
fulfil — that IS the "contextual" mechanism. Reused later by the file tree,
List-mode, Search, Sky View.

NEW RenameDialog.svelte — small reusable rename dialog (RTL-aware via detectDir,
reuses actions.rename/dialogs.cancel, no new strings). Full-page surfaces have no
inline tree row, so they rename through this -> the host's existing
handleRenameComplete (rename + wikilink cascade + collision dialog all reused).

OrgChart now builds its menu via buildContextMenu and emits one onNodeMenuAction
(action, target) to +layout's handleOrgNodeMenuAction; every op reuses an existing
handler (openNoteTab / clipboard / suggestSources / confirmDelete / handleCreate* /
handleRenameComplete). Expand/Collapse stays OrgChart-local. libIdForPath =
longest-prefix library lookup (correct with nested libraries).

R2 menu — notes: Open, Open in new tab, Rename, Copy path, Copy name, Suggest
sources, Delete. Folders: New Note/Folder/Base, Expand/Collapse, Rename, Delete.
Libraries: New Note/Folder/Base, Expand/Collapse. (Move + Add tag = A3-R3/R4.)

Reveal-in-tree intentionally omitted: constellation:reveal-in-tree is dispatched
(editor breadcrumb) but has NO listener anywhere in src -> dead app-wide; shipping
it would be a dead item. Flagged separately for a real fix.

i18n x15: contextMenu.{openInNewTab,move,addTag} added natively (move =
tableToolbar.move verbatim; addTag = addProperty grammar with the native tag noun;
openInNewTab = standard localized phrasing).

svelte-check 0 errors / 315 warnings (baseline); npm run build + cargo build
--release green; bundle-confirmed (openInNewTab/addTag incl. Arabic + RenameDialog).
